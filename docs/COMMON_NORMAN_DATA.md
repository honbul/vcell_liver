The common Norman dataset is distinct from both paper reproduction tracks. The [original Norman study](https://doi.org/10.1126/science.aax4438) and [GEO experimental sample](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM3906026) describe K562. The GEARS processed archive used by both paper tracks has a constant `A549` value in `obs.cell_type`, with no batch or replicate column. C0 treats the input as Norman K562 by provenance and ignores that source label. It never interprets its cells as independent biological replicates. A sample check against the same file's counts layer confirmed `expm1(X)` is proportional to the counts within each cell. C0 preserves the author-provided X and does not read the counts layer or the author DE rankings during preparation.

The source contains 91,205 cells, 5,045 gene symbols, 7,353 control cells, and 283 treated labels. Sorting the target identities exposes 47 duplicate orderings among the source conditions. Those labels remain recorded but their cells are assigned together to one canonical intervention. The protocol excludes genes outside the scGPT checkpoint vocabulary and interventions missing any target. The data receipt produced by the preparation job enumerates split sizes and hashes; its server-side manifests preserve exact cell and gene IDs and excluded targets. The isolated `outcomes_test.npz` is reserved for the confirmation evaluator. The public benchmark and derived split are not a blind test.

Models use one shared evaluation control set. For fixed training pairs each treated cell is assigned one control, using a seed and the treated ID; data stage D will compare changing those IDs across epochs, and balance interventions at fixed training exposure. The response mean, additive, and linear controls fit only the training pairs. Additive is defined only where both single interventions occur in train; its restricted subset is scored separately for every eligible method. Common model tuning waits for the two paper-track statuses to be recorded.
