# R6 일시 정지와 재개 조건 (private plan 2026-11-20 §6.3)

## 1. 현재 상태 (정지 시점)
- 유지: O0/O1 관측량 비교 결과와 checkpoint(v2 `vcell_liver_r6_specificity_v2/assets/runs`, 동결 `087d700`)는 그대로 보존한다. O1은 N=16에서 전체 RMSE를 −0.21~−0.23% 줄였다(Holm 유의, 사전 실용 기준 0.5% 미만 → `improved_small`). pool 내 약물 대비는 개선되지 않았다. "오차가 23~33% 줄었다"(그 숫자는 N16 손실 가운데 O1이 없앤 몫이다)거나 "약물 고유 반응 예측이 해결됐다"고 쓰지 않는다.
- 반복성: R6-R `not_established`. v3에서 S5/S7 comparator를 정정한 뒤에도 같다(`RESULTS.md`).
- 결정: **모델 확장 보류.** 새 학습·새 분자 표현·set encoder·R6-E probe를 시작하지 않는다.

## 2. 재개하려면 필요한 자료 (약물 고유 반응 예측을 계속 핵심 목표로 둘 경우)
현재 자료로 판정할 수 없는 이유(관측): 배양 날짜·계대·batch·lot 기록이 없다. 0.5 µM에서 두 plate 이상에 있는 R6 TRAIN 약물은 21개, wrong-match가 가능한 주 집합은 17개·plate 쌍 3개이고, 모두 plate8을 포함한다. plate 간 "같은 약물"이 다른 catalog 화합물(염·입체이성질체)인 경우가 많다.

| 요구 | 내용 | 이유 |
|---|---|---|
| 동일 화합물·lot | 같은 catalog 화합물, 같은 lot(또는 lot 기록) | 이름 계열(identical/salt)만으로는 lot 동일성을 알 수 없다 |
| 독립 배양 | 다른 날짜 또는 다른 계대에서 배양한 반복. 날짜·계대·세포 stock을 기록 | 다른 plate만으로는 독립 배양을 식별할 수 없다 |
| 교차 plate 배치 | 한 약물이 최소 두 plate에 있고, plate 쌍마다 공통 약물 ≥4(겹치지 않는 wrong-match 쌍이 생기도록). 한 plate에 모든 쌍이 의존하지 않도록 plate 쌍을 분산 | 현재는 주 집합 전체가 plate8에 의존한다. plate11 하나를 빼면 효과가 사라진다 |
| 공통 anchor | plate마다 같은 anchor 약물 세트(강한 반응 양성 대조 포함, 예: 이번에 재현된 tirabrutinib·trametinib·crizotinib 계열과 약한 반응 약물) | plate 간 이동을 공통 기준으로 제거하기 위해 |
| 독립 vehicle | plate마다 DMSO well ≥2 | 대조군 기준을 반으로 나누지 않아도 되도록 |
| 반복 수를 따로 셈 | 생물학적 반복(독립 배양) 수와 기술 반복(같은 배양의 well·barcode 반쪽) 수를 따로 보고 | 기술 반복은 독립 생물학적 반복이 아니다 |
| 같은 용량·시간 계약 | 0.5 µM, 24 h(R6 계약). 다른 용량은 별도 질문 | 용량이 다르면 같은 반응을 반복한 것이 아니다 |

표본 수: 확정 수량을 제시하지 않는다. v2 §5의 "약물 약 270개" 외삽은 약물 단위 분산이 같다고 가정한 거친 가설 수준의 계산이다. 반응이 소수 약물에 몰려 있어 설계 근거로 쓸 수 없다. 실제 설계 전에 pilot 반복 자료로 약물 단위 분산과 독립 배양 간 분산을 다시 재야 한다.

## 3. 이미 접근 가능한 후보 (목록만; 추출·비교 실험은 하지 않음)
상세: `candidate_repeat_data_inventory.tsv`. 확인 수준은 metadata와 디렉터리 목록뿐이다.

| 후보 | 결론 |
|---|---|
| Tahoe-100M 0.5 µM cross-plate (이미 사용) | 독립 배양 정보가 없다. v2/v3에서 쓴 자료가 전부다 |
| Tahoe-100M 5 µM cross-plate (base 이름 109개 약물이 두 plate 이상) | 용량이 다르고 같은 연구이며 배양 정보가 없다. R6 반복 질문의 적격 자료가 아니다. 별도의 cross-plate 기술 질문 후보일 수는 있다(well 배열 미추출, split 구분 미확인) |
| Tahoe-100M 0.05 µM cross-plate (38개) | 용량이 다르고 배양 정보가 없다. 적격하지 않다 |
| Sci-Plex3 (R10 자산; A549·MCF-7은 Tahoe에도 있음; 화합물 이름 21개 겹침) | 연구·플랫폼이 다르고, 500 nM이 없으며, lot·독립 배양 기록이 없다. 같은 화합물·lot 독립 반복이 아니다. 기껏해야 교차 연구 일관성이라는 새 질문이다 |
| LINCS L1000, TG-GATEs, scPerturb(유전 섭동) | 측정법·계통·섭동 종류가 다르다. 적격하지 않다 |

**결론: R6 반복성 질문에 적격한 독립 반복 자료는 지금 서버에 없다 → 자료 대기.** 새 자료를 확보하려면 외부 자료 신청, 협력 또는 wet-lab 실험이 필요하다. 이번 사이클에서는 자동으로 진행하지 않는다(plan §0, §6.3).

## 4. 재개 순서 (자료가 생기면 제안할 순서; 자동 실행 아님)
1. 새 자료의 적격성 표(위 요구 항목)를 만들고, 반복 대비 주 대비(P1/P2와 comparator 정의, v3 방식으로 query와 후보에 같은 규칙)를 응답을 읽기 전에 동결한다.
2. 반복성이 확인되면, 그때 구조 표현 probe(R6-E)를 열지를 사용자가 결정한다. 확인되지 않으면 R6 모델 연구는 종료를 권한다.
3. 낮은 비용의 새 표현 가설 실험은 제안할 수는 있다. 하지만 이 문서와 plan은 그 실행을 승인하지 않는다.
