## 2. 말할 수 없는 것

- **"학습한 metric이 HCC에서 kernel보다 낫다"** — 구분되지 않았다. source에서만 0.0023 나았다(계획서 §12의 "source만 개선" 행).
- **"상태 보존이 쓸모없다" / "관측 가중은 해롭다"는 일반 명제** — 시험한 것은 FiLM 한 가지 구조, 공분산 모형 한 가지(와 그 변형 하나)다. 다른 구조·다른 자료에 대해서는 말하지 않는다.
- **"공통 보정이 세포주의 생물학적 차이를 잡는다"** — source 검사에서는 같은 plate 안에서만 뚜렷했다. 측정 환경(대조군·배치)을 맞힌 것과 구별하지 못한다.
- **"HCC에서 독립 plate로 재현됐다"** — JHH7은 검출 plate 1장이고, HUH7은 한 화합물 plate의 X 반복 3장이다. 독립 plate 평가는 하지 못했다.
- **"B10v2/B11v2(개정 arm)가 낫다"** — HCC 동등 평균에서 −0.0005, −0.0008로 구간이 0 아래지만 대부분 HUH7 한 계열에서 오고, source 확인에서는 구분되지 않았으며, 15개 변형 중 dev에서 고른 뒤 덧붙인 arm이다.
- **계열별 방향(예: 공분산 가중이 HUH7에서 낫고 JHH7에서 나쁨)을 근거로 한 선택** — 사후 소집단 선택이다. 관찰로만 적는다.
- **"처음 보는 시험 결과다"** — HCC 자료와 이 test 분할은 연구 B와 R2에서 이미 채점됐다(`EXPOSURE.md`).
- **약물 효과의 크기를 맞힌다는 주장** — 예측의 RMS는 정답의 1/3–1/2이다.
- **978 유전자 밖, 다른 용량·시간, 단일세포, 환자 조직에 대한 주장.**

## 3. 한계

| 한계 | 영향 |
|---|---|
| HCC 계열 3개, HUH7 test query 14개/분할, JHH7 22개 | 계열별 구간이 넓다. 세 계열 평균은 기술적 요약이지 모집단 추정이 아니다 |
| 약물별 효과의 크기가 0.001–0.01 수준 | 모델 seed 간 범위(HUH7 0.004)와 같은 크기다. 방향은 일관되지만 실용적 의미는 작다 |
| 같은 plate / 다른 plate 검사가 X 반복 plate 쌍에만 가능 | 다른 날짜·다른 화합물 plate로의 전이는 알 수 없다. 조건을 만족한 쌍 중 서로 다른 화합물 plate는 0개였다 |
| X 반복이 독립 배양인지 공개 자료에 없음 | "반복 plate" 결과를 생물학적 반복으로 읽을 수 없다 |
| unit 신호 분산 v_r이 바닥값으로 추정됨 | 공분산 모형의 상수가 추정이 아니라 규칙(전체의 5%)에서 왔다. 개정 R-2는 이 값을 키워 본 것이다 |
| XC 혼합 pool 제외 | 포함했을 때의 결과는 모른다. R2·연구 B의 수치와 직접 비교할 수 없다(source 구성이 다르다) |
| TranSiGen 미세조정 설정을 확인 family에서 고름(R2 규칙) | TranSiGen에 유리한 조건이다. 그래도 C0보다 높았다 |
| 선택 지표가 K=16 ΔRMSE 하나 | 다른 지표(retrieval, 방향 일치)로 고르면 순위가 달라질 수 있다 |
| 개정 2회 사용 | 교차검증 자료를 두 번 더 본 셈이다. 주 2×2 arm은 개정 전에 고정한 것 그대로다 |
| 예측 구간·coverage 미구현 | 불확실성에 대한 주장은 없다 |

## 5. 다음 결정 (사용자 판단 필요, 하나)

이 벤치마크에서 방법 개발을 멈추고 C1을 고정 기준선으로 채택할지, 아니면 공통 보정의 plate 간 전이를 가릴 독립 plate 복제 HCC 자료를 먼저 확보할지. 이 연구는 음성 결과로 끝났고 자동으로 이어 갈 확장은 없다.
