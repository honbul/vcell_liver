# 연구 R8 — 쉬운 설명 (BEGINNER_SUMMARY)

**작성일:** 2026-11-17 · 수식 없이 읽을 수 있게 썼다. 숫자의 출처는 `RESULTS.md`에 있다.

## 1. 무엇을 알고 싶었나

간암 세포주 하나를 새로 받았다고 하자. 약물을 넣으면 유전자 978개의 활동(RNA 양)이 어떻게 바뀌는지 알고 싶다. 약물은 수백 가지인데 실험할 수 있는 것은 **16개**뿐이다. 16개의 실험 결과를 보고 나머지 약물의 결과를 맞히는 것이 과제다.

앞선 연구(R2)에서 "16개 결과의 평균적인 어긋남을 조금만 믿고 모든 약물에 똑같이 더해 주는" 아주 단순한 방법이 복잡한 방법만큼 잘 맞았다. 이번 연구는 그 위에 세 가지를 물었다.

1. 모든 약물에 똑같이 더하는 **공통 보정** 말고, 약물마다 다르게 고쳐 주는 **약물별 보정**이 정말 도움이 되는가?
2. 실험 결과마다 믿을 만한 정도가 다르다(여러 번 반복한 것, 같은 판에서 같이 잰 것). 이것을 계산에 넣으면 나아지는가?
3. 약물을 넣기 전 세포의 상태를 모델이 잊지 않게 해 주면 나아지는가?

## 2. 비유

새 동네 식당들의 맛을 예측한다고 하자. 다른 동네에 같은 체인점이 있어서 "이 체인은 보통 4점"이라는 것은 안다. 새 동네에서는 16곳만 가 볼 수 있다.

| 이 연구에서의 이름 | 비유 |
|---|---|
| 같은 약물 평균 | 다른 동네 지점들의 평균 평점을 그대로 쓴다 |
| 축소 평균 | 지점이 몇 개 없는 체인의 평균은 덜 믿고 "보통" 쪽으로 당긴다 |
| 공통 보정 (C0) | 가 본 16곳이 예상보다 평균 0.3점 낮았다 → 절반쯤만 믿고 모든 식당을 0.15점 깎는다 |
| 약물별 보정, 계산식 (C1) | 가 본 곳 중 **닮은 식당**이 예상과 얼마나 달랐는지를 그 식당에 더 반영한다. "닮았다"의 기준은 사람이 미리 정한다 |
| 약물별 보정, 학습 (B00) | "닮았다"의 기준을 다른 동네들의 자료로 컴퓨터가 배운다 |
| 관측 가중 (B10) | 세 번 가 본 식당의 평가를 한 번 가 본 식당보다 더 믿고, 같은 날 같이 간 식당들의 평가는 한 묶음으로 본다 |
| 상태 보존 (B01) | 그 동네의 전반적인 분위기(약물을 넣기 전 세포 상태)를 "닮음"을 판단할 때 같이 본다 |

## 3. 어떻게 공정하게 비교했나

- 모든 방법이 **똑같은 16개 약물**의 결과만 보고, **똑같은 나머지 약물**을 맞힌다.
- 맞히려는 약물의 실험 결과는 어떤 방법도 미리 보지 않는다.
- 방법의 세부 설정은 전부 간암이 아닌 다른 세포주들(115개 계열)에서만 정했다. 간암 세포주 세 개(HUH7, JHH5, JHH7)의 자료는 설정을 다 정해 못 박은 뒤에 딱 한 번 열었다.
- 다만 이 간암 자료는 앞선 연구들에서 이미 채점에 쓴 적이 있다. 완전히 처음 보는 시험은 아니다.
- 방법을 고칠 기회는 두 번으로 제한했고, 고치기 전에 "왜, 무엇을, 어떻게 판정할지"를 먼저 적었다. 두 번 다 썼다.

## 4. 결과 (약물 16개, 세 간암 세포주 평균, 오차는 낮을수록 좋다)

| 방법 | 오차 |
|---|---:|
| 아무 변화도 없다고 본다 | 0.663 |
| 다른 세포주의 같은 약물 평균 | 0.640 |
| 그 평균을 덜 믿고 줄인다 | 0.616 |
| + 공통 보정 (C0) | 0.595 |
| + 약물별 보정, 계산식 (C1) | 0.590 |
| + 약물별 보정, 학습 (B00) | 0.590 |
| + 상태 보존 / + 관측 가중 / + 둘 다 | 0.590 / 0.591 / 0.590 |
| 공개 딥러닝 모델(TranSiGen)을 16개로 미세조정 | 0.614 |

읽는 법:

- **가장 큰 개선은 아주 단순한 세 단계에서 왔다.** 평균을 쓰고, 그 평균을 덜 믿고, 16개의 평균적인 어긋남을 조금 더한다. 전체 개선의 93%다.
- **약물별 보정은 작지만 실제로 있었다.** 0.595 → 0.590. 세 세포주 모두 같은 방향이었고, 16개의 결과를 약물끼리 뒤섞어 주면 이 이득이 사라졌다.
- **"닮음"을 학습할 필요는 없었다.** 사람이 정한 계산식(C1)과 학습한 모델(B00)이 간암 세포주에서 구분되지 않았다. 다른 세포주들에서는 학습한 쪽이 아주 조금 나았지만 간암에서는 그 차이가 재현되지 않았다.
- **이번에 새로 제안한 두 가지(관측 가중, 상태 보존)는 도움이 되지 않았다.**
- 공개 딥러닝 모델을 16개로 미세조정한 것보다는 단순한 방법들이 나았다(세 세포주 중 한 곳에서는 비슷했다).

## 5. 조심해서 읽어야 할 점

**공통 보정은 "세포주의 특성"이 아니라 "그날 그 실험판의 특성"을 맞힌 것일 수 있다.**

다른 세포주들에서 따로 확인해 보았다. 같은 약물들을 실험판 두 장에서 각각 잰 자료가 있을 때,

- 맞히려는 약물과 **같은 판**에서 잰 16개로 공통 보정을 하면 오차가 0.029 줄었다.
- **다른 판**(같은 실험의 반복판)에서 잰 16개로 하면 0.002밖에 줄지 않았고, 0과 구분되지 않았다.

같은 판 안의 측정들은 같은 대조군(약물을 넣지 않은 well)과 비교한 값이다. 그 대조군이 조금 높거나 낮게 나오면 그 판의 모든 약물이 같은 방향으로 밀린다. 공통 보정은 이 밀림을 맞히는 데 능하다. 약물별 보정은 판이 달라도 비슷하게 작동했다.

간암 세포주 중 JHH7은 실험판이 한 장뿐이다. 그래서 이 세포주의 결과가 "다른 날 다시 실험해도 맞는다"는 뜻인지는 **확인할 수 없다.**

그 밖에:

- 간암 세포주는 세 개뿐이고, 그중 둘은 맞힐 약물이 14–22개라 숫자의 흔들림이 크다.
- 모든 방법이 "덜 틀리려고" 변화의 크기를 실제보다 훨씬 작게 예측한다. 오차가 낮다고 해서 약물 효과의 크기를 맞혔다는 뜻은 아니다.
- 유전자 978개, 한 가지 농도, 한 가지 시간에서의 결과다.

## 6. 결론

- 새로 제안한 적응 방법(관측 가중 + 상태 보존)은 **채택하지 않는다.**
- 지금 가장 쓸 만한 것은 학습이 필요 없는 세 단계다: **평균을 줄여 쓰고 → 공통 보정을 줄여 더하고 → 닮은 약물의 어긋남을 계산식으로 빌려 온다(C1).**
- 다음에 정할 것은 하나다. 이 벤치마크에서 방법 개발을 멈추고 C1을 기준선으로 삼을지, 아니면 "공통 보정이 실험판이 달라도 통하는가"를 가릴 수 있는 자료(같은 약물을 다른 날·다른 판에서 다시 잰 간암 자료)를 먼저 구할지.
