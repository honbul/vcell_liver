# R16 사전 명세 실행 기록

- 내부 후보 배열의 첫 실행 `29718`에서 안쪽 위치 배열 변수를 최종 적합 배열로 덮어써 차원이 맞지 않았다. 별개 변수로 보관하여 출력 전에 실패한 배열을 `29824`로 교체했다. 판정·데이터·선택 절차는 동일하다.
- GPU로 R15 안쪽 적합을 복원한 결과, XPert의 일부 epoch 우승자가 원 영수증과 일치하지 않았다. 공정 비교의 정의대로 원 영수증의 epoch를 유지하고, 재적합한 그 epoch의 안쪽 검증 예측만 배율 선택에 쓴다. 재현 우승자도 기록한다. 기존 기록과 일치한 배열은 보존한다. 이 조정은 R16 외부 fold 채점 전에 확정했다.
- 공정 비교를 대조하는 과정에서 R15 FiLM·concat의 안쪽 검증 호출이 epoch별 유전자 예측 대신 R12의 중심화 RMSE 스칼라를 반환하는 것을 확인했다. 이 결함은 R15의 FiLM·concat epoch 선택 기록에 영향을 주며, R15 외부 예측 배열에는 그 epoch로 최종 적합한 유전자별 예측이 들어 있다. 원 R15 기록과 판정은 보존한다. R16 최초 개발 점수는 이 호출을 배율·결합에 재사용했으므로 폐기하고 별도 원장에 남긴다. 최종 R16은 R15에 기록된 FiLM·concat 설정을 고정한 채 해당 epoch의 안쪽 유전자 예측을 다시 계산해 배율을 고른다. CMap 확인은 같은 격자의 실제 유전자 예측으로 안쪽 설정을 선택한다. 선택 예측의 행과 유전자 차원을 검증한다. 후보, 격자, 데이터, 기준은 유지했다. CMap의 첫 채점 전에 영향받은 예측만 교체했다.
