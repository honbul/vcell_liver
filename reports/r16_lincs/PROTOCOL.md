# R16 HEPG2 6 h 공정 비교와 결합 모델 명세

R15의 동결 및 판정은 그대로 둔다. GSE92742 HEPG2 6 h·5–20 µM R15 주 범위, 동일한 canonical parent 외부 3-fold, 안쪽 5분할의 검증 fold, 역할별 DMSO, 978 landmark와 행을 사용한다. 이 범위는 이미 공개 채점한 개발 fold다. 1번은 사후 보강이며 2번 결합도 같은 외부 fold를 두 번째로 본다. 탐색 diag16은 후보 동기이며 선택 입력이나 채점 예측으로 쓰지 않는다.

## 1. 공정 비교

R15 기존 VC 7종 원 외부 예측은 동결 배열 그대로 사용한다. 전 모델의 R15 inner validation을 새로 적합하고 기존 설정 선택을 동일 손실과 정렬 순서대로 재현한다. 재현한 하이퍼파라미터는 원 예측 영수증과 대조한다. 기존 설정을 고정한 뒤 공유 anchor를 제외한 출력에만 0/.125/.25/.5/.75/1을 적용하고 안쪽 검증 손실로 배율을 고른다. A anchor는 R15의 위치 성분, B는 위치+배율 1의 B_cell이다. 별도로 B_cell 단독 예측에 동일 격자로 배율을 고른다. 선택 손실은 R15와 동일한 0.5×parent 균등 RMSE/B0_RMSE + 0.5×SSE/SST, 9자리 반올림 뒤 설정 사전순 동률 해소다. 외부 fold 정답은 배율 선택에 사용하지 않는다.

R15 대 배율을 준 최선 7개 전체, 최선 출판 모델(chemCPA, TranSiGen, XPert, PRnet), 최선 내부 기준(ChemBERTa Ridge, FiLM, concat)을 각각 비교한다. B에서는 독립적으로 B_cell×g도 비교한다. R15 사전 판정을 재판정하지 않는다.

## 2. 사전 고정 결합

후보는 선정한 R15 추정과 FiLM의 결합, concat의 결합 두 개다. R15 추정은 원 R15의 최종 배율을 곱하기 전 잔차이며 같은 검증으로 재현한 선택 후보의 잔차다. FiLM과 concat도 원 설정의 배율 전 출력이다. A는 원 위치 anchor, B는 원 위치 + 1번에서 고른 B_cell×g를 anchor로 쓴다. B에서 원 모델들의 학습 잔차를 만들 때 R15 계약에 따라 배율 1의 공통 입력을 유지한다. 결합 시 각 모델의 공통 anchor를 한 번 제거한 잔차를 새 anchor에 더한다. 다음 식에서 a,b는 독립적으로 동일 격자를 검증 손실로 고른다.

```
prediction = anchor + a * R15_residual + b * neural_residual
```

FiLM 결합이 주 후보, concat 결합은 보조 후보다. 둘의 외부 성적으로 우승자를 재선택하지 않는다. 각 후보 대 B0, B_pos, 배율을 준 지표별 최선 기존 VC, 최선 출판, 최선 내부, R15, 그리고 B에서 B_cell×g를 비교한다.

## 공통 기준

행별 RMSE를 parent 안에서 균등 평균하고 parent를 균등 평균한다. 에너지 가중 설명 분산 R²는 1−ΣSSE/ΣSST다. 같은 10,000회 parent 짝 재표집과 양측 99% 구간을 사용하고 매 재표집에 지표별 최선 기존 VC를 다시 구한다. 쌍마다 ΔRMSE 상한 < 0 및 ΔR² 하한 > 0일 때 통과다. 결합의 종합 통과는 해당 시나리오의 모든 지정 주 비교에서 두 기준 충족이다.

반복 측정에서는 품질 통과 동일 parent·정확한 용량·시간·세포주 중 서로 다른 RNA plate donor만 사용한다. 각 query에 대해 다른 plate의 같은 parent를 plate별 평균 후 균등 평균하여 예측한다. donor에는 적합 역할 DMSO, query에는 반대 역할 DMSO를 적용한다. 모든 query plate·역할을 사용한다. 같은 위치 donor를 제외한 반복값도 진단에 제공한다. 모형+B0는 동일 반복 지원 행으로 제한한다. RMSE 기준 도달률은 (B0−모형)/(B0−반복), R² 기준은 (모형−B0)/(반복−B0)이며 양의 반복 이득일 때만 보고한다. 반복값은 같은 화합물의 쌍이므로 미관측 화합물 모델과 구별해 해석한다.

1·2번 예측과 비교 입력을 한 번 동결한 뒤 각 번호를 별개 작업에서 채점한다. 반복 분석은 채점 단계에서 생성하며 모델 선택에 사용하지 않는다. 확인 자료는 별도 감사 뒤 이 결합 절차를 고정한 준비 계약을 추가한다. 확인 학습 가중치를 새로 적합하고 Tahoe를 재평가하지 않는다. 봉인·격리·예약 코호트는 제외한다. GPU 배열은 동시 8개 이하로 고정한다.
