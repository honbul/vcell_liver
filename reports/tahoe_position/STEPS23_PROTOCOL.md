# Tahoe 위치 검증 후속 2·3단계 공동 명세

R13 0.5 µM·24시간의 203개 화합물군 3-fold, 물리 처리 웰, 세포주 행, 반대 DMSO 역할, 고정된 예측을 재사용한다. 동결 예측을 재학습하거나 후보를 추가하지 않는다. 아래 위치 nuisance만 각 평가 fold에서 배제한 학습군으로 추정한다. Tahoe와 Sci-Plex3는 프로젝트에 노출된 자료의 후속 진단이다. 공개 바코드 위치 인덱스를 사용한다. [1단계 결과](RESULTS.md)

## 2단계 평가 대상

| 항목 | 사전 지정 계약 |
|---|---|
| a 위치 보정 | 같은 0.5 µM에서 다른 plate의 동일 바코드 위치·세포주인 적합 화합물의 pool 중심화 발현을 plate 균등 평균한다. 동일 화합물군의 모든 웰·용량은 donor 제외다. 내부 두 fold에서 각자의 적합 유전자 패널로 배율 0–1을 **0.125 간격**으로 비교하고 등점이면 작은 배율을 쓴다. 식은 `center(y − P)`이며 `P`는 배율을 곱한 nuisance다. donor가 없는 행은 P=0으로 유지하고 지원을 보고한다. B0는 0, B_pos는 P, 과거 모델은 원 동결 델타를 그대로 적용한다. 보정된 정답에서 B_pos는 잔여 위치 연관성을 보는 대조다. |
| b 세포 수 | R13 원 대상에 최소 50·100·200·500세포를 각각 적용해 pool을 다시 만들고 고유 3군 이상을 유지한다. 별도 전 행 가중 분석은 원래 행 가중치×세포 수를 화합물군 안에서 정규화해 군 간 동등 가중을 유지한다. 이 모드의 pool 중심 가중치는 원래 중심 가중치×세포 수로 정한다. |
| c 유전자 패널 | Tahoe와 동일한 Ensembl GRCh38 release 109의 `protein_coding` 유전자만 남기고 `MT-` 기호·미토콘드리아 염색체를 제외한다. 가변도 상위 2,000개는 각 적합 fold 안에서 다시 뽑는다. B0·B_pos는 새 전체 패널, 과거 예측은 새 패널과 해당 동결 패널의 교집합에서 대응 B0·B_pos와 비교하며 정확한 유전자 수를 표기한다. |
| d 반응 강도 | R3와 같이 관측 F4 플래그를 원본 약물×용량×세포주 조건 단위로 복원한다. 하나 이상의 웰이 실제 DMSO well 쌍 최대값을 넘어 검출된 조건을 detectable, 그 두 배를 넘은 조건을 strong으로 둔다. F4가 측정한 SNU-423·HepG2/C3A에서 weak, detectable(강함 제외), strong을 표기한다. 나머지는 unlabeled다. 패널과 예측을 고른 뒤 평가 층화에만 사용한다. 층화에서는 부모 pool로 중심화하고 행 집계만 층 내부에서 정규화한다. |
| e 결합 | `center(y−P)`를 코딩 2,000 유전자에서 계산한다. 최소 200세포를 적용하고 b의 세포 수 가중을 쓰며, d의 층화로 보고한다. 동일 결합 대상의 전체 적격행도 보고한다. c와 같이 전체 패널 기준선과 과거 동결 예측 교집합을 구분한다. |

원 패널과 재선정 패널 각각에서 nuisance를 적합한다. 모든 대상에서 B0, B_pos, R12 통합 선택기·C2·C3·L1(smooth RMSE), R13 선택기·커널·표적/작용기전의 가능한 동결 파일을 확인하고 같은 행, 같은 유전자에서 비교한다. 예측 seed별 RMSE를 계산한 뒤 평균한다. 원 대상, a, d 및 e의 전체·교집합에서는 R13과 같이 seed 130113, 10,000회 양수 화합물군 재표집으로 pool을 다시 중심화해 95% 대응 구간을 계산한다. b·c 단독은 사전 지정한 기술 점추정과 표본 수로 보고한다. 결과는 원 scale 내에서 비교한다. ## 3단계 재현성 및 판정

**f. 제곱평균.** 각 대상의 가중화된 유전자당 제곱평균을 쓴다. 순서는 위치 nuisance 제거와 남은 같은 물리 웰의 세포주 간 가중 평균 제거다. 각 단계 전후 제곱평균 차이와 남은 제곱평균을 더하면 원 제곱평균이 된다. 결합 행·패널에서 위치 보정 전 총량과 보정 뒤 남은 총량을 함께 기록한다. 차이는 교차항을 포함할 수 있다. 웰 공유 성분에 공통 생물학적 변화가 포함될 수 있다. 기술 반분할의 표본 잡음은 R6의 이용 가능한 동일 웰 A/B에서 중심화 반차의 제곱평균으로 추정하고, 원·결합의 행 및 유전자 교집합을 보고한다. R6 캐시가 다른 정규화이면 그 측정값을 별도의 기술 대리치로 보고하고 R13 정확 분해의 나머지에서 임의 차감하지 않는다.

**g. 위치가 다른 반복.** 같은 화합물군·세포주이면서 바코드 위치와 물리 plate가 다른 쌍을 사용한다. 결합 규칙에서 0.05·0.5·5 µM의 동일 용량을 따로 보고하고, 0.5 µM를 대상으로 한 다른 용량의 비교도 별도 표기한다. 보조 용량의 중심은 해당 평가 fold 내 용량·plate pool에서 계산한다. 위치 보정은 동일 fold에서 동결한 0.5 µM nuisance와 배율을 적용한다. 동일 용량 쌍은 양방향으로 보며 target별 다른 plate의 대응 donor 평균을 사용한다. 똑같은 query pool과 행에서 0과 donor×0.25를 비교한다. donor×1과 방향 코사인도 기술 지표로 낸다. 합산 및 weak·detectable·strong은 평가 행만 해당 층으로 집계한다. 화합물군 10,000회 재표집 95% 구간은 고정한 부모 pool 중심과 반복 매칭에 조건부다. 약한 반응이나 희소 반복에서 그룹 수를 명시한다.

**h. Sci-Plex3.** A549·K562·MCF7의 24시간 및 0.01·0.1·1·10 µM에 대해 같은 화합물·세포주·용량의 rep1/rep2를 서로 다른 plate에서 맞춘다. 각각 QC 세포 20개 이상과 해당 plate의 유효 vehicle 웰 두 개 이상을 사용한다. 패널은 세포주별 vehicle 가변도 2,000개다. 웰 합산 log1p CP10k와 같은 plate vehicle 평균차를 계산한다. 같은 세포주·용량 내 공통 맞춤 약물에서 각 반응을 중심화하고 양방향으로 B0와 donor×1을 비교한다. 가능하면 고정 donor×0.25를 기술 비교한다. 계열 균등 합산과 계열별 결과, 10,000회 화합물 재표집의 방향 및 RMSE 차이 95% 구간을 보고한다. 한 화합물의 두 방향과 모든 세포주를 함께 재표집한다. 이 결과는 Tahoe 판정식을 대신하지 않는다.

**i. 고정 판정.** 상대 감소는 `100 × (B0−donor×0.25 RMSE)/B0`다. 동일 용량, 다른 위치·plate인 대응군이 **10개 이상**이고 상대 감소 **양측 95% 구간 하한이 +1.00%보다 크면** 해당 조건이 통과한다. 1%는 프로젝트 R6의 운영상 효과 크기 기준이다. 아래 순서대로 처음 충족되는 하나를 선택한다.

1. 결합 대상 전체 0.5 µM가 통과하면 **0.5 µM 전체 화합물 대비 과제 유지**.
2. 전체가 미통과이고 결합 대상의 0.5 µM strong 또는 5 µM 전체가 통과하면 **통과 범위로 축소**. 둘 다 통과하면 0.5 µM strong을 먼저 선택한다.
3. 두 단계가 미통과이고, 0.5 µM 결합 대상에서 다른 plate·다른 화합물의 같은 공개 fine MoA가 불일치 MoA보다 높은 관측 코사인을 갖는 짝 순위 AUC의 95% 하한 >0.55이고 평가 anchor 화합물군이 10개 이상이면 **MoA 수준 검색을 다음 과제로 선택**한다. 이 계산은 후보 선택용 회귀 학습을 포함하지 않는다.
4. 해당 지지가 없으면 **다른 위치에서 독립 반복을 확보할 수 있는 자료로 이동**한다. 지원 부족과 효과 부족은 결과에서 구분한다.
