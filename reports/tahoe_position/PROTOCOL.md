# Tahoe의 위치 인덱스 단독 예측 검증

R12·R13에서 이미 노출된 Tahoe 네 plate의 동결 화합물군 분할을 사용한다. 0.5 µM·24시간의 동일한 물리 웰·세포주 행, fold별 2,000 유전자 패널, pool 중심화, 화합물군 가중치와 DMSO A/B 반대 역할을 재사용한다. 공개 메타데이터의 1차 바코드 번호를 기본 위치 인덱스로 사용한다. `smp_` 순위의 전체 일치를 독립 메타데이터 검사로 확인했다. 약물 처리 plate의 A1–H12로 이어지는 공개 배치표가 확인되기 전에는 결과의 범위를 바코드 위치 인덱스 효과로 제한한다. [Tahoe 메타데이터](https://huggingface.co/datasets/tahoebio/Tahoe-100M) · [Tahoe 실험 방법](https://www.sciencedirect.com/science/article/pii/S0092867426010081) · [Parse 1차 바코딩](https://www.parsebiosciences.com/technology/)

## 사전 지정 비교

- B0는 약물 대비 0이다. `B_pos`는 **같은 0.5 µM·24시간** 조건에서, 같은 세포주·위치 인덱스의 다른 plate에 있는 학습 웰들의 pool 중심화 발현 벡터를 plate 균등 평균한다. 다른 용량의 발현은 예측에 제공하지 않는다. 평가 화합물군과 평가 물리 웰은 각 fold의 모든 적합에서 제외한다. 지원이 없는 행에는 0을 예측하고 점수 분모에는 포함한다.
- 각 외부 fold의 내부 두 fold에서 같은 대비 RMSE를 최소화하는 배율을 `[0, 0.25, 0.5, 0.75, 1]` 중 선택한다. 내부 패널도 해당 내부 학습행으로 다시 뽑는다. 동률이면 작은 배율을 사용한다. pool 공통 DMSO는 대비 중심화에서 상쇄된다. 따라서 예측은 A/B에서 공유하고 각각의 반대 물리 DMSO로 채점한다.
- 위치 순열 대조는 seed 41·42·43으로 각 plate 안에서 물리 웰의 위치 라벨을 섞는다. 같은 물리 웰의 모든 세포주 행은 함께 이동한다. 각 순열에 같은 적합·배율 선택 규칙을 사용한다.
- **판정 기준은 `B_pos − B0`의 사전 지정 양측 99% 구간 상한이 0보다 작을 때 개선 확인**이다. R13의 seed 130113으로 10,000회 양수 화합물군 가중 재표집을 하고 매 회 pool을 다시 중심화한다. 세 순열은 95% 구간 및 점추정으로 비교한다. 사전에 공개된 B0 0.0927918471289385와의 일치 허용 오차는 0.00000002이다.

## 별도 진단

동결 후 같은 화합물군·세포주이며 plate와 위치가 모두 다른 반응의 방향과 B0 대비 RMSE를 계산한다. 동일 0.5 µM와 보조 0.05·5 µM를 구분한다. 관측 반응을 입력으로 쓰는 재현성 진단으로 표본 지지 범위만 보고한다. 또 네 plate에서 DMSO A−B 벡터의 plate 쌍별 코사인을 같은 세포주로 맞춰 계산한다. 그 방향과 위치 인덱스를 기록한다. 이 두 진단은 후보 선택 및 공식 판정에 사용하지 않는다.

예측과 배율, 행, 패널을 G1의 별도 연구 디렉터리에서 해시로 동결한 뒤 채점을 시작한다. 이 문서는 평가 대상을 변경하거나 새로운 외부 자료 학습을 시작하기 전의 검증만 명세한다.
