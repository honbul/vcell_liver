# R18 승인 실행

사용자가 R18의 C1–C3 예약 발현 접근과 1회 동결·채점을 승인했다. 대상과 모델의 범위는 이미 등록된 108개 조합, 역할별 접근 명부 및 고정 명세를 따른다. [고정 명세](R18_CONFIRMATION_PROTOCOL.md) · [접근 명부 영수증](data/preflight/r18/access/receipt.json)

G1의 `r18-confirm-c1-c3`에 실행 Git 스냅샷과 작업 원장을 보관한다. 같은 실행명으로 중복 제출을 차단한다. CPU 예측과 네 GPU 비교군을 독립 실행한 뒤 병합·동결·채점을 Slurm 의존성으로 연결한다. GPU 작업은 한 작업에 한 개, 전체 동시 8개까지다. 추출 발현과 예측 배열은 G1에 보관한다. 저장소에는 최종 동결과 채점의 해시, 집계 및 노출 이력을 기록한다.

입력 추출 `31927`과 CPU 예측 `31928`은 처음 제출한 작업을 사용한다. Slurm 제출 수 상한으로 한꺼번에 접수되지 않은 GPU 적합과 병합은 묶음 스크립트 `12c9aa4`에 따라 고정 조합을 12개씩 순차 실행한다. 접수된 GPU 예측 `31984`, 병합 `31985`, 동결 `31986`, 별도 채점 `31987`은 앞 단계 성공을 조건으로 이어진다. [실행 원장](data/r18_confirmation/launch.tsv)
