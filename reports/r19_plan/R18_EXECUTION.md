# R18 승인 실행

사용자가 R18의 C1–C3 예약 발현 접근과 1회 동결·채점을 승인했다. 대상과 모델의 범위는 이미 등록된 108개 조합, 역할별 접근 명부 및 고정 명세를 따른다. [고정 명세](R18_CONFIRMATION_PROTOCOL.md) · [접근 명부 영수증](data/preflight/r18/access/receipt.json)

G1의 `r18-confirm-c1-c3`에 실행 Git 스냅샷과 작업 원장을 보관한다. 같은 실행명으로 중복 제출을 차단한다. CPU 예측과 네 GPU 비교군을 독립 실행한 뒤 병합·동결·채점을 Slurm 의존성으로 연결한다. GPU 작업은 한 작업에 한 개, 전체 동시 8개까지다. 추출 발현과 예측 배열은 G1에 보관한다. 저장소에는 최종 동결과 채점의 해시, 집계 및 노출 이력을 기록한다.

입력 추출 `31927`과 CPU 예측 `31928`은 처음 제출한 작업을 사용한다. Slurm 제출 수 상한으로 한꺼번에 접수되지 않은 GPU 적합과 병합은 묶음 스크립트 `12c9aa4`에 따라 고정 조합을 12개씩 순차 실행한다. 접수된 GPU 예측 `31984`, 병합 `31985`, 동결 `31986`, 별도 채점 `31987`은 앞 단계 성공을 조건으로 이어진다. [실행 원장](data/r18_confirmation/launch.tsv)

마지막 XPert 묶음은 실행 중인 적합을 마친 뒤 종료했다. 종료 시 모든 기존 GPU 작업의 상태를 확인하고, 시작 전에 이관됐다는 로그와 예측 영수증의 부재를 모두 확인한 13개 조합만 `32195`에 재배치했다. CPU 108개와 기존 GPU 예측 419개를 재사용했다. 병합 `31985`는 `32195`의 성공을 기다리며 동결과 채점은 첫 제출 ID를 쓴다. 별도 집계 검증 `32159`는 채점 파일의 해시와 판정만 읽는다. [이관 조합](data/r18_confirmation/gpu_deferred.tsv) · [실행 원장](data/r18_confirmation/launch.tsv)

## 완료

XPert 잔여 예측 `32195`, 병합 `31985`, 동결 `31986`, 별도 채점 `31987`, 검증 `32159`가 완료됐다. 108개 조합을 한 번 동결했고 동결 SHA-256은 `71df741cdd544ee689b707fb79d872702248689267ba976f36e6e893456b7d06`이다. `32159`가 동결과 연결된 채점 결과 10개 파일, 532개 코호트·시나리오 지원, C1 판정을 재검산했다. 채점 영수증 SHA-256은 `9cf6441a45da327245be3e7ee7d19120f7e3afb43d06406134ee0a91def6f88b`다. [동결](data/r18_confirmation/freeze.json) · [채점 영수증](data/r18_confirmation/score/receipt.json) · [검증](data/r18_confirmation/verified.json)

최종 판정은 **확인되지 않음**이다. C1 A는 4/12, B는 13/14를 통과했다. B에서 R15 대비 pooled R² 차이의 99% 구간이 0을 포함했다. C2는 B의 두 농도에서 보조 기준을 통과했고 C3는 HUH7 기술 평가로 집계했다. 이 결과로 승인된 R18 실행과 R19 트랙을 종료했다. [R18 최종 결과](R18_RESULTS.md) · [트랙 종료](FINAL_CLOSEOUT.md)
