# 독립 10 µM 파일럿의 공개 VC 추가 비교 동결

미측정 96군의 기존 배율 보정 편차 축소·단일 배율·8토큰 State 및 다섯 대조의 예측을 그대로 둔다. XPert·PRnet·chemCPA·TranSiGen의 JHH-7 기술 비교 규약을 같은 96군에 사전 적용해 별도 동결한다. 기존 독립 파일럿의 배치와 채점은 유지한다. [원 예측 동결](HCC_OFF_POSITION_PILOT_FREEZE_PROTOCOL.md) · [JHH-7 공개 비교 규약](JHH7_OFF_POSITION_NATIVE_PROTOCOL.md)

- 원 동결에 사용한 JHH-5 277군과 신규 96군의 원천 8개를 재사용한다. 새 모델은 원천 평균의 단일 배율 anchor에 JHH-5 적합 DMSO 참조와 해당 구현의 화학 특징을 이용한 잔차를 합한다. 내부 선택은 같은 `R19-JHH7-native-select` parent 분할과 세 DMSO 역할을 쓴다. 기존 epoch·배율 격자·공동 손실·동률 해소와 공개 코드 버전을 유지한다. 신규 96군의 처리 또는 DMSO 발현은 받지 않는다. 사전학습 모델 가중치의 신규 도입은 없다.
- 입력 및 설정 선택을 등록하고 각 역할·모델별 `96 × 978` 예측의 슬롯·유전자·계보를 별도 동결한다. 원 동결과 동일한 단일 배율 anchor가 재구성되는지 검증한다. 두 목표 세포주에 각각 같은 화합물 예측을 사용한다. 예측에 합성 또는 실측 목표 반응을 사용하지 않는다.
- 실측 채점의 추가 표는 원래 `lock`과 원 예측 동결 및 이 추가 동결을 모두 검증한 뒤 같은 행과 DMSO로 계산한다. 다섯 공개 비교군(State 및 네 추가 모델)의 최선을 각 지표·재표집에서 다시 고른다. 각 세포주별 parent-only와 parent·독립 배양 블록을 함께 고려한 10,000회 가중 구간을 낸다. 각 공개 모형과 최선 모형에 대한 후보 차이, 지표별 최선 빈도, 적격 반복 지원을 보고한다. 파일럿의 추정치로만 해석하고 독립 본시험 판정을 선언하지 않는다. 원 채점 경로는 그대로 실행할 수 있다.

합성 검산은 원 예측·추가 예측과 기존 합성 인수 묶음에서만 수행한다. 실측을 검증할 추가 후보 정보는 새로 제공되지 않았다. R18 예약 자료, 신규 다운로드와 실제 실험 발주는 범위 밖이다.
