# T.A 구조 입력에서의 source-only 전이 보정

**유전자별 분산 보정은 구조 입력 모델의 단순 배율을 개선하지 못했다.** 기존 X의 GSE92742 실측 10 µM·6시간과 493개 화합물군·다섯 세포주·14,898 처리 웰을 사용했다. 각 분할에서는 평가 대상 세포주와 평가 화합물을 함께 제외했고, 그 화합물의 다른 세포주 반응도 사용하지 않았다. [사전 명세](TA_PROTOCOL.md) · [짝 채점 원표](data/t_a/score/paired.tsv)

전체 주 비교의 개선 방향 공동 교환 p는 `1.0`이었다. 두 오차 지표의 악화 방향은 세 fold와 331개 plate를 하나씩 뺀 비교에서 일치했다. 분산 단독과 분산·배율 결합의 T1 대비 99% 개선 상한은 두 지표에서 실용 문턱인 상대 RMSE 0.5%와 R² 0.5%p 미만이다. 사전 판정에 따라 이 분산 보정 규약은 종료한다. [Fold 및 plate 민감도](data/t_a/score/sensitivity.tsv)

단순 배율은 지정한 10 epoch 기본 모델의 전체 RMSE를 0.121% [0.013%, 0.231%] 낮췄다. 같은 parent의 세포주 평균을 뺀 기술 상호작용에서는 RMSE가 0.518% 감소하고 R²가 0.974%p 올랐지만, 배율 적용 뒤 pooled R²는 −1.69%였다. HEPG2에서 분산 추가의 RMSE 감소는 +0.00494%였다. 이미 안쪽 검증에서 학습 설정과 배율을 선택했던 동결 X0가 전체 절대 예측에서 더 낮은 오차를 보였다. X0와의 차이에는 기본 모델 설정 차이도 있다. [상호작용 원표](data/t_a/score/interaction.tsv)

45개 조각의 사전 메타데이터 감사에서 전체 평가 맥락의 fit DMSO는 154–484웰·38–98plate였다. 각 조각의 네 source 맥락·세 parent 분할에는 각각 85–128군이 있었다. 평가 세포주의 select DMSO를 읽지 않았다. 분산 규칙 선택은 평가 맥락과 parent를 전부 뺀 source 중에서 수행했다. Source 안에서도 검증 맥락과 보정 배율을 적합하는 맥락을 분리했고, 기본 모델 적합·배율 적합·선택 parent를 분리했다. 각 최종 단순 배율은 0.607–0.762였다. 기존 DEV Holm 원표의 미실행 슬롯은 보존하고, 이 후속 결과를 별도로 기록했다.
