# HepaRG 위치 보정 후의 반복과 화학 예측

T3와 P3 결과를 관측한 뒤 등록한 개발 자료의 기술 비교다. GSE296254의 기존 24 h·실제 ≥10 µM(`ge10uM`)을 주 조건으로 두고, 순번 7·8 및 GSE284321을 보조로 보고한다. GSE296254의 반복은 별도 culture 표기가 있는 다른 배양·plate·위치에서 측정된 같은 화학 identity·용량이다. GSE284321에서는 배양 독립성이 미확인이다. 원 T3 공유 parent 3-fold, 적합 2,000 유전자 및 모든 원 평가 웰과 logCP10k pool 대비를 보존한다. 이 분석에는 기존 HepaRG 자료와 T3의 HepaRG 전용 예측만 사용한다.

- 주 고정 기준선은 `B_context_plus_position`이다. 실제 µM·최대 µM·순번·화합물군·scaffold 예측에, 적합 parent에서 다른 plate의 같은 위치와 농도 decade가 제공하는 잔차를 더한 기존 T3 모델이다. 원 T3 `joint_dose_response`는 구조와 용량으로 합동 적합한 Hill 예측이다. 동일 행에서 두 동결 예측의 합과 위치 기준선을 비교한다. 같은 비교를 `B_pos`, 위치 없는 `B_context` 및 세 고정 위치 순열에서 기술적으로 반복한다. 화학 예측의 계수는 1로 고정한다. 구조와 위치를 공동으로 재적합한 모델의 효과는 이 비교로 판정하지 않는다.
- `ge10uM`의 별도 고정 참조에서는 같은 strata·parent·정확한 물질·시간·농도 내의 T3 독립 반복 규칙을 적용한다. donor에서 각 donor 웰 자신의 동결 위치 기준선을 뺀 뒤 plate를 균등 가중하고 0.25배 값을 목표 기준선에 더한다. support가 있는 동일 목표 행에서 구조 추가와 실제 반복 추가를 각각 기준선과 비교한다. 평균 코사인은 목표와 donor의 위치 보정 잔차에서 parent별 평균으로 계산한다. 위치 접근 지원을 따로 집계하되 원 모델의 fallback과 full-pool 중심화는 유지한다.
- 분석 단위는 canonical parent이며, 10,000회 짝 parent bootstrap에서 상대 RMSE 개선과 pooled R² 변화의 99% 구간을 계산한다. R²는 기준선의 잔차 에너지로 정규화하고 `residual_R2`로 표기한다. 원 T3와 크기를 비교할 때 분모 차이를 명시한다. 주 두 비교의 판정은 각 ≥100군 및 fold별 ≥20군에서 두 지표의 99% 하한 > 0이다. 원 T3와 P3 판정은 보존한다. 보조 조건은 기술 민감도다.

원 T3 freeze와 각 fold의 metadata·예측 해시를 먼저 고정한 뒤 별도 채점에서만 처리 반응을 읽는다. 새 학습·수집 또는 예약·봉인·격리 자료 접근 없이 실행한다. HepaRG의 간 반응 결과는 성인 간암에 대한 외부 확인과 구분한다.
