# JHH-7 위치 분리 기술 평가의 공개 VC 비교 확장

이미 채점한 JHH-7 10 µM 위치 분리 기술 평가에서 비교군을 확장한다. 기존 배율 보정 편차 축소, 원평균 단일 배율, B0와 8토큰 State는 원 동결값을 재사용한다. 새 비교군은 고정 공개 코드의 XPert, PRnet, chemCPA, TranSiGen이다. 네 구현은 웰 수준 L1000 적응이며 공개 사전학습 가중치는 사용하지 않는다.

- 같은 비간계열 8개 원천, 같은 JHH-5 적합 203군, 같은 JHH-7 목표 88군 및 978개 유전자를 유지한다. 네 구현에는 8개 원천 평균을 이용한 단일 배율 anchor, 적합 JHH-5의 DMSO 평균과 구현별 ECFP·FCFP·RDKit2D 구조 특징을 준다. State는 원 동결의 개별 8개 벡터를 받았다. 편차 축소 예측은 외부 화학 특징을 사용하지 않았다. 새 VC는 JHH-7 발현을 적합·선택·입력에 사용하지 않으며, 단일 JHH-5 맥락 코드를 양쪽에서 공유한다.
- 각 역할별 JHH-5 전체에서 `R19-JHH7-native-select` 5분할 중 0을 내부 선택으로 고정한다. 내부 적합 DMSO와 선택 손실의 DMSO는 서로소 역할이다. 원천 normalization은 해당 예측 역할 안에서 수행한다. 원평균의 단일 배율은 각 내부/전체 적합에서만 [0,2]로 구한다. 공개 구현의 baseline 입력은 적합 plate DMSO 평균을 plate 균등으로 합친 벡터에 해당 약물의 anchor를 더한 벡터다. 학습 표적은 같은 고정 JHH-5 참조에 실제 JHH-5 처리 대비를 더한 값이다. 구현 출력의 baseline 대비 잔차에 별도 gain을 곱해 anchor 위에 합한다. chemCPA의 무처리 학습 입력은 적합 plate DMSO만 쓴다.
- 기존 공개 적응 epoch 설정을 사용한다. XPert 3/8/16, chemCPA 5/15/30, TranSiGen 1/5/15/30, PRnet 100이다. R17 방식의 RMSE·제곱오차 공동 선택 손실을 최소화하는 epoch와 gain `0, .125, .25, .5, .75, 1`을 고른다. 동률은 소수 9자리 공동 손실, 낮은 gain, 짧은 epoch 순이다. 선택을 동결하고 전체 JHH-5에서 새로 적합한다. PRnet은 등록된 32 latent-noise 평균을 사용한다. 양쪽 역할 사이의 원본 웰과 표적 정보는 구분한다.
- 새 네 비교군과 기존 State의 최선을 동일 parent 재표집에서 RMSE 및 pooled R²별로 각각 다시 정한다. 후보는 이 최선 비교군 대비 상대 RMSE ≥0.5%, R² ≥+0.5%p, 짝 parent 10,000회 99% 구간의 개선 방향, 3개 평가 fold 중 2개 이상에서 두 지표의 방향을 모두 충족해야 한다. 비교군 개별 점수, 선택 epoch·gain, 모형별 최선 빈도와 지표별 기준을 함께 낸다. 앞선 State 및 단일 배율 대비 판정은 원 결과로 보존한다.

고정 원천·적합 자료 준비 → 각 VC 예측 → 해시 동결 → 별도 채점 순이다. 같은 B1 노출 평가 plate 한 개를 쓰는 사후 기술 평가이며 R18 예약 발현이나 독립 파일럿 결과와 연결하지 않는다.
