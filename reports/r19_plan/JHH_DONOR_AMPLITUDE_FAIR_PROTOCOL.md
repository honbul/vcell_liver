# 원천 반응 크기 보정을 공통으로 준 성인 HCC 비교

기존 B1 노출 개발 자료의 JHH-5 305군과 JHH-7 88군에서, 유전자별 원천 편차 축소가 원평균에도 같은 약물별 배율 적합을 허용한 뒤에 이득을 보이는지 검증한다. 기존 10 µM·24 h, 위치가 다른 비간계열 원천 8개, 978개 유전자, fit·score DMSO 역할과 평가 parent·scaffold·plate 차단을 고정한다. JHH-7의 적합 표적은 모두 JHH-5다.

비교는 원평균과 편차 축소 벡터 각각에 고정 배율 또는 약물별 배율을 붙인 네 arm이다. 약물별 배율의 유일한 설명 변수는 같은 8개 원천 평균의 로그 RMS다. 기존 일치도 실험의 적합 표준화, 원점 제곱오차, 기울기 ridge 0.05, 추론 범위 [0,2]를 재사용한다. 원평균과 축소는 같은 적합 표적과 설명 변수를 받고 계수를 별도로 적합한다. 후보 격자와 평가 결과 기반 선택은 없다. 고정 배율 두 arm과 이전 로그 RMS 축소의 동결 배열을 정확히 재현할 때만 새 원평균 예측을 동결한다. [기존 적합 명세](JHH_DONOR_AGREEMENT_GAIN_PROTOCOL.md)

주 비교는 약물별 배율을 준 축소 대 같은 배율 규약을 준 원평균이다. 기존 parent-macro RMSE와 pooled R²를 물리 웰·역할을 묶은 짝 parent bootstrap 10,000회로 채점한다. 두 성인 세포주 각각 상대 RMSE 개선 ≥0.5%, pooled R² 개선 ≥0.5%p, 두 개선 방향의 99% 구간, 3 fold 중 2개 이상에서 양 지표의 개선을 모두 요구한다. 원평균의 약물별 배율 대 두 고정 배율, 축소의 기존·새 배율 비교와 두 약물별 배율 arm의 B0 비교를 함께 보고한다. 새 비교가 통과하더라도 이미 노출된 개발 결과로 표시하고 독립 파일럿에 동결한 후보와 채점을 바꾸지 않는다.

사전 명세 → 예측 → 동결 → 별도 채점 순서로 등록한다. 새 자료 또는 R18 보호 발현을 읽지 않는다.
