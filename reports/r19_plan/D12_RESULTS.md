# D1·D2 동일 표본수 비교 결과

**D1은 공유 DMSO가 큰 gain을 선택하게 한다는 가설을 지지했다. D2의 공동 선택 효과는 모델마다 달랐다.** HEPG2 6 h 개발 자료의 1,862 parent와 6,773개 물리 처리 웰을 사용했다. 각 plate에 fit·select·score의 DMSO 수를 같게 두고 총 486개 물리 DMSO를 사용했다. 3개 역할 회전은 같은 parent 묶음으로 재표집했다. [명세](D12_PROTOCOL.md) · [지원과 물리 역할](data/preflight/d1/access/support.tsv)

## D1. 내부 선택의 공유 DMSO → 독립 DMSO

학습 정답·공통 위치 효과·체크포인트 예측은 고정하고, 선택 정답을 만들 때 빼는 DMSO만 바꿨다. PRnet을 제외한 6종은 9개 분할·회전 모두 gain이 낮아졌고, 독립 score 대비에서 두 지표가 모두 개선됐다. 아래 차이는 독립 선택에서 공유 선택을 뺀 값이며 99% 구간이다.

| 비교군 | gain 중앙값 공유 → 독립 | ΔRMSE [99% 구간] | Δpooled R², %p [99% 구간] |
|---|---:|---:|---:|
| ChemBERTa | .75 → .25 | −.03863 [−.04114, −.03615] | +8.322 [+7.398, +9.403] |
| Concat | 1 → .25 | −.05746 [−.06023, −.05471] | +12.068 [+11.148, +12.999] |
| FiLM | 1 → .25 | −.05729 [−.06007, −.05453] | +11.994 [+11.083, +12.913] |
| PRnet | 0 → 0 | 0 [0, 0] | 0 [0, 0] |
| TranSiGen | .125 → 0 | −.00837 [−.00936, −.00738] | +1.161 [+.911, +1.409] |
| XPert | 1 → .25 | −.09482 [−.09900, −.09055] | +20.316 [+18.992, +21.675] |
| chemCPA | .5 → .125 | −.03713 [−.03867, −.03552] | +7.583 [+7.094, +8.063] |

공유 정책에서 고른 신경망 잔차와 두 선택 정답의 차이 방향 사이 cosine 중앙값은 FiLM .588, Concat .592, XPert .552였다. PRnet은 그 값이 .074였고 양쪽 모두 위치 anchor와 같은 예측을 냈다. 이 비교는 물리 DMSO 표본수 변화와 분리해 공유 선택의 효과를 보여 준다. 과거 R15–R17 규약은 적합 정답과 결합 계수도 바꿨다. [선택과 방향 진단](data/d12/selection.tsv)

## D2. 독립 정답에서 순차 선택 → 공동 선택

공동 선택은 Concat·FiLM·XPert의 두 지표를 개선했다. TranSiGen은 두 지표가 악화했다. chemCPA의 RMSE 구간은 0을 포함했다. 고정 checkpoint 하나만 가진 ChemBERTa·PRnet은 두 정책의 전체 추정값이 같았다.

| 비교군 | 바뀐 checkpoint 수 / 9 | ΔRMSE [99% 구간] | Δpooled R², %p [99% 구간] |
|---|---:|---:|---:|
| Concat | 9 | −.001464 [−.002056, −.000930] | +.328 [+.184, +.501] |
| FiLM | 9 | −.000914 [−.001521, −.000473] | +.200 [+.079, +.366] |
| XPert | 7 | −.002318 [−.002734, −.001890] | +.462 [+.355, +.573] |
| TranSiGen | 7 | +.000805 [+.000663, +.000951] | −.125 [−.152, −.099] |
| chemCPA | 8 | −.000046 [−.000284, +.000192] | +.066 [+.007, +.127] |

순차 선택에서 FiLM의 RMSE .896593이 Concat .896726보다 낮았다. 공동 선택에서는 Concat .895262가 FiLM .895680보다 낮았다. 같은 모델과 데이터에서 선택 규약만 바꿔 비교군의 순서가 달라질 수 있음을 보여 준다. 이 수치의 적용 범위는 HEPG2 개발 자료와 개별 신경망 비교군이다. [전체 짝 채점 원표](data/d12/score/paired.tsv)

초기 GPU 작업 `30780`은 반환된 checkpoint와 자원 정보의 묶음을 잘못 해석해 중단했다. `8f46108`에서 어댑터를 고친 후 완료된 27개 CPU 예측은 검증하여 재사용했다. GPU 재실행 `30829`가 끝난 뒤 동결 `30830`과 별도 채점 `30831`이 종료 코드 0이었다. 63개 예측·선택 영수증, 전체 동결과 점수 해시를 대조했다. 초기 GPU 상세 사용량은 Slurm 회계 DB 연결 오류로 모두 복구할 수 없었다.
