# JHH-5 6개 plate의 위치 분리 공개 VC 비교

JHH-7에서 사용한 공개 VC 비교를 이미 채점한 JHH-5 10 µM·24 h 위치 분리 평가로 확장한다. 기존 305개 parent, 309개 처리 웰, RNA plate 6개, 978개 유전자와 세 DMSO 역할을 고정한다. 평가 웰은 B1에 노출됐다. 기존 동결 후보와 State, 단일 배율, B0를 재사용한다. 처음 실행하는 arm은 고정 공개 코드의 XPert, PRnet, chemCPA, TranSiGen 웰 수준 적응 네 개다. R18 예약 발현과 독립 파일럿 발현을 사용하지 않는다.

각 원 분할의 적합에는 평가 fold·scaffold·RNA plate를 제외한 기존 명부만 쓴다. 평가 후보와 동일한 비간계열 8개 원천을 사용하며, 네 VC에는 원천 평균의 단일 배율 anchor와 적합 plate DMSO 참조, 각 구현의 화학 특징을 준다. 원 동결의 단일 배율을 정확히 재현한 경우에만 진행한다. 내부 parent 선택은 JHH-7과 같은 `R19-JHH7-native-select` salt의 5분할 중 0으로 고정한다. 내부 선택 정답은 fit DMSO와 물리적으로 서로소인 다음 역할 DMSO로 계산한다. 평가 plate의 처리와 DMSO는 설정 선택에 사용하지 않는다. 상기 명세에서 지정한 동일 epoch·gain 후보, 손실과 동률 규칙으로 선택하고 원 적합 명부 전체에서 다시 적합한다. 체크포인트와 후속 배율에 공개 사전학습 가중치를 사용하지 않는다. [JHH-7 공개 비교의 동일 규약](JHH7_OFF_POSITION_NATIVE_PROTOCOL.md)

원 동결 후보와 State에 네 새 예측을 결합한 뒤 해시로 동결하고 별도 단계에서 원 평가 정답을 읽는다. 주 비교는 동일 parent를 짝으로 10,000회 재표집하여 다섯 VC 중 최선을 RMSE와 pooled R²별로 다시 고른다. 상대 RMSE 개선 ≥0.5%, R² 개선 ≥0.5%p, 두 99% 구간의 개선 방향, 세 fold 중 두 개 이상에서 두 지표의 개선 방향을 기술 기준으로 고정한다. 각 plate 삭제 민감도와 개별 비교, 선택 배율·epoch, 최선 선택 빈도를 보고한다. Plate 삭제로 달라지는 판정은 따로 표시한다.
