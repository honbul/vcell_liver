# 공통 44개 세포주로 정의한 SNU-423 반응의 재적합

기존 Tahoe P4 5 µM·24 h·최소 20세포의 SNU-423, 203군·275웰을 고정한다. 앞선 메타데이터 잠금의 모든 plate×fold에서 공통인 44개 세포주를 모든 처리 웰의 기준으로 사용한다. 978개 고정 landmark, 외부 parent fold, 물리 vehicle A/B 역할을 보존한다. 이 평가 대상은 앞선 DMSO 진단 뒤 정한 개발 후속이다.

- SNU-423 정답은 같은 웰의 고정 44개 세포주 대비 평균을 뺀 값이다. 적합과 안쪽 선택 각각에서 해당 행의 plate×line×dose×time pool을 독립적으로 중심화한다. 외부 채점은 반대 DMSO로 만들고 채점 pool의 중심을 별도로 뺀다. 정답의 A/B 교체 불변성은 적합에 쓰는 입력 대조의 교체 불변성을 뜻하지 않는다. State에는 원 방식의 fit-role DMSO 셀 토큰이 들어간다.
- 주 분석은 같은 scaffold 성분 전체를 외부 fit에서 차단한다. 원 outer parent만 차단한 비교는 기술 분석이다. 정답과 구조의 동일 범위를 받는 SNU-423 단독 모델을 적합한다. 후보는 ECFP4 Tanimoto Ridge(λ=1)의 예측을, 해당 분할에서 가장 가까운 fit chemical의 Tanimoto ≥0.70일 때 그 약물의 측정값으로 바꾸는 고정 규칙이다. 동률은 숫자 parent ID 순서다. B0, 같은 ECFP Ridge, 같은 ChemBERTa Ridge(λ=1), 임계값 미만에서 0인 형제 복사, 원 T2의 Morgan State 구조 적응을 각각 둔다. State는 원 공식 GPT2 기반 구현·8개 DMSO 토큰·epoch 40·seed 42를 그대로 사용하고 978 유전자 및 SNU-423 단독 학습으로 적응한다. 모델별 gain만 `0, .125, .25, .5, .75, 1`에서 선택한다.
- 안쪽 두 분할은 원 Tahoe `inner_fold` 레지스트리를 사용하며 각 방향의 적합과 실제 정답은 parent를 공유하지 않는다. 두 분할의 parent 균등 대비 MSE를 같은 비중으로 평균하며 값은 소수 10자리에서 비교하고 작은 gain을 우선한다. 선택한 gain은 해당 외부 fit을 다시 적합한 예측에 적용한다. 평가 scaffold 차단은 안쪽 두 적합에도 유지한다. B0의 gain은 0이다. 후속 비교 중 44개 패널, 임계값, rank나 epoch를 고르지 않는다.
- 모델별 동결 예측을 동일 행에서 10,000회 짝 scaffold 성분 재가중으로 채점한다. parent 재가중은 기술 민감도다. 주 후보는 차단 범위에서 B0, 동일 ECFP Ridge, 새 State 적응 각각에 대해 상대 RMSE 개선 ≥0.5%, pooled R² 차이 ≥0.5%p, ΔRMSE의 99% 상한 <0 및 ΔR²의 99% 하한 >0을 모두 요구한다. 일반 parent 분할의 결과와 Tanimoto 지원은 기술 비교다. 본 평가의 기존 VC 비교 범위는 고정 State 적응이며 이전 전체 기존 VC 표의 원 판정은 유지한다.

명세 → Slurm 적합·예측 → 해시 동결 → 별도 채점 순서다. 보호·예약 자료와 신규 다운로드는 사용하지 않는다. GPU 동시 사용은 최대 2개다.
