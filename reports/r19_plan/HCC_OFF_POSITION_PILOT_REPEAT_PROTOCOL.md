# 독립 10 µM 파일럿의 반복 재현성 추가 채점

기존 96군 파일럿의 등록 명부, DMSO 역할, 원 예측과 다섯 공개 VC의 추가 동결을 적용한다. 독립 배양 실측을 받은 뒤 다른 RNA plate·well 위치와 다른 배양 시작에서 얻은 동일 약물 반복으로 실험 재현성 및 모델 격차를 산정한다. 기준선은 같은 약물의 다른 반복을 실제로 관측했을 때 얻는 참조값이다. 기존 0.25배 평균 반복과 후보의 고정 채점을 보존한다. 이 추가 진단의 결과를 모델 적합·선택으로 돌려보내지 않는다.

- 각 세포주에서 사전 QC 통과 및 서로소 DMSO 역할을 갖춘 처리 웰만 사용한다. 동일 parent의 서로 다른 독립 배양·실제 plate·well 위치 전체 쌍을 양방향으로 센다. 각 표적 웰에 가용한 반복의 수로 나눠 웰을 균등하게 두고, RMSE를 parent 내에서 평균한다. 세 vehicle 회전은 동일 물리 웰의 값을 평균하는 축이다. 두 방향과 세 역할을 별도 실험 반복으로 세지 않는다. 서로 다른 batch의 지지 수는 별도로 보고한다.
- 같은 평가 지원에서 상대 반응 코사인, 두 반복 차이의 제곱평균을 2로 나눈 뒤 제곱근을 취한 반복 불일치 RMS, 원 반복 복사, 같은 약물 반복의 고정 교차적합 단일 배율, B0, 동결 후보와 공개 VC 5종을 보고한다. 단일 배율은 슬롯 문자열에 고정 CRC32 salt `R19-pilot-repeat-193501`을 붙인 세 fold의 두 적합 fold에서만 parent 균등 원점 최소제곱으로 [0,2]에서 정한다. 평가와 적합 scaffold는 서로소다. 어떤 지원 fold에서 적합 반복 parent가 10군 미만이면 그 세포주의 배율 비교를 보류하고 나머지 참조는 계산한다. 양쪽 반복에 실제 DMSO 차이까지 포함될 수 있어 불일치 RMS를 순수 생물학적 또는 측정 잡음으로 귀속하지 않는다.
- 각 후보의 절대 오차와 후보 대 최선 VC·B0·가용한 반복 참조의 짝 차이를 보고한다. 최선 VC는 각 지표·재표집에서 다시 고른다. 99% 구간은 10,000회 parent-only 지수 가중 및 `parent × 두 배양`의 교차 가중으로 낸다. 교차 가중은 같은 배양에 하나의 공통 가중치를 주고 각 방향 쌍에 원천과 표적 배양의 가중치 곱을 적용한다. Parent-macro RMSE는 각 parent의 쌍 가중치로 다시 나눈 후 parent 간 평균한다. Pooled R²는 같은 가중의 제곱오차 합과 B0 에너지로 구한다. 교차적합 배율은 재표집에서 고정한다.

실제 발현은 원본 assay·intake·두 모델 동결과 모든 해시를 검증한 뒤 별도 채점 단계에서 읽는다. 합성 검산은 현재 합성 인수 자료만 사용한다. 측정의 효과·상한 판정과 R18에는 합성 결과를 쓰지 않는다.
