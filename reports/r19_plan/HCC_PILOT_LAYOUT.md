# 성인 HCC 독립 검증 파일럿 배치표

SNU-423과 HUH7에서 각각 96개 화합물군을 5 µM·24 h에 측정하는 규모 추정 파일럿의 배치표다. `P001`–`P096`은 예약 자리이며 화학물질을 선정하지 않았다. 목적은 배양 블록과 웰 위치의 변동, 다른 위치에서의 반복 상한, 기존 VC와의 대응 오차 변동을 추정하는 것이다. [규모 산정](HCC_CONFIRM_DESIGN.md) · [배치 원표](data/hcc_pilot_layout/plate_layout.tsv) · [plate별 검산](data/hcc_pilot_layout/support.tsv)

- 세포주별 독립 배양 블록 8개에 96웰 plate를 하나씩 배정한다. 각 plate에는 처리 36웰과 vehicle 12웰이 있다. 세 블록을 선택하는 56개 조합을 모두 쓰고, 나머지 40자리는 블록당 총 처리 수가 같도록 채운다. 각 화합물은 한 세포주에서 세 블록에 한 번씩 관측되며, 그중 가장자리 한 번과 내부 두 번이다. 두 세포주를 합한 화합물별 여섯 좌표도 서로 다르다. 웰 배치는 고정 seed와 유효 좌표에서의 무작위 할당으로 생성됐다.
- plate 안 vehicle은 A·B·C에 4웰씩이며, 각 역할이 네 사분면에 하나씩 있고 가장자리에 정확히 하나 있다. 채점 전 회전마다 fit/select/score를 물리적으로 분리한다. 좌표가 달라도 동일 배양에서 나온 plate들은 같은 독립 블록으로 기록한다. 이 배치표는 별도 배양이 실제로 수행됐음을 검증하지 않는다.
- 각 세포주는 별도 plate에서 측정한다. 주 목표는 같은 세포주의 처리−vehicle 전사 반응이다. Tahoe의 같은 물리 웰 평균을 뺀 P4 목표를 이 단독 배양 설계에 그대로 적용할 수 없다. 두 성인 HCC 맥락의 차이를 별도 탐색할 때도 각 세포주의 독립 웰 반복과 대조군으로 효과를 만든다.
- 실제 사용 시 측정 전에 canonical parent, 염·이성질체·농도 확인, 화합물 계열 및 노출, 독립 배양·실제 plate ID와 사전 QC를 외부 명부로 잠근다. 사용자는 익명 자리와 실제 화합물의 일대일 매핑을 고정할 수 있다. 물리 vehicle 역할과 평가 약물의 분할은 같은 정보 조건의 모든 모델에 공통이다. A와 같은 약물 비간계열 데이터가 추가되는 B는 별도 분석이다.

총 처리 576웰, vehicle 192웰, plate 16개다. 나머지 768웰은 이 파일럿 채점에 배정하지 않았다. 효과를 본 뒤 후보를 선택하는 데 쓴 파일럿의 화합물과 배양은 최종 확인에서 분리한다. [생성기](../../src/r19_plan/hcc_pilot_layout.py) · [검증 영수증](data/hcc_pilot_layout/receipt.json)

이 배치와 연결되는 실제 ID 검증, 예측 동결 및 별도 채점을 합성 자료에서 검증했다. 대조군 부족 plate와 독립 반복 지원의 감소를 반영하며, 실제 표본 명부가 들어오기 전까지 합성 상태로 둔다. [채점 검증](HCC_PILOT_SCORING.md)
