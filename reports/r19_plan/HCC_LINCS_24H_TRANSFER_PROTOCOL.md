# JHH-5 성인 간암의 동일 assay 24시간 전이

사전 지원 감사에서 자격을 충족할 때만 실행하는 후속 개발 비교다. CMap 2020 JHH-5의 실측 10 µM·24시간 Level 3 웰을 사용한다. B1에서 사용한 측정을 표에 표시한다. 주 질문은 **이미 다른 세포주에 같은 약물의 10 µM·24시간 실측이 있는 경우**, 새 JHH-5 평가 plate와 새 구조군에서 전사체 대비를 얼마나 잘 예측하는지다. R18과 약물의 6→24시간 전이는 각각 별도 과제다.

## 고정 명부

- 지원 감사의 비간계열 보유 대상과 해당 동일 약물 실측만 쓴다. 원 R17의 978개 landmark 및 CRC32 기반 웰 배정과 세 역할 회전을 사용한다. 평가 fold의 모든 parent·Bemis–Murcko scaffold와 평가 RNA plate 전체를 JHH-5 적합에서 뺀다. 적합과 평가의 약물 실측 원천을 다른 세포주로 한정한다. 대상 대조군과 donor 대조군을 분리한다.
- 매 평가 조합의 조회 명부에는 대상 측정의 행 인덱스가 없다. 적합 처리와 적합 DMSO만 포함하는 별도 예측 명부, 평가 처리와 채점 DMSO를 포함하는 별도 채점 명부를 만든다. 고정 donor 집합은 물리 DMSO 역할마다 다른 웰로 정규화한 후, 동일 약물 안에서 먼저 cell×plate별 처리 웰을 평균하고, cell 안의 plate에 균등 가중한 후 cell에 균등 가중한다. 각 역할에 정확히 같은 donor 처리 ID를 사용한다.
- 각 Level 3 파일에서 메타데이터 ID 축만 확인한 뒤 명부와 해시를 준비한다. 대상 처리와 대조의 역할은 모든 조합에서 조회 입력으로 거슬러 들어갈 수 없다. 후속 모델 실행은 이 명부와 별도 모델 명세를 고정한 뒤 진행한다.

지원 감사에서 미달한 대상은 별도 실측 접근을 시작하지 않는다. 현재 대상은 기존 공개 개발 데이터이며, R18 확인 및 독립 성인 HCC 논문 검증의 판정은 그대로 둔다.

## 고정 모델과 판정

- 같은 donor 벡터와 같은 JHH-5 적합 parent를 모든 전이 모델에 제공한다. JHH-5 적합 웰과 원천 donor 웰을 각각 먼저 parent로 집계한다. 단순 기준은 무반응, 적합 JHH-5 평균, 동일 약물 donor 평균, 동일 약물 donor의 원점 배율, 적합 JHH-5와 donor의 평균 차이를 허용한 배율이다. 배율은 해당 적합 자료에서 제곱오차를 최소화하도록 `[0,2]`로 제한한다.
- 주 후보는 평균 보정 배율에 rank-16/ridge-1 잔차 사상을 더한다. 기존 T4 코드를 재사용하며, 적합 donor와 평가 donor의 입력 정의를 일치시킨다. 순열 대조에서는 공유 평균 보정 배율을 유지하고 잔차 적합의 parent 대응만 섞는다. 혼합 seed 38105를 fold·평가 plate에 고정하고 세 역할에서 같은 순열을 사용한다. 기술 비교에 얹지 않은 원 rank-16 사상도 둔다.
- 공개 State Transition은 T4와 같은 upstream GPT2의 실측 RNA 1토큰 적응으로, 동일 donor 벡터와 동일 JHH-5 적합 parent를 받아 매 조합에서 새로 적합한다. 고정 seed 42·40 epoch·학습률 0.0003·AdamW weight decay 0.001·batch 128·MSE를 사용한다. 모델 계열·ridge·체크포인트·출력 배율의 선택은 없다.
- 주 판정은 JHH-5 24시간 웰 대비의 parent-macro RMSE와 pooled R²다. 주 후보는 평균 보정 배율, State, 순열 대조 각각에서 좋은 방향의 짝 99% 구간과 상대 RMSE 0.5%, R² +0.5%p의 점추정 문턱을 충족해야 한다. 고정 역할을 묶은 10,000회 parent bootstrap을 사용한다. scaffold 단위 재표집과 평가 plate 삭제, 같은 plate·농도의 풀 중심 대비 및 후보 내 cosine 검색은 기술 분석이다. B0와 직접 donor 같은 기존 단순 비교군의 수치도 같은 표에 남긴다.
- 학습용 donor → 조합별 예측 → 전체 해시 동결 → 별도 채점으로 연결한다. 이후 채점은 동결된 모델 출력과 그 조합의 채점 처리·채점 DMSO만 연다. 공개 DEV의 기존 측정이며, 독립 배양·반복 조건 및 다른 성인 HCC 계열에 대한 주장은 별도 근거가 필요하다.
