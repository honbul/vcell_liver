# 성인 HCC 독립 배양 파일럿의 입력 검증과 채점

이 계약은 익명 96군 파일럿을 실제 자료에 연결하기 전 구현을 검증하기 위한 것이다. 현재 실행 범위는 합성 검사다. 목적은 배양·좌표 지원과 기술 점수 및 불확실성 산정에 필요한 원표를 확인하는 것이다. 파일럿에서의 모델 순위로 최종 독립 확인을 대신하지 않는다.

- 고정 배치표의 768개 좌표와 실험 기록을 일대일로 연결한다. 한 plate slot은 실제 plate 하나, 한 culture slot은 검증 가능한 독립 배양 하나를 뜻한다. 독립성은 실제 기록 확인이 필요하며 서로 다른 이름만으로 입증되지 않는다. 실험 명부에는 parent 식별자, 발현 specimen ID, plate·배양 ID, 연속 µM·시간, 사전 QC 상태를 기록한다. 서로 다른 plate 또는 표본 ID가 같은 배양을 공유하면 이 설계에서 별개 반복으로 세지 않는다. 한 canonical parent를 두 slot에 매핑하는 경우를 거부한다. 처리·vehicle·예측 행과 유전자축은 순서까지 해시로 잠근다.
- score에 앞서 동결 예측을 받는다. 예측 arm 집합, 비교군 집합, 하나의 A 또는 B 정보 계약, 유전자 순서, 역할에 사용한 물리 vehicle manifest를 먼저 고정한다. A는 query 처리 RNA를 금지하고 B의 허용 비간계열 동일 약물 입력은 별도로 기록한다. 예측과 채점 코드에서 실제 발현으로 역할·모델·gain을 고르지 않는다. 형식 검사는 공급된 예측 발행 기록을 대조한다. 실제 학습 프로세스에 대한 독립 노출 감사와 연구별 QC 명세는 실측 착수 전에 별도로 결합한다.
- 회전마다 A/B/C를 각각 fit/select/score로 순환한다. 지정된 score 역할의 해당 physical plate vehicle 평균을 처리 발현에서 뺀다. 합성 검사에서는 사전 QC 통과 vehicle이 역할별 3웰 이상인 plate를 사용한다. 실측에는 동결 인수 명세에 합의한 숫자를 쓴다. 같은 plate나 culture의 다른 좌표를 새 독립 반복으로 세지 않는다. 전체 적격 웰과 같은 화합물의 다른 배양·plate·좌표 반복을 가진 공통 지지를 구분한다. 보정된 다른 반복의 평균을 0.25배로 쓰는 참조는 별도 score 단계에서만 계산한다.
- 세포주별 parent-macro RMSE, zero contrast 대비 pooled R²를 산출한다. 두 모델이 같은 physical treatment와 vehicle role로 평가되며 역할은 독립 반복 수에 넣지 않는다. parent만의 99% 구간과 parent 및 독립 culture block에 별도 가중치를 준 99% 구간을 함께 제공한다. 10,000 paired 지수 가중을 사용한다. 모델 간 대비는 같은 가중치로 계산하고 최선 VC는 지표와 반복마다 새로 구한다. 반복 참조는 동결된 모델과 구분하며 재표집은 이미 구성한 donor 참조에 조건부다. 실제 파일럿의 독립성, calibration, 효과 산포와 예산을 확인한 뒤 최종 본시험 설계에 적용한다.
