# R19 착수와 D0

기획서 5·7·9·10·18·21절과 R19 실행 요청에 따른 1단계다. R18의 후보, 비교군, 고정 격자, 역할 순환, 선택 손실, 판정 기준은 R17 및 R18 원 요청을 참조한다. 이 단계에서 새 처리 발현값은 읽지 않는다. 위치는 지원 메타데이터로만 감사하고, B_pos−B0 효과량은 R18의 별도 동결·채점 단계에서 낸다.

## 감사 입력과 판정 단위

- C1은 R16의 CMap HEPG2 24 h 5–20 µM 레지스트리에서 QC 적격인 기존 물리 웰을 그대로 가져온다. R16 이전 규약 채점과 B1·R8 노출을 기록한다.
- C2는 GSE70138과 CMap HEPG2 24 h의 정확한 0.04–3.33 µM 측정을 후보로 삼는다. 원장에 기록된 물리 웰 및 원·파생 서명과의 직접 일치가 있으면 후보에서 제외한다. CMap 서명의 구성 웰 하나라도 두 GEO release 중 하나에 있으면 해당 CMap 서명을 제외한다. 동일 parent의 다른 실측 노출은 표시한다. C2는 100 parent 미만 용량층을 기술 분석으로 유지한다.
- C3은 GSE92742 HUH7 3 µM의 6 h와 24 h를 각각 감사한다. HEPG2에서 가능한 학습·내부 선택 지원과 HUH7 채점 지원을 나란히 보고한다. 고정 parent fold는 두 세포주에서 공통이다. HUH7 측정을 학습에 추가하는 설계의 지원은 별도 행이다.
- Canonical 구조가 확인된 parent, QC, 실제 원 실험의 물리 웰과 plate를 각각 센다. DMSO는 R17처럼 ID의 CRC32, 동률일 때 ID, plate별 순서대로 A/B/C에 순환 배정한다. 별칭은 한 물리 웰로 합친다. 역할이 셋 모두 있는 plate가 주 지원 대상이다. GSE70138 원 배포본의 DET 좌표와 기존 CMap 메타데이터에서 확인 가능한 RNA 좌표와는 지위를 구별한다. DMSO 역할 회전은 독립 측정 수에 포함하지 않는다.
- B의 외부 실측은 별도 허용 명부의 비간계열·같은 시간·허용 용량대 안에서만 사용한다. DMSO와 physical well 지원은 metadata에서 확인한다. R18 주 후보의 적합, 동결과 평가가 끝나기 전에는 모델 결과나 판정을 기록하지 않는다.

## D0 재현과 DEV 차단

R14의 공개된 기존 동결·채점 집계표만 회수해 커밋의 해시 및 점수 영수증의 파일별 해시와 비교한다. R17 CPU 재집계는 원본 예측·동결을 읽기 전용 링크로 참조하여 새 경로에 쓴다. 978 랜드마크 ID와 순서, 물리 DMSO CRC32 배정, paired 점수 및 모델 선택 기록을 해시로 대조한다.

DEV의 다음 실행은 측정 단위 provenance에 원래 표본 ID 및 파생 서명의 구성 웰을 포함하고, 적합·선택·특징 사전학습 전에 `python -m src.r19_plan.contracts`로 차단 검사를 통과해야 한다. [기준선 명세](baseline_contract.yaml)와 [실험 상태](experiment_matrix.tsv)를 참조한다.

## DEV D1·D2 선택 계산 사전 검증

D1은 등록된 동일 개수의 물리 DMSO로 같은 내부 처리 행에서 두 정답을 구성한다. 두 정책은 같은 checkpoint 예측, 같은 anchor, 같은 gain 격자와 손실을 사용한다. 공유 조건의 정답에는 fit DMSO를, 독립 조건의 정답에는 select DMSO를 뺀다. 선택 계산에는 score DMSO의 물리 식별자만 제공하며 실제 DMSO 값은 제공하지 않는다. [동일 표본수의 plate별 지원](data/preflight/d1/plate_support.tsv)

D1의 접근 명부는 R18 보호 입력과 겹침이 없다고 감사한 I 트랙 개발 처리 웰의 순서와 분할을 사용한다. 이전에 잠근 균등 DMSO 명부를 같은 물리 대조군 역할의 교집합으로 검증하고 Level 3의 표본 ID와 유전자 ID만 읽어 좌표를 고정한다. 각 회전마다 예측용 fit/select 대조군과 채점용 score 대조군을 별개로 기록한다. 측정 좌표의 변경, 역할 중복, 같은 plate에서의 역할별 표본수 차이가 있으면 중단한다. 이 명부를 만드는 단계는 발현 및 모델 예측을 읽지 않는다.

D2는 독립 select 정답 하나를 기준으로 R17의 순차 선택과 DEV의 checkpoint×gain 공동 선택을 같은 유전자별 배열에서 비교한다. R17 순차 선택은 gain 1에서 먼저 checkpoint를 고르고 고정 격자의 gain을 고른다. DEV 공동 선택은 손실을 소수 9자리로 맞춰 비교한 뒤 동률이면 낮은 gain, 그 다음 고정 config ID의 사전순을 사용한다. 순차 선택은 R17의 동률 규칙을 유지한다. 두 정책은 각 parent의 웰 RMSE를 매크로 평균한 항과 전체 제곱오차 항을 결합한 원 R17 손실을 사용한다.

합성 테스트는 동일 checkpoint 묶음에서 DMSO 역할을 바꿨을 때 gain이 달라지는 경우, 순차와 공동 선택이 다른 checkpoint를 고르는 경우, 동률과 허용된 물리 웰·parent·유전자 순서의 검사를 포함한다. 물리 DMSO 적재와 기대 동결 해시를 검사하는 별도 채점 경로를 합성 캐시로 검증했다. 실제 D1·D2 효과를 재려면 새 checkpoint 묶음과 동결된 outer 예측이 필요하다. [D1·D2 실행 명세](D12_PROTOCOL.md)

## DEV D3 물리 fit DMSO 보정 명세

D3a는 물리 fit DMSO를 원래처럼 평균한다. D3b는 plate 안의 fit DMSO 물리 ID를 CRC32로 정렬하고 두 집합에 교대로 배정한다. 같은 처리 웰에서 두 DMSO 평균을 각각 빼고 같은 anchor를 뺀다. 분할의 물리 DMSO 수에 비례해 기존 웰 가중치를 나눠, 두 관측의 가중치 합과 가중평균 잔차를 D3a와 같게 유지한다. fit DMSO가 두 개 미만인 plate는 D3b 지원 부족으로 기록한다.

D3c는 fit DMSO를 각각의 plate 안에서 중심화한 뒤 각 plate의 공분산에 같은 가중치를 준다. 서로 다른 두 plate 이상에서 반복이 있어야 하며, 수치적으로 지원하는 rank `1, 2`에서 제거 강도 `0, .25, .5`를 고정한다. 선택과 평가에는 신경망 잔차만 줄여 원 anchor에 더하고, D3a와 동일 축에서 공통 효과와 약물 대비 보존을 측정한다. score DMSO의 식별자는 역할 중복 검증에만 사용한다. 합성 검증은 배율 0의 항등성, 역할 중복 차단, 유전자 순서, 가중치 보존 및 rank 지원 부족을 확인했다.

## X·L1 메타데이터 지원 감사

X는 GSE92742의 실측 10 µM·6 h에서 R18 보호 측정과 donor를 제외한다. RNA plate가 여러 세포 맥락에 공유된 경우 해당 plate의 모든 행을 뺀다. HEPG2와의 공통 parent가 전체 100군·fold마다 20군 이상이고 독립 RNA plate가 최소 3개인 다른 세포주를 지원 순으로 최대 12개까지 놓고 탐색한다. HEPG2와 4개 다른 맥락의 공통 지원에 같은 기준을 적용한다. 적격 조합에서는 공통 parent가 가장 많은 조합을 택하고, 동률이면 가장 작은 fold의 지원이 큰 순과 세포주 ID 순을 쓴다. 채점은 수행하지 않는다.

L1은 기존 개발 처리 명부를 대조하고 release·물리 RNA plate·세포주·시간·실측 용량이 일치하는 서로 다른 parent가 한 pool에 몇 개 있는지 센다. 서로 다른 parent 두 개를 최소 짝 지원으로 두고 3개와 5개 지원도 함께 기록한다. 각 inner fit·select·outer fit·score를 별도로 집계하며, 실측 용량은 반올림 없이 기준 µM으로 변환한다.

X의 선정 조합은 HEPG2·A375·HA1E·HT29·MCF7이다. 공통 495 parent가 fold별 166·165·164개로 나뉘며, 모든 parent가 각 세포 맥락에서 RNA plate 두 개 이상에 나타난다. 따라서 한 맥락을 빼고 네 맥락에서 적합하는 구조의 자료 지원이 있다. 별도 기저 RNA의 provenance와 모델의 전이 성능은 이 감사로 판정하지 않는다. [원 맥락 지원](data/x_l_support/x/contexts.tsv) · [선정 조합과 fold](data/x_l_support/x/loco_support.tsv)

X2 기저 특징 후보는 G1에 보유한 DepMap 25Q3 RNA다. 세포주 이름·catalog와 단일 기본 non-stranded RNA profile ID로 매칭하고, 중복 없는 L1000 Entrez 열을 센다. 전 맥락에 기저 자료가 있는 기존 적격 조합 중 원 X 지원 규칙을 다시 적용한다. 이 단계는 RNA feature 값을 배열에 적재하거나 모델을 적합하지 않는다.

L1 held fold를 합치면 두 parent 이상이 있는 138개 pool에 1,818 parent, 6,558개 물리 웰이 포함된다. 전체 6,773웰 중 실측 용량과 기존 캐시 용량이 다른 웰은 284개였다. 따로 측정한 실제 용량으로 짝을 구성하고, 같은 캐시 용량에 속하더라도 실측이 다른 웰은 서로 다른 pool에 둔다. [지원 원표](data/x_l_support/l1/support.tsv) · [실측 용량 영수증](data/x_l_support/l1/receipt.json)

## S·L 구성 검증

S0/L0는 기존 parent 가중 MSE FiLM을 공유한다. S1은 같은 폭의 concat이며 S2는 기존 방향 벡터에 별도의 비음수 크기 출력 하나를 더한다. S3는 적합 반응의 parent 가중 PCA만으로 rank `32, 64, 128` 중 지원되는 후보를 만든다. 모든 구성에서 실제 유전자별 체크포인트 예측 배열을 확보하며, 조회 처리값 없이 동작한다.

L1은 MSE에 동일 물리 pool 내 parent별 평균 오차의 짝 제곱차를 추가한다. 환산한 실측 용량으로 훈련 batch를 구성하며, 두 parent 미만인 pool에서는 추가항이 0이다. L2는 적합 잔차 norm의 10분위수로 방향항을 안정화하고 가중한다. 두 추가항의 가중은 `.01, .1, 1`이다. L3는 fit 잔차 scale의 `.5, 1, 2`배에서 Huber 전환점을 둔다. 합성 검증에서 S0의 예측이 기본 코드와 정확히 일치하고, 다른 용량 및 같은 parent의 반복이 L1의 독립 약물 짝을 늘리지 않음을 확인했다.
