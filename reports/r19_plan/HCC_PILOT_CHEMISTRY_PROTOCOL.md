# 96군 독립 HCC 파일럿의 화합물 후보 메타데이터 감사

목적은 실제 구매·측정에 앞서 기존 반응 자료와 정확 구조가 분리되는 후보의 수와 구조 지원을 확인하는 것이다. 작업 범위는 이미 확보한 등록 메타데이터와 구조만이다. PRISM 생존율, ChEMBL 활성값, 유전체·발현, 예약 웰은 사용하지 않는다. 여기서 고른 이름은 검토용 후보이며 최종 독립 확인 명부는 별도다.

- 후보 원본은 I4에서 감사한 PRISM 19Q4 treatment-info다. 단일 parent로 해석되는 구조 및 공개 chemical ID가 있고 임상 상태가 Launched, Phase 3 또는 Phase 2인 parent를 우선한다. 입체 구조가 서로 다른 등록이 동일 parent로 접히면 제외한다. Phases 1·Preclinical 등을 포함한 구조 지원은 별도 후보 풀로 보고하되 같은 96 슬롯에 자동 충원하지 않는다.
- 공개 LINCS 세 등록표, Tahoe-100M·Emerald Bay 구조, Sci-Plex3, R14 HepaRG·MIX-seq 사용 명부와 R18 예약 parent·donor **식별자만** 대조한다. 동일 tautomer parent, 연결성, 원 ID 또는 정규화 이름의 일치 하나라도 있으면 보수적으로 제외한다. 지목된 목록에 매칭이 없다는 것은 외부 VC가 그 약물을 전혀 보지 않았다는 보증이 아니다. 별도로 예측에 사용할 모델별 pretraining/fit 명부를 감사할 때까지 구조 외삽 후보로만 해석한다.
- 고정 Tahoe P4 203군의 구조를 기준으로 ECFP4 2,048비트 최대 Tanimoto와 Bemis–Murcko scaffold를 계산한다. 유사도 <0.35, [0.35,0.55), ≥0.55에 각 32군을 우선 배정한다. 먼저 높은 유사도 층을 배정하고, 빈자리는 중간·낮은 층에 순서대로 채운다. 고정 seed 정렬에서 각 비어 있지 않은 scaffold는 하나만 채택한다. Acyclic parent는 고유 parent 단위로 다룬다. 96개가 없으면 실제 남은 수만 기록한다. 어떤 반응에 잘 맞았는지로 고르지 않는다.
- 최대 96개를 고정 seed로 익명 배치에 임시 대응시킨다. 배양 반복·좌표 대조는 기존 배치에서 다시 검증한다. 임상 단계/분자 구조는 구매 가능, 해당 농도에서의 용해성 또는 용매 적합성의 증거로 취급하지 않는다. 실측 확정에는 실물 lot·염 및 stereo, 용해도·용매, 공급 및 최종 QC 검토가 필요하다. 사용자 승인 전 구매, 외부 문의 또는 측정은 진행하지 않는다.
