# 성인 HCC 10 µM 위치 분리 예측의 약물 대비와 검색

이미 채점한 CMap 24 h의 JHH-5 305군·309웰 및 JHH-7 88군·88웰에서, 배율 보정 편차 축소의 개선이 같은 물리 plate 안의 약물 차이에서도 남는지 사후 재채점한다. 이전 B1에 노출된 동결 배율 보정 편차 축소와 공개 VC 5종, 원평균 단일 배율을 사용한다. 네트워크, 배율, 입력, 화합물, 평가 role을 바꾸지 않는다. 원 공개 비교의 절대 지표를 먼저 검산한다. 새 자료와 R18 예약 자료는 열지 않는다.

- `RNA plate × parent fold × DMSO role × 실측 농도`를 풀로 고정한다. 같은 풀의 여러 웰에 같은 parent가 있으면 먼저 parent를 균등하게 반영해 풀의 평균 벡터를 계산한다. 실측 및 각 모델 벡터에서 각각의 풀 평균을 뺀다. 처리는 원 물리 웰 단위를 유지한다. Top-1·Top-5와 코사인에는 풀 내 parent 평균을 사용한다. 모든 풀은 최소 3 parent를 요구하며, Top-5는 후보 6군 이상의 풀에서 보고한다. 서로 다른 pool의 약물을 검색 후보로 섞지 않는다. 거리 동률은 동률 후보에 확률을 균등 분배하고 무작위 기대는 k/풀 크기다.
- 기존 `wrong_parent`의 score 정보가 없는 일대일 순열을 같은 풀에 적용한 배율 보정 편차 축소를 함께 비교한다. 무반응은 0 벡터이며 검색에서는 무작위 기대를 사용한다. 풀 중앙화는 score-only 지표 변환이다. 실측 풀 평균은 모든 후보의 예측 생성에서 제외됐다.
- 주 판정은 중심화 RMSE와 pooled R²의 개선 방향을 각 99% 구간에서 모두 확인하는 것이다. 재표집마다 풀을 채점 때 고정한 채 parent 및 해당 웰·역할을 묶어 10,000회 짝 재표집하고 각 지표의 공개 VC 최선을 다시 고른다. 원평균 단일 배율 및 다른 약물 대조, B0의 중심화 비교도 보고한다. 상대 RMSE 0.5%와 pooled R² 0.5%p의 실용 점추정을 표시한다.
- 검색과 부호를 보존한 코사인은 보조 지표다. 양쪽 모델에 같은 후보와 대조를 준다. 각 pool의 실제 parent 참조를 고정하며 parent별 다수 pool·역할을 평균한다. 모델별 점수와 원평균 단일 배율·State·다른 약물·재표집별 공개 VC 최선 대비 짝 99% 구간을 낸다. Top-k는 무작위 기대도 비교한다. 검색 개선 여부는 벡터 오차의 주 판정에 합치지 않는다.
