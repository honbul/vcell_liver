# 같은 8개 원천을 사용하는 성인 HCC 전이 비교

8개 원천의 보정식이 무반응을 앞섰지만 16개 원천과의 비열등성에는 미달했다. 이 후속 개발 실험은 **동일한 8개 원천으로 기존 VC를 적합·평가했을 때** 보정식이 얼마나 정확한지 비교한다. JHH-5 실측 10 µM·24시간 605군·611웰·6개 plate가 주 범위다. JHH-7 97군·97웰·한 plate는 세포주 전이 기술 범위다. 원 B1 노출과 두 개발 세포주의 약물 겹침을 보고한다.

- 고정 978유전자, 기존 8개 원천의 8개 중첩 패널, 세 DMSO 역할을 재사용한다. 원 평균과 편차 축소는 기존 동결값이다. 대상 처리값을 쓰지 않는 편차 축소의 설정은 고정한다. 비교의 모든 평가 웰과 패널은 일치한다.
- State Transition은 이전 T4·JHH 비교와 같은 공개 GPT2 구현의 1토큰 적응이다. 토큰은 해당 8개 원천의 반응 평균이다. JHH-5는 각 외부 fold×평가 plate에서 예전에 등록한 다른 parent·scaffold·plate의 JHH-5 적합 명부를 쓴다. JHH-7은 JHH-7 전체 평가 parent와 scaffold를 제외한 JHH-5만 적합한다. 둘 다 8개 패널이 동결된 605군의 범위 안에서 적합하며 JHH-7 처리 라벨은 채점 전 제공하지 않는다.
- State에서 parent당 한 패널씩 매 epoch 제공한다. canonical parent 해시의 시작 오프셋에서 여덟 패널을 순환하므로 고정 40 epochs 동안 각 패널을 다섯 번 사용한다. 집계한 적합 대상과 parent 균등 MSE, seed 42, 최대 batch 128, AdamW 0.0003·weight decay 0.001을 유지한다. 새로운 조기 종료나 출력 선택은 없다. 단순 원점 배율은 같은 적합 parent와 여덟 패널을 동일 가중해 [0,2] 범위에서 제곱오차를 최소화한다.
- 주 판정은 JHH-5에서 편차 축소 대 State·원점 배율·원 평균이다. 각각 상대 RMSE 개선 점추정 ≥0.5%, pooled R² +0.5%p 이상, 두 개선 방향의 parent 짝 99% 구간과 외부 fold 3개 중 2개 이상에서 두 지표가 같은 개선 방향이어야 한다. 무반응은 기술 참조다. JHH-7에는 같은 효과 크기와 구간을 표시한다. 한 plate 범위의 기술값이며 정식 확인 판정은 없다.
- 점수는 패널별로 계산한 웰 오차를 평균한 뒤 parent를 모은다. panel 예측 벡터 자체는 평균하지 않는다. 10,000회 parent 재표집에서 같은 parent의 웰·패널·역할을 묶는다. JHH-5 plate를 하나씩 뺀 기술 민감도를 내고 해당 단일 plate 데이터를 반복 연구로 세지 않는다.

입력과 조건을 예측 전에 고정하고, 예측은 적합 처리·fit DMSO만 읽는다. 예측과 이전 후보의 계보를 동결한 뒤 별도 Slurm 채점에서 등록된 처리·score DMSO만 읽는다. 16개 독립 파일럿과 R18 규약을 유지한다. 신규 다운로드와 예약 발현 접근은 없다.
