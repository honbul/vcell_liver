# 세포 맥락을 옮길 때 평균 반응과 잔차의 영향

**다른 세포에서 학습한 유전자별 절편을 더하는 조작이 두 방향에서 예측을 악화했다.** HEPG2→PHH의 67화합물·105웰과 PHH→HEPG2의 132화합물·268웰에서 같은 대상 6시간 실측, 같은 L1000 랜드마크, 같은 source 적합 집합을 사용했다. 대상 24시간 정답으로 모델을 적합하거나 설정을 선택하지 않았다. [사전 명세](T4_CONTEXT_RESIDUAL_PROTOCOL.md)

| 예측과 비교군 | PHH 대상 상대 RMSE 증가 [99% 구간] | PHH 대상 pooled R² 변화 [99% 구간] |
|---|---:|---:|
| 원 전이 연산자 대 절편만 제거한 연산자 | +3.99% [3.38, 4.59] | −7.78%p [−9.06, −6.54] |
| source 절편을 더한 배율 대 단순 source 배율 | +3.59% [2.93, 4.24] | −6.66%p [−8.04, −5.29] |
| 절편을 제거한 연산자 대 단순 source 배율 | +0.52% [−0.51, +1.63] | −2.02%p [−4.44, +0.28] |
| 배율 위에 잔차를 더한 후보 대 단순 source 배율 | +1.83% [1.21, 2.55] | −3.63%p [−5.46, −2.32] |
| 배율 위에 잔차를 더한 후보 대 원 전이 연산자 | −2.58% [−3.70, −1.41] | +6.17%p [3.78, 8.64] |

PHH에서 기존 전이 연산자의 source 배율 대비 절대 RMSE 초과는 0.04832였다. 절편을 제거하자 0.04275만큼 줄고 0.00557이 남았다. 이 절편은 적합 세포에서 계산한 평균 24시간 반응과 평균 6시간 반응의 선형 예측 차이다. 기존 모델의 오차 증가 대부분을 설명했으며, 절편 없는 행렬을 채택할 개선 근거는 확보되지 않았다. 주 후보인 배율 위 잔차는 원 전이 연산자보다 정확했으나 단순 source 배율보다 양 지표에서 악화해 공동 기준에 미달했다. PHH의 24시간 개발 적합 자료로 얻은 지역 배율과 비교해도 RMSE가 3.43% 높았다. [PHH 전체 원표](data/t4_context_residual/PHH/score/paired.tsv)

역방향 기술 비교에서 원 연산자에 절편을 포함했을 때 RMSE가 절편 없는 버전보다 4.75% [99% 4.08, 5.48] 높았다. 역방향에서는 절편을 제거하고도 단순 source 배율 대비 RMSE가 3.96% [3.22, 4.69] 높아, 평균을 지우는 것만으로 선형 변환의 손실을 설명할 수 없었다. 배율 위 잔차도 단순 source 배율보다 RMSE가 1.15% 높고 R²는 1.84%p 낮았다. 두 코호트의 실측 6시간 입력을 사용한 DEV 결과이며 성인 HCC와 R18의 독립 확인은 별도다. [HEPG2 전체 원표](data/t4_context_residual/HEPG2/score/paired.tsv)
