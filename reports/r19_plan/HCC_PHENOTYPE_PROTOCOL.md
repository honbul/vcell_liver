# SNU-423 표현형 입력과 scaffold 차단 예측

지원 감사에서 I2 120군, I4 156군, 두 뷰 119군이 등록 기준을 통과했다. 5 µM·24 h·최소 20세포의 SNU-423 기존 DEV에, scaffold 차단 후에도 비간계열 외부 표현형이 추가 약물 신호를 제공하는지 묻는다. 이 후속은 M-phenotype 계약이다. I1은 쓰지 않는다. 기존 A 기준선은 공통 행에서 다시 채점한다.

- 원 scaffold 차단 실험의 203군, 물리 RNA 역할 A/B, 978 landmark, 웰 내 전 세포주 평균을 뺀 반응, 적합 pool 중심화, parent별 대표 entity, group fold와 scaffold 차단 집합을 재사용한다. 예측은 해당 fold fit 발현과 held 메타데이터를, 별도 채점은 상대 역할 대조 정답을 읽는다. 원 `scaffold_ecfp`를 같은 계산으로 재현하고 기준선의 기존 동결값과 최대 절대 오차 1e−10 이내로 맞춘다. 원 B0 및 `scaffold_chemb`도 같은 행에 비교한다.
- 후보는 구조 + I2 + I4다. 단독 I2 및 I4는 기여 분석이다. 세 후보 각각에 동일 마스크와 구조를 받는 두 대조를 둔다. `mask`는 관측된 표현형 벡터를 값 1의 단일 좌표로 대체한다. `shuffle`은 각 뷰의 관측 parent를 fit과 query 안에서 따로 순열하고 가용성 마스크를 그대로 둔다. 고정 seed 1501과 기존 I 트랙 순열 규칙을 쓴다. PSD masked Gram은 값 블록의 단위 가중을 합친 뒤 행·열의 가용 뷰 수를 보정한다. 각 가공에 사용되는 평균 대치·표준화·PCA 최대 64축·L2 정규화는 scaffold 차단 fit 정보만으로 정한다. Ridge λ=1, gain=1, 절편 없음과 뷰 가중치를 고정한다. 선택한 뷰가 모두 결측인 query는 정확히 동결 ECFP 예측을 반환한다. 하나만 관측되면 그 뷰를 쓴다.
- 모두 사용하는 전체 203군을 주 분석으로 둔다. 각 후보의 관측 지원에도 같은 비교를 낸다. 결합 후보 관측 지원에는 두 뷰가 모두 있는 parent가 필요하다. 공통 지원을 제한한 후 같은 최소 3 parent pool 규칙과 parent 가중 중심화를 적용하고 실제 지원을 낸다. 공동 지원의 전체 100군 및 fold별 20군 기준이 pool 적용 뒤에도 충족돼야 주 판정에 쓴다. 모든 비교는 10,000회 짝 scaffold 성분 재가중에서 pool을 다시 중심화한다.
- 결합 모델이 전체와 공통 지원 양쪽에서 구조 ECFP와 B0를 대상으로 상대 RMSE 개선 점추정 ≥0.5%, pooled R² 차이 ≥0.5%p, RMSE 차이 99% 상한 <0 및 R² 차이 99% 하한 >0을 모두 충족해야 실용 개선으로 판정한다. 같은 지원의 mask와 shuffle 모두에 두 지표의 99% 구간이 개선 방향이어야 표현형 값의 독립 기여로 판정한다. `scaffold_chemb` 비교와 단일 뷰는 기술 결과다. 기존 표에서 등장한 adult HCC 모델의 독립 확증으로 해석하지 않는다.

지원 명부와 명세 해시 고정 → fold·역할별 예측 → 동결 → 별도 채점 순서다. 발현을 포함한 원본 보류 자료나 예약 코호트는 열지 않으며, no-download 조건을 유지한다. PRISM은 배포자가 treatment 단위로 ComBat을 적용한 자료다. 직접 모델 입력에서 간·담관계 및 미확인 조직 열을 제외한 기존 규칙을 유지한다.
