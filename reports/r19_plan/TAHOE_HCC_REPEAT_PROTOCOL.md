# 성인 HCC 웰 위치 분리 반복의 기술 비교 명세

P4와 기존 반복 결과를 보고 등록하는 후속 비교다. 이미 사용한 Tahoe 개발 203 canonical parent, 0.5·5 µM·24 h, 최소 20·200세포와 기존 fold별 2,000개 유전자를 사용한다. SNU-423이 주 맥락이며 HepG2/C3A는 별도로 보고한다. 같은 release의 검증된 barcode 인덱스를 위치 지표로 쓰고, 실제 배양 배치나 물리 row·column까지 독립임을 가정하지 않는다. 예약 40쌍, plate 13 및 다른 봉인·격리·예약 자료는 접근하지 않는다.

- 사전 메타데이터에서는 **같은 entity, parent, 용량, 시간, 세포주**의 다른 plate 웰을 연결한다. 한 parent의 서로 다른 구조 entity를 약물 반복으로 세지 않는다. 위치 인덱스가 같은 donor와 다른 donor를 분리한다. 가능한 모든 방향의 적격 목표 웰을 유지하며 여러 donor는 plate별로 평균한 뒤 plate 균등 평균한다. 두 종류의 donor가 같은 목표 웰에 동시에 가능한 공통 지원도 집계한다. SNU-423·C3A를 고르기 전에 P4의 10세포주·pool 지원을 적용한다. 적격 웰·parent·공통 지원과 위치 정보의 해시를 값에 접근하기 전에 고정한다.
- 1차 좌표는 원 P4의 세포주 고유 반응이다. 보조 좌표는 원 pool 대비의 실측과 동결 B_pos-all 간 차이다. 각 physical well의 전체 P4 세포주 평균과 원 pool의 parent 가중 중심은 그대로 둔다. 반복 지원 하위군에서 다시 중심화하지 않는다. 평가 정답은 기존 반대 역할 DMSO를 뺀 원 측정이다. 반복 donor에도 자기 plate의 대조 역할을 적용하지만 평가 plate의 관측은 donor 평균에 들어갈 수 없다. 이 분석은 실제 반복을 읽는 채점 단계의 재현성 비교다.
- 비교는 B0, 동일 조건 반복 `0.25`·`1.0`배 및 다른 parent의 donor plate 일치 대조다. 다른 parent 대조는 원 full pool에서 같은 세포주·용량·시간·fold·donor plate의 다른 parent 웰 중 CRC32 최솟값을 선택한다. 다른 위치 반복에는 대조도 평가 웰과 다른 위치를 요구한다. 그 대조가 존재하는 공통 subset의 점수를 함께 낸다. P4 좌표에서는 동결 형제 복사와 위치를 받은 기존 State의 동일 행 점수도 낸다. 비교와 donor 배율을 실측에 맞춰 바꾸지 않는다.
- 점수는 parent-macro RMSE와 pooled R², 평균 parent cosine이다. 10,000회 짝 parent 재표집에서 같은 화합물 내 웰·방향·DMSO 역할을 함께 묶는다. 주 기술 관심은 5 µM·20세포 SNU-423의 다른 위치 반복 0.25배다. 전체 반복 참조는 같은 위치와 다른 위치의 두 범위를 유지한다. 사전 지원 10 parent 미만 또는 공통 지원 부족을 따로 표기하며, 같은 위치 대비 다른 위치의 점수 차이는 공통 목표 웰에서만 해석한다. 99% 구간은 노출된 개발 자료의 기술 불확실성이며 일반 성인 HCC에 대한 확인 판정으로 올리지 않는다.

메타데이터 잠금 → 원 예측 동결 해시 대조 → 별도 채점으로 진행한다. 원 P4 및 앞선 단계 3의 결과와 판정은 보존한다. 새 학습이나 자료 수집은 하지 않는다.
