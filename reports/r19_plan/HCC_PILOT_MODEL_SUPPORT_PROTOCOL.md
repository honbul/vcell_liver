# HCC 파일럿 비교 모델의 학습 노출과 구조 입력 감사

앞서 고정한 96군 초안의 SHA-256을 검증한다. 이 단계는 A 계약에서 비교할 후보들의 실제 약물 반응 노출과 구조 입력을 감사한다. 발현·생존율·예약 코호트와 예측 배열은 읽지 않는다. 모델을 적합하거나 점수로 비교군을 고르지 않는다.

- R17 A의 3 fold × 세 vehicle 회전에 있는 원 동결 예측 영수증에서 모델별 fit·select parent를 확인한다. 커널+FiLM과 기존 비교군 7종의 실제 기록을 본다. 기존 score 영수증으로 동결을 확인하고 각 개별 영수증 및 held parent 원표의 해시와 분리를 대조한다.
- T2의 5 µM·20/200세포 두 조건에서 기존 비교군 10개를 검사한다. 정식 score의 동결이 가리키는 영수증과 공통 cache를 사용한다. 같은 dose·세포수에 맞춘 fit 명부에서 실제 세포주 지원을 확인한다. 두 역할의 영수증을 모두 검증한다. R17 및 T2는 별도 학습 이력이다. 같은 이름의 모델도 동일 가중치로 취급하지 않는다.
- 초안의 canonical 구조에서 만든 parent·tautomer·연결성 키를 실제 label fit 및 select의 구조에 대조한다. 대조 판정은 해당 적합의 약물 반응에 한정한다. 맞는 항목이 있으면 필요한 모델·분할·slot을 기록한다. 구조 전용 ChemBERTa의 원 사전학습 화합물 목록과 scGPT·UCE의 샘플별 사전학습 노출이 로컬 영수증으로 확인되지 않으면 이를 미확인으로 기록한다. 공개 State ST-Tahoe 범주형 drug 조건과 CPA 기본형은 새 parent의 입력 적격성을 별도로 명시한다.
- 독립 CPU 작업에서 기존 ChemBERTa의 체크포인트·토크나이저 해시를 확인한다. R17/R18과 같은 CLS 384차원과 R17의 ECFP4 2,048비트를 96군의 canonical 구조에서 계산한다. 모든 parent의 coverage, shape, 유한성, 잘림 없음과 피처 해시를 기록하고 배열은 G1에 보관한다. 이 단계에서 PCA fit이나 출력 gain 선택은 하지 않는다. 978 landmark map은 구조 어댑터 호환성 확인에만 쓴다. 파일럿 측정의 실제 유전자축은 들어온 자료의 사전 명세에서 확인한다.

이 산출물은 과거 학습 노출과 현재 구조 입력을 검증한다. 성인 HCC의 최종 비교는 실제 독립 배양과 assay/QC 명부, 모든 모델에 같은 정보로 생성한 동결 예측 및 별도 채점을 요구한다.
