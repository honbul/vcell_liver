# 독립 HCC 파일럿의 사전 동결 배율 대조

10 µM·24 h의 96군·8원천 파일럿에 원평균과 유전자별 축소의 약물별 배율 예측을 추가한다. 이 비교는 기존 두 JHH 개발 자료에서 고정 배율 원평균이 약한 대조였음을 확인한 후 등록했다. 원 파일럿과 공개 VC 다섯 개의 배치·예측·판정은 기존 명세를 사용한다. [개발 비교](JHH_DONOR_AMPLITUDE_FAIR_RESULTS.md) · [기존 파일럿](HCC_OFF_POSITION_PILOT_RESULTS.md)

- 원 동결과 같은 scaffold 차단 JHH-5 277군과 역할별 원천 8개를 사용한다. 공개 VC 추가 동결에 사용한 적합 자료와 96군 원천 평균을 영수증·해시로 검증한다. 원평균과 축소 벡터에 대해 같은 개발식 `clip(a + b × 표준화(log RMS), 0, 2)`를 각각 적합한다. 로그 RMS는 두 arm 모두 원평균에서 산출하며 평균·표준편차는 적합군에서만 계산한다. 같은 적합 표적·ridge 0.05·가중 규칙을 적용한다. 두 원 고정 배율 예측을 역할별로 정확히 재현해야 진행한다. 새 목표의 처리 및 기저 발현은 예측 입력 계약에 포함하지 않는다.
- 두 arm의 각 역할별 96 × 978 배열은 SNU-423과 HUH7에 동일하게 적용한다. 슬롯·유전자 순서, 기존 두 동결, 세 원 적합 자료, 새 배열과 코드를 해시로 연결해 별도 동결한다. 원 인수 잠금·원 동결·공개 VC 동결·추가 동결을 모두 확인한 뒤 별도 채점한다.
- 보조 주 비교는 같은 약물별 배율 규칙의 유전자별 축소 대 원평균이다. 두 새 arm을 B0, 원 고정 배율 축소, 공개 VC의 지표별 재표집 최선과 비교하고 약물별 배율 원평균을 고정 배율 원평균과도 비교한다. 공개 VC 비교의 제어 범위는 동일 원천 정보이며 공개 모델에는 새 약물별 배율을 재적합하지 않는다. 세포주·전체 적격 또는 다른 배양 반복 지원별로 parent-macro RMSE와 pooled R²의 99% 구간을 낸다. 기존 파일럿과 동일한 parent 및 parent×배양 10,000회 가중 방식이다. 기존 실용 기준 0.5%·0.5%p와 함께 추정치를 해석한다. 이 보조 파일럿은 독립 본시험을 선언하거나 기존 파일럿의 주 판정을 대체하지 않는다.

G1 합성 검산은 예측과 동결이 끝난 후 기존 539웰 인수 묶음에 별도 연결한다. 합성 지표는 소프트웨어 검증에만 쓴다. 발현 수집과 R18 보호 코호트 접근은 포함하지 않는다.
