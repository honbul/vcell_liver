# 보유 LINCS에서 성인 HCC 6·24시간 짝 지원 감사

GSE92742·GSE70138·CMap 2020에서 HUH7, JHH-5, JHH-7, SNU-423, SNU-387, PLC/PRF/5의 단일 화합물 6·24 h를 확인한다. HEPG2의 기존 T4 개발 결과를 성인 HCC에서 직접 시험할 수 있는지 판단하는 metadata-only 감사다. 같은 세포주와 canonical parent에서 두 시간·정확한 실제 µM가 있는지를 센다. 여러 용량을 화합물 수에 중복 계상하지 않는다.

- 각 release와 세포주별로 원 서명 수·시간, QC 서명, 실제 농도로 연결한 물리 웰의 시간 짝, 채점 plate와 분리된 시간 짝 및 두 시간 각각 두 plate 이상인 짝을 기록한다. 서명 QC는 반복 2개 및 `cc_q75 ≥ .2`이며 CMap은 publisher 서명·웰 QC도 필요하다. 각 물리 plate에 서로 다른 vehicle 웰 3개 이상을 요구한다. 물리 웰 실측 농도는 단위를 µM로 바꾼 십진수 전체를 사용한다. CMap의 GEO 중복 여부는 서명, constituent ID 및 RNA/DET 물리 좌표를 대조해 진단한다.
- R18 처리·별칭, 채점 웰 및 B donor·대조군은 기존 네 manifest로 제외한다. CMap의 GEO 별칭은 새 평가 지원으로 계상하지 않는다. GSE70138의 DET 좌표는 별도 열에 두며 검증된 RNA plate와 동등하게 보지 않는다. Level 3 파일의 보유 여부만 확인하고 GCTX와 발현은 열지 않는다.
- 같은 release·세포주의 적격 parent 전체 100군 이상과 기존 세 fold 각각 20군 이상, 시간 사이 RNA plate 비중복 및 각 시간의 서로 다른 RNA plate 2개 이상인 짝을 정규 DEV 비교의 지원 문턱으로 등록한다. 문턱 미만은 구체적인 단계별 손실을 적고, 발현을 사용한 적합·채점을 시작하지 않는다. 해당 문턱을 통과하면 승인된 Level 3 축과 독립 대조 역할을 별도 잠금 후 모델 비교를 명세한다. 이 감사에서는 R18 원 판정과 예약 지위를 변경하지 않는다.
