# 같은 6시간 실측을 받은 HEPG2 시간 모델과 State 비교

**저랭크 시간 모델이 같은 6시간 측정을 받은 State 적응보다 24시간 반응을 더 정확하게 예측했다.** HEPG2 GSE92742의 기존 DEV 132개 화합물군과 독립 RNA plate의 24시간 웰 268개에서 두 사전 지표를 통과했다. 이 비교는 기존 T4 점수를 본 뒤 등록했다. [사전 명세](T4_STATE_PROTOCOL.md) · [짝 채점 원표](data/t4_state/score/paired.tsv)

저랭크 모델은 State 대비 RMSE를 **7.44%** 줄였다 [99% 구간 5.33, 9.54]. 절대 RMSE 차이는 −0.07299 [−0.09656, −0.04992], pooled R² 차이는 **+15.27%p** [11.99, 18.32]였다. 두 지표의 99% 구간과 실용 문턱을 모두 통과했다. 121개 scaffold 군으로 재표집해도 상대 RMSE 개선은 7.44% [5.28, 9.57], pooled R² 차이는 +15.27%p [11.99, 18.43]였다.

State는 6시간 측정을 그대로 복사했을 때보다 RMSE가 4.60% 낮았고 [2.41, 6.73], R²가 +5.92%p 높았다 [1.40, 10.63]. 같은 자료에서 적합한 단순 배율 대비 State의 두 구간은 0을 포함했다. 기술 참조인 24시간 실측 직접 복사는 State보다 두 지표가 좋았다. 앞선 별도 실험에서는 단순 배율을 적용한 24시간 반복이 저랭크 모델보다 정확했다. [보정한 24시간 반복](T4_REPEAT_RESULTS.md)

두 모델에 같은 화합물·실측 농도의 6시간 대비 벡터를 제공했다. 평가 화합물과 같은 Bemis–Murcko scaffold 및 평가 RNA plate를 적합에서 제외했다. 기존 저랭크 예측은 재사용하고, 공개 State Transition 구현을 978개 유전자의 웰 평균 벡터 1토큰에 맞춰 초기화부터 다시 적합했다. 84개 fold·plate·vehicle 조합에서 두 모델의 적합 지원은 조합당 70–90군 및 137–163개 조건 쌍으로 일치했다. State 학습은 40 epoch와 seed 42를 고정했다. 결과의 적용 범위는 같은 약물의 초기 반응 실측이 있는 HEPG2·L1000 조건과 이 State 적응이다. 성인 간세포암의 독립 평가에는 별도 지원이 필요하다.
