# JHH-7 처리값을 적합에 쓰지 않는 저용량 전이

JHH-5의 두 저용량 평가에서 같은 용량의 비간계열 약물 반응을 줄인 단일 배율이 가장 낮은 RMSE를 보였다. 이 비교에서는 JHH-5 1.11111 µM의 보정을 JHH-7 1 µM에 고정 적용한다. JHH-7 0.1 µM는 더 먼 용량에서의 기술 범위다. 같은 농도·24 h 비간계열 실측은 대상 화합물의 추론 입력으로 쓴다. JHH-7 처리값은 채점에만 쓴다.

- 해시로 고정한 저용량 감사에서 JHH-7 1 및 0.1 µM를 각각 선택한다. 이전 10 µM JHH-7 평가와 같은 처리 ID·RNA/DET 좌표를 차단하고, 이전 parent·대상 plate·DMSO의 겹침을 표시한다. 두 평가 용량의 모든 parent와 scaffold를 빼고 JHH-5 1.11111 µM 적합을 구성한다. 목표 plate와 JHH-5 적합 plate를 원천에서 제외한다. 각 용량의 canonical parent마다 같은 실측 농도의 비간계열 세포주·RNA plate가 8개 이상이어야 한다. 목표 용량별 90 parent 및 적합 100 parent 이상, 각각의 cell×plate에서 독립 DMSO 3개 이상이어야 실행한다. 주·보조 용량은 같은 RNA plate에 있다.
- plate와 세포주 순으로 균등 평균한 원천에서 기존 단일 배율 [0,2]와 State 1토큰을 같은 JHH-5 적합에 고정한다. 978유전자, 서로소 DMSO 역할 순환, State 40 epochs·seed 42·batch 128·AdamW 0.0003·weight decay 0.001을 기존과 같이 쓴다. 추가 비교군은 무반응 B0, 배율 없는 원 평균, 기존 고정 편차 축소와 같은 평가 fold×plate×용량의 다른 parent에 같은 배율을 적용한 대조다. 용량별로 분리해서 채점한다.
- 주 기술 판정은 1 µM 단일 배율이 같은 입력 State·B0·다른 parent 대조 각각에 대해 상대 RMSE 0.5%, pooled R² 0.5%p 이상 좋아지고, 두 방향의 짝 parent 99% 구간이 0을 제외하는지다. 10,000회 재표집에서 같은 parent의 웰과 세 역할을 묶는다. 평가 plate가 한 개이므로 판정은 관측 plate의 기술 결과다. 0.1 µM에서는 동일 지표와 구간만 보고한다.

접근 명부 → 예측 → 해시 동결 → 별도 채점이다. 예약 코호트를 열거나 파일을 새로 받지 않는다.
