# SNU-423 P4의 DMSO 역할과 고정 세포주 패널

Tahoe SNU-423의 기존 P4는 적합과 안쪽 선택에 같은 물리 DMSO 역할을 썼다. 먼저 원 Tahoe sample metadata와 고정 A/B 대조군 명부에서 같은 plate 안의 세 역할이 가능한지 확인한다. 5 µM·24 h·최소 20세포의 기존 203군·275웰과 scaffold 재적합 때 고정한 978개 landmark를 사용한다. 격리 plate와 보류 표본은 제외한다.

발현을 읽기 전에 plate×outer fold별 세포주 조합과 쓸 수 있는 웰을 고정한다. 기존 P4는 각 웰에 실제 존재하는 전체 eligible cell line을 평균한다. 고정 패널의 기술 비교는 두 가지다. 첫째, 적합·held 양쪽 SNU-423 웰에 공통으로 존재하는 세포주 집합을 사용하며 10종 미만이면 해당 pool은 미지원이다. 둘째, 적합 웰만 사용해 SNU-423에 세포주를 하나씩 추가한다. 현 패널 전체를 보유한 적합 웰을 가장 많이 보존하는 세포주를 선택하고 동률은 등록 ID 문자순으로 해소한다. 패널 10개를 해당 held plate에 고정한다. 기존 pool 최소 3 parent 조건을 양쪽 모두에 적용하고 적격 후 전체 100군 및 fold별 20군을 기술 지원 기준으로 보고한다.

별도 진단 작업은 잠근 명부를 대조한 뒤 기존 적격 A·B 정답 캐시에서 차량 대비를 읽는다. 원 단일 세포주 대비, 웰마다 가용 세포주를 뺀 기존 P4 및 고정 패널에 대해 같은 plate pool 중심을 적용하고 A−B의 parent 균등 RMS와 RMS(target 평균) 대비 비율을 계산한다. 고정 패널과 기존 P4를 같은 행에서도 비교한다. 구간은 고정 pool의 parent 재표집 10,000회 99%다. 같은 패널을 쓰면 line·plate당 상수인 차량 대비 차이는 pool 중심화 후 상쇄되며, 최대 절대 잔차 1e−6 이하를 수치 검증 기준으로 고정한다.

이 실행은 평가 대상의 DMSO 민감도와 배치 지원에 대한 사후 진단이다. 기존 선택·동결 예측과 그 판정은 유지한다. 원 3분할 선택 편향의 직접 재현이나 고정 패널의 예측 개선을 판정하는 새 적합은 포함하지 않는다. 예약 발현은 열지 않는다.
