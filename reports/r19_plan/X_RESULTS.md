# X0–X2. 세포주와 화합물을 함께 제외한 DEV A 결과

**기저 RNA X2는 사전 승격 기준에 미달했다.** HEPG2·A375·A549·HT29·MCF7에 공통인 실측 10 µM·6 h의 493 parent와 14,898개 물리 처리 웰을 평가했다. 예측점마다 평가 세포주와 해당 parent fold 전체를 적합에서 제외했다. 4,196개 물리 DMSO는 독립 fit·select·score로 나눴다. [실행 명세](X_PROTOCOL.md) · [물리 지원](data/x_a/access/support.tsv)

X2의 전체 상대 RMSE 개선은 +0.0225% [99% 구간 −0.0059, +0.0517]였다. 두 지표가 같은 개선 방향인 fold는 1/3이었다. 개선 방향 공동 순열 p는 보정 전 0.270이다. HEPG2만 보면 절대 반응의 점추정은 개선됐지만 두 99% 구간에 0이 포함됐다. R17식 fit DMSO PCA(X0)는 전체 상호작용에서 ID 비교군(X1)보다 소폭 개선됐으나, pooled R²는 −2.55%로 0 반응 기준을 밑돌았다. 전체 DMSO 대비에서 화학 입력을 제거하거나 적합 parent에서 섞으면 X2의 두 지표가 악화했다. 기저 맥락 제거와 적합 세포주 profile 순열에 대한 X2의 두 지표 차이는 99% 구간에 0을 포함했다. 세포별 평균을 뺀 상호작용에서는 오히려 X2의 RMSE가 화학 입력 제거 모델보다 +0.003159 높았다 [99% 구간 +.002426, +.003923]. 화학 정보는 공통 약물 반응의 절대 예측에 기여했다. 이 FiLM 설계로 독립 기저 RNA가 세포주 고유 반응을 더 잘 예측한다는 근거는 확보되지 않았다.

독립 기저 RNA는 DepMap 25Q3에 보관된 5개 배양 profile에서 978개 Entrez 좌표로 연결했다. HEPG2는 같은 catalog의 DepMap 질환 분류가 `Hepatoblastoma`이므로 이 결과의 범위는 등록된 세포 맥락이다. X3의 같은 약물 donor와 CNV 추가 비교는 별도 실험이다. [기저 발현 provenance](data/x_l_support/x-basal/context_profiles.tsv)
