# T.A 구조 입력 전이의 source-only 보정 명세

기존 T.B와 X.A를 본 뒤 등록한 A 후속 비교다. 원 X의 GSE92742 동일 실측 10 µM·6 h에서 공통 493 parent, 5개 세포주, 14,898 처리 웰 및 978 유전자를 유지한다. 각 평가 세포주와 3개 parent fold를 함께 적합에서 제외하고 DMSO fit/select/score 물리 역할을 세 번 회전한다. 구조와 fit DMSO만 입력한다. 어떤 세포에서도 평가 parent 처리 측정은 예측·선택에 접근하지 않는다. R18 보호 명부는 원 X와 같다. 원 Holm 표의 미실행 T.A를 소급 변경하지 않는다.

- 동일한 원 X0의 구조·fit DMSO PCA·FiLM으로 `T0_A`를 만든다. 새 보정 선택과 모델 설정의 중복 적합을 없애기 위해 모든 source 및 outer 기본 모델은 기존 X0 설정 후보 중 학습률 .0003, epoch 10, 동일 seed, 원 parent 균등 MSE와 폭을 사전에 고정하고 출력 배율은 1로 둔다. 원 X0의 동결 최종 예측도 기술 비교에 남긴다. 원 X0는 source-select에서 학습 설정과 별도 배율을 선택했으므로 fixed T0_A와 설정이 다를 수 있다.
- 적합 시작 전에 고유 fit DMSO가 각 맥락에 ≥12웰·≥3plate인지 명부로 확인한다. 네 source 세포주 전부와 parent 세 부분을 선택에 쓴다. `T123A-inner-{outer-fold}`의 CRC32 3-fold를 기본 모델 적합, 보정 배율 적합, 규칙 선택에 하나씩 순환 배정한다. 각 검증 조합에서 검증 세포주는 기본 모델 및 배율 적합 양쪽에서 제외한다. 배율 적합용 예측은 나머지 세 source 중 하나씩을 제외해 나머지 두 세포주로 기본 모델을 적합하고 배율용 parent에서 예측한다. 검증 예측은 세 source 전체로 기본 모델을 적합하고 검증 parent에서 예측한다. 배율용과 검증용 parent의 정답은 모두 기존 물리 역할의 독립 select DMSO를 뺀다. 평가 세포주의 select DMSO는 가져오지 않는다.
- T.B의 `T1` [0,2] 에너지 최소제곱 배율, `T2`의 fit DMSO 분산비 8규칙(수축·바닥·clip), `T3`에서 분산 변환 뒤 배율 재적합을 그대로 쓴다. 선택은 4개 source 도메인 × 3개 검증 parent fold의 R17 공동 손실 균등 평균이다. 선택 규칙에서 최종 T1·T3 배율은 source의 다른 세 세포주와 다른 두 parent 부분에서 적합한 조합으로 만든 별도 source OOF 전체에 다시 적합한다. 평가 예측의 분산비에는 사전 등록된 source와 평가 세포주의 fit DMSO만 들어간다. 마지막으로 네 source 세포주의 outer-fit parent에서 기본 모델을 재적합해 평가 parent를 예측한다.
- `B0`, `T0_A`, `T1_A`, `T2_A`, `T3_A`, 기존 `X0`을 같은 웰에 둔다. 주 비교는 전체의 `T3_A−T1_A`이며 두 지표의 99% 구간이 개선 방향이면 방향 기준을 만족한다. 실용 해석은 상대 RMSE 0.5% 및 pooled R² 0.5%p를 유지한다. 두 보정의 T1 대비 99% 상한이 양 지표에서 이 문턱보다 작으면 현 분산 보정의 실용 이득이 부족하다고 판정한다. fold·plate 제외와 HEPG2·상호작용을 보조 보고한다. 같은 약물 RNA가 있는 B와 혼합하지 않는다.

명부 감사 → 예측 → 해시 동결 → 독립 채점으로 진행한다. 이 소스의 세포주·assay 계약을 넘는 독립 성인 HCC 성능은 별도다.
