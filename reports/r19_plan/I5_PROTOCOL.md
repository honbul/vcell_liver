# I5 탐색 명세

I5는 I 트랙에서 채점이 끝난 `I3_all_without_I1`을 보고 선택한 후속 DEV 실험이다. R18과 다른 DEV 트랙의 입력·선택·판정을 그대로 둔다. R18 보호 측정·별칭·donor를 제외한 기존 개발 명부, 적합·선택·채점 DMSO의 서로소 역할 회전과 세 canonical parent fold를 사용한다. 978개 L1000 landmark의 지원과 순서를 고정한다. 외부 뷰는 이미 감사한 A549 Cell Painting I2와 비간계열 PRISM I4다. ChEMBL I1 원본·파생 특징·출력은 I5에 투입하지 않는다.

- `I5_kernel`은 기존 동결 `I3_all_without_I1`의 전체 예측을 해시로 고정해 다시 채점한다. 구조와 PSD masked I2·I4 커널에 기존 위치 anchor와 구조-only FiLM을 공유한다. 비교군 `B_R17`, `I0`도 기존 동결값을 사용한다. 새 설정 선택은 없다. 참고용인 `kernel_only.npz`의 같은 키는 위치와 커널만 포함하며 신경망의 공통 anchor로 사용한다.
- `I5_neural`은 위 위치와 커널을 고정하고 FiLM 입력의 구조 PCA 뒤에 I2·I4 좌표와 가용성 비트 두 개를 추가한다. 각 뷰의 표준화, 적합 평균 대치, 최대 64축 PCA와 L2 정규화는 I 트랙과 같은 코드로 처리한다. 내·외 분할마다 각각 적합 parent에서만 추정한다. 적격 차원이 없거나 관측값이 없는 뷰는 0 벡터와 0 가용성 비트를 준다. FiLM의 DMSO 입력, 학습 정답, 모델 구조와 MSE 손실은 R12/R17과 같다.
- `I5_neural_mask_only`는 같은 입력 폭에서 두 뷰의 숫자 좌표를 0으로 둔다. `I5_neural_parent_shuffle`은 각 뷰에서 가용성 비트를 보존한 채 관측된 parent 좌표를 적합과 조회에서 따로 섞는다. 내분할의 조회는 select, 외분할의 조회는 held이고 각 뷰 고유 seed에 1501을 사용한다. 세 arm 모두 동일한 커널 정보를 받고 같은 방법으로 체크포인트와 gain을 독립적으로 고른다. 이 대조는 커널에 이미 들어간 표현형 신호 위에, 신경망 입력으로 그 값을 추가할 때의 증가분을 시험한다.
- 설정은 배율 `0, .125, .25, .5, .75, 1`, 학습률 `.0003, .001`, epoch `1, 5, 10, 20, 40`에서만 고른다. fit DMSO로 학습하고 select DMSO의 R17 공동 손실로 선택한다. 손실을 소수 9자리로 비교하고 gain이 낮은 순, 기존 checkpoint 문자열 순으로 동률을 해소한다. 원 커널의 ridge와 gain 및 위치 gain으로 독립 select에서 공통 anchor를 재구성한다. 어느 뷰도 없는 select 행에는 원 구조 FiLM을 재현해 결합한 I0를 쓰고, held 행에는 동결된 I0와 정확히 같은 I5_kernel 예측을 사용한다. 새 신경망은 기존 gain 선택의 값을 읽지 않고 이 새로운 select에서 정한다.

예측은 기존 합법적 predictor-only 묶음 9개만 읽는다. 새 예측·가용성·체크포인트·입력·코드의 해시를 검증해 한 번에 동결한 뒤 독립 채점이 기존 score DMSO와 처리 웰 값을 읽는다. 직전 동결과 뷰 가용성이 다른 경우 채점 전에 중단한다. 주 지원은 양쪽 보유 345군, PRISM 보유 722군, 전체 fallback 1,862군이다. Cell Painting만 있는 군과 두 뷰 결측군은 지원 진단으로 표에 남긴다. 최소 전체 100군 및 각 fold 20군은 I 트랙과 같다. 두 주 지표는 parent-macro RMSE와 pooled R², 구간은 짝 parent bootstrap 10,000회 99%다. `I5_kernel`은 B_R17·I0와, `I5_neural`은 B_R17·I5_kernel·두 신경망 대조군과 비교한다.

RMSE 차이 99% 상한 < 0과 R² 차이 99% 하한 > 0을 각각 표시한다. 기존 실용 기준인 상대 RMSE 0.5% 개선과 R² 0.5%p 개선도 함께 해석한다. 원 커널의 재채점과 I5 선택에 노출된 DEV 결과는 후속 탐색으로 기록한다. 새 공개 수집과 봉인·격리·예약 코호트 접근 없이 실행한다.
