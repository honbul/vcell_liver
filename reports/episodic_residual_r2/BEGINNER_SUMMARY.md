# 연구 R2 — 쉬운 설명 (BEGINNER_SUMMARY)

**작성일:** 2026-11-17 · 수식 없이 읽을 수 있게 썼다. 숫자의 출처는 `RESULTS.md`에 있다.

## 1. 무엇을 알고 싶었나

간암 세포주 하나를 새로 받았다고 하자. 이 세포주에 약물을 넣으면 유전자 978개의 활동(RNA 양)이 어떻게 바뀌는지 알고 싶다. 약물은 수백 가지인데, 실험할 수 있는 것은 그중 **16개**뿐이다.

질문은 이것이다. **16개만 실험하고, 나머지 약물의 결과를 맞힐 수 있는가? 그리고 "닮은 약물의 실험 결과를 빌려 오는 요령"을 다른 세포주들에서 미리 배워 두면 더 잘 맞히는가?**

## 2. 비유로 보는 방법들

새로 이사 간 동네의 식당 맛을 예측한다고 생각하면 된다.

| 방법 | 비유 | 이 연구에서의 이름 |
|---|---|---|
| 아무 변화도 없다고 본다 | "모든 식당이 평범하다" | 무변화 |
| 다른 동네 지점들의 평균 평점을 그대로 쓴다 | "이 체인은 다른 동네에서 평균 4점이었다" | source 같은 약물 평균 (f0) |
| 이 동네에서 가 본 16곳이 예상보다 평균 0.3점 낮았으니 전부 0.3점씩 깎는다 | "이 동네는 전반적으로 박하다" | mean-offset (넘어야 할 기준선) |
| 가 본 16곳 중 **닮은 식당**이 예상보다 얼마나 달랐는지를 더 크게 반영한다 | "여기 국숫집들이 유독 좋았으니 다른 국숫집도 좋을 것이다" | 제안법 (잔차 적응) |
| 지점 수가 적은 체인의 평균, 16곳만의 평균은 **덜 믿고** 0 쪽으로 당긴다 | "표본이 적으면 평균을 깎아서 듣는다" | 축소 기준선 (이 연구가 중간에 덧붙인 것) |

제안법에서 "무엇이 닮은 약물인가"는 사람이 정하지 않았다. 간암이 아닌 다른 세포주들(학습용 150개 가운데 약물이 충분한 것)을 번갈아 "새 세포주인 척" 시키는 연습 문제를 수천 번 풀게 해서 배우게 했다.

## 3. 공정하게 비교하려고 지킨 것

- **모든 방법이 같은 16개만 본다.** 간암 세포주에서 추가로 정답을 보고 설정을 고르는 일은 하지 않았다(0개). 8개, 32개일 때도 같은 순서의 앞에서부터 썼다.
- **설정은 전부 간암이 아닌 세포주에서 정했다.** 간암 세포주 점수를 본 뒤에는 아무것도 고치지 않았다. 방법을 먼저 기록으로 "동결"하고 그다음에 한 번만 채점했다.
- **세 간암 세포주끼리는 서로의 실험 결과를 주고받지 않는다.**
- 이 간암 자료는 앞선 연구에서 이미 한 번 채점해 본 것이다. 그래서 이번 결과는 "새 시험"이 아니라 "이미 본 시험을 규칙을 정해 놓고 다시 본 것"이다.

## 4. 결과

점수는 "예측이 실제와 얼마나 다른가"이고 **낮을수록 좋다.** 아래는 세 간암 세포주(HUH7, JHH5, JHH7)를 같은 무게로 평균한 값이다.

| 방법 | 8개 실험 | 16개 실험 | 32개 실험 |
|---|---:|---:|---:|
| 아무 변화 없음 | 0.663 | 0.663 | 0.663 |
| 다른 세포주 평균 그대로 | 0.639 | 0.639 | 0.639 |
| 평균 보정 (기준선) | 0.650 | 0.635 | 0.625 |
| 닮은 약물 빌려 오기, 학습 없이 | 0.645 | 0.626 | 0.606 |
| **제안법 (학습한 규칙)** | 0.630 | 0.622 | 0.607 |
| 일반적인 신경망 (CNP) | 0.620 | 0.619 | 0.619 |
| 공개 모델 TranSiGen을 16개로 미세조정 | 0.636 | 0.611 | 0.591 |
| 덜 믿기(축소)만 적용, 학습 없음 | **0.599** | **0.594** | **0.589** |

읽는 법:

1. **제안법은 기준선(평균 보정)보다 좋았다.** 세 세포주, 세 가지 실험 수 모두에서 같은 방향이었다.
2. **하지만 "학습한" 덕분이라고 말할 수는 없었다.** 같은 재료를 학습 없이 쓰는 방법과 16개·32개에서 구분되지 않았다.
3. 제안법의 이득 대부분은 "16개의 평균을 덜 믿게 한 수정"에서 나왔다. 닮은 약물을 빌려 오는 부분의 몫은 8개·16개에서 불확실했고 32개에서만 뚜렷했다.
4. **가장 단순한 "덜 믿기"가 평균적으로 가장 좋았다.** 다만 이 차이는 주로 HUH7 한 세포주에서 나왔고, 이 방법은 실험 도중에 덧붙인 것이라 미리 약속한 확인이 아니다.
5. 공개 모델 미세조정은 HUH7에서는 매우 좋았지만 JHH5·JHH7에서는 8개·16개일 때 기준선보다 나빴다.

## 5. 그래서 결론은

- "소량 실험에서 닮은 약물의 차이를 빌려 오는 요령을 미리 배워 두면 좋아진다"는 생각은 **이번 자료에서 확인되지 않았다.** 제안한 모델은 채택하지 않고 끝냈다.
- 배운 것은 있다. 이 자료에서는 **약물별로 반복되는 신호가 약하고**(같은 약물을 다시 재도 차이의 대부분이 반복되지 않았다), **적은 표본의 평균을 덜 믿는 것**만으로 꽤 좋아진다.
- 이것은 세 세포주, 한 농도·한 시간, 978개 유전자에 한정된 결과다. 다른 자료에서도 같다고 말하지 않는다.
