# R3 주장 범위와 한계

## 주장하는 것 (시험한 구성에 한함)

구성: Tahoe-100M 0.5 µM 실제 세포 표본, 유전자 2,000개 log1p(CP10k), well당 최대 64 세포, Energy distance(train well 내부 SD로 표준화), 약물 구조 그룹 단위 split.

1. train 약물에서, 처리군의 실제 평균으로 옮긴 대조군 세포와 처리군 사이의 거리는 같은 조건의 다른 well과 처리군 사이의 거리와 구별되지 않았다
   (−0.023 [−0.073, 0.025]; 약물 26개).
2. 시험 약물 70개에서 shifted control, shifted treated pool, Gaussian 저차원(k=50)의 ED는 서로 0.002 이내이고 차이의 구간이 0을 포함한다. SNU-423에서도 같다.
3. 같은 shape에서 평균 예측을 무변화로 바꾸면 ED가 0.130 [0.090, 0.171] 나빠진다. 세포주 평균으로 바꾸면 0.0045 [−0.0013, 0.0106]로 구간에 0을 포함한다.
4. 대조군 0 비율을 쓰는 비음수 복원(v2)은 계획의 복원(v1)보다 모든 평균 고정 방법에서 좋다(shifted 0.248, Gaussian 약 1.85). 이는 도메인 유효성 처리의 기여다.

## 주장하지 않는 것

- **잔차 diffusion, 절대 DDPM, CellFlow의 성능에 대한 어떤 주장도 하지 않는다.** 실제 자료로 학습하지 않았다(gate G1 실패에 따른 보류이며, 실행 불가였던 것이 아니다).
- "평균 외에는 약물 특이적 분포 차이가 없다"고 주장하지 않는다. 이 표본 크기와 지표로 측정되지 않았다는 것까지다.
- 평균이 맞는다는 사실을 어떤 방법의 이득으로도 보고하지 않는다(설계상 성질).
- 대조군 → 처리군을 같은 세포의 전후로 해석하지 않는다. 서로 다른 세포 집단이다.
- HepG2/C3A를 성인 HCC로 부르지 않는다. HCC 관련 결과는 SNU-423 하나, 약물 70개에 한한다.
- 다른 용량, 다른 자료, 환자 조직, 임상적 유용성으로 일반화하지 않는다.

## 사후 pilot에 대하여 (탐색적)

- 위의 "주장하지 않는 것" 첫 항목은 **사전 계획 평가** 기준으로 유지된다. 그 뒤 사용자 승인으로 실행한 pilot([PILOT_GENERATORS.md](PILOT_GENERATORS.md))은 탐색적 결과로만 다음을 말한다:
  시험한 구성(폭 256·2 block DDPM, 유전자 공간 직접 학습의 축소 CellFlow 1개 설정)에서, 평균을 맞추고 복원 v2를 적용하면 잔차 DDPM은 shifted control보다 0.0048 [0.0025, 0.0069],
  Gaussian k=50보다 0.0031 [0.0013, 0.0051] 나빴고, 절대 DDPM과 CellFlow도 shifted control을 이기지 못했다. SNU-423도 같다.
- pilot은 gate 실패 뒤에 승인됐고 기준선의 시험 점수를 본 뒤 설계됐다. 확증 결과로 인용하지 않는다. CellFlow 수치를 CellFlow 일반의 성능으로, DDPM 수치를 diffusion 일반의 한계로 읽지 않는다.

## 한계

1. **Gate 판정의 근거가 좁다.** G1은 well이 둘 이상인 조건(약물 26개)에서만 계산되고, 재현 well의 78%가 다른 plate에 있어 plate 효과가 재현 변동에 포함된다.
   같은 plate 부분집합은 약물 8개뿐이다.
2. **평균 맞춤 ED는 유한 표본 편향이 있다.** 표본 평균으로 중심화하면 값이 음수 쪽으로 치우친다(대략 1/N). 같은 N·같은 처리끼리의 차이만 해석했다.
   원형 표와 평균 고정 표를 가로질러 비교하면 이 offset이 섞인다.
3. **주 지표와 PCA50의 결론이 한 쌍에서 다르다.** Gaussian k=50은 주 지표에서 shifted control과 같지만 PCA50에서는 나쁘다(+0.124).
4. **시험 약물은 재사용됐다.** 같은 split의 시험 점수가 이전 연구에서 보고됐다. 이번 평가는 동결 후 1회지만 완전히 새 자료는 아니다.
5. **복원 v2는 dev 결과를 보고 고친 것이다.** 사전 규칙(1회 수정, 사전 결정 기준)에 따랐고 시험에서 다시 고르지 않았지만, v1이 원래 계획이었다.
6. **기준선 추가.** shifted treated pool과 평균 종류 대조는 진단 뒤에 추가했다(실행 전 기록).
7. **평균 예측기는 약하다.** kernel ridge가 세포주 평균을 CV에서 0.3% 앞설 뿐이고 λ가 격자 끝에서 선택됐다. 더 넓은 격자는 시도하지 않았다.
8. **표본 크기.** well당 64 세포로 고정했다. 128·256 확장은 gate 실패로 하지 않았다. 표본 안정성(반분 상관 0.905)은 train 약물에서만 쟀다.
9. **2차 지표**(분산비, 0 비율, cluster TV, 공분산)는 구간 없이 평균만 보고했다.
10. **seed.** 표본추출 seed 3개만 반복했다. m_ψ·Gaussian 적합은 결정적이다. 생성 세포 파일은 seed 0 하나만 서버에 남겼다.
11. **CellFlow.** v0.0.9(commit 03bff12e)를 별도 환경에 설치해 합성 자료로만 작동을 확인했다. 라이선스는 PolyForm Noncommercial이다.
