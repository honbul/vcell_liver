# 선행연구와의 관계 (LITERATURE_GAP)

조사 기준일 2026-11-17. 아래 서술은 각 연구의 공개 초록·공식 저장소 설명 수준에서 확인한 범위에 한정한다. 원문 그림·표의 수치를 새로 추출하지 않았고,
이번 연구에서 **다시 실행한 선행 모델은 없다**(아래 CellFlow 항목 참고). 따라서 어떤 선행 모델에 대해서도 "더 좋다/나쁘다"를 말하지 않는다.

## 가장 가까운 연구와 겹치는 부분 / 다른 부분

| 연구 | 겹치는 부분 | 이번 연구에서 다른 부분 | 이번에 확인한 것 |
|---|---|---|---|
| CARD (Han et al., NeurIPS 2022, arXiv:2206.07275) | 조건부 평균 예측기와 diffusion을 결합 | — | "평균 + diffusion" 구성은 새롭지 않다. 이번에는 diffusion을 학습하지 않았다 |
| CellFlow (theislab, 2025 preprint, 공개 코드) | 개입 후 단일세포 분포를 조건부 flow로 예측 | 같은 split 재학습 비교군으로 계획 | 설치·합성자료 smoke까지만. **실제 자료 학습은 gate로 미실행**, 수치 없음 |
| PerturbDiff (ICML 2026) | 단일세포 분포를 diffusion 대상으로 구성 | — | 미실행 |
| sc2Flow (IJCAI 2026) | 단계 분리(발현 여부 → 발현량) | 여기서는 평균/형태 분리 | 미실행. 이번 복원 v2(0의 비율을 따로 정함)와 발상이 닿아 있으나 같은 방법이 아니다 |
| MRFlow (2026 preprint, arXiv:2610.13966) | 구조화된 효과 + residual 생성 | — | 미실행. "잔차형 생성"도 선행이 있다 |
| Ahlmann-Eltze et al. 2025; Systema 2025; Nat Biotechnol 2026 (보정 지표) | 단순 기준선·체계적 변동·지표 민감도 점검의 필요 | 분포 지표에 같은 점검을 적용 | 지표가 real-real과 다른 약물을 구분함을 먼저 확인(M 통과)하고, 그다음 shape 여지를 쟀다 |

## CellFlow를 실행하지 않은 정확한 사유

- 코드: `theislab/CellFlow` 릴리스 `v0.0.9`, commit `03bff12e71326742ad53a0909a4a8fee36958794`로 고정해 전용 conda 환경에 설치했다
  (Python 3.11, jax 0.10.2 + CUDA, 서버 `assets/envs/cellflow`). 라이선스는 PolyForm-Noncommercial-1.0.0이다.
- 합성 무작위 자료(세포주 20 × 약물 30, 2,000유전자, PCA 50)에서 학습 500 iteration과 **미관측 약물 fingerprint**에 대한 예측이 A30 1개에서 끝까지 돌았다
  (총 63초, JAX peak 167 MB). 이는 파이프라인이 동작한다는 것만 보여 주며 정확도 정보가 아니다.
- **실제 Tahoe 자료로는 학습하지 않았다.** 사전 지정한 gate G1(평균을 맞춘 뒤 반복 well 변동을 넘는 shape 차이)이 실패해 생성기 비교 전체를 보류했기 때문이다.
  구현 불능이나 자료 부족이 아니다. 따라서 CellFlow의 native 표와 mean-matched 표는 모두 비어 있다.

## 이번 연구가 더한 것과 더하지 못한 것

- **더한 것(이 자료·이 설정 한정):** (1) Tahoe-100M 0.5 µM, 2,000유전자, well당 약 64세포에서 "평균을 맞춘 뒤 남는 분포 차이"를 반복 well과 직접 비교한 진단.
  (2) 같은 평균·같은 세포 수에서 shifted control, 처리 세포 pool, Gaussian(대각/저차원)을 비교한 표. (3) 비음수 복원 규칙이 분포 지표에 주는 영향의 크기.
- **더하지 못한 것:** 생성 모델의 방법론적 기여. diffusion·flow 모델은 학습하지 않았으므로 "필요 없다"는 결론도 내리지 않는다.
  확인된 것은 "이 진단에서 생성기가 채울 여지가 측정되지 않았다"까지다.
- 방법 구성(평균 예측 + 분포 기준선 + 복원)은 기존 기법의 조합이며 신규성을 주장하지 않는다.
