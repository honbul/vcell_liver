## R3-0. 자산 확인과 분포 신호 진단 (D1/D2) — 2026-11-17, 실행 전 작성

- **관측:** 이전 연구의 실제 세포 표본 `tahoe_cells.h5ad`(1,256,568세포 × 2,000유전자, sha256(X)는 `manifests/chemcpa_moe_v2/anndata.json`)와
  조건표 `v2/data`는 서버에 남아 있다. `v2/raw`(중간 산물)는 2026-11-16에 삭제됐으나 이번 연구에 필요하지 않다.
  표본은 (well, 세포주)당 중앙값 63개이고, 대조군은 plate마다 DMSO well 2개(세포주당 합계 중앙값 126개)다.
  train 약물 조건 중 2,000개가량은 well이 2개 이상이다(독립 well 비교 가능).
- **가설(미검증):** 처리군 분포는 대조군을 평균만 옮긴 것과 다르고, 그 차이의 일부는 약물마다 재현된다.
- **예측:** 가설이 맞다면 train 약물에서
  (i) `정답 평균으로 옮긴 대조군 ↔ 실제 처리군`의 ED가 `같은 조건의 다른 well(평균을 맞춘 것) ↔ 실제 처리군`의 ED보다 크고,
  (ii) `다른 약물의 처리 well(평균을 맞춘 것) ↔ 실제 처리군`의 ED가 `같은 약물의 다른 well`보다 크다.
- **실험:** train 역할 약물의 유효 well 전체(48개 세포주)에서 well별로 아래를 계산한다. 모든 비교는 같은 세포 수
  `N = min(관측, 대조군, 64)`, 같은 비음수 복원. 평균을 맞출 때 쓰는 "정답 평균"은 **oracle 진단**이며 배포 방법이 아니다.
  - a: 대조군 ↔ 처리군
  - b: 정답 평균으로 옮긴 대조군 ↔ 처리군 (복원 전/후)
  - c: 처리군 split-half(같은 well; **표본추출 안정성**일 뿐 생물학적 재현성이 아님), 원본/평균 맞춤
  - d: 같은 조건의 다른 well ↔ 처리군, 원본/평균 맞춤 (같은 plate인지 기록)
  - e: 같은 세포주·같은 plate의 **다른 train 약물** well ↔ 처리군, 원본/평균 맞춤 ("shuffled")
  - f: 같은 plate·세포주의 DMSO well 1 ↔ DMSO well 2, 원본/평균 맞춤 (약물 없는 well 간 변동)
  - D2: 유전자별 분산 변화·zero fraction 변화의 well 간 재현성(같은 약물 vs 다른 약물), source 고정 k-means 상태 비율,
    library size·plate와의 관계
  - 표본 안정성(§3.1): N=32 부분표본과 N=64의 조건별 ED 차이, 집계값의 약물 블록 bootstrap 표준오차
- **결정 규칙(사전 지정, 그대로 적용):** 약물 블록 bootstrap(2,000회) 95% 구간 기준.
  - **지표 점검 M:** `e_raw − c_raw > 0`(구간이 0을 넘지 않음)이면 지표가 real-real과 shuffled를 구분한다고 본다.
    실패하면 development에서 표본 수·척도를 **한 번만** 점검한다.
  - **G1 (shape 여지):** 다중 well 조건에서 `H = b(복원 후) − d_mm`의 구간 하한 > 0 **그리고**
    `H ≥ 0.10 × (a − d_mm)` (전체 설명 가능 차이의 10% 이상이 평균 이동 뒤에도 남음).
  - **G2 (약물별 재현성):** 다중 well 조건에서 `e_mm − d_mm`의 구간 하한 > 0.
  - G1 충족 → "추가 shape 신호가 명확"으로 보고 R3-1, R3-2(생성기 prototype)로 진행한다.
    G2는 **약물 조건부** shape 주장이 가능한지를 정한다: G2 실패 시 생성기를 만들더라도 약물 조건부 이득 주장은 하지 않고,
    R3-5(약물 조건 제거 대조)에서 차이가 없을 것으로 예상한다고 미리 적는다.
  - G1 실패(평균 반응은 있음) → mean-only·shifted-control·Gaussian만 끝까지 평가하고 **생성기 주장은 보류**한다.
  - **표본 수:** 집계 ED의 bootstrap 표준오차가 `H/4`보다 작으면 64개로 진행한다. 크면 read-only 원자료에서
    hash 규칙으로 128개 확장을 검토한다(그 전에는 원자료를 다시 읽지 않는다).

읽는 법: "평균 맞춤" 값이 음수인 것은 **표본 자신의 평균으로 맞춘 oracle 진단의 유한표본 편향**(두 표본의 평균 차이가 0으로 강제됨)이며
N에 따라 크기가 달라진다(N=32에서 약 −1.6, N≈62에서 약 −0.76). 따라서 같은 N끼리의 **차이**만 해석한다.

- **M 통과:** 지표는 real-real(split-half)과 다른 약물 well을 구분한다. 표본 수·척도 재점검은 하지 않는다.
- **G1 실패:** 평균을 맞춘 대조군은 같은 조건의 다른 well만큼 실제 처리군에 가깝다(H의 구간이 0을 포함, 비율 −2%).
  같은 plate 짝으로 좁혀도 같다. PCA50에서는 대조군 쪽이 오히려 더 가깝다(−0.041 [−0.061, −0.022]).
- **G2 실패(반대 방향):** 같은 약물의 다른 well보다 같은 plate의 **다른 약물** well이 더 가깝다. 분산·zero-fraction 변화 프로파일도
  같은 약물끼리(0.13)보다 같은 plate의 다른 약물끼리(0.49) 더 닮았다.
- **관측(게이트 밖):** 같은 well을 둘로 나눈 것보다는 옮긴 대조군이 멀다(0.175). 같은 plate의 다른 약물 처리 well은 옮긴 대조군보다 0.08 가깝다.
  이 차이는 library size 차이와 함께 움직인다(상관 0.62). **가설(미검증):** 남는 차이는 약물 특이 shape가 아니라 well·plate·깊이 수준의 변동이다.
- **표본 수:** H ≤ 0이라 "SE < H/4" 조건을 적용할 대상이 없다. 64개를 늘려야 한다는 근거가 없으므로 **128/256 확장은 하지 않는다**(원자료 재독 없음).

### R3-0 결정

사전 규칙 그대로: **G1 실패 → "shape 신호가 불명확하지만 평균 반응은 있음"**. mean-only·shifted-control·Gaussian 기준선을 dev와
held-out 약물에서 끝까지 평가하고, **생성기(절대 DDPM, 잔차 DDPM) 주장은 보류한다. DDPM과 CellFlow는 실제 자료로 학습하지 않는다**
(R3-2~R3-5 미실행). 작성해 둔 `ddpm.py`는 실행되지 않은 코드로 남긴다.

## R3-1. 공통 평균 예측기와 분포 기준선 — 2026-11-17, 실행 전 작성 (R3-0의 gate 결과와 무관하게 수행)

- **관측:** 이전 연구에서 이 과제의 평균 반응은 세포주 평균·ridge가 무변화보다 조금 낫고(시험 RMSE 0.092 대 0.104), 약물별 신호는 약했다.
- **가설(미검증):** 평균 예측기는 Ridge 계열이면 충분하고, 작은 MLP가 이를 넘지 못한다.
- **예측:** train 약물 3-fold CV에서 kernel ridge와 MLP의 조건 RMSE가 세포주 평균과 비슷한 범위에 있을 것이다.
- **실험:** (a) `mean_model --mode cv`: nochange / linemean / Tanimoto kernel ridge(공유, λ 5개) / 세포주별 다중과제 kernel ridge(λ 5개) /
  작은 MLP(epoch 2개 설정). 목표는 이전 연구의 조건 평균 Δ(`Y.npy`, train 약물만). 평가·선택은 train 약물 내부 3-fold뿐.
  (b) 선택된 m_ψ를 dev 설정(8개 세포주, dev fold 0·1로 적합, fold 2 평가)에 적합하고, 같은 μ̂을 쓰는 control / mean-point /
  shifted control / Gaussian(diag) / Gaussian(저차원 k∈{10, 50})을 같은 N·같은 비음수 복원으로 채점한다. 표본추출 seed 3개.
- **결정 규칙:** CV 조건 RMSE가 가장 낮은 Ridge 계열 또는 MLP 하나를 m_ψ로 고정한다(이후 변경 없음).
  Gaussian 저차원 k는 dev ED가 낮은 쪽 하나로 고정한다. 8개 dev 세포주는 `valid train 조건 수 → 표본 세포 수 → ID` 순 메타데이터 규칙으로 정했다
  (반응 점수 미사용).

- **R3-0 이후 추가(실행 전 작성, 2026-11-17):** R3-0에서 "같은 plate의 다른 train 약물 처리 well이 옮긴 대조군보다 가깝다"는 관측이 나왔다.
  **가설(미검증):** 대조군 잔차 대신 같은 plate·세포주의 **train 약물 처리 세포 잔차**를 재사용하면 shifted control보다 낫다.
  **예측:** dev에서 `shifted_pool`의 ED가 `shifted`보다 낮다. **실험:** 기준선 하나(`shifted_pool`: 같은 (plate, 세포주)의 적합용 train 약물 well에서
  세포를 무작위로 뽑아 각자 well 평균을 뺀 잔차 + μ̂ + 같은 복원)를 추가한다. 생성 모델이 아니며 held-out 약물의 세포를 쓰지 않는다.
  **결정 규칙:** 결과와 무관하게 최종 평가에 포함한다(기준선 추가이지 선택이 아님).
