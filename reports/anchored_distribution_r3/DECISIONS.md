## R3-0. 자산 확인과 분포 신호 진단 (D1/D2) — 2026-11-17, 실행 전 작성

- **관측:** 이전 연구의 실제 세포 표본 `tahoe_cells.h5ad`(1,256,568세포 × 2,000유전자, sha256(X)는 `manifests/chemcpa_moe_v2/anndata.json`)와
  조건표 `v2/data`는 서버에 남아 있다. `v2/raw`(중간 산물)는 2026-11-16에 삭제됐으나 이번 연구에 필요하지 않다.
  표본은 (well, 세포주)당 중앙값 63개이고, 대조군은 plate마다 DMSO well 2개(세포주당 합계 중앙값 126개)다.
  train 약물 조건 중 2,000개가량은 well이 2개 이상이다(독립 well 비교 가능).
- **가설(미검증):** 처리군 분포는 대조군을 평균만 옮긴 것과 다르고, 그 차이의 일부는 약물마다 재현된다.
- **예측:** 가설이 맞다면 train 약물에서
  (i) `정답 평균으로 옮긴 대조군 ↔ 실제 처리군`의 ED가 `같은 조건의 다른 well(평균을 맞춘 것) ↔ 실제 처리군`의 ED보다 크고,
  (ii) `다른 약물의 처리 well(평균을 맞춘 것) ↔ 실제 처리군`의 ED가 `같은 약물의 다른 well`보다 크다.
- **실험:** train 역할 약물의 유효 well 전체(48개 세포주)에서 well별로 아래를 계산한다. 모든 비교는 같은 세포 수
  `N = min(관측, 대조군, 64)`, 같은 비음수 복원. 평균을 맞출 때 쓰는 "정답 평균"은 **oracle 진단**이며 배포 방법이 아니다.
  - a: 대조군 ↔ 처리군
  - b: 정답 평균으로 옮긴 대조군 ↔ 처리군 (복원 전/후)
  - c: 처리군 split-half(같은 well; **표본추출 안정성**일 뿐 생물학적 재현성이 아님), 원본/평균 맞춤
  - d: 같은 조건의 다른 well ↔ 처리군, 원본/평균 맞춤 (같은 plate인지 기록)
  - e: 같은 세포주·같은 plate의 **다른 train 약물** well ↔ 처리군, 원본/평균 맞춤 ("shuffled")
  - f: 같은 plate·세포주의 DMSO well 1 ↔ DMSO well 2, 원본/평균 맞춤 (약물 없는 well 간 변동)
  - D2: 유전자별 분산 변화·zero fraction 변화의 well 간 재현성(같은 약물 vs 다른 약물), source 고정 k-means 상태 비율,
    library size·plate와의 관계
  - 표본 안정성(§3.1): N=32 부분표본과 N=64의 조건별 ED 차이, 집계값의 약물 블록 bootstrap 표준오차
- **결정 규칙(사전 지정, 그대로 적용):** 약물 블록 bootstrap(2,000회) 95% 구간 기준.
  - **지표 점검 M:** `e_raw − c_raw > 0`(구간이 0을 넘지 않음)이면 지표가 real-real과 shuffled를 구분한다고 본다.
    실패하면 development에서 표본 수·척도를 **한 번만** 점검한다.
  - **G1 (shape 여지):** 다중 well 조건에서 `H = b(복원 후) − d_mm`의 구간 하한 > 0 **그리고**
    `H ≥ 0.10 × (a − d_mm)` (전체 설명 가능 차이의 10% 이상이 평균 이동 뒤에도 남음).
  - **G2 (약물별 재현성):** 다중 well 조건에서 `e_mm − d_mm`의 구간 하한 > 0.
  - G1 충족 → "추가 shape 신호가 명확"으로 보고 R3-1, R3-2(생성기 prototype)로 진행한다.
    G2는 **약물 조건부** shape 주장이 가능한지를 정한다: G2 실패 시 생성기를 만들더라도 약물 조건부 이득 주장은 하지 않고,
    R3-5(약물 조건 제거 대조)에서 차이가 없을 것으로 예상한다고 미리 적는다.
  - G1 실패(평균 반응은 있음) → mean-only·shifted-control·Gaussian만 끝까지 평가하고 **생성기 주장은 보류**한다.
  - **표본 수:** 집계 ED의 bootstrap 표준오차가 `H/4`보다 작으면 64개로 진행한다. 크면 read-only 원자료에서
    hash 규칙으로 128개 확장을 검토한다(그 전에는 원자료를 다시 읽지 않는다).

## R3-1. 공통 평균 예측기와 분포 기준선 — 2026-11-17, 실행 전 작성 (R3-0의 gate 결과와 무관하게 수행)

- **관측:** 이전 연구에서 이 과제의 평균 반응은 세포주 평균·ridge가 무변화보다 조금 낫고(시험 RMSE 0.092 대 0.104), 약물별 신호는 약했다.
- **가설(미검증):** 평균 예측기는 Ridge 계열이면 충분하고, 작은 MLP가 이를 넘지 못한다.
- **예측:** train 약물 3-fold CV에서 kernel ridge와 MLP의 조건 RMSE가 세포주 평균과 비슷한 범위에 있을 것이다.
- **실험:** (a) `mean_model --mode cv`: nochange / linemean / Tanimoto kernel ridge(공유, λ 5개) / 세포주별 다중과제 kernel ridge(λ 5개) /
  작은 MLP(epoch 2개 설정). 목표는 이전 연구의 조건 평균 Δ(`Y.npy`, train 약물만). 평가·선택은 train 약물 내부 3-fold뿐.
  (b) 선택된 m_ψ를 dev 설정(8개 세포주, dev fold 0·1로 적합, fold 2 평가)에 적합하고, 같은 μ̂을 쓰는 control / mean-point /
  shifted control / Gaussian(diag) / Gaussian(저차원 k∈{10, 50})을 같은 N·같은 비음수 복원으로 채점한다. 표본추출 seed 3개.
- **결정 규칙:** CV 조건 RMSE가 가장 낮은 Ridge 계열 또는 MLP 하나를 m_ψ로 고정한다(이후 변경 없음).
  Gaussian 저차원 k는 dev ED가 낮은 쪽 하나로 고정한다. 8개 dev 세포주는 `valid train 조건 수 → 표본 세포 수 → ID` 순 메타데이터 규칙으로 정했다
  (반응 점수 미사용).

- **R3-0 이후 추가(실행 전 작성, 2026-11-17):** R3-0에서 "같은 plate의 다른 train 약물 처리 well이 옮긴 대조군보다 가깝다"는 관측이 나왔다.
  **가설(미검증):** 대조군 잔차 대신 같은 plate·세포주의 **train 약물 처리 세포 잔차**를 재사용하면 shifted control보다 낫다.
  **예측:** dev에서 `shifted_pool`의 ED가 `shifted`보다 낮다. **실험:** 기준선 하나(`shifted_pool`: 같은 (plate, 세포주)의 적합용 train 약물 well에서
  세포를 무작위로 뽑아 각자 well 평균을 뺀 잔차 + μ̂ + 같은 복원)를 추가한다. 생성 모델이 아니며 held-out 약물의 세포를 쓰지 않는다.
  **결정 규칙:** 결과와 무관하게 최종 평가에 포함한다(기준선 추가이지 선택이 아님).

## Cycle 1. 비음수 복원 수정 (계획 §5.6의 1회 수정) — 2026-11-17, 실행 전 작성

- **관측:** 위 (2)(3). 복원 v1(`mean max(v+a,0)=μ̂`)은 희소 유전자에서 값을 대량으로 0에 붙이거나(0이 아니어야 할 세포), 양의 shift에서는
  0을 전부 없앤다. 과도한 clipping이 dev에서 확인됐다.
- **가설(미검증):** 0의 비율을 대조군에서 가져오면(허용된 입력: 같은 plate·세포주 대조군 통계) 평균을 맞추면서 분산 손실이 줄어든다.
- **예측:** dev에서 복원 v2의 ED가 v1보다 shifted control과 Gaussian 모두에서 낮고, zero fraction 오차와 분산비가 개선된다.
- **실험(하나만 변경):** 복원 v2 = 유전자마다 생성값이 가장 작은 `round(π_ctrl·n)`개 세포를 0으로 두고(π_ctrl = 같은 plate·세포주 대조군 표본의 0 비율),
  나머지 세포에만 v1과 같은 1차원 탐색 `mean max(v+a,0)=max(μ̂,0)`을 적용. 처리군 통계는 쓰지 않는다. 모든 평균 고정 방법에 동일 적용.
  Gaussian k, 평균 예측기, N, 지표는 그대로. 함께 "shifted + 무변화 평균", "shifted + 세포주 평균" 대조를 같은 실행에 넣는다(선택 대상 아님).
- **결정 규칙:** shifted control과 Gaussian(저차원) **둘 다**에서 `ED(v2) − ED(v1)`의 약물 블록 bootstrap 95% 구간 상한 < 0이면 v2를 공통 복원으로 동결한다.
  아니면 v1을 유지한다. 어느 쪽이든 최종 보고에는 복원 전 / v1 / v2를 모두 싣는다. 복원 수정은 이 한 번으로 끝낸다.
  Gaussian 저차원 k는 dev ED가 같으므로(−0.110) PCA50 민감도가 더 낮은 k=50으로 고정한다.

# 사용자 승인 사후 pilot: 생성기(DDPM·CellFlow) 학습 — 2026-11-17, 실행 전 작성

**먼저 밝힘.** 사전 지정 gate G1은 실패했고, 계획 규칙에 따라 생성기 주장은 보류된 채 위 R3-6까지 보고가 끝났다. 아래 pilot은 그 **뒤에** 사용자가 별도로 승인해서
(조율 에이전트를 통해 전달받음) 실행하는 탐색적 실험이다. 사전 계획된 확증 시험이 아니며 그렇게 제시하지 않는다. 위의 gate 결정, 기준선 표, 첫 동결(`freeze_manifest.json`, commit 628e454)은 바꾸지 않는다.
또한 기준선의 시험 약물 점수를 **이미 본 뒤에** pilot 모델을 설계한다. 따라서 pilot의 held-out 평가는 재사용 벤치마크를 두 번째로 보는 것이다.

- **관측:** G1 = −0.023 [−0.073, 0.025], G2 = −0.069 [−0.116, −0.028]. 시험 약물에서 shifted control, shifted treated pool, Gaussian k=50은 서로 0.002 이내였다.
- **가설(미검증):** 평균을 고정한 뒤에는 학습된 생성기가 대조군 흩어짐 재사용이나 Gaussian보다 실제 처리 세포에 더 가까운 집단을 만들지 못한다.
- **예측(G1이 함의하는 것):** 평균 고정 표에서 `잔차 DDPM − shifted control`과 `잔차 DDPM − Gaussian k=50`(복원 v2)은 0 이상이거나 구간에 0을 포함한다.
  절대 DDPM과 CellFlow도 평균을 맞추면 shifted control을 이기지 못한다. 원형 표에서는 평균 오차만큼 더 나쁘다.
- **실험 (계획 R3-2 이후, 원래 예산 안에서):**
  1. *개발(train 약물만, 같은 세포주 8개·같은 fold; fold 0·1 적합, fold 2 채점).* 폭 256, 2 block, FiLM 조건, v-prediction, cosine schedule, 20,000 step, 표본추출 100 step, 학습 seed 0.
     잔차 DDPM: LR {1e-3, 3e-4} × scale {train 잔차 scale, 대조군 분산 scale} = 4개. 절대 DDPM: LR {1e-3, 3e-4} 2개(scale은 전체 SD 하나뿐).
     context는 (대조군 평균, 대조군 log 분산, ECFP4). 모든 평균 고정 방법에 같은 m_ψ, 같은 N, 같은 유전자 척도, 동결된 복원 v2.
  2. *선택 규칙.* 잔차 DDPM은 dev ED(복원 v2)가 가장 낮은 설정, 절대 DDPM은 dev 원형 ED가 가장 낮은 설정. 최종 후보는 이 2개뿐이다.
  3. *개선 cycle.* 계획의 두 cycle 중 하나는 이미 복원 규칙(v2)에 썼다. 남은 것은 cycle 2(early conditioning 또는 self-conditioning 중 하나)인데,
     그 전제는 "조건에 따른 생성 변화가 너무 작고 **실측 차이는 확실**"이다. G2가 실측 약물별 차이를 확인하지 못했으므로 이 전제가 충족되지 않는다. **cycle 2는 쓰지 않는다.**
  4. *CellFlow.* v0.0.9(commit 03bff12e) 고정, 같은 split·같은 유전자·같은 세포로 재학습, 설정 1개(dev 점수로 튜닝하지 않음), 학습 seed 1개.
     ECFP adapter와 입력 표현은 `PILOT_GENERATORS.md`에 기록한다. 학습이 안 되면 정확한 이유를 적고 수치를 비운다.
  5. *귀속 대조.* dev에서 `잔차 DDPM − shifted`와 `잔차 DDPM − Gaussian k=50`(v2)의 구간 상한이 둘 다 0 미만이면 late-concat, 약물 조건 제거 모델을 같은 설정으로 학습해 동결에 포함한다.
     이득이 시험에서만 나타나면 귀속 대조를 사후에 실행하고 사후임을 표시한다. 이득이 없으면 학습하지 않는다.
  6. *held-out.* 두 번째 동결 기록(`freeze_manifest_pilot.json`: pilot 설정 + 코드 commit)을 push한 뒤, 전체 train 약물 209개·48개 세포주로 재학습한 모델을 같은 시험 약물 70개에서 **한 번** 채점한다.
     DDPM 후보 2개는 학습 seed 3 × 표본추출 seed 3, 약물 블록 bootstrap, 전체 세포주와 SNU-423 분리. 지표 코드는 그대로다.
- **결정 규칙:** 원형 표와 평균 고정 표를 분리한다. 평균 고정 표에서 생성기가 shifted control·Gaussian보다 좋지 않으면 **이 구성에 한정된 완결된 negative**로 보고한다.
  좋다면 귀속 대조 전에는 어떤 주장도 하지 않는다. 범위 확장(새 자료·용량·세포주, 128/256 세포)은 하지 않는다. 어느 쪽이든 탐색적 결과로만 표기한다.
