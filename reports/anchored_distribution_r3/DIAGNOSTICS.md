# R3 진단 (R3-0): 평균 이동 말고도 예측할 분포 차이가 있는가

실행: Slurm 24444 (A30 1개, 770초), 코드 `src/anchored_distribution_r3/diagnostics.py`, commit `acb2997`.
원자료: `tables/d1_summary.json`, `tables/d1_wells_train.tsv.gz`(well별), `tables/d1_ctrl_wells.tsv`. 그림: `figures/fig1_gate_diagnostics.png`.
사전 규칙과 결정은 [DECISIONS.md](DECISIONS.md)의 R3-0에 있다. 이 문서는 무엇을 재었고 어떻게 읽는지를 설명한다.

## 1. 쓴 자료

- train 역할 약물만 사용했다(유효 well이 있는 구조 그룹 208개, 조건 9,883개, well 11,461개, 세포주 48개). validation·test 약물의 처리 세포는 읽지 않았다.
- 세포는 이전 연구의 실제 세포 표본 그대로다(복제·잡음 추가 없음). well마다 barcode hash 순서로 앞에서부터 `N = min(관측, 대조군, 64)`개를 썼다
  (N 중앙값 64, 최소 33; N<32인 well 5개 제외).
- 대조군은 같은 plate·같은 세포주의 DMSO 세포다(plate마다 DMSO well 2개). 대조군과 처리군은 서로 다른 세포다.
- 지표: Energy distance, U-통계량, clip 없음. 유전자 2,000개를 train well 내부 표준편차(하위 10% 분위수로 바닥)로 나눈 공간.

## 2. 무엇을 비교했나

| 기호 | 비교 | 뜻 |
|---|---|---|
| a | 대조군 ↔ 처리군 | 아무것도 예측하지 않을 때의 거리 |
| b | 처리군의 **실제** 평균으로 옮긴 대조군 ↔ 처리군 | 평균을 완벽히 맞춰도 남는 차이 (oracle 진단, 배포 방법 아님) |
| c | 같은 well의 세포를 둘로 나눔 | 표본추출 변동(생물학적 재현성이 아님) |
| d | 같은 조건의 **다른 well** ↔ 처리군 | 실험을 다시 했을 때의 변동 |
| e | 같은 plate·세포주의 **다른 약물** well ↔ 처리군 | 약물을 섞었을 때 |
| f | 같은 plate의 DMSO well 1 ↔ well 2 | 약물 없이도 생기는 well 간 변동 |

`_mm`은 왼쪽 집단을 오른쪽 집단의 표본 평균으로 옮기고 비음수 복원을 한 뒤 잰 값이다.

## 3. 결과

| 양 | 값 [약물 블록 bootstrap 95%] |
|---|---|
| a | 0.605 [0.504, 0.724] |
| c (raw) | −0.001 [−0.004, 0.002] |
| e (raw) | 0.687 [0.602, 0.790] |
| **M** = e_raw − c_raw | 0.688 [0.603, 0.791] → 통과 |
| 다중 well 조건: b / d_mm / e_mm | −0.703 / −0.680 / −0.749 |
| **G1** = b − d_mm | −0.023 [−0.073, 0.025] → **실패** |
| G1 비율 = (b − d_mm)/(a − d_mm) | −0.021 [−0.068, 0.022] (기준 0.10 이상) |
| **G2** = e_mm − d_mm | −0.069 [−0.116, −0.028] → **실패(반대 방향)** |
| 전체 well: b_half − c_mm (같은 N=32) | 0.175 [0.130, 0.220] |
| DMSO well 쌍 239개: f_raw / f_mm | 0.170 / −0.759 |

다중 well 조건은 약물 26개, well 2,820개이고 짝 well의 78%는 다른 plate에 있다. 같은 plate 짝만 보면(약물 8개) G1 = −0.016 [−0.093, 0.071].

### 읽는 법과 주의

- **평균을 맞춘 값이 음수인 이유.** 한 표본을 다른 표본의 평균으로 정확히 옮기면 두 표본의 평균 차이가 0으로 강제되어, 불편추정량이
  음수 쪽으로 치우친다. 크기는 N에 반비례한다(N=32에서 약 −1.6). 그래서 **같은 N끼리의 차이만** 해석했다. 이것은 진단의 성질이며 숨기지 않았다.
- **G1.** 평균을 맞춘 대조군은 "같은 약물의 다른 well"만큼 처리군에 가깝다. 즉 평균을 맞춘 뒤 남는 차이는 실험을 반복했을 때의 변동 크기를 넘지 않았다.
- **G2.** 같은 약물의 다른 well보다 같은 plate의 다른 약물 well이 더 가깝다. 유전자별 분산 변화 프로파일도 같은 약물끼리(상관 0.13)보다
  같은 plate의 다른 약물끼리(0.49) 더 닮았다. 이 자료에서 평균을 뺀 뒤의 분포 모양은 약물보다 plate·well에 더 따라간다.
- **split-half와의 차이(0.175)**는 0이 아니다. 같은 well 안에서 세포를 나눈 것보다는 옮긴 대조군이 멀다. 다만 이것은 well 간 변동과 구분되지 않는다
  (독립 well과의 차이가 0을 포함).

## 4. library size·plate와의 관계

- 처리 well과 대조군의 library size 중앙값 로그 차이: 5%–95% 분위수 −0.51 ~ +0.32.
- well별 b와 |Δlog library size|의 상관 0.62, a와는 0.45. 총분산 비(처리/대조)의 로그와 Δlog library size의 상관 −0.88.
- plate별 평균 b: plate11 −0.76, plate13 −0.66, **plate2 −0.33**, plate5 −0.61, plate8 −0.73. plate2는 Δlog library size 평균이 −0.25로 가장 크다.

**관측**은 "남는 분포 차이가 세포당 읽은 양(depth)의 차이와 함께 움직인다"까지다. 그것이 기술적 변동인지 약물이 만든 RNA 총량 변화인지는
이 자료만으로 구분하지 못했다(**미검증**). 따라서 "관측 분포 변화"라고만 부른다. 처리군의 library size는 시험 약물의 처리군 통계이므로 어떤 방법의 입력에도 넣지 않았다.

## 5. 표본 수(계획 §3.1)

- 조건별 b를 N=32 두 반쪽으로 따로 계산했을 때 상관 0.905, 두 반쪽 차이의 표준편차 0.19(조건 간 표준편차 0.36).
- 집계값의 약물 블록 bootstrap 표준오차 0.022.
- G1의 여지 H가 0 이하이므로 "지표 변동이 방법 차이보다 큰가"를 따질 방법 차이 자체가 확인되지 않았다. 128/256 확장의 근거가 없어 **원자료를 다시 읽지 않았다.**

## 6. 결정

G1 실패 → 계획 §4의 둘째 갈래: **평균 반응은 있으나 추가 shape 신호가 불명확**. mean-only·shifted control·Gaussian을 끝까지 평가하고 생성기 주장은 보류했다.

## 7. 이 진단이 말하지 않는 것

- 다중 well 조건은 약물 26개뿐이고 무작위 표본이 아니다(여러 well에 놓인 약물). 전체 208개 약물로 일반화한 값이 아니다.
- 0.5 µM 한 용량, 2,000유전자 panel, (well, 세포주)당 세포 약 64개에서의 결과다. 더 높은 용량이나 더 많은 세포에서 shape 신호가 없다고 말하지 않는다.
- Energy distance가 보지 못하는 분포 차이(예: 소수 세포 아집단)는 여기서 검사되지 않았다. 보조로 본 k-means 상태 비율(TV 거리 0.10)은 기준 비교 없이 값만 기록했다.
