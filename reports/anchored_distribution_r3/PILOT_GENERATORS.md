# R3 사용자 승인 사후 pilot: 생성기(DDPM·CellFlow) — 탐색적 결과

2026-11-17.

## 0. 먼저 읽을 것

- 사전 지정 gate G1은 **실패**했고, 계획 규칙에 따라 생성기 주장은 보류된 채 본 연구가 끝났다([RESULTS.md](RESULTS.md)). 그 결정과 기준선 표, 첫 동결(commit 628e454)은 그대로다.
- 이 pilot은 그 **뒤에** 사용자가 별도로 승인해(조율 에이전트를 통해 전달받음) 실행한 **탐색적** 실험이다. 사전 계획된 확증 시험으로 제시할 수 없다.
- 기준선의 시험 약물 점수를 이미 본 뒤에 pilot 모델을 설계했다. 따라서 held-out 평가는 **재사용 공개 벤치마크를 두 번째로 본 것**이다.
- 실행 전 기록(관측·가설·예측·실험·결정 규칙), dev 결과와 선택은 [DECISIONS.md](DECISIONS.md)의 "사용자 승인 사후 pilot" 절에 있다.
  두 번째 동결 기록은 `manifests/anchored_distribution_r3/freeze_manifest_pilot.json`(코드 commit d8ca980, 평가 코드 해시는 첫 동결과 동일)이며 held-out 작업 제출 전에 push했다.

**한 줄 결론.** 평균을 맞춘 조건(같은 m_ψ, 같은 N, 복원 v2)에서 잔차 DDPM, 절대 DDPM, CellFlow 어느 것도 shifted control이나 Gaussian k=50보다 좋지 않았다.
G1이 함의한 예측과 같은 방향이다. 이 구성에 한정된 negative이며, 귀속 대조는 조건이 충족되지 않아 실행하지 않았다.

## 2. 모델과 공통 조건

- **잔차 DDPM(제안 형태):** 처리 세포에서 자기 well 평균을 빼고 train 잔차 scale로 나눈 값을 생성. 폭 256, 2 block, FiLM 조건, v-prediction, cosine schedule, 20,000 step, 표본추출 100 step, 파라미터 4.43M.
  context = (같은 plate·세포주 대조군 평균, 대조군 log 분산, ECFP4). 생성 뒤 표본 평균을 빼고 공통 μ̂를 더한다.
- **절대 DDPM(일반 조건부 DDPM):** 같은 denoiser·context·학습량으로 절대 발현(전체 평균·SD 표준화)을 생성. 원형 출력과, 평균을 μ̂로 바꾼 진단을 따로 채점.
- **CellFlow v0.0.9 (commit 03bff12e):** 같은 train 약물·같은 세포·같은 유전자로 재학습. adapter(`src/anchored_distribution_r3/cellflow_adapter.py`):
  튜토리얼의 PCA 잠재공간 대신 **유전자 2,000개를 직접** 입력(`sample_rep="X"`), 약물 조건은 2048-bit ECFP4, 세포주는 one-hot, source는 같은 plate·세포주 DMSO 세포,
  OT flow matching, 라이브러리 기본값보다 **줄인 네트워크**, 설정 1개(dev 점수로 튜닝하지 않음), 학습 seed 1개, 가중치는 저장하지 않음. 평가 well마다 그 plate·세포주의 대조군 n개를 source로 쓴다.
- **공통:** 평균 예측기 m_ψ, `N = min(관측, 대조군, 64)`, 유전자 척도, 복원 v2, 지표 코드는 본 연구와 동일하다(평가 소스 해시가 첫 동결과 같음을 `freeze_pilot.py`가 확인).
  시험 약물 처리군의 통계는 어느 생성기의 입력·복원에도 들어가지 않는다.
- **쓰지 않은 것:** 개선 cycle(계획의 두 번 중 한 번은 이미 복원 v2에 썼고, cycle 2의 전제 "실측 약물별 차이가 확실"은 G2로 확인되지 않았다), 귀속 대조(late-concat, 약물 조건 제거), 128/256 세포 확장.

## 6. 관측 / 가설 / 미검증

**관측**
1. 평균 고정 + 복원 v2에서 잔차 DDPM은 shifted control보다 0.0048, Gaussian k=50보다 0.0031 나쁘다(구간이 0을 포함하지 않음). 실행 전 예측("0 이상이거나 0 포함")과 일치한다.
2. dev에서 본 "잔차 DDPM이 shifted control보다 0.004 좋음"은 held-out에서 **부호가 바뀌었다**(+0.0048). dev의 `Gaussian − shifted`(−0.007)가 held-out에서 재현되지 않은 것과 같은 양상이다.
3. 차이의 크기는 모두 0.01 미만으로, 평균 예측(0.130)이나 복원 규칙(0.248)의 효과보다 한두 자릿수 작다.
4. 복원 v2 뒤에는 생성기 종류와 무관하게 값이 거의 같아진다(잔차 DDPM −0.066, 절대 DDPM −0.067, CellFlow −0.070, shifted −0.071). 복원 전·v1에서는 생성기가 기준선보다 뚜렷하게 나쁘다.
5. 원형 출력에서 절대 DDPM과 CellFlow는 대조군 세포 그대로보다 나쁘다. 음수 값이 약 29%이고 분산이 작다(0.57, 0.81).
6. 주 지표에서 구간이 0을 포함한 CellFlow(평균 고정)도 PCA50에서는 shifted control보다 나쁘다(+0.087).

**가설 (확인하지 않음)**
- 연속 Gaussian 잡음에서 출발하는 생성기는 값의 74%가 0인 log 발현의 0/비0 구조를 재현하지 못하고, 복원 v2가 그 구조를 대조군에서 가져와 덮어쓴다. 그래서 v2 뒤에는 생성기의 차이가 사라진다.
- 평균 고정 뒤 남는 well 간 차이가 약물 특이적이지 않다면(G1·G2), 약물 조건을 받는 생성기가 얻을 것이 없다.

**미검증**
- 더 큰 모델, 더 긴 학습, count 기반 likelihood나 0을 직접 다루는 decoder, PCA 잠재공간 CellFlow(튜토리얼 설정), 원래 크기의 CellFlow 네트워크, CellFlow 학습 seed 반복.
- 세포 수가 더 많거나 다른 지표·용량·자료에서의 결과.
- 귀속 대조(late-concat, 약물 조건 제거): 이득이 없어 실행하지 않았으므로 "조건이 block마다 필요한가", "shape가 약물별로 달라야 하는가"에는 답하지 않는다.

## 7. 계획 §10 표 적용 (pilot 기준, 탐색적)

| 행 | 적용 |
|---|---|
| 잔차 diffusion이 Gaussian·shifted를 이기고 약물 조건 제거 시 이득 소실 | **해당 없음** — 이기지 못했다 |
| Gaussian과 같음 → 공분산 모형이면 충분할 수 있음 | **부분 해당** — 잔차 DDPM은 Gaussian보다 0.003 나쁘고, Gaussian은 shifted control과 구별되지 않는다. 이 구성에서는 대조군 흩어짐 재사용으로 충분했다 |
| 후처리를 적용한 모든 모델이 같이 좋아짐 | **해당** — v1 → v2에서 생성기 포함 모든 방법이 함께 좋아지고 값이 수렴한다. 도메인 유효성 처리의 기여다 |
| source는 좋고 SNU-423 실패 | 해당 없음 — 같은 방향 |
| 실제-실제와 모델-실제 차이를 구별 못함 | 진단 단계에서 해당(G1), 변동 없음 |

## 8. 한계와 계획 대비 달라진 점

1. **탐색적·사후.** gate 실패 뒤 승인된 실행이고, 시험 약물을 두 번째로 본 것이다. 확증 결과로 인용할 수 없다.
2. **CellFlow는 한 설정·한 학습 seed.** 유전자 공간 직접 학습, 줄인 네트워크, 120,000 iter라는 이 adapter의 결과다. dev(60,000 iter)에서는 분산이 0.20으로 붕괴했고 held-out 학습(120,000 iter, 자료 약 9배)에서는 0.81이었다.
   학습량에 민감하다는 뜻이며, CellFlow 일반의 성능이나 "최신 모델 대비 우위/열위"로 읽으면 안 된다. 평균 고정 CellFlow는 수정 후 평가이지 CellFlow의 정식 출력이 아니다.
3. **DDPM은 계획의 최소 규모**(폭 256, 2 block, 20,000 step)이고 개선 cycle을 쓰지 않았다. 원형 절대 DDPM의 나쁜 점수는 이 규모·이 표현(Gaussian 확산, 0 구조 미처리)의 결과다.
4. dev 격자는 학습 seed 1개다. 네 잔차 설정의 차이(0.0006)는 seed 변동과 구별되지 않으므로 선택된 설정이 "더 좋다"고 볼 근거는 없다.
5. 절대 DDPM의 LR 격자는 2개다(scale 설정이 하나뿐이라 계획의 2×2 대신 2개).
6. 생성 세포는 CellFlow 원형 출력(npz)만 서버에 남겼다. DDPM은 모델 파일을 남겼고 생성 세포는 저장하지 않았다(seed가 고정돼 재생성 가능).
7. 2차 지표(분산비, 0 비율, cluster TV)는 구간 없이 평균만 보고한다.
