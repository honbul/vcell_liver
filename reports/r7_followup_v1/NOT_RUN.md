# 실행하지 않은 것 (NOT_RUN)

이 목록의 어떤 항목에도 추정 성능을 적지 않는다. "실행하지 않음"은 결과가 아니다.

## 1. §10/§11 분기 중 실행하지 않은 것

| 분기 | 실행 여부 | 이유 (근거: `DECISIONS.md` F-1, `manifests/r7_followup_v1/d3_decision_inputs.json`) |
|---|---|---|
| F1 target-set pooling 대 graph | 실행 안 함 | 1행 조건(CI\*(GR−M) < 0 그리고 CI\*(GR−GS) < 0) 불성립. 실제 표적의 추가 가치가 확인되지 않아 전달 구조 비교의 전제가 없다 |
| F3 보정량 수축(α grid, metadata 수축 함수) | 실행 안 함 | 4행 불성립: GR−C는 0보다 나쁘지 않고(−0.00083 [−0.00126, −0.00037]), 보정 크기 상위 1/3에서도 GR−C < 0 |
| F4 도달 가능 여부 gate, 3-hop 경로 profile | 실행 안 함 | 5행 불성립: K1∪K2에서 GR−M, GR−GS의 95% 구간이 0 아래가 아님 |
| 6행 "모델 추가 없는 점검" | 분기로는 실행 안 함 | 6행 불성립(두 핵심 동시 구간 하한이 −0.001보다 큼). 같은 종류의 표(학습곡선, 양성 대조, 효과 범위)는 D3 산출물로 이미 있다 |
| F2 표적 유래 보정(TD/TDS) | **실행함** | 2행 + F2 진입 조건 (a)(b)(c) 충족. 결과: 종료 조건(TD−TDS 동시 구간이 0 포함), `RESULTS.md` §5 |

분기는 사전 규칙대로 하나만 실행했다. F2 결과를 보고 다른 분기를 추가하지 않는다.

## 2. 계획 범위 안이지만 하지 않은 것

| 항목 | 이유 |
|---|---|
| F2 종료 뒤의 추가 수정(차분 구조 변형, M 확장·튜닝, 다른 분기) | 사전 규칙상 F2가 유일한 분기이고 종료 조건이 성립했다. "자동 연장"을 하지 않는다 |
| F2 이후 M을 "후속 채택 모델"로 다시 학습하거나 test로 비교 확장 | M은 이미 D3·동결 목록에 있는 대조다. 유지 모델로 적었을 뿐 새 실험을 하지 않았다 |
| 전역 simple-graph rewiring null의 새 버전 | §9.1에서 "필요하면" 만드는 항목. F1·F4가 실행되지 않아 필요가 생기지 않았다. 원 rewiring의 감사(`rewiring_audit.tsv`)만 남겼다 |
| 한 묶음을 확률 0.5로 통째로 가리는 새 masking stress test | 원 masking의 실현 비율만 감사했다(`realized_masking*.tsv`). 새 stress 평가는 어느 결정에도 필요하지 않았다 |
| 기전군(mechanism-class) retrieval | 보조 항목. 정의를 사전에 고정하지 않았으므로 사후에 만들지 않았다 |
| 추가 null mapping(> 3개), formal permutation p | 사전 고정 범위가 mapping 3개다. 세 mapping으로 permutation p를 주장하지 않는다 |
| epoch 연장 | 학습곡선에서 구체적 미수렴 근거가 없었다(best가 마지막 평가인 run: GR 1/9, G0 1/9, GS 4/27, M 0/9) |
| 독립 확인 자료(미열람 새 반복·새 plate) | 확보하지 않았다. 결론 범위는 내부 재분할 안정성과 기존 benchmark 후속 평가로 제한한다 |
| XPert와의 비교 | 후속 연구 범위 밖. 원 R7 연구가 다룬다. 외부 모델 대비 우월성은 주장하지 않는다 |
| R6 후속 | 다른 트랙(별도 세션) |

## 3. 원 R7 실행 관련

- 원 R7 최종 test 점수, 원 연구의 RESULTS/CLAIMS 문서 내용은 후속 작업 중 읽지 않았다. 원 최종 평가 디렉터리는 **존재 여부만** 확인했다(`STATUS_CURRENT_RUN.md`).
