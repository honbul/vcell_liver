# R7 후속 연구 — 쉬운 요약

## 무엇을 물었나

R7 모델은 새 약물을 세포에 넣었을 때 유전자 978개의 발현 변화를 예측한다. 기본 예측(약물 구조 + 처리 전 세포 상태)에, 공개 데이터베이스의 "이 약물은 어떤 단백질(표적)에 붙는다"는 정보와 유전자 관계 그래프를 이용한 **보정**을 더한다. 원 연구에서는 이 보정을 넣으면 오차가 조금 줄었다.

이번 질문: **그 개선이 정말 "올바른 표적 정보" 덕분인가, 아니면 보정 모듈이 추가로 생긴 덕분(더 많은 조절 손잡이)인가?**

## 어떻게 시험했나

- 원래 학습용 약물 5,802개를 셋으로 나눠, 돌아가며 둘로 학습하고 하나로 채점했다(모든 모델을 매번 처음부터 다시 학습).
- 같은 기본 예측 위에 다섯 가지를 비교했다.
  - C: 보정 없음(기준)
  - M: 표적 이름은 모르고 "주석이 있는지, 표적이 몇 개인지" 같은 요약 정보만 쓰는 보정
  - G0: 같은 그래프 보정이지만 표적 정보를 비움
  - GS: 같은 그래프 보정이지만 **표적을 다른 약물의 것과 무작위로 바꿔 줌**
  - GR: 실제 표적을 쓰는 원래 보정
- 실제 표적(GR)이 **M과 GS를 둘 다** 이겨야 "표적 정보가 도움이 된다"고 말하기로 미리 정했다.

## 무엇이 나왔나 (오차, 낮을수록 좋음)

| 모델 | 오차 |
|---|---:|
| C 보정 없음 | 0.6288 |
| G0 표적 비움 | 0.6280 |
| GR 실제 표적 | 0.6280 |
| GS 엉뚱한 표적 | 0.6279 |
| M 요약 정보만 | **0.6276** |

- 보정을 넣으면 C보다 조금 좋아진다. 그런데 **표적을 비우거나 엉뚱한 표적을 줘도 거의 똑같이 좋아진다.** 요약 정보만 쓰는 M이 오히려 약간 더 좋았다.
- 그래서 원 연구의 작은 개선은 "올바른 표적" 때문이라기보다 "보정 모듈이 추가된 것" 또는 "주석이 있다는 사실" 때문으로 보인다.
- 실험의 정밀도로 보면, 실제 표적이 대조군보다 운영 기준(0.001) 이상 좋을 가능성은 배제된다.
- 같은 데이터를 둘로 나눈 반복 측정끼리는 모델보다 훨씬 잘 맞았다. 즉 데이터에는 아직 예측하지 못한 약물별 차이가 남아 있다.

## 주의할 점

- 결론은 이 데이터(CMap LINCS, 10 µM·24 시간), 이 표적 데이터베이스, 이 그래프 구조에 한정된다. "약물 표적 지식은 쓸모없다"는 뜻이 아니다.
- 학습용 약물을 나눠서 한 평가와, 이미 다른 연구에서 열린 공개 시험 자료에서의 재평가다. 처음 보는 독립 자료로 확인한 것은 아니다.
- 간암 세포주 3개(HUH7, JHH5, JHH7)의 결과는 보고만 했고, 그 결과로 아무것도 조정하지 않았다.
- 모델 안의 보정 크기나 차이는 모델의 계산 성질이다. 약물이 실제로 세포에서 어떻게 작용하는지를 보여주는 것이 아니다.
