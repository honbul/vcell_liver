# R7 후속 연구 결과 (RESULTS) — target attribution v1

후속 버전 `followup-v1`의 결과다. 원 R7 연구의 결론·동결·최종 평가와는 별개다. 모든 수치는 이 브랜치의 표에서 옮겼고, 표 경로를 함께 적는다(`manifests/r7_followup_v1/` 생략). 차이는 `candidate − comparator`, 음수가 개선이다. 운영 기준은 원 연구의 절대 ΔRMSE 0.001이며 생물학적 임계값이 아니다.

## 0. 한 줄 결론

**음성(완료된 음성 결과).** source out-of-fold에서 실제 표적을 쓰는 graph 보정(GR)은 backbone(C)보다 오차가 작았지만(−0.00083), 그 이득은 주석 상태만 쓰는 보정(M), 표적을 비운 같은 graph(G0), 표적을 재배정한 같은 graph(GS)에서도 같은 크기로 나왔다. 핵심 대비 GR−M +0.00039 [동시 −0.00022, 0.00103], GR−GS +0.00005 [동시 −0.00007, 0.00018]. 사전 규칙의 2행에 따라 실행한 분기 F2(표적 유래 보정만 남기는 차분 구조)에서도 실제−재배정 차이가 없었다(TD−TDS −0.00001 [동시 −0.00018, 0.00017]). 원 test의 1회 후속 평가도 같은 방향이었다. 결론: 이 자료·주석·그래프·학습 조건에서 **실제 약물–표적 대응의 추가 예측 가치는 확인되지 않았고**, 관측된 작은 개선은 추가 보정 용량·주석 상태로 설명 가능하다(§11.6 "generic 보정만 유효").

## 1. 무엇을 넣어 무엇을 예측했는가 (§13.4-1)

- 한 예시 = (세포주, 약물 그룹). 입력: 처리 전 RNA(X0, 978 landmark), 약물 구조(ECFP4), 공개 DB의 약물–표적 주석과 지식 그래프. 정답: CMap LINCS 2020 Level 3, 10 µM·24 h의 실측 평균 ΔRNA(978 landmark).
- 모형: `Δ̂ = Δ̂_chem + m_available · r`. 주석 없는 약물(K0)은 모든 arm에서 backbone과 같은 출력이다(구조적 결과, OOF에서 최대 차이 < 1e-5).
- 평가: 원 **train** 약물 5,802 그룹을 3-fold로 다시 나눈 source out-of-fold(내부 재분할 평가). fold마다 backbone부터 모든 모델을 다시 적합했다. 원 test는 후속 설정 동결 뒤 1회만 "기존 benchmark 후속 평가"로 열었다(§6).

## 2. 사실의 종류

| 종류 | 내용 |

| 미확인 범위 | 독립 자료에서의 확인, 다른 주석 DB·다른 출력 축·다른 dose/time, HCC 일반화, 외부 모델(XPert) 대비 |

## 3. 진단 D1–D2

### D1 (label-free, `target_reachability.tsv`, `k_group_counts.tsv`, `d1_summary.json`)
- 지식 그래프 4,696 노드·63,234 edge. 표적 노드 2,453개 중 landmark 275, landmark 밖이지만 실제 계산 경로(방향 edge, 2 block)로 2-hop 안에 landmark에 닿는 것 1,065, 닿지 못하는 것 1,113.
- 원 train 약물 그룹: K0 3,451 / K1 770 / K2 1,168 / K3 413 (주석 그룹 중 K3 17.6%). test: K0 778 / K1 144 / K2 248 / K3 73.
- 원 "50% masking"의 실제 가림 비율(`realized_masking_summary.tsv`): 주석 그룹의 34–37%는 표적 묶음이 하나라 block masking에서 아무것도 가려지지 않음; 평균 block 제거 비율 0.33–0.35(다중 묶음 그룹만 0.52–0.53).
- `evidence_off`는 약물–표적 seed feature 9개만 바꾼다(`evidence_feature_audit.tsv`). graph edge provenance 제거가 아니다.
- 원 rewiring은 relation별 in/out-degree를 보존하고 typed edge의 11.5%를 원래대로 남기며, self-loop 64개·중복 typed edge 3,037개를 만든다(`rewiring_audit.tsv`).

### D2 (고정 원 B11 checkpoint, 원 validation source; 개발 분석, `checkpoint_target_sensitivity.tsv`)
- 주석 unit에서 `RMS(r)` 0.0529, seed만 지운 `RMS{r(S)−r(∅)}` 0.0020 → 비율 **0.037**(3 seed 0.034–0.039). 표적을 재배정한 경우의 변화 비율 0.045.
- K1 0.048, K2 0.012, K3 ~1e-7.
- 해석: 고정 checkpoint의 보정은 거의 전부 seed가 없어도 남는 경로(q/status/node identity)에서 나온다. 이것은 입력 조작 민감도이며 재학습 귀속을 대신하지 않는다(그래서 D3).

## 5. 선택 분기 F2: 표적 유래 보정 (§13.4-4, -5)

결정 기록: `DECISIONS.md` F-1(실행 전 계획·판정 규칙), F-1 결과, F-2(운영 변경). 표: `branch_f2/`. 그림: `reports/r7_followup_v1/figures/figB_branch_f2_contrasts.png`.

- **무엇을 바꿨나:** 같은 graph 보정을 두 번 계산해 빼는 구조 `r_target = F(S,q,G) − F(∅,q,G)`(TD). 표적이 없으면 보정이 정확히 0이 되므로, D2·D3에서 보정을 지배한 "seed 없이도 남는 경로"를 구조적으로 없앤다. 직접 대조는 같은 차분 구조에 재배정 표적을 넣은 TDS(mapping 3개)와 M. 데이터·backbone·손실·증강·예산은 그대로.
- **왜:** D2 비율 0.037(보정의 대부분이 seed 없이도 남음), D3 2행(GR이 C만 이기고 M·G0·GS와 구분 안 됨), 양성 대조(측정상 구별 가능한 약물 차이가 남음) → F2 진입 조건 셋 모두 충족.
- **실행량:** 3 fold × seed 42–44 × (TD + TDS 3) = 36 run, 모두 완료.

- 해석: source OOF와 같은 방향이다(GR이 C보다 좋지만 M·GS와 구분 안 됨; TD는 TDS와 같고 M보다 나쁨). 이 benchmark에서 후속 결론을 바꿀 관측은 없었다. 원 R7 B11의 원 test 점수와는 모델 학습 실행이 다르므로 같은 표로 섞지 않는다.

## 7. §11.6 결론표에서 해당하는 행

- **"generic 보정만 유효 → 추가 용량/metadata 효과; 실제 표적 대응 효과는 미확인"** 이 해당한다. 근거: GR, G0, GS, M 모두 C보다 좋고(source, test 모두), GR은 M·GS·G0와 구분되지 않으며, 차분 구조(F2)에서도 실제−재배정 차이가 없다.
- 보조로 "충분한 대조 뒤에도 차이 불명확 → 이 panel·주석·모형 조건의 한계; 지식 일반의 무용성 증명은 아님"이 함께 적용된다. 단 "불명확"의 범위는 좁다: source에서 두 핵심 대비의 동시 구간 하한(−0.00022, −0.00007)이 운영 기준 −0.001보다 커서, 0.001 이상의 실제 표적 이득은 배제된다.
- 해당하지 않는 행: "GR이 M·GS를 모두 개선", "graph가 pooling·rewiring보다 우세", "pooling이면 충분", "신뢰도 수축으로 손해 감소"(F3 미실행), "도달 가능한 일부 군에서만 유효"(K1∪K2에서도 구분 안 됨).

## 8. 여섯 질문에 대한 답 (§13.4)

1. **무엇을 입력해서 무엇을 예측했는가?** 처리 전 RNA(978 landmark), 약물 구조(ECFP4), 공개 약물–표적 주석과 지식 그래프를 넣어, 새 약물 처리 후 978 landmark의 평균 ΔRNA(CMap LINCS 2020 Level 3, 10 µM·24 h)를 예측했다(§1).
2. **처음의 성능 개선은 어떤 요인으로 설명되었는가?** 원 연구의 작은 개선(GR−C)은 source OOF에서 −0.00083으로 재현됐지만, 표적 정체성이 없는 M(−0.00122), G0(−0.00079), 재배정 표적 GS(−0.00089)도 같은 크기로 C를 이겼다. 고정 checkpoint에서 seed를 지워도 보정이 거의 그대로였다(바뀐 부분의 RMS가 보정 RMS의 3.7%, D2). 따라서 개선은 추가 보정 용량·주석 상태로 설명 가능하다(가설 수준의 귀속; 인과 기전 주장 아님).
3. **원인을 확인하는 직접 대조는 무엇이었는가?** 같은 fold별 고정 backbone·예산 위의 M(주석 metadata MLP, 작동 parameter ±0.06%), G0(같은 graph, seed만 비움), GS(약물–표적 연결을 층화 double-edge swap으로 재배정한 mapping 3개). 핵심 대비 GR−M, GR−GS는 Bonferroni 동시 구간과 Holm으로 판정했다.
4. **원인에 맞춰 무엇을 하나 바꾸었고, 왜?** 사전 규칙의 2행과 F2 진입 조건이 충족되어, seed 없는 경로를 구조적으로 제거하는 표적 차분 보정(TD)을 하나만 시험했다. 우회 경로가 보정을 지배해 표적 정체성의 이득이 가려졌을 가능성을 직접 겨냥한 변경이다.
5. **그 변경은 어느 조건에서 도움이 됐고 어디에서 실패했는가?** 도움이 된 조건은 찾지 못했다. TD−TDS는 source 전체·K1·K2·fold별 모두 0 근처였고(전체 −0.00001 [동시 −0.00018, 0.00017]), TD는 M보다 나빴다(+0.00100). 원 test 후속 평가도 같다(TD−TDS +0.00002, TD−M +0.00147).
6. **이 자료로는 무엇을 아직 말할 수 없는가?** 다른 주석 DB·다른 graph·다른 출력 축(전체 전사체)·다른 dose/time에서의 표적 정보 가치; 0.0002 미만의 아주 작은 실제 표적 효과(이 설계의 해상도 밖); HCC에서의 효과(unit이 적음); 독립 미열람 자료에서의 확인; 외부 모델(XPert) 대비 우열; M의 이득이 "주석이 있다는 사실" 자체인지 주석 metadata가 다른 약물 성질과 상관된 결과인지.

## 9. 비교 가능 범위와 한계

- source OOF는 원 train 약물의 내부 재분할이다. 같은 3-fold로 분기를 고른 뒤의 F2 결과는 독립 확인이 아니라 "내부 재분할 안정성"이다.
- 원 test는 이전 연구(R4 job 25374)와 원 R7 최종 평가에서 이미 열린 benchmark다. 후속 재평가는 맹검 시험이 아니다.
- 구간은 고정된 세포주·plate 패널에 조건부인 약물 그룹 bootstrap이다. model seed·세포 수·유전자 수를 독립 반복으로 세지 않았다. 세 null mapping으로 permutation p를 주장하지 않는다.
- 보정 크기·gate 값·모델 내부 차분은 모델 함수의 성질이다. 약물 표적의 인과 효과나 생물학적 경로로 해석하지 않는다.
- 하나의 주석 자원(kg_v1), 978 landmark 출력, 10 µM·24 h 조건, 한 graph 구조에 대한 결과다. "지식 일반이 쓸모없다"는 증명이 아니다.
