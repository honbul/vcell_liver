# E5 H2-v3 실험 잠금

기준 커밋은 `7c4ddc2bc36aecd26c7ba923749ee36a762d14d7`다. 원 CTRPv2·GDSC2·PRISM20Q2 지원 670,830행·1,186 exact parents·LINCS 관측 724약물과 E4 outer/inner 명부를 사용한다. Track 2에만 E4 outer fit의 원래 v1 `inner0/1/2` 3분할을 pooled 비교용으로 추가한다. 모든 역할의 exact parent·connectivity·전이적 scaffold 교집합은 0개다. Track 1은 outer 스크린 전체, Track 2는 outer 골격 전체를 해당 내부 선택에서 격리한다. Track 3은 전체 DRP 안에서만 선택한다. 이미 고정된 E4 Stage 1 내부 점수를 읽되, 새 Track 2 pooled 역할은 동일한 그리드를 평가한다. E4의 외부 메트릭·곡선·예측 파일과 외부 코호트 자산은 전체 선택 봉인 전 접근하지 않는다.

CPU partition에서 `fu-e5-*`, GPU=0, `--exclude=c4`를 적용한다. 오직 하나의 배열 단계가 실행되며 한도는 동시 8개, 각 4코어다. CPU 전용 노드 c3/c5로 제한해 GPU 노드의 연구를 그대로 둔다. 모든 G1 쓰기는 `followup_20261124/h2_e5_upgrade`에 한정한다.

## 공통 격자와 P1

- 각 구조는 λ={.25,.5,1,2,4,8,16,32}, w={.125,.25,.5,1,2}, shape={cos,rbf_wide}, base={v1_base,v2_base}의 160점을 사용한다. 모든 점은 E4의 978 landmark 24h mean, mask=.60 및 기저 가중치를 그대로 사용한다. 상한을 비롯한 어떤 점도 외부 관측으로 배제하거나 고정하지 않는다. P3B는 이 격자 전체를 τ={0,.25,.5,1,2,4} 각각에서 평가한다.
- 각 정책의 Pooled 점수 p와 LOSO 점수 ℓ은 각 검증 스크린의 적격 LINCS 약물 ρ를 균등 평균한다. Pooled에서는 스크린 안 fold를 먼저 균등 평균한다. 절대 후회는 max(p*−p,ℓ*−ℓ), 상대 후회는 max((p*−p)/p*,(ℓ*−ℓ)/ℓ*)다. 최고점 p*와 ℓ*는 해당 역할·구조의 전체 그리드에서 독립 최대화한다. 각 후회의 최솟값에서 .001 이내면 λ가 큰 점, 그 안에서는 후회가 작은 점, 이후 고정 그리드 순서를 따른다. 상대 최고점이 양수가 아닌 역할은 상대 비교를 정의할 수 없으므로 그 역할의 실패를 기록한다.
- P1-Minimax 및 P1-RelMinimax의 절편은 각자의 커널을 고정하고 E4의 16개 Pooled 전략으로 각각 고른다. 동일 절대 Minimax 커널과 이 절편의 arm을 `P1-Minimax`로 기록한다.

## P2 절편

- P2-Decoupled는 P1-Minimax와 똑같은 개인화 예측을 공유한다. E4의 16개 전략과 그에 속한 축소 γ=.50/.75/1을 재사용하고, 두 교차 스크린 전략까지 포함한 18개 전략을 오직 LOSO NDCG@5로 선택한다. 동일 후보 순서의 정확 동점은 첫 후보를 유지한다.
- 추가 `screen_median_centered_shrinkage`는 각 fit 스크린의 약물 source mean에서 그 스크린 약물 중앙값을 뺀 후 약물별 균등 평균한다. 그 약물 타깃에 E4의 최상 화학·LINCS 공식을 같은 가중으로 적용한다. 그 결과의 절반을 fit 스크린 중앙값들의 중앙값에 더한다.
- 추가 `rank_robust_blend`는 각 fit 스크린에서 약물 source mean의 중간순위를 (rank−.5)/n으로 변환한 후, 해당 스크린의 중앙값을 중심으로 IQR를 폭으로 삼아 원 단위로 환산한다. 스크린별 값을 약물별로 평균해 E4 최상 화학·LINCS 공식의 .5/.5 결합에 사용한다. 두 추가 전략의 계수는 고정한다. 본 절편들은 새 exact parent에 적용하며 기존 fit exact 부모에는 기존 fit-only 원 절편을 유지한다.
- P3A/B/C의 구조 비교는 각자의 커널과 16개 Pooled 절편을 사용한다. 통합 모델만 선택된 P3 구조의 커널과 동일 구조의 18개 LOSO 절편을 결합한다. 개인화와 절편의 기여는 같은 커널 전후 차이로 분해한다.

## P3 구조

- P3A-ScreenDebiased는 fit에서만 native endpoint를 E4 방식으로 맞춘 뒤, 각 (screen, endpoint) 안에서 약물 및 세포 오프셋을 관측 행의 교대 최소제곱으로 제거한다. 이후 (screen, drug) 잔차를 표준편차로 나눈다. 상수 잔차는 0이다. 예측 잔차에는 fit에서 얻은 양의 screen-drug 표준편차 중앙값을 곱해 절편의 원 응답 스케일로 복귀한다. E4의 aligned source mean 절편은 그대로 보존한다. 이 변환에는 query 응답과 query 세포 평균을 쓰지 않는다.
- P3B-HierarchicalMTK는 `K_cell × K_drug × (11ᵀ+τI)`의 가중 KRR이다. 스크린별 관측 가중치를 보존하며 shared 곱과 S개 특정 곱을 사용한다. `Shared`는 작업별 계수의 합으로, `InScreen`은 여기에 동일 fit 스크린 계수의 τ배를 더해 예측한다. 내부 pooled에서는 알려진 스크린의 InScreen으로, LOSO와 Track 1·3에서는 Shared로 선택·평가한다. Track 2는 Shared와 InScreen 둘 다 보고하고 통합 모델은 등록 스크린에서 InScreen을 사용한다. τ=0에서 원 모델과 같은 수학적 해를 적용한다. 11ᵀ의 영 고유공간은 이 경우 의도된 공유 전용 구조다. SPD 검사는 τ>0이면 전체 task Gram, τ=0이면 활성 rank-1 Gram에 적용하고 원 행렬의 PSD도 확인한다.
- P3C-EqualScreenWeight는 원 row weighting에서 각 스크린의 총 유효 가중치를 정확히 전체의 1/S로 바꾼다. 총 질량을 보존해 λ의 비교 단위를 고정한다. 스크린 한 개인 역할은 원 가중치와 일치한다.
- P3A/B/C 각각 독립 절대 Minimax로 선택한다. P3-Best는 세 사전 정의 구조의 raw Pooled 및 LOSO 점수를 공통 좌표로 놓고 전체 P3 그리드의 두 최댓값에 대한 Minimax를 적용한다. 두 단계 동안 외부 점수는 사용하지 않는다. H2-v3-Combined는 이 구조·커널을 고정해 P2 LOSO 절편을 적용한다. LINCS 미관측의 개인화는 같은 E4 C1 잔차로 복귀한다. Track 2의 C2/C3는 통합 모델의 구조·커널·절편 조건에 맞춘 availability-only, fit/query 내 별도 값 순열이다.
- Track 1은 E4 Sel-Pooled 및 Sel-LOSO 그대로를 주 기준으로 사용한다. H2-v2 역사 설정을 outer fit에 재적합한 참조도 표기하되, 해당 설정의 원래 선별 범위 때문에 방법 확인 gate에는 쓰지 않는다. Tracks 2/3는 기존 동결 C1, F00/F11, E4 예측을 사용한다. GDSC1·LIMORE·LICOB·LICOB18은 모두 이전 노출 외부 점검이다.

## 테스트, 진단, 판정

- 공식 선별은 모든 역할과 그리드 원표 및 소스 해시를 타임스탬프로 잠근다. 실제 E5 명부와 E4 동결 재생의 F00/F11/E4 최대 차이가 1e−6 미만이어야 한다. 모든 적합 역할에서 구조 키 0 겹침과 query 라벨 차단을 확인한다. 실제 역할과 합성 이동에서 P3A centering/scaling의 fit-only 불변식과 P3B τ=0 다중과제 해 대 기존 단일 해 차이 1e−4 미만을 검증한다. 모든 선택 약물 Gram과 유효 task Gram의 최소 고유값은 양수여야 한다. P1/P2 모든 평가의 약물별 중간순위가 정확히 같아야 한다.
- 배타적 접근 가드를 만든 뒤 TRAIN과 외부 원 라벨을 공식 평가에서 각각 한 번 읽는다. E4와 동일하게 exact scaffold 또는 lineage에 2,000회 짝 95% 구간을 적용한다. ρ·상호작용 ρ는 관측 LINCS를 주 지원, NDCG@5·Precision@5·고유 Top-5는 전체 행을 주 지원으로 사용한다. 전체/관측/비관측 지원도 표기한다. 지표 고정 후 같은 메모리의 라벨로 선택 P3B 기하·λ에서 τ만 변화시킨 곡선, 내부 Pooled/LOSO의 비지배점과 두 후회를 기록한다. 사후 표의 값은 선택이나 gate에 입력되지 않는다.
- `GO-V3-PARETO-UPGRADE`는 **통합 모델**에 다음을 모두 요구한다. Track 1 Sel-Pooled 대비 ρ 하한 >0 또는 ρ 하한 ≥−.003 및 NDCG 하한 >0, 동시에 E4 대비 ρ 하한 ≥−.005. Track 2 C1/C2/C3 대비 ρ 하한 >0, v2 대비 ρ 점 ≥−.010와 전체 NDCG 점 ≥−.015. Track 3 GDSC1 v2 대비 NDCG 점 ≥+.05, E4 대비 관측 ρ 점 >0 및 v2 대비 ρ 하한 ≥−.008, LIMORE v2 대비 관측 ρ 점 >+.015.
- `PARTIAL-PILLAR-WIN`은 통합 GO 실패 시 개별 주 기둥 arm이 Track 1 또는 2의 동일 지지에서 E4 대비 관측 ρ와 전체 NDCG의 하한이 모두 0 이상이며 하나 이상 0을 초과하는 경우다. 해당 트랙의 개선 축과 다른 트랙의 손실을 함께 보고한다. `NO-GO-KEEP-E4-DUAL`은 양쪽 기준을 통과한 기둥이 없을 경우다.
