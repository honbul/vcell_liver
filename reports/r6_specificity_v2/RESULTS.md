## 2. R6-R — 반복 가능한 약물 차이부터 확인

### 2.1 목적과 가설
v1의 plate 간 pool 중심화 cosine(약물 평균 0.010)이 낮은 반복성 때문인지, plate마다 다른 약물 구성으로 만든 pool 평균의 차이 때문인지를 가린다. 같은 plate의 두 약물 차이 `c_P = x_d − x_e`는 pool 공통 이동과 대조군 기준 평균을 정확히 지우므로, 두 plate에 공통인 약물쌍에서 `c_P`와 `c_Q`를 비교한다.

### 2.2 입력·정답과 적격 집합 (metadata만으로 고정, 응답값을 읽기 전)
- 입력: TRAIN 약물 처리 well(0.5 µM)의 처리군 평균 log1p(1e4·count/library), 2,000 유전자. 같은 (세포주, 약물, plate)의 well이 둘 이상이면 세포 수 가중 평균. 모델 예측은 쓰지 않는다.
- 적격 링크 수(`manifests/r6_specificity_v2/eligibility_summary.json`):

| TRAIN 약물 / 두 plate 이상에 있는 약물 | 209 / 21 (세포주×약물 964) |
| pair link (세포주 × plate 쌍 × 공통 약물쌍) | 2,773 (고유 약물쌍 59, 약물 20, plate 쌍 6, 세포주 47) |

- metadata 한계(관측): Tahoe sample metadata에 날짜·계대·배양 batch 열이 없다 → **독립 배양 여부는 식별 불가**. 다른 plate는 다른 well·plate라는 뜻일 뿐이다. 또 R6의 약물 단위(구조 그룹)가 plate마다 다른 catalog 화합물인 경우가 많다: 염/용매화물 변형이 대부분이고, 64(crizotinib/(S)-crizotinib), 68(glycyrrhizinate/glycyrrhizic acid), 205(doxorubicin/epirubicin), 320(salicylate/salicylic acid)은 다른 이름이다(`repeat_compound_names.tsv`).
- 사전 식별 기준(약물 ≥8, plate 쌍 ≥2)은 충족했다. 다만 plate 모집단 CI는 줄 수 없다.

### 2.3 비교 조건
matched(`c_P` 대 `c_Q`), wrong-match(같은 stratum의 겹치지 않는 쌍), zero(대비 0 예측), 같은 well의 barcode 반쪽(기술적 분할 상한), 잡음을 맞춘 cross-plate 반쪽. 주 대비 P1(cos, matched − wrong), P2(RMSE, matched − wrong), Holm. 판정 규칙은 동결 명세(`RUN_SPEC_R6R.md`)에 적힌 그대로 적용했다. 배선 확인은 난수 입력으로만 했고 실제 응답은 동결 뒤 job `26743`에서 한 번 읽었다.

### 2.5 의미
- 관측: 같은 pool 안에서 측정된 약물 차이는 같은 well을 반으로 나누면 cos 0.80으로 일치하지만, 잡음 수준을 맞춘 다른 plate에서는 0.10(구간 0 포함)이다. 재현되는 신호는 소수의 강한 반응 약물(주로 plate11–plate8 쌍)에 몰려 있다.
- 관측: pool 평균 대신 약물쌍 대비(공통 이동·대조군 제거)를 써도 plate 간 일치는 통계적으로 확립되지 않았다. v1의 0.010은 같은 링크에서 v1 방식으로 0.009로 재현되었고, 공통 anchor 중심화는 0.047, 쌍 대비 matched는 0.101이다. 방향은 "pool 구성 차이가 일부 기여" 가설과 맞지만 차이의 구간을 검정하지 않았고 주 대비가 유의하지 않으므로 **가설로 남는다**.
- 불확실: plate 일반화. 주 집합의 plate 쌍이 3개뿐이고 모두 plate8을 포함하며, plate11을 빼면 효과가 사라진다. 독립 배양 여부와 화합물 동일성(염·입체이성질체)도 metadata로 가릴 수 없다. 음성은 약물의 생물학적 효과가 없다는 증거가 아니다.
- 다음 행동: 계획 §3.2/§8.3에 따라 "독립 반복 signal 자체가 불확실 → 반복 자료 설계 우선". 더 큰 encoder 반복보다 5절의 자료 요구를 우선한다.

## 3. R6-E — 약물 표현 probe: 미실행 기록

- 하지 않은 것: E0(약물 없음)/E1(ECFP4)/E2(label-free 고정 구조 embedding) 선형 probe.
- 이유: 동결 명세(`configs/r6_specificity_v2/r6r_spec.json`의 `r6e_entry`)는 R6-R 판정이 `repeatable` 또는 `weak_or_uncertain`일 때만 실행한다고 정했고, 판정은 `not_established`였다. 조건을 그대로 적용했다.
- 표현 자체의 가용성(확인한 사실): 서버 chemCPA 환경에 RDKit 2026.09.2가 있어 SMILES로 label-free descriptor/지문 변형을 계산할 수 있다. 기존 `tahoe_rdkit2D_embedding.parquet`(chemCPA 저자 코드로 계산한 RDKit 2D descriptor)도 있으나 정규화가 시험 약물을 포함한 전체 Tahoe 약물에 맞춰져 있어, 쓰려면 inner-train만으로 다시 정규화해야 한다. GROVER 코드는 있으나 가중치·학습 자료의 provenance는 확인하지 않았다. response-pretrained embedding은 처음부터 제외.
- 실행을 여는 조건: (a) 새 반복 자료나 다른 설계로 R6-R 주 대비가 `weak_or_uncertain` 이상이 되거나, (b) 사용자가 반복성 근거 없이도 표현 probe를 "모든 probe 음성 + 반복 신뢰도 낮음 → 자료 우선" 판단용으로 실행하기로 결정하는 경우. 비용은 CPU 중(ridge/작은 선형 head)으로 추정한다(미측정).

## 4. R6-O — 세포 수×깊이 훈련을 맞춘 관측 예산

- 실제 관측량(`observation_umi_inputs.tsv`): 세포당 UMI 평균 2,368(p=1), 1,184(p=0.5), 592(p=0.25); 세트 UMI 평균 N16·p1 38,121, N64·p0.25 37,895(중앙값 35,990 대 35,370). 모든 세트에서 모든 세포가 usable(UMI>0).
- UMI 일치 보조 비교: pool마다 N64를 N16·p1과 같은 기대 UMI가 되게 p*로 박화했다. p* 중앙값 0.252이고 48%의 pool에서 훈련 범위 하한 0.25로 잘려, B(64세포)의 세트 UMI가 A보다 평균 4.6%(중앙값 +0.36%) 많다. 이 조건에서 64세포 − 16세포: O0 −0.60%, O1 −0.38% (둘 다 구간 0 아래). 잘림 때문에 정확한 UMI 일치 비교는 아니다.
- 연산: 갱신 수는 같지만 O1이 처리한 세포 수는 O0의 약 59%(예: fold 0 seed 42 1.30M 대 2.21M). run당 학습 13–27초(A30/A40).

### 4.2 판정과 의미
- 사전 규칙 그대로: 주 family의 세 대비가 모두 Holm 유의·음수 → **"불일치 몫 지지"**. 동시에 크기는 −0.21~−0.23%로 사전 실용 기준(0.5%) 미만이다(`improved_small`). 즉 v1 3절의 N=16 손실 가운데 약 1/4–1/3은 N64 전용 훈련 때문이었고, 나머지 N=16 손실(O1에서도 N64 대비 +0.47~+0.72%)은 훈련을 맞춰도 남는다.
- O1은 N=64 성능을 잃지 않았다(차이 0, 구간이 ±0.06% 안).
- 이 자료·M 모델에서 같은 N×p일 때 "64세포·p0.25가 16세포·p1보다 낫다"는 순서는 훈련을 맞춰도 남는다(−0.38%). 이것은 N×p(그리고 대략 맞춘 UMI) 비교이며 실제 비용 비교가 아니다.
- pool 내 대비는 어디에서도 바뀌지 않았다 → 약물 고유 반응의 회복으로 해석하지 않는다. 어느 (N, p)에서도 O0·O1 모두 pool 평균(0.080189)보다 1.1–2.2% 나쁘다(N=8 제외).
- SD는 추가하지 않았다(집합 encoder 비교 필요성이 이 결과에서 생기지 않음: M의 N 의존은 훈련으로 일부만 줄었고 pool 내 신호는 없다).
- 다음 행동: 관측 설계 권고는 실제 library·sequencing 비용과 반복 변동 자료가 있을 때만(5절). 이 결과로 새 학습을 이어 붙이지 않는다.

## 5. §3.5 — 독립 반복 자료가 필요한 경우 (자료 요구 메모)

현재 자료로는 약물 차이의 생물학적 재현성을 판정할 수 없다(2절). 이것을 "효과 없음"으로 결론내리지 않고, 판정에 필요한 자료를 적는다.

- 지금 부족한 것(관측): TRAIN 약물 209개 중 두 plate 이상에 있는 것은 21개, wrong-match까지 가능한 주 집합은 17개·plate 쌍 3개이며 모두 plate8을 포함한다. 배양 날짜·계대·batch 기록이 없고, plate 간 "같은 약물"이 다른 catalog 화합물(염·입체이성질체)인 경우가 많다.
- 필요한 설계:
  1. 같은 화합물·같은 lot을 독립 배양(다른 날 또는 다른 계대)에서 적어도 2회 관측하고, 배양 날짜·계대·plate·well 위치를 기록한다.
  2. plate마다 공통 anchor 약물 집합을 둔다. 강한 반응 약물(이번에 재현된 10 tirabrutinib, 16 trametinib, 64 crizotinib 등)을 양성 대조로 포함하고, 약한 반응 약물도 섞는다.
  3. query 약물을 plate에 교차 배치한다(한 약물이 최소 두 plate, plate 쌍마다 겹치지 않는 약물쌍이 생기도록 공통 약물 ≥4). 현재 plate 쌍 0-4/1-4/3-4처럼 한 plate에 모든 쌍이 의존하지 않게 plate 쌍을 ≥4개로 분산한다.
  4. plate마다 독립 DMSO well을 둘 이상 둔다(대조군 기준을 반으로 나누지 않아도 되게).
- 규모(대략, 가설): 이번 P1 구간 폭(약 ±0.2, 약물 17개)과 약물 단위 분산이 비슷하다고 가정하면, P1의 구간 반폭을 0.05로 줄이려면 약물 수가 약 (0.2/0.05)²×17 ≈ 270개 필요하다. 반응이 소수 약물에 몰려 있어 이 추정은 거칠다. 실제 설계 전에 pilot 반복 자료로 약물 단위 분산을 다시 재야 한다.
- N/깊이 권고: 4절의 결과도 N×p 비교이며 UMI·라이브러리·시퀀싱 비용과 같지 않다. 실제 권고에는 library preparation·sequencing 단가와 반복 변동 자료가 필요하다.
