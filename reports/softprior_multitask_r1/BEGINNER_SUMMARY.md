# 연구 R1 한눈에 보기 (입문용)

작성일 2026-11-17. 수식 없이 썼습니다. 숫자의 출처는 [RESULTS.md](RESULTS.md)입니다.

## 무엇을 물었나

간암 세포 모델에 약물을 넣기 **전**의 RNA만 보고, 그 세포가 약물 90개 각각에 얼마나 민감할지 예측하는 문제입니다. 자료는 LIMORE 세포 모델 79개이고, 같은 환자·같은 원천에서 나온 것을 하나로 묶으면 독립 표본은 76개입니다.

앞선 연구 A는 유전자 약 1만 9천 개를 "경로 50개의 점수"로 줄여 넣었고, 그렇게 하면 예측이 오히려 나빠졌습니다. R1은 두 가지 생각을 시험했습니다.

1. **줄이지 말고 기울이기.** 유전자를 전부 남기되, 경로가 가리키는 방향을 조금 더 믿도록 합니다(soft prior).
2. **약물 90개를 함께 배우기.** 약물들의 반응에 공통 패턴이 있으면 서로 빌려 쓸 수 있습니다.

## 무엇을 얻었나

점수는 낮을수록 좋습니다. 모든 세포에 "그 약물의 평균"만 답하면 약 1.05입니다.

| 모델 | 점수 |
|---|---|
| 평균만 답하기 | 1.054 |
| 경로 점수 50개로 줄인 모델 (연구 A) | 1.035 |
| 유전자 전체 Ridge (연구 A) | **0.992** |
| R1 통합 모델 (경로 기울이기 + 함께 배우기) | 1.000 |
| 같은 모델에서 경로만 뺀 것 | 1.000 |
| 같은 모델에 무작위 유전자 묶음을 넣은 것 (20번) | 0.999 |

- 통합 모델은 경로로 줄인 모델보다 좋았습니다.
- 그러나 기존의 단순한 Ridge보다 좋지 않았습니다. 0.008만큼 나빴습니다.
- 진짜 경로를 넣든, 유전자 이름을 섞은 가짜 경로를 넣든, 경로를 빼든 점수가 같았습니다.

**한 문장 결론:** 이 자료에서는 경로 지식을 부드럽게 넣어도 예측이 좋아진다는 근거를 찾지 못했습니다.

이것은 실패한 실험이 아니라 끝난 실험입니다. "경로 점수가 나빴던 것은 정보를 버렸기 때문이고, 버리지 않으면 경로 지식이 도움이 될 것"이라는 설명의 앞 절반은 맞았고 뒤 절반은 확인되지 않았습니다.

## 네 가지 질문

### 1. 세포 하나의 RNA는 "경로 부분"과 "나머지"로 어떻게 나뉘나

경로 50개의 평균 점수로 만들 수 있는 예측은 유전자 1만 9천 개의 방향 가운데 50개 방향만 씁니다. 실제 세포 하나(CLC1)의 RNA 변이를 나눠 보면 **경로 부분이 1.7%, 나머지가 98.3%**입니다. 경로 점수만 쓰는 모델은 98%를 버립니다. soft prior는 버리지 않고, 나머지 쪽을 조금 더 조심스럽게 쓸 뿐입니다.
([tutorial 02](../../tutorials/softprior_multitask_r1/02_pathway_and_rest_one_cell.ipynb))

### 2. 같은 약물에서 세 방식의 예측은 얼마나 다른가

한 약물, 한 번의 나눔에서 세 방식(경로만 / 부드러운 prior / prior 없음)의 예측을 나란히 놓으면 서로 매우 비슷합니다. 부드러운 prior와 prior 없는 예측의 상관은 0.98입니다. 세 방식 모두 "평균 근처에서 조금 움직이는" 예측을 냅니다. 차이가 작으므로, 한 약물이나 한 번의 나눔으로는 우열을 말할 수 없고 전체 표로만 판단해야 합니다.

### 3. 유전자를 1만 개 더 넣어서 좋아진 것인가, 규제가 한 일인가

둘 다 필요했습니다.

- 유전자를 전부 넣어도 규제(계수를 작게 누르는 힘)가 너무 약하거나 너무 세면 점수가 나빠집니다. 알맞은 세기에서 가장 좋습니다.
- 경로 부분을 **통째로 빼고** 나머지만 써도 점수가 같았습니다. 경로가 담은 정보는 다른 유전자들에도 들어 있습니다.
- 가상 자료로 만든 예제([tutorial 03](../../tutorials/softprior_multitask_r1/03_penalty_demo_synthetic.ipynb))에서는 신호가 정말 경로 안에 있으면 soft prior가 오차를 크게 줄이고, 신호가 경로 밖에 있으면 오히려 늘립니다. 방법은 작동합니다. 이 간암 자료의 신호가 Hallmark 경로 방향에 모여 있지 않았을 뿐입니다.

### 4. 약물 90개를 함께 배우면 표본이 90배가 되나

되지 않습니다. 약물 90개의 반응은 **같은 76개 계열**에서 잰 값입니다. 새로운 세포는 하나도 늘지 않습니다. 함께 배우면 약물들의 공통 패턴(예: 어떤 세포는 약물 전반에 민감함)을 더 안정적으로 잡을 수 있지만, "RNA가 어떤 세포를 어떻게 구분하는가"를 배울 표본은 여전히 76개입니다.

실제로 공통 패턴은 있었습니다. 모든 모델이 "이 세포가 전반적으로 민감한가"(일치도 약 0.5)를 "이 세포가 어떤 약물을 더 좋아하는가"(약 0.25)보다 잘 맞혔습니다. 하지만 함께 배우는 모델도 잘 조정한 Ridge를 넘지 못했습니다.

## 이 모델이 예측하는 것과 못 하는 것

| 예측하는 것 | 못 하는 것 |
|---|---|
| 학습에 쓴 약물 90개에 대한, **새 간암 세포 모델**의 민감도(실험값) | 새 약물에 대한 반응 |
| 세포들 사이의 순서(누가 더 민감한가)를 약하게 | 환자의 치료 반응 |
| | 학습 평균보다 크게 나은 정확도 (가장 좋은 모델도 약 6% 개선) |

## 얼마나 믿을 수 있나

- 독립 표본이 76개여서 모델 사이의 작은 차이(0.01 이하)는 가리기 어렵습니다.
- 다른 연구의 간암 세포주(LCCL)에서도 통합 모델과 Ridge는 구분되지 않았고, 경로로 줄인 모델은 우연 수준이었습니다. 완전히 새로운 계열은 4개뿐이어서 일반화 여부는 말할 수 없습니다.
- 이 자료들은 연구 A에서 이미 본 것입니다. 처음 보는 자료로 한 검증이 아닙니다.
- 개발 중에 더 좋아 보였던 설계가 최종 평가에서는 더 나빴습니다. 작은 표본에서 작은 차이로 설계를 고르는 일이 얼마나 불안정한지를 보여 줍니다.
