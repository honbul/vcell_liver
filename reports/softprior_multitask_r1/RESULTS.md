# 연구 R1: 결과

작성일 2026-11-17. 동결 커밋 `88d4c21`, 동결 선언 `bdb52bd`(`manifests/softprior_multitask_r1/freeze_manifest.json`). 최종 평가는 작업 25297에서 한 번 실행했습니다.

**이 평가의 성격:** 이미 공개된 자료를 다시 쓴 동결 후 평가입니다. LIMORE와 LCCL의 점수는 연구 A에서 이미 본 적이 있으므로, 처음 보는 독립 코호트의 검증이 아닙니다.

## 1. 결론

1. 통합 모델(`full_resid`: soft prior + 약물 공통 저차원 성분 + 약물별 잔차)의 주지표는 **0.9999** [0.910, 1.083]입니다.
2. 같은 격자의 약물별 Ridge(`ridge_pd`, 1.0009)와 차이가 없습니다. 차이 −0.0010 [−0.0040, +0.0021].
3. 연구 A의 순위 Ridge(A1r, 0.9917)보다 **나쁩니다.** 차이 +0.0082 [+0.0024, +0.0133].
4. hard prior보다는 좋습니다. A3 대비 −0.0354 [−0.0510, −0.0176], `par_pd` 대비 −0.0281 [−0.0415, −0.0135].
5. 실제 Hallmark prior는 무작위 prior 20개 가운데 어느 것보다도 좋지 않았습니다. 차이 +0.0006 [−0.0007, +0.0019].
6. LCCL에서도 통합 모델과 Ridge의 차이 구간은 0을 포함합니다.

계획서 9절의 판정표에서 쓸 수 있는 주장은 **"이번 데이터에서 prior의 추가 가치 미확인"** 하나입니다. 판정 과정은 7절에 있습니다.

## 5. 실제 prior 대 무작위 prior

`tables/final_internal_real_vs_permuted_prior.tsv`, `figures/fig3_real_vs_permuted_prior.png`. 무작위 prior는 유전자 이름표를 통째로 섞은 것 20개이며(묶음 크기와 겹침 구조는 보존), 실제 prior와 같은 중첩 경로를 처음부터 다시 탔습니다.

| 모델 | 실제 prior | 무작위 20개 평균 (최소–최대) | 실제보다 좋거나 같은 무작위 수 | 실제 − 무작위 평균 [95% 구간] |
|---|---|---|---|---|
| full_resid | 0.99989 | 0.99929 (0.99928–0.99932) | 20 / 20 | +0.0006 [−0.0007, +0.0019] |
| soft_pd | 1.01149 | 1.00336 (0.99707–1.00641) | 20 / 20 | +0.0081 [−0.0002, +0.0180] |
| par_pd (hard) | 1.02794 | 1.03844 (1.02234–1.04800) | 2 / 20 | −0.0105 [−0.0266, +0.0087] |

- **관측:** soft prior에서는 실제 Hallmark가 무작위 유전자 묶음 20개 모두보다 점수가 나쁩니다. 차이의 구간은 0을 포함하므로 "실제가 더 나쁘다"고도 말하지 않습니다.
- **관측:** 경로 부분공간만 쓰는 hard prior에서는 실제가 20개 중 18개보다 좋습니다. 차이의 구간은 0을 포함합니다.
- **관측:** `full_resid`의 무작위 prior 점수 20개는 거의 같은 값입니다(표준편차 0.00002). 무작위 prior가 주어지면 선택 절차가 prior를 쓰지 않는 설정으로 모입니다.

`tables/final_not_run.tsv`는 비어 있습니다. 실행하기로 한 비교군은 모두 실행됐습니다.

**cwKBMF 행의 범위.** 저자 공개물에는 학습·예측 함수와 작은 시연만 있고 자료 처리 과정이 없습니다. 그래서 다음은 이 연구가 정한 값입니다: Hallmark 50개 각각의 유전자 + 나머지 유전자 전체로 만든 kernel 51개, Gaussian kernel의 폭, 반복 200회, 성분 수 후보 {10, 20}(안쪽 fold로 선택). 표의 숫자는 "저자 코드를 이 과제에 적용한 결과"이며 원 논문 결과의 재현이 아닙니다.

- **관측:** cwKBMF는 내부에서 통합 모델과 차이가 없습니다(+0.0038 [−0.0062, +0.0138]). LCCL에서는 순위 일치도가 0 근처입니다.
- **관측(정답을 쓰지 않은 확인):** cwKBMF의 LCCL 예측은 세포 사이의 퍼짐이 Ridge의 약 1/10입니다(약물별 표준편차 평균 0.008 대 0.080). 세포를 거의 구분하지 않습니다.
- **검증하지 않은 설명:** LCCL 세포의 RNA는 측정 연구가 달라 LIMORE 세포 모두와 kernel 거리가 비슷하게 멉니다. 확인 실험은 하지 않았고, LCCL 결과를 보고 kernel 폭을 바꾸지도 않았습니다.

**ElasticNet 행의 범위.**

- **관측:** 내부 예측 21,330개 가운데 27개가 AA 2를 넘습니다(최대 37.5; AA의 실제 범위는 0–1 부근). 약물 15개, 세포 몇 개(CLC23, CLC13 등)에 몰려 있습니다. 약물별 nRMSE의 **중앙값**은 1.055로 학습 평균(1.038)과 비슷합니다. 평균 1.355는 이 극단값들이 만든 값입니다.
- **검증하지 않은 설명:** 학습 세포에서 거의 변하지 않던 유전자가 시험 세포에서 크게 다르면, 표준화한 값이 매우 커집니다. 순위 입력은 이 문제가 없습니다.
- 동결한 설정이므로 고치지 않았습니다. 이 행은 "raw FPKM을 표준화해 ElasticNet에 넣는 구성은 이 자료에서 불안정했다"로만 읽어야 하고, ElasticNet 일반의 성능으로 읽으면 안 됩니다.

## 7. 계획서 9절 판정표 적용

"이긴다"는 쌍 차이의 95% 구간 전체가 0 아래라는 뜻입니다. 통합 모델은 `full_resid`, Ridge는 `ridge_pd`와 A1r, hard prior는 A3와 `par_pd`, prior 없는 multitask는 `mt_resid`입니다.

| 판정표의 행 | 조건별 결과 | 해당 여부 |
|---|---|---|
| full이 Ridge·hard prior를 이기고 실제 prior가 무작위보다 좋음 | hard prior: 이김. Ridge: 이기지 못함(`ridge_pd`와 같고 A1r에 짐). 실제 prior: 무작위보다 좋지 않음 | 해당 없음 |
| full이 좋지만 prior 없는 multitask와 같음 | "multitask와 같음": 성립. "full이 좋음": 성립하지 않음 | 해당 없음 |
| η=0이 선택되고 Ridge와 같음 | "Ridge와 같음": `ridge_pd`에 대해 성립. "η=0이 선택됨": 학습 집합 15개 중 7개에서만 성립 | 절반만 충족 |
| 주로 broad sensitivity만 개선 | 개선이 없음 | 해당 없음 |
| 외부에서 재현 안 됨 | 재현할 내부 개선이 없음 | 해당 없음 |

어느 행도 글자 그대로 전부 충족하지는 않습니다. 가장 가까운 3행의 주장("이번 데이터에서 prior의 추가 가치 미확인")을 채택합니다. 그 근거는 η 선택 빈도가 아니라 5절의 무작위 prior 대조와 4절의 prior 제거 비교입니다. 여기에 "통합 모델이 연구 A의 순위 Ridge보다 0.008 나빴다"를 함께 적습니다.
