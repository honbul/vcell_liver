# 연구 R1: 진단

작성일 2026-11-17. 모델을 만들기 전에 두 가지를 먼저 확인했고(R1-D1, R1-D2), 설계 단계마다 개발 구간에서 무엇이 달라졌는지 기록했습니다. 이 문서의 모든 수치는 **개발 구간**에서 나왔습니다. 개발 구간은 바깥 학습 집합 15개(계열 5겹 × 3회) 각각의 안쪽 3겹이며, 바깥 시험 계열의 AA와 LCCL의 값은 쓰지 않았습니다. 표는 `tables/`에 있습니다.

읽는 법 세 가지입니다.

- 점수는 macro nRMSE이고 낮을수록 좋습니다.
- 개발 점수(약 1.03)는 최종 점수(약 0.99)보다 높습니다. 안쪽 학습 집합이 더 작기 때문입니다(계열 약 40개 대 60개). 두 종류의 점수를 서로 비교하지 않습니다.
- "선택 정직 점수"는 한 안쪽 겹을 채점할 때 설정을 **나머지 두 겹으로** 고른 값입니다. 후보가 많은 모델이 저절로 유리해지는 것을 막습니다.

## 0. 유전자 축 수정의 영향 (R1-0)

연구 A는 같은 유전자 기호를 가진 Ensembl ID가 여럿일 때 **평균 발현이 가장 높은 ID**를 남겼습니다. 발현값을 보고 정하는 규칙입니다. R1은 **사전순으로 가장 작은 ID**를 남기도록 고쳤습니다.

| 항목 | 값 |
|---|---|
| 중복 기호 | 7개. 이 가운데 4개에서 남는 ID가 바뀜 |
| 축 크기 | 19,018개로 같음 |
| 공유 유전자의 상대 순위 변화 | 최대 0.00021 |
| Hallmark 점수 변화 | 최대 0.0025 |
| A1r (순위 Ridge) | 0.991605 → 0.991653, 차이 +0.00005 [−0.0000003, +0.00009] |
| A3 (Hallmark Ridge) | 1.035337 → 1.035338, 차이 +0.000001 [−0.0003, +0.0003] |
| A1 (log2 Ridge) | 1.012623 → 1.012667, 차이 +0.00004 [+0.000005, +0.00008] |

수정의 영향은 모델 사이 차이(0.02–0.06)의 약 1/500입니다. 새 채점 코드는 연구 A가 커밋한 예측표에서 연구 A의 숫자를 소수 여섯째 자리까지 재현했습니다(`r0_scorer_check.json`).

## 1. R1-D1: 경로를 빼고 남는 정보에도 신호가 있는가

같은 Ridge를 세 입력으로 풀었습니다. 전체 유전자 공간, 경로 부분공간만(Hallmark 50개의 평균 점수가 만들 수 있는 방향, 약 50차원), 경로 부분공간을 뺀 나머지.

| 입력 (모든 약물에 λ 하나) | 선택 정직 개발 점수 | 전체와의 차이 (95% 구간) |
|---|---|---|
| 학습 평균 | 1.0830 | — |
| 전체 | 1.0377 | — |
| 경로 부분공간만 | 1.0555 | +0.018 [+0.007, +0.027] |
| 경로를 뺀 나머지 | 1.0377 | +0.00004 [−0.0010, +0.0010] |

- **관측:** 경로 부분공간만 써도 평균보다는 좋습니다(−0.027). 그러나 전체보다 0.018 나쁩니다.
- **관측:** 경로 부분공간을 **빼도** 점수가 변하지 않습니다. 경로 방향의 정보는 경로 밖 방향으로 대체됩니다.
- **관측:** λ를 약물마다 고르면 하나로 고를 때보다 0.007 좋습니다([+0.005, +0.010]).
- **해석(가설):** hard 압축의 부진은 정보 손실로 설명됩니다. 그러나 경로 방향이 특별히 더 유용하다는 근거는 없으므로, 경로 방향을 우대하는 soft prior의 이득은 작을 것으로 예상했습니다. 이 예상은 R1-2 실행 전에 DECISIONS.md에 적었습니다.

## 2. R1-D2: 약물 사이에 공유할 구조가 있는가

학습 계열의 약물 90개 사이 상관을 분석했습니다.

| 질문 | 결과 |
|---|---|
| 첫 공통 성분이 차지하는 분산 | 35.2% (둘째 6.9%, 셋째 5.5%). 약물 쌍의 평균 상관 0.30 |
| 학습 계열의 첫 성분이 **보지 않은 계열**의 분산에서 차지하는 몫 | 29.7% (무작위 기대 1.1%, 약물별 섞기 대조 1.2%) |
| 상위 5개 / 10개 성분 | 41.0% / 49.6% (대조 5.6% / 11.1%) |
| 계열을 다시 뽑았을 때 첫 성분의 안정성 | 제곱 코사인 0.97 |
| 2–10번째 성분의 안정성 | 0.71–0.76 (무작위 0.02–0.11) |
| RNA로 예측되는 정도(학습 평균 대비 손실 감소율) | 첫 성분 0.19–0.20, 2–5번째 0.12–0.20, 개별 약물 평균 0.06–0.08 |

- **관측:** 강하고 안정적인 공통 성분이 하나 있습니다. "이 세포가 전반적으로 약에 잘 듣는가"에 해당합니다. 그 뒤의 성분들은 성분당 1–3%씩만 더합니다.
- **관측:** 공통 성분은 개별 약물보다 RNA로 잘 예측됩니다.
- **해석(가설):** 약물들을 함께 학습하면 이 공통 성분의 추정이 좋아질 수 있습니다. 다만 공통 성분이 사실상 하나라는 점은 이득의 상한이 작을 수 있음을 뜻합니다.
- **정정 기록:** RNA 예측 정도의 첫 계산은 단위를 잘못 잡아, 예측이 없어도 좋아 보였습니다. 학습 평균 대비 감소율로 고쳤고 처음 표는 `d2_rna_predicts_components_v1_scale_error.tsv`로 남겼습니다.

## 3. 설계 단계별 개발 점수

| 단계 | 모델 | 선택 정직 개발 점수 | 핵심 비교 (95% 구간) |
|---|---|---|---|
| 기준 | Ridge, 약물별 λ (`ridge_pd`) | 1.0306 | — |
| 기준 | Ridge, λ 하나 (`ridge_gl`) | 1.0377 | — |
| R1-2 | soft prior만 (`soft_gl`) | 1.0374 | `ridge_gl` 대비 −0.0003 [−0.0027, +0.0023] |
| R1-2 | 다중약물 수축만 (`mt_noprior`) | 1.0336 | `ridge_gl` 대비 −0.0041 [−0.0079, −0.0004] |
| R1-2 | 처음의 통합 설계 (`full`) | 1.0358 | `ridge_pd` 대비 **+0.0052 [+0.0001, +0.0104]** |
| R1-3 | 공유 low-rank + 약물별 잔차 (`mt_resid`) | 1.0296 | `ridge_pd` 대비 −0.0010 [−0.0037, +0.0018] |
| R1-3 | 위 구조 + soft prior (`full_resid`) | 1.0299 | `mt_resid` 대비 +0.0004 [−0.0008, +0.0016] |

무엇이 문제였고 무엇을 고쳤는가:

1. **처음 설계의 문제.** 다중약물 수축은 "λ 하나" Ridge보다 0.004 좋았습니다. 그러나 모든 약물에 같은 규제 강도를 써야 해서, 약물마다 강도를 고르는 Ridge에는 못 미쳤습니다. 약물별로 보면 46개는 좋아지고 44개는 나빠졌으며, 0.01 넘게 나빠진 약물이 26개였습니다(`r2_per_drug_pairs.tsv`).
2. **수정 1.** 공유 부분은 모든 약물에 한 설정으로 맞추고, 그 잔차에 약물마다 강도를 고른 Ridge를 더했습니다. 처음 설계보다 0.006 좋아졌습니다(구간 0 아래). 약물별 Ridge와는 0.001 차이로 구간이 0을 포함합니다.
3. **수정 2는 쓰지 않았습니다.** 특정 원인을 가리키는 진단이 없었습니다.

풀이 관련 기록: nuclear norm 문제는 ADMM으로 풀었고, 개발과 최종을 합쳐 수렴 실패는 없었습니다(RESULTS.md 6절). τ/τ_max = 0.03, 0.1, 0.3에서 해의 rank 중앙값은 39, 22, 4였습니다.

## 4. 실제 경로와 무작위 경로 (개발 구간)

유전자 이름표를 통째로 섞은 무작위 경로 20벌로 같은 계산을 반복했습니다.

| 모델 | 실제 | 무작위 평균 (최소–최대) | 실제보다 같거나 좋은 무작위 | 실제 − 무작위 평균 (95% 구간) |
|---|---|---|---|---|
| 경로 부분공간만 (`par_gl`) | 1.0555 | 1.0586 (1.0496–1.0657) | 6 / 20 | −0.0030 [−0.0141, +0.0095] |
| soft prior, λ 하나 (`soft_gl`) | 1.0374 | 1.0359 (1.0326–1.0372) | 20 / 20 | +0.0015 [−0.0008, +0.0042] |
| soft prior, 약물별 (`soft_pd`) | 1.0332 | 1.0282 (1.0241–1.0298) | 20 / 20 | +0.0050 [−0.0011, +0.0119] |
| 최종 통합 (`full_resid`) | 1.0299 | 1.0296 (1.0295–1.0296) | 20 / 20 | +0.0004 [−0.0008, +0.0016] |

- **관측:** soft prior 계열에서 실제 Hallmark는 무작위 20벌 모두보다 점수가 높았습니다(나빴습니다). 차이의 구간은 0을 포함합니다.
- **관측:** 최종 통합 모델은 prior가 무엇이든 점수가 거의 같습니다(무작위 사이 표준편차 0.00003).
- **확인하지 않은 것:** 무작위 prior의 `soft_pd`(1.0282)가 `ridge_pd`(1.0306)보다 낮은 이유. "임의의 50차원을 덜 규제하는 후보가 늘어난 효과"일 수 있으나 검증하지 않았습니다.

## 5. 진단이 지지한 것과 반박한 것

| 가정 | 진단 결과 |
|---|---|
| hard 압축이 정보를 버린다 | **지지.** 경로 부분공간만 쓰면 0.018 나쁨 |
| 경로 방향이 다른 방향보다 유용하다 | **지지하지 않음.** 빼도 같고, 무작위 묶음보다 낫지 않음 |
| 약물 사이에 공유 구조가 있다 | **지지.** 강한 공통 성분 하나 |
| 그 공유를 모델에 넣으면 예측이 좋아진다 | **부분적.** λ 하나 Ridge보다는 좋으나 약물별 λ Ridge 대비 이득은 0.001로 미확인 |
| 표본 부족이 한계다 | 직접 시험하지 않음. 모든 구간의 폭(±0.09)이 모델 간 차이(0.001–0.02)보다 훨씬 큼 |
