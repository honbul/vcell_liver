## R1-0. 유전자 축의 중복 기호 규칙 수정과 A1r/A3 재계산 (2026-11-17 기록)

- **관측:** 연구 A는 같은 유전자 기호가 여러 Ensembl ID에 붙은 경우 "LIMORE 평균 발현이 가장 높은 ID"를 남겼습니다(19,025 → 19,018개). 이 규칙은 발현값을 봅니다. 연구 A의 Ridge는 alpha 후보의 가장 큰 값(10000)을 1,350번 중 896번 골랐습니다(`internal_alpha_counts.tsv`).
- **가설:** 중복 기호는 7개뿐이므로 규칙을 "가장 작은 Ensembl ID"(발현값과 무관)로 바꿔도 A1r·A3의 점수는 사실상 같을 것입니다.
- **예측:** 고친 축에서 A1r ≈ 0.9916, A3 ≈ 1.0353이고, 두 축의 차이의 계열 bootstrap 구간이 0을 포함합니다. 새 채점 코드는 연구 A가 커밋한 예측표에서 연구 A의 수치를 소수 다섯째 자리까지 재현합니다.
- **실험:** (1) 축을 고정 ID 규칙으로 다시 만들고 순위·Hallmark 점수를 다시 계산합니다. 다른 것은 모두 연구 A와 같습니다(같은 유전자 전체집합, 같은 계열표·분할·약물 대응·정답표). (2) 연구 A의 코드(`nested.fit_predict`)로 A0·A1·A1r·A3을 같은 바깥 fold에서 다시 학습합니다. (3) 풀이기 점검: η=0, τ=0이 연구 A의 가중 Ridge와 같은지, 쌍대 풀이·축약 풀이·전체 공간 풀이·PyTorch 풀이가 합성 자료에서 일치하는지 확인합니다.
- **결정 규칙:** 차이의 구간이 0을 포함하면 고친 축을 이후 모든 단계에 씁니다. 차이가 크면 다음 단계로 가지 않고 자료 원인을 먼저 확인합니다. 풀이기 점검이 하나라도 실패하면 실제 자료 학습을 시작하지 않습니다.

## R1-1. 경로 부분·경로 밖 부분의 Ridge 진단(D1)과 약물 간 공유 구조 진단(D2) (2026-11-17 기록, 실행 전)

### D1 — 경로 요약에서 빠지는 정보에도 예측 신호가 있는가

- **관측:** 연구 A에서 유전자 순위 Ridge(0.9916)가 Hallmark 점수 Ridge(1.0353)보다 좋았습니다. Hallmark 점수의 선형 모델은 유전자 가중치를 50차원 부분공간(표준화 좌표에서 `diag(s)·M`의 열공간) 안에 가둡니다. 이 대응은 합성 자료 점검(`test_hard_limit_is_pathway_subspace_regression`)에서 확인했습니다.
- **가설:** 차이는 "경로가 쓸모없어서"가 아니라, 경로 부분공간 밖에 남는 유전자 정보에도 예측 신호가 있는데 hard 요약이 그것을 버렸기 때문일 수 있습니다.
- **예측:** 안쪽 fold 손실에서 (a) 경로 밖 부분만 쓴 Ridge(`perp`)가 학습 평균 수준(손실 1.0 부근)보다 좋고, (b) 전체(`whole`)가 경로 부분만(`par`)보다 좋습니다. 반대로 `perp`가 평균 수준이면 경로 밖 정보에 신호가 없다는 뜻입니다.
- **실험:** grid `d1_subspace` — τ=0, λ 7개(10⁻⁴…10²), 커널 3종(`whole`, `par`, `perp`). 15개 바깥 학습 집합 각각의 안쪽 3-fold 손실만 계산합니다(바깥 시험 정답 미사용). 약물별 λ 선택과 전체 공통 λ 선택을 모두 봅니다. 선택된 λ가 격자 끝에 몰리는지도 확인합니다.
- **결정 규칙:** (a)와 (b)가 모두 성립하면 경로 밖 정보를 보존하는 soft prior를 R1-2의 기본 설계로 둡니다. `perp`에 신호가 없으면 잔차 갈래를 복잡하게 하지 않고 단순 soft prior만 시험합니다. λ가 격자 끝(10⁻⁴ 또는 10²)에서 절반 이상 선택되면, R1-2 전에 한 번만 범위를 넓히고 그 사실을 여기에 적습니다.

### D2 — 약물 사이에 공유할 구조가 있는가

- **관측:** 정답 행렬은 79×90으로 빠짐이 없습니다. 약물 90개가 계열 76개를 공유하므로, 약물 사이 상관이 있으면 함께 학습할 여지가 있습니다. 아직 그 크기를 재지 않았습니다.
- **가설:** 여러 약물에 공통인 민감도 축(예: 전반적 민감도)이 있고, 학습 계열에서 구한 그 축이 보지 않은 계열에서도 재현됩니다.
- **예측:** (a) 안쪽 학습 계열의 상위 k개 주성분이 안쪽 시험 계열의 표준화 AA 분산에서 차지하는 몫이 무작위 부분공간 기대값 k/90과, 약물별로 따로 섞은 대조보다 뚜렷이 큽니다. (b) 계열 bootstrap에서 상위 부분공간이 안정적입니다. (c) RNA로 그 주성분 점수를 예측한 안쪽 손실이 개별 약물의 평균 손실보다 낮습니다. (c)가 성립하지 않으면 공유 구조가 있어도 RNA 모델의 다중과제 수축이 도움이 될 근거는 약합니다.
- **실험:** `diag_drug_cov.py` — 15개 바깥 학습 집합과 그 안쪽 fold 안에서만 계산합니다. k ∈ {1, 2, 3, 5, 10, 20}, 계열 bootstrap 200회, 섞기 대조 20회. 시험 AA로 약물군이나 rank를 고르지 않습니다.
- **결정 규칙:** (a)·(b)가 성립하면 τ>0(다중과제 수축)을 R1-2 설계에 포함합니다. τ 후보는 `τ_max`(해가 0이 되는 최소 τ, 학습 자료만으로 계산)의 세 가지 비율로 두고, 비율은 D2에서 본 스펙트럼 모양을 근거로 R1-2 기록에 먼저 적습니다. (a)가 성립하지 않으면 τ는 진단용 한 설정만 남깁니다.

**갱신된 결정:** 사전 규칙대로 (1) 경로 밖 정보를 보존하는 soft prior를 R1-2의 기본 설계로 두고, (2) 다중과제 수축(τ>0)을 설계에 포함합니다. 다만 D1의 추가 관측(경로 부분공간을 빼도 같음) 때문에 η>0의 이득에 대한 기대는 낮습니다. 이것은 R1-2의 예측에 반영합니다.

## R1-2. 처음의 통합 설계: soft prior + 다중과제 수축 (2026-11-17 기록, 실행 전)

- **관측:** D1 — 전체 공간이 경로 부분공간만보다 좋고, 경로 부분공간을 빼도 점수가 같습니다. D2 — 약물 사이에 강한 공통 성분 하나와 약한 성분 몇 개가 있고, 공통 성분은 개별 약물보다 RNA로 잘 예측됩니다. 약물별 λ가 공통 λ보다 0.007 좋습니다.
- **가설:** (H-τ) 약물 계수행렬에 nuclear-norm 수축을 걸면 여러 약물이 공유하는 방향에 학습이 모여 공통 λ Ridge보다 좋아집니다. (H-η) 경로 밖 방향을 더 세게 규제하는 soft prior는 D1에 비추어 이득이 작거나 없습니다.
- **예측:** 선택 정직 개발 점수에서 (1) `mt_noprior`(η=0, τ≥0)가 `ridge_gl`보다 낮습니다. (2) `soft_gl`(η≥0, τ=0)은 `ridge_gl`과 구간이 겹치고 η/λ=0이 가장 자주 선택됩니다. (3) `full`(η≥0, τ≥0)은 `mt_noprior`와 같습니다. H-τ가 틀리면 (1)에서 차이의 구간이 0을 포함하거나 τ=0이 선택됩니다.
- **실험:** grid `r2_soft_multitask` — λ 7개(계획서 값) × η/λ ∈ {0, 1, 10, 100} × τ/τ_max ∈ {0, 0.03, 0.1, 0.3}. τ_max는 해가 0이 되는 최소 τ로, 해당 학습 집합의 RNA와 AA만으로 계산합니다. 비율 세 값은 D2의 스펙트럼(첫 성분 35%, 이후 5–7%씩)에 맞춰 "rank 1 부근 / 몇 개 / 열 개 이상"이 되도록 기하 간격으로 잡은 것이며, 실제 rank는 실행 후 기록합니다. η=0·τ=0 열은 D1 실행의 값을 그대로 씁니다. 풀이는 축약 공간 ADMM(허용오차 10⁻⁷, 최대 20,000회)이고 수렴 실패는 모두 기록합니다. 모델 5종: `soft_pd`, `soft_gl`, `mt_noprior`, `full`, 비교 기준 `ridge_pd`·`ridge_gl`·`par_gl`. 15개 학습 집합의 안쪽 fold만 사용합니다. 실행 전에 PyTorch 대조를 포함한 풀이기 점검을 다시 통과해야 합니다.
- **결정 규칙:**
  1. `full`이 `ridge_gl`과 `ridge_pd` 모두보다 낮고 두 차이의 구간이 0 아래이면 이 설계로 R1-4(무작위 prior·결합 제거)로 갑니다.
  2. 그렇지 않으면 계획서 7절의 분기를 따릅니다. η/λ=0이 대부분 선택되면 prior의 이득이 없다는 결과로 기록하고, 경로 수십 종을 탐색하지 않습니다. τ>0이 선택되는데 일부 약물이 나빠지면 "공통 low-rank + 약물별 Ridge 잔차" 한 변형을 수정 1로 검토합니다. ADMM이 수렴하지 않거나 학습 손실이 Ridge보다 나쁘면 풀이·척도를 먼저 점검합니다.
  3. τ 비율 세 값이 모두 같은 rank 영역(전부 rank ≤ 1 또는 전부 rank ≥ 30)에 떨어지거나 선택이 격자 끝(0.3 또는 0.03)에 80% 이상 몰리면, 비율을 3배 옮기는 범위 확장을 한 번만 허용합니다.

## R1-3. 수정 1: 공통 low-rank 적합 + 약물별 Ridge 잔차 (2026-11-17 기록, 실행 전)

- **관측:** 약물 사이 공유(τ>0)는 공통 λ Ridge보다 0.004 좋지만, 모든 약물에 같은 규제 강도를 쓰기 때문에 약물별 λ Ridge(0.007 좋음)에 못 미칩니다. 약물의 절반은 공유로 좋아지고 절반은 약물별 강도를 잃어 나빠집니다.
- **가설:** 두 이득은 서로 다른 약물에서 나오므로 합칠 수 있습니다. 공유 부분은 모든 약물에 한 설정으로 맞추고, 남은 잔차에 약물마다 강도를 따로 고른 Ridge를 더하면 `ridge_pd`와 `mt_noprior` 둘 다보다 좋아집니다.
- **예측:** 선택 정직 개발 점수에서 `mt_resid`가 `mt_noprior`보다 낮고(구간 0 아래), `ridge_pd`보다 낮습니다. 가설이 틀리면 `mt_resid`가 `ridge_pd`와 같거나(공유 부분이 선택되지 않거나 잔차 단계가 공유의 이득을 되돌림) 더 높습니다. `full_resid`(η≥0)는 `mt_resid`와 같을 것으로 예측합니다(R1-2의 예측 (3)과 같은 근거).
- **실험:** grid `r3_lowrank_residual`. 1단계는 R1-2와 같은 목적함수의 해(η/λ ∈ {0, 1, 10, 100}, λ 7개, τ/τ_max ∈ {0.1, 0.3}; 0.03은 rank가 39로 학습 계열 수에 가까워 "low-rank 공유"가 아니므로 제외)이고, 2단계는 그 해의 **학습 잔차**에 약물별 전체 공간 Ridge(λ₂ 7개 + "더하지 않음")를 더합니다. 설정 선택은 "공유 부분은 모든 약물에 하나, λ₂는 약물마다"이며, 공유 부분이 없는 경우(= `ridge_pd`)를 후보에 포함합니다. 따라서 `ridge_pd`는 새 모델의 특수한 경우이고, 후보 수는 `ridge_pd`보다 많습니다(선택 정직 점수로 비교하는 이유). 이것은 순차 적합이며 두 부분을 함께 최적화한 해가 아닙니다. 15개 학습 집합의 안쪽 fold만 사용합니다. 실행 전 새 시험(특수한 경우 2건, sklearn 대조 1건)을 통과해야 합니다.
- **결정 규칙:**
  1. `mt_resid` 또는 `full_resid`가 처음 설계의 `full`보다 낮고 차이의 구간이 0 아래이면 이 구조를 최종 설계로 채택합니다. 둘 가운데 무엇을 "통합 모델"로 부를지는 정의로 정해져 있습니다(η≥0을 포함한 `full_resid`가 통합 모델, `mt_resid`가 prior 없는 대조).
  2. 그렇지 않으면 처음 설계(`full`, `mt_noprior`)를 최종 설계로 둡니다.
  3. 어느 경우든 `ridge_pd`를 이기는지는 채택 조건이 아니라 결과입니다. `ridge_pd`와 구간이 겹치면 "공유의 추가 이득 미확인"으로 적습니다.
  4. 수정 2는 이 실행의 진단이 특정한 원인(예: 잔차 단계가 격자 끝에 80% 이상 몰림, 수렴 실패)을 가리킬 때만 씁니다. 원인이 특정되지 않으면 쓰지 않습니다.

## R1-4. 무작위 prior 대조와 결합 제거 (2026-11-17 기록, 실행 전)

- **예측 대조:** "실제 − 무작위 평균의 구간이 0을 포함한다"는 모든 모델에서 성립했습니다. "실제 점수가 무작위 20개의 범위 안에 있다"는 soft prior 계열 네 모델에서 **글자 그대로는 빗나갔습니다.** 실제 prior가 무작위 20개 모두보다 **나쁜 쪽**으로 범위 밖입니다(예: `soft_gl` 1.0374 대 무작위 최대 1.0372). 가설을 뒤집는 경우로 미리 적어 둔 "실제가 20개 모두보다 좋다"와는 반대 방향입니다.
- 관측: `full_resid`에서 무작위 prior 사이의 표준편차는 0.00003입니다. prior가 무엇이든 점수가 거의 같다는 뜻입니다.
- 관측: `soft_pd`는 무작위 prior일 때 평균 1.0282로 `ridge_pd`(1.0306)보다 낮습니다. 이 차이의 구간은 계산하지 않았습니다. "임의의 50차원 부분공간을 덜 규제하는 후보가 늘어난 효과"로 볼 수 있으나 **검증하지 않은 해석**입니다.
- hard 부분공간(`par`)에서는 실제가 무작위 평균보다 0.001–0.003 낮지만 20개 중 6개가 실제보다 좋고 구간이 0을 포함합니다.
- 결합 제거: `mt_resid` − `ridge_pd` = −0.0010 [−0.0037, +0.0018](R1-3). 공유를 넣은 효과는 개발 구간에서 확인되지 않았습니다.
- **갱신된 결정:** 사전 규칙대로 모델 구성은 바꾸지 않습니다. 개발 구간의 증거는 "실제 Hallmark prior의 추가 가치 없음, 약물 공유의 추가 가치는 약물별 λ Ridge 대비 0.001 수준으로 미확인"입니다. 이 상태로 동결합니다. 남은 수정 1회는 쓰지 않습니다.

## R1-5. 동결과 최종 평가 (2026-11-17 기록, 실행 전)

- **관측:** 개발 구간(안쪽 fold)에서 `full_resid` 1.0299, `mt_resid` 1.0296, `ridge_pd` 1.0306, `ridge_gl` 1.0377, `par_gl` 1.0555. 실제 prior는 무작위 prior보다 낫지 않았습니다.
- **가설:** 바깥 fold에서도 순서가 같습니다. `full_resid`는 hard prior(`par_pd`, A3)보다 좋고, `ridge_pd`·A1r과는 구간이 겹치며, `mt_resid`·무작위 prior와 같습니다.
- **예측:** 계획서 9절 표에서 "full이 좋지만 prior 없는 multitask와 같음"의 앞 조건(full이 Ridge를 이김)이 성립하지 않고, "η=0이 선택되고 Ridge와 같음"에 가장 가까운 결과가 나옵니다(다만 η>0은 선택되지만 무작위 prior와 같은 형태). LCCL에서는 `full_resid`와 `ridge_pd`의 순위 일치도 차이의 구간이 0을 포함합니다.
- **실험:** `freeze_manifest.json`에 적힌 커밋·설정·모델 목록·비교 쌍으로 한 번만 실행합니다. 중첩 family CV(바깥 5-fold × 3회, 안쪽 3-fold; 연구 A의 분할 그대로)에서 모든 격자를 바깥 학습 집합마다 다시 계산하고, 각 모델이 그 학습 집합의 안쪽 손실로만 설정을 고릅니다. 무작위 prior 20개도 같은 경로를 탑니다. LCCL은 LIMORE만으로 학습한 뒤 예측하며, 공유 계열은 해당 계열을 LIMORE 학습에서 뺍니다. 비교군: 학습 평균, 연구 A의 A1·A1r·A3(고친 축), raw-RNA ElasticNet, cwKBMF(저자 MATLAB 코드를 Octave로), TabPFN v2(학습 전용 PCA ≤50).
- **결정 규칙:** 최종 실행 뒤에는 모델·격자·비교 쌍을 바꾸지 않습니다. 계획서 9절의 표를 글자 그대로 적용합니다. "이긴다"는 주지표 차이의 95% 계열 bootstrap 구간이 0 아래에 있다는 뜻으로 고정합니다. 비교군이 실행되지 않으면 이유를 적고 칸을 비웁니다. LCCL 결과로 어떤 것도 고치지 않습니다.
