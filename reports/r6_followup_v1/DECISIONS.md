- 단계 A: 원 R6 checkpoint에서 약물 부분 h의 크기는 pool 내 약물 간 실제 차이의 2.6%이고 h를 0으로 두어도 전체 RMSE가 0.1%만 변한다. 양성 대조(한 well을 반으로 나눈 것)에서는 같은 지표가 0.082 → 0.049로 내려가고 pool 내 retrieval top1이 0.99가 되므로, 지표가 신호를 못 보는 것은 아니다.
- R의 Ridge 벌점은 아홉 번 모두 약물 블록 벌점이 격자의 최댓값(1e5)에서 골라졌다. 격자를 넓히지 않았다(넓히면 약물 블록이 더 줄어들 뿐이고, SD/S/M의 결론과 무관하다).

### 해석

1. (관측) 대조군 세포를 입력으로 쓴 모델들이 세포주 평균을 이긴 양(−10%)은 **pool 평균 하나로 더 크게(−12.4%) 얻어진다.** 모델은 pool 평균보다 1.2–2.4% 나쁘다.
2. (관측) 약물 입력을 뺀 S와 넣은 SD는 pool 내 대비에서 구분되지 않고, 전체 RMSE 차이는 0.2%이다. 현재 구조·손실에서 약물 입력은 약물 간 차이를 예측하는 데 쓰이지 않는다.
3. (관측) count 집합 encoder(SD)는 집합 평균만 본 MLP(M)보다 낫지 않다(1.2% 나쁨). 낮은 관측량에서 집합 모델이 유리해지는 모습도 없다.
4. (가설, 미검증) 모델이 pool 평균 수준에 닿는 까닭은 "그 pool의 다른 약물 반응"을 학습 때 보았기 때문이고, 대조군 세포에서 pool 이동을 **읽어내는** 능력 때문이 아닐 수 있다. 이것은 처음 보는 plate로 옮겨 보아야 가려진다.

### 결정: 분기 F1과 F2를 실행한다 (최대 2개). F3는 추론 전용 표만 만든다.

**F1 — pool 평균 앵커 + 약물 쌍 대비 손실** (프로토콜 6절 첫 행에 해당: SD가 S보다 pool 내 대비에서 낫지 않다)
- 바꾸는 것 하나: 예측을 `fit 약물의 축소 pool 평균(자기 약물 제외, κ=2) + 모델 출력`으로 두고, 같은 대조군 집합의 약물 12개 사이의 **차이**에 대한 오차를 손실에 더한다. 구조·입력·view·갱신 수는 SD와 같다.
- 개발(fold 2의 inner dev, seed 42)에서 네 설정만 본다: (쌍 손실 1, h 축소 10), (쌍 손실 1, h 축소 0), (쌍 손실 4, h 축소 0), (앵커만, 쌍 손실 0). h 축소 항(계수 10)은 약물 부분을 0으로 미는 항이라 쌍 손실과 정면으로 부딪치므로 0도 후보에 넣는다. 고르는 기준: inner dev의 pool 내 대비 RMSE가 가장 낮은 쌍 손실 설정(동률이면 전체 RMSE).
- 확인: 고른 설정 하나(F1)와 앵커만(F1A, 귀속용 대조)을 fold 3 × seed 3으로.
- 판정(미리 고정): `F1 − SD`와 `F1 − pool 평균`의 pool 내 대비가 `improved_*`이면 "약물 차이를 직접 학습하면 일반화되는 약물 신호가 있다". `no_large_gain`이면 끝난 부정 결과. 전체 RMSE는 `F1 − pool 평균`으로 본다.
- 예상(가설): 부정 쪽. 근거는 (a) 원 R6 개발에서 h 축소가 큰 설정이 골라졌다는 점, (b) 같은 약물이 두 plate에 있는 21개 약물에서 pool 중심화 반응의 plate 간 cosine 평균이 0.01이고 강한 약물 3개에서만 0.4–0.8이었다는 점(`positive_control_replicate_wells.tsv`). 다만 (b)는 plate와 반복이 섞여 있는 관측이라 원인은 미확인이다.

**F2 — plate 이동** (프로토콜 6절 둘째 행에 해당: 전체 RMSE 이득이 pool 평균으로 설명된다)
- 평가 방식만 바꾼다: plate 하나를 통째로 빼고(그 plate에 조건이 있는 학습 약물은 모두 fit에서 제외) S/SD/M/R을 학습해, 빠진 plate의 조건을 예측한다. 5개 plate × seed 3. 학습률은 단계 C의 값을 그대로 쓴다. Ridge 벌점은 fit 약물 안에서 다른 plate 하나를 빼는 같은 구성으로 고른다.
- 이때 pool 평균은 쓸 수 없다(그 pool의 반응이 하나도 없다). 이동 기준선은 fit 약물의 세포주 평균이다. 참고선으로 "그 plate의 반응을 본" pool 평균과 단계 C의 SD를 같은 조건에서 함께 적는다.
- 판정(미리 고정): `SD − 세포주 평균(이동)`의 전체 RMSE 범주, 그리고 gap_closed = (세포주 평균 − 팔)/(세포주 평균 − pool 평균(참고)). gap_closed가 0에 가까우면 "모델은 대조군 세포에서 pool 이동을 읽지 못하고, 본 pool의 평균을 외웠다"; 1에 가까우면 "대조군 세포가 pool 이동의 정보를 실제로 나른다".
- 한계(미리 적음): plate는 5개뿐이다. 약물 bootstrap 구간은 plate 표본 불확실성을 담지 않으므로 plate별 행을 결과의 일부로 본다.

**F3 — 관측 예산**: 학습을 바꾸는 분기로는 고르지 않는다. 이유: SD가 M보다 낮은 관측량에서 유리하다는 관측이 없다(깊이 상호작용 0). 학습이 필요 없는 추론 전용 N × p 표(`observation_budget.tsv`)만 병행해서 만든다. N과 p를 함께 표집하는 재학습은 `NOT_RUN.md`에 적는다.

### 고르지 않은 것과 이유
- F3 재학습: 위와 같음. 분기는 최대 2개이다.
- 구조를 키우거나 약물 표현을 바꾸는 것: 이번 분석의 범위가 아니다(하나의 변경만).
- 시험 약물 재평가(단계 E): 분기 결과를 본 뒤 따로 결정한다. source에서 pool 평균보다 나은 설정이 없으면 동결할 새 모델이 없으므로 하지 않는다.

## D6. 분기 결과 뒤의 결정 (2026-11-18, F1·F2 표를 본 뒤)

- 관측 (`anchor_pairloss.tsv`, `plate_transfer.tsv`): `F1 − pool 평균` 전체 RMSE +0.000210 [−0.000117, +0.000530], pool 내 대비 +0.000247 [−0.000108, +0.000564], 둘 다 no_large_gain. `F1 − SD` pool 내 대비 +0.000171 [−0.000066, +0.000374], no_large_gain. F2에서 `SD − 세포주 평균(이동)` −4.2% (improved_operational), gap_closed 0.22 [0.17, 0.27], plate별 −0.16–0.58.

## D7. 기존 벤치마크 후속 평가 — 기록 전용 (2026-11-18, 채점 실행 전에 적고 커밋함)

**이름: "existing-benchmark follow-up evaluation, record only, after the follow-up concluded negative" (기존 벤치마크 후속 평가, 기록 전용, 후속 분석이 부정으로 끝난 뒤).**

- 배경: D6에서 단계 E를 하지 않기로 했다(동결할 새 모델이 없음). 그 뒤 사용자가 최종 보고의 열린 결정 1번을 승인했다: S, M, F1A를 시험 약물에 **한 번, 기록용으로만** 채점한다. 이것은 모델 선택이 아니고 성공 주장도 아니다. 이 숫자로 아무것도 고르지 않고, 결론(7절)을 바꾸는 근거로도 쓰지 않는다.
- 왜 하나: 시험 약물에서 새 팔이 어떤 값을 내는지는 7.3절에서 "모른다"로 남은 항목이다. 그 칸을 채워 두려는 것이다. 이미 한 번 채점된 시험 집합이므로 독립 검증이 아니다.
- 채점하는 것 (설정은 모두 이미 쓴 것, 새 조정 없음):
  - S: count 집합, 약물 입력 없음, lr 1e-3 (D3).
  - M: 집합 평균 + ECFP4, lr 3e-3 (D3).
  - F1A: SD 구조 + 축소 pool 평균 앵커(κ=2, D1), 쌍 손실 0, h 축소 10, lr 3e-3 (D5의 귀속용 대조).
