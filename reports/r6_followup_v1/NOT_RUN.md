# 실행하지 않은 것 (R6 후속 분석 followup_v1)

여기 적힌 것은 **결과가 없다.** 아래 어느 항목도 "했으면 좋아졌을 것"이라는 뜻이 아니다. 자동으로 이어 붙이지 않았고, 다음에 할지는 사람이 정한다.

| 항목 | 무엇인가 | 하지 않은 이유 |
|---|---|---|
| 단계 E — 시험 약물 70개의 후속 평가 | 동결 커밋 뒤 새로 학습한 팔을 시험 약물에 한 번 채점 | `DECISIONS.md` D4에 미리 적은 조건("source에서 pool 평균보다 나은 설정이 없으면 하지 않는다")에 해당했다. source out-of-fold에서 어느 팔·어느 분기도 pool 평균보다 전체 RMSE가 낮지 않았다. 동결할 새 모델이 없으므로 동결 커밋도 없다. 시험 약물은 단계 A의 원인 진단 표(기존 예측의 재채점)에만 쓰였다. |
| F3 재학습 — N과 p를 함께 표집하는 학습 | 세포 수 N ∈ {8…64}와 유지율 p를 학습 중에 함께 바꾸는 모델 | 분기는 최대 2개이고 F1·F2를 골랐다. source에서 집합 encoder가 낮은 관측량에서 유리해지는 모습이 없었다(깊이 상호작용 0, 추론 전용 표의 모든 칸에서 SD가 M보다 나쁨). 추론 전용 N × p 표(`observation_budget.tsv`)만 만들었고, 그 표의 N<64 칸은 학습·추론 불일치가 섞여 있다. |
| F1의 더 넓은 탐색 | 쌍 손실 계수·h 축소·학습률의 넓은 격자, 다른 대비 손실(순위 손실, 대조 학습 등), 약물 표현 교체 | 미리 적은 네 설정만 개발에서 보았다(D4·D5). "하나의 변경" 범위를 넘는다. |
| F1 설정 가운데 h 축소 0 두 개의 확인 실행 | (쌍 손실 1, 축소 0), (쌍 손실 4, 축소 0)을 fold 3 × seed 3으로 | 개발(inner dev)에서 pool 평균보다 pool 내 대비가 3.5–3.8% 나빴다(학습 약물의 차이를 외우고 새 약물로 옮기지 못함). 미리 정한 기준으로 고르지 않았다. |
| F2에서 F1 방식(앵커) 결합 | plate 이동 상황에서 앵커를 쓰는 모델 | 처음 보는 plate에는 pool 평균 앵커 자체가 없다. 정의할 수 없는 조합이다. |
| F2의 plate 수준 불확실성 | plate를 표본 단위로 한 구간 | plate가 5개뿐이다. plate별 행을 그대로 보고했다. |
| Ridge 벌점 격자 확장 | 약물 블록 벌점을 1e5 위로 | 격자 끝에서 골라졌지만, 넓히면 약물 블록이 더 줄어 R이 "약물 없는 선형 모델"에 가까워질 뿐이다. SD·S·M의 결론과 무관하다고 판단했다(미검증). |
| 독립 반복 실험에 의한 양성 대조 | 다른 날·다른 배양의 같은 (세포주, 약물)로 지표 상한 추정 | 자료에 독립 반복이 없다. 한 well을 반으로 나눈 기술적 분할과, 같은 약물이 두 plate에 있는 21개 약물만 있었다(후자는 plate와 반복이 섞여 있다). |
| plate 간 재현성이 낮은 원인 분석 | plate × 약물 상호작용인지 기술 효과인지 가리기 | 이 자료로는 가릴 수 없다(1.4절). 따로 설계가 필요하다. |
| 검증 약물 70개 | 어떤 용도로든 | 원 R6에서 쓰지 않은 채 남겨 둔 집합이다. 이번에도 열지 않았다. |
| 다른 seed·더 많은 반복 | seed 42/43/44 밖 | 계획의 상한(신경망 확인 27회)을 지켰다. seed 간 차이는 팔 간 차이보다 작았다(`*_runs.tsv`). |
| 구조 확대, 사전학습 encoder, 다른 약물 지문 | 모델 용량·표현 변경 | 이번 분석의 범위가 아니다. |
