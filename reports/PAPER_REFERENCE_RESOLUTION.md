GEARS: the public run project [pert_gnn_simulation_norman2019](https://wandb.ai/kexinhuang/pert_gnn_simulation_norman2019) has five trained GEARS runs and five matching no-perturb runs. The original source, logs and configuration establish 20 epochs, batch 32, hidden size 64, and split seeds 1–5, using the private input name `norman_same_splits`. Demonstration scripts contain other epoch counts. The exact reference values and public run IDs are in [the reference TSV](../manifests/reference/gears_fig2f_author.tsv). The figure normalization divides the average GEARS error in a subgroup by the average no-perturb error in that subgroup. The collector reports actual group membership separately from the author simulation labels.

scGPT: Fig. 3a is driven by `tutorials/Fig3_AB_PerturbPred.py` in the manuscript release. Its [Figshare data index](https://figshare.com/articles/dataset/scGPT_reproducibility/24954519) points to the public GEARS Norman archive. The run used seed 0, simulation split seed 1, 15 epochs and batch 64, with 1,536 sampled training genes and full-panel evaluation. The original run points to a private pretraining directory and existing PyG and split files. The public whole-human release used for the new run is hashed and the loaded backbone tensors will be checked by value. The paper path preserves the manuscript's random gene panel behavior and records missing flags. The common path always includes targets and keeps its metrics separate.

The [environment freezes](../manifests/environment) document the new runtime. Compatibility changes include scGPT JSON vocabulary indexing without torchtext, strict fused QKV key translation, PyTorch attention in place of the original FlashAttention package, removal of the unused scIB import and visualization block, and replacing a retired NumPy float alias. Both runners add epoch checkpoints and local output; the paper tracks retain native selection and evaluator logic. The runtime and published asset differences mean the two jobs are modified reproductions, even if their scores later happen to be close to the author values.

Submission records on G1: GEARS seed 1 `17663`, remaining GEARS seeds `17665` (array concurrency limit four), scGPT `17664`, environment `17660` (completed). Runtime checks while the jobs are active: scGPT's regenerated simulation split has 9/52/18/37 test conditions in the author groups `combo_seen0`/`combo_seen1`/`combo_seen2`/`unseen_single`, exactly the counts printed in the original log. Matching group sizes and key names cannot establish identity of condition IDs, paired controls or the original private checkpoint's tensor values.


The figure denominator was further verified from all five original `No_Perturb` run sources and output logs. The pinned historical model forwards each input control cell's expression directly, and its training script bypasses optimization. The public source and shared patch corroborate that behavior; the local R1 denominator uses the same identity operation on the newly generated pairs. [Baseline provenance and subgroup counts](../manifests/reference/gears_fig2f_no_perturb_provenance.json) preserve the original logs' hashes. For seed 1 the regenerated GEARS groups contain 9/52/18/37 conditions, matching the original denominator log's counts. That does not establish original pair identity.

The original GEARS array held seeds 2–5 behind seed 1 as an execution check. After seed 1 completed seven training/validation epochs and its checkpoint passed the read-only verification, that dependency was released on the existing array. The strict paper handoff still waits for all five GEARS repetitions and scGPT.

After seeds 2 and 3 began training, the scheduler showed four free A40s on g3. The existing array limit was raised from two to four to let seeds 4 and 5 become eligible for dispatch. The five requested splits and model settings did not change.

All five GEARS replays and the scGPT replay have now entered training. The [split metadata check](preflight/paper_split_alignment.json) records the split hashes and matches the four reported subgroup counts to the original no-perturb GEARS logs for all five seeds and to the original linked scGPT run. Across all six regenerated splits there is no cross-role overlap even when reversing the order of two genes is treated as the same intervention. This rules out that particular overlap in these runs. It does not identify the original private cells or control pairs and does not establish score equivalence.

GEARS split seed 1 finished on G1 at 20:11 KST on November 5, 2026. The [execution audit](paper/R1-s1/execution_audit.json) confirms all 20 epochs, the final marker, test condition coverage and the recorded hashes for the split, prediction and model files. The [same-seed comparison](paper/R1-s1/same_seed_comparison.tsv) gives normalized error of 0.22839 / 0.33268 / 0.42942, versus the author runs' seed 1 values of 0.25916 / 0.31056 / 0.29896 for 0/1/2 unseen targets. These values describe one split of the modified replay; the five-split comparison is still pending.

The published grouping is assigned by the outer simulation split before the [pinned splitter](https://github.com/snap-stanford/GEARS/blob/9d27bd619935cebe6f1519c3b53f61d2777dee59/gears/data_utils.py) carves out validation. For this replay the final train singles alone differ from the labels in 4/8/0 conditions for 0/1/2 unseen targets. Counting train plus validation singles resolves all 12 differences. The comparison preserves the published grouping.

Seed 1 diagnostic: the author used a private preprocessed dataset and saved pairs, so exact cell, gene and pair identity cannot be checked. Both scripts initialize a fresh GEARS model and train for 20 epochs with batch size 32. The replay records 1,602 batches per epoch. Both logs print through step 1,601 every epoch, consistent with 1,601–1,650 author batches under the pinned code's 50-step logging cadence. The minimum logged validation top-20 DE MSE occurs at epoch 3 for the author (0.1561) and epoch 6 for the replay (0.1441, both rounded); the best checkpoint thus differs before test scoring. The [author run](https://wandb.ai/kexinhuang/pert_gnn_simulation_norman2019/runs/3m9uygq6) package record lists Torch 1.12.1+cu116 and PyG 2.1.0 (requirements SHA-256 `10ee0e5e62a05cc64140950ec39500ea24c8a4ac602642b14971012388010079`); this replay uses Torch 2.5.1+cu124 and PyG 2.6.1. The test table uses the pinned native non-dropout evaluator. The observed discrepancy cannot be attributed to any one of the data, pairing or runtime differences.

The independent seed 1 spot check (Slurm `17702`, exit 0) confirmed condition coverage and counts, gene order, and measured condition means against the public matrix. Recomputing top-20 non-dropout MSE from saved predictions agreed exactly with all 116 condition values in the GEARS column (maximum absolute difference 0). This checks the local metric calculation; the full paper audit still covers all repetitions.
