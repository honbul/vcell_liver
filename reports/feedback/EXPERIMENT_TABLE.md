## F1 진단 (A1–A5) — Norman K562 CRISPRa, 저장된 체크포인트 재분석

다섯 항목 모두 **새 학습 없이** 기존 산출물을 다시 채점했다. 공통 분할은 이전 연구의 분할 시드 26, 학습 155개 개입 / 검증 34개 개입이며 홀드아웃은 손대지 않았다. 출처: [F1_DIAGNOSTICS](F1_DIAGNOSTICS.md).

| 고정 조건 | 분할 시드 26, 학습 시드 0, 15회차, 동일 전처리·평가 대조군 32개 |

### F3-2

| 항목 | 내용 |
|---|---|
| 가설 | 다른 세포주의 같은 표적 반응을 크기 보정해 옮기면 무변화보다 낫다 |
| 고정 조건 | fold별 평가 패널, 표적 단위 paired bootstrap |

## 공통 한계

- 모든 bootstrap은 개입 또는 표적 단위이고, 이들은 독립 생물 반복이 아니다.
- Norman(CRISPRa)·4세포주(CRISPRi)·Tahoe(화학) 결과를 하나의 지표로 합산하지 않았다.
- A6–A9는 단일 시드·단일 분할의 선별 실험이다.
- `sacct` 접근이 막혀 전 작업에서 peak memory를 기록하지 못했다. 시간은 작업 로그와 `scontrol`에서 왔다.
