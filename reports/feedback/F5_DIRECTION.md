## 2. 선정: R1 세포주 간 유전자 섭동 일반화

세 후보를 같은 기준으로 놓고 보면 다음과 같다.

| 기준 | R1 유전자 섭동, 세포주 간 | R2 Full FT 원인 | R3 약물 반응, SNU-423 |
|---|---|---|---|
| 자료 | 4세포주 CRISPRi, 공통 표적 1,688개 | Norman 기존 자산 | Tahoe 50개 세포주, 로컬 보유 |
| 정답 신호 품질 | 외부 가공본과 반응 r≈0.9999 | 시드 간 검증 범위 0.0018로 비교 차이와 비슷한 크기 | 약물 없는 DMSO well도 같은 well 다른 세포주와 r 0.76. 반복 well을 예측으로 쓰면 no-change보다 나쁨 |
| 최신 모델 검증 | PIE 공개값 재현. 관측 표적에서 기준선 대비 AUPRC +0.052. seed 3회·4 fold에서 결론 유지 | 해당 없음 | 미실행. 공개 체크포인트에 SNU-423 포함, 재학습 필요 |
| 다음 실험의 명확성 | 높음. PIE의 약점(미관측 표적 자체 순위, Δ 크기 보정)이 구체적 | 질문이 좁고 ablation으로 정리됨 | 기술 효과 보정 방법부터 정해야 함 |
| 간 관련성 | HepG2(간모세포종 유래, 이전 노출 있음) | 없음 (K562) | 성인 HCC 유래 세포주 |

**선정 이유.** R1은 자료 품질, 재현성, 다음 실험의 구체성이 모두 확보됐다. 세 실험(F3 기준선, G3 PIE, R3 약물)이 같은 방향을 가리킨다. 어려움의 중심은 새 세포주보다 새 개입(새 표적, 새 약물)에 있다. R1은 이 질문을 가장 깨끗한 자료로 다룰 수 있다.

**R3의 위치.** 간 적용 보조 트랙으로 유지한다. 범위는 강한 기전 약물(HDAC, proteasome 등) 부분집합과 well·plate 효과를 보정한 정답 정의로 제한한다. 정답 정의가 정해지기 전에는 모델 재학습에 GPU를 쓰지 않는다.

**R2의 위치.** A6–A9 결과로 정리하고 종료한다. 추가 탐색은 R1의 모델 학습 설정에 필요한 경우에만 한다.

## 4. R1 첫 실행 계획

G4가 좁혀 준 지점에서 시작한다. 미관측 세포주 자체는 "같은 표적 평균 + 크기 보정"으로 대부분 해결되므로 거기에 GPU를 더 쓰지 않는다. 남은 격차는 두 가지다. (가) 미관측 표적에서 PIE의 표적 특이 순위 우세가 Δ 크기 오차 때문에 원자료 지표로 옮겨가지 않는다. (나) 관측 표적에서는 단순 기준선이 더 낫다. 첫 실행은 이 둘을 합치는 쪽으로 간다.

| | E1 사후 크기 보정 | E2 조건부 결합 | E3 fold 일반성 |
|---|---|---|---|
| 질문 | PIE의 Δ 크기를 보정하면 순위 우세가 원자료 RMSE·pert-centred r로 옮겨가는가 | 관측 표적은 기준선, 미관측 표적은 PIE로 나누면 전체가 두 방법 각각보다 나은가 | E1·E2의 이득이 HepG2 밖에서도 같은가 |
| 고정 | PIE 공식 체크포인트, F3 패널·정답, 4 fold | E1의 최선 보정 | E1·E2 설정 |
| 변경 | 보정 함수(스칼라 / 조건별 스칼라 / isotonic) | 분기 규칙(표적이 소스 세포주 학습 집합에 있는지) | fold, seed |
| 분할 | 보정 계수는 **소스 세포주 검증에서만** 적합. 보류 세포주는 보지 않는다 | 분기 임계도 검증에서만 | 좌동 |
| 자원 | GPU 불필요 (저장된 예측 재채점, CPU 수십 분) | GPU 불필요 | 3 fold × 3 seed ≈ 52 A100 GPU-h |
| 선행 조건 | 없음 | E1 완료 | E1 또는 E2가 기준선을 넘을 때만 |

**판정 기준.** [F3 §7](F3_CROSS_CELL_LINE.md#7-최신-모델txpertstatepie-등이-넘어야-할-기준)의 calibrated same-target 기준선을 넘어야 하고, 차이가 G4에서 잰 잡음보다 커야 한다 — seed 폭 0.011 AUPRC, fold 간 SD 0.03–0.04. 이보다 작은 차이는 결론에 쓰지 않는다.

**하지 않는 것.** State 재학습(G4 §6에서 탈락), few-shot(계획서의 "보류 세포주 처리 세포 미학습" 조건을 깬다), TxPert(E1·E2가 끝난 뒤 재검토), 보류 세포주 결과를 본 뒤의 설정 변경.

**R3 약물 트랙.** §2에 적은 대로 보조로 둔다. 기술 효과 보정된 정답 정의가 정해지기 전에는 재학습하지 않는다.
