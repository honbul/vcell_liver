# Track 8 pan-cancer combination models

The benchmark estimates adult HCC synergy and added growth inhibition after training on public pan-cancer combination assays. DrugComb v1.5 contributes oncology-only ZIP, Bliss and CSS. The Sanger pan-cancer screen provides independent adult HCC dose matrices, published Bliss and the measured maximum growth inhibition gained over the stronger single agent. The outcome table keeps CSS and Sanger added inhibition as different endpoints. HUH7 antiviral combinations and other nononcology protocols are excluded. DrugCombDB supplies the O'Neil public assay matrices and their published synergy scores. Its dose-grid efficacy uses the lowest observed viability across matched combination and single-agent dose wells, normalized by the observed vehicle. The merged training corpus uses one O'Neil release to avoid counting mirrored experiments twice. The DrugComb v1.5 archive contains AstraZeneca study rows. We omit that study under the repository's stated agreement requirements. Source HTTP statuses and checksums are in the five-track preflight. [DrugComb data terms](https://doi.org/10.1093/nar/gkab438), [DrugCombDB paper](https://doi.org/10.1093/nar/gkz1007)

The additional Sanger ZIP endpoint reconstructs the zero-interaction-potency reference and mean of the two directional fitted interaction surfaces. Four-parameter log-logistic curves use bounded potency, Hill slope and effect ranges. Published matched-dose observations supply the single-agent margins of each matrix, and normalized DMSO anchors zero. The output labels record completeness per study. The reconstruction differs from native DrugComb ZIP in dose coverage and solver. Sanger and DrugComb metrics are reported separately.

Sanger CSS uses the same measured dose matrices. Each single-agent four-parameter model must have at least ten percentage points of fitted amplitude and a relative IC₅₀ within the observed nonzero dose range. Each measured combination cross fixes the background agent at its nearest tested dose to that midpoint. The reconstruction averages the two foreground curve integrals over log dose, with the original ten-percent inhibition normalization. Per-source manifests report the number of usable CSS matrices and HCC observations. [CSS primary study](https://doi.org/10.1371/journal.pcbi.1006752)

The assay registry requires exact DepMap cell model IDs or concordant source identity. Lineages use the DepMap patient field and cohort histology. Parent identity uses standardized InChI and unordered connectivity. If one parent has multiple generic scaffold assignments, those scaffold groups and their compounds are held together. LCO excludes all liver lineages from development and inner validation. LPO groups unordered drug pairs. LDO reserves each generic scaffold on either arm, uses a different blocked validation axis, and assigns every test combination to one fold without using its outcome. The predictor reads fitting and source validation labels plus blinded assay identities. The scoring CLI verifies the prediction hashes, feature coverage, label hashes and panel roles. Lineage-macro scores include bootstrap confidence intervals. Positive joint retrieval requires observed Bliss and minimum added inhibition both at least ten percentage points.

Study means, pair means, target dependency signal, orthogonal GDSC2 monotherapy Bliss additivity, Ridge, ElasticNet and LightGBM provide baselines. The additive model is evaluated on the independently matched monotherapy subset for endpoint-scale efficacy. Noninteraction assigns zero excess synergy by definition. DeepSynergy and MatchMaker use route-specific neural architectures with full ECFP4 and basal RNA context. Pair symmetry averages both orders. The proposed model uses two layers of dual-branch cross-attention over Morgan, MoLFormer, target pathways, cell state and Chronos dependency. Ablations remove the molecular foundation representation, target prior or CRISPR channels. Source-specific contexts retain the assay protocol. Features and biological priors are independent of held combination outcomes. Fitting uses effect masks for missing measurements.

Virtual screening applies an LCO model chosen on source-only validation to public paired GSE182593 organoid expression and low-sorafenib-response LIMORE cultures. FDA DILIrank v2 No or Less concern verifies the approved partner and supplies an explicit liver concern category. Predictions include Bliss, ZIP and added inhibition. Ranking requires positive forecast Bliss and added inhibition, and each donor is weighted equally. Paired sensitive organoids provide an expression-domain contrast. Donor bootstrap intervals describe variation of model predictions. The held source validation error radius is an uncertainty indicator whose coverage has not been established in organoids. The ranked combinations have no measured treatment outcomes from GSE182593.

## Offline execution

`python -m vc_combo_hcc.prepare_assays`, `python -m vc_combo_hcc.splits`, and `python -m vc_combo_hcc.context` register input roles. `python -m vc_combo_hcc.predict` fits and freezes outputs on the selected head and device. `python -m vc_combo_hcc.score` opens scoring outcomes. `python -m vc_combo_hcc.screen` supports separate registration and ranking. Batch scripts under `experiments/vc_combo_hcc_v1` use the G1 shared data and the Track 6 offline embedding CLI.
