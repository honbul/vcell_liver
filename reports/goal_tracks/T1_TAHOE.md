# T1 Tahoe 용량별 동결 평가

R12/R13의 canonical parent 203군과 3-fold를 고정했다. 0.5 µM·20세포의 평가 행 순서와 gene token 2,000개는 R13과 세 fold에서 정확히 일치했다. 각 용량에서 20세포와 200세포 제한별로 학습 분산 패널을 다시 만들었다. 하나의 학습 parent에 속한 모든 용량과 물리 웰을 같은 쪽에 두고, 처리 세포 집계와 DMSO의 logCP10k 차이를 사용했다. R13의 0.5 µM에서 선택한 각 모델 설정은 그대로 이식했고 대응하는 내부 fold에서 스케일을 다시 선택했다. 추가 용량 모델의 low/high 슬롯은 현재 용량을 제외한 두 용량으로 대응했다. 5 µM의 작은 ECFP/MACCS 격자도 내부 fold에서만 선택했다.

위치 성분은 다른 plate의 동일 release barcode 인덱스와 세포주에서 추출했다. 각 pool에서 중심화한 donor는 parent마다 균등 가중했다. 약물 잔차를 적합할 때 해당 학습 행의 parent를 다른 plate의 donor와 donor의 중심 계산에서 함께 제외했다. 학습 잔차에서는 위치 성분을 단위 배율로 뺐고, 예측에서는 위치와 화학 잔차 배율을 각각 골랐다. 위치 성분 밖의 절대 수준에는 B_abs를 적용했다. 10,000회 대응 parent 재표집에서 양의 exponential 가중치로 pool을 매번 다시 중심화했다.

Plate 14의 반복 비교에서 plate 6의 위치 보정 관측값은 채점 과정에만 읽었다. 20세포에서 53쌍·51 parent, 200세포에서 52쌍·50 parent가 같은 위치와 세포주에서 연결됐다. 203군과 분리된 나머지 40쌍은 발현 행 4,000개·세포 5,590,684개로 캐시에 따로 보존했다. 표본 이름의 Selinexor 끝 공백을 제거한 뒤 출처의 단일 화학물질 레코드에 연결했다. 암종 단독·간 유래 세포주 합산과 전체의 성능을 각각 제공한다.

G1 원본은 `/mnt/S1/sdata/workbench/Virtual_Cell/gssong/vcell_liver_goal_tracks/v1/t1/first/` 아래에 있다. 용량별 `d{0.05,0.5,5}/scored/`에는 지표, 대응 구간, 위치 지원율이 있고, `d5/scored/`에는 반복 RMSE와 도달률이 있다. 별도 추적 코호트는 `v1/t1/reserved_40_pairs/`에 보관했다.

5 µM에서 v0는 B0 대비 전체 −0.002836 [−0.004010, −0.001708], 간 유래 합산 −0.003169 [−0.004453, −0.001910]이었다. B_pos-all과 비교한 99% 구간에는 모든 범위에서 0이 포함되었다. SNU-423은 −0.000449 [−0.001536, +0.000151], HepG2/C3A는 −0.000147 [−0.000956, +0.000242]였다. 따라서 사전 지정된 두 기준을 함께 통과한 범위는 없다. 200세포 기준에서 B_pos-all 대비 점추정 개선은 전체 0.623%, 간 유래 합산 0.507%였다. 구간 상한은 각각 +0.000130과 +0.000246이었다. 5 µM 전용 ECFP/MACCS 재튜닝 행도 B0보다 낮은 대비 RMSE를 확인하지 못했다.

Plate 14 짝지어진 5 µM 평가에서 B_pos-all 대비 0.25배 반복 잔차가 주는 RMSE 개선은 전체 0.009694 [0.004303, 0.023276], 간 유래 합산 0.011118 [0.005086, 0.026412]였다. v0의 반복 격차 도달률은 전체 5.67% [−6.43%, 19.79%], 간 유래 합산 5.57% [−7.61%, 20.02%]였다. 200세포에서는 각각 17.23% [−1.73%, 49.81%], 14.38% [−4.44%, 41.71%]였다. 단위 배율 반복은 전 범위에서 분모의 구간이 0을 가로질렀다. 같은 위치의 고용량 반복은 재현 가능한 반응 성분을 보여 주며, 새 parent의 화학 구조 모델이 위치 기준선 위에서 이를 재구성하는 정도는 구간상 불확실하다.
