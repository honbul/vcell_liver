# 간암 Virtual Cell 용량 및 기존 모델 비교 사전 명세

## 공통 평가

분석 단위는 물리 처리 웰과 세포주다. Tahoe는 R12/R13의 canonical parent 203군·3-fold를 고정한다. 같은 parent의 처리 반응은 모든 물리 웰, 용량, 세포주에서 한꺼번에 외부 fit에서 제외한다. 내부 검증은 외부 학습에 남은 두 parent fold를 번갈아 사용한다. A/B DMSO 역할을 교환하여 실측 fit·validation 대비는 자기 역할 DMSO, 공식 채점은 반대 역할 DMSO를 사용한다. 평가 웰의 반응은 설정 선택과 예측 파일 생성에 접근할 수 없다. 모든 지표는 앞선 연구에 노출된 공개 자료의 새 프로토콜 검증이다.

Tahoe의 24시간 0.05/0.5/5 µM를 같은 명목 용량 내부에서 평가한다. 5 µM는 plate 3·6·9·12·14를 포함한다. 용량·외부 fold·역할별 학습 자료에서만 뽑은 2,000 유전자 패널로, 최소 세포 수 20을 주 분석으로, 200을 민감도로 사용한다. 평가 pool은 plate·세포주·용량·fold·DMSO 역할로 구분하고 각 pool에서 평가 대상의 평균을 빼 대비를 구한다. 세 parent 미만 pool은 지원 부족으로 제외한다. 웰 반복과 역할을 같은 parent 내에서 함께 재표집하며 10,000회 재표집마다 가중 pool 중심을 다시 계산한다. 화합물군을 균등 가중한다. 전체와 간 유래 두 세포주 합산, 그리고 SNU-423 및 HepG2/C3A별 값을 제공한다. 간암에 직접 해당하는 SNU-423과 HepG2/C3A는 조직학적 범주가 다르다.

예측에는 행 키, fold, 역할, 유전자와 모델 ID를 기록한다. Slurm에서 예측 → SHA-256 동결 → 별도 채점 작업을 성공 의존성으로 연결한다. 동결 영수증은 사전 명세 및 버전, 입력 계약, 선택 설정과 모든 제출 예측의 해시를 포함한다. 채점은 해당 해시와 행·패널을 검증하고 동결 해시를 영수증에 기록한다. 실패 후 재시도는 시도와 변경 근거를 기록하며 동결 예측과 설정은 유지한다. 학습과 설정 선택에 사용한 R4–R14와 Claude 탐색은 노출 이력으로 보존한다.

## T1 Tahoe 용량별 평가

- B0는 처리 효과 0, B_abs는 R13 절대 RMSE anchor 선택 규칙이다. B_pos는 같은 용량, B_pos-all은 전 용량의 다른 plate·같은 위치 인덱스·같은 세포주에 해당하는 fit parent 처리 반응에서 pool 평균을 뺀 성분을 쓴다. 위치 인덱스는 컨소시엄 물리 좌표가 확인되지 않은 barcode 유래 인덱스다. 위치 추정에서 자기 plate 및 평가 parent를 제외한다. 지원이 없는 행에서 예측 성분은 0으로 두고 지원율을 별도로 낸다. 위치 공여 평균은 다수 용량·웰이 겹치는 parent의 과대 가중을 피하도록 parent 균형화하고, 각 용량 원래 단위를 유지한다.
- R13의 0.5 µM 화합물 분할에서 이미 고른 fold·역할별 모델 설정을 커널·검색, 표적·작용기전, 세포주 전이, 보조 용량, neural 대표 arm에 이식한다. R13 배율 후보 0/0.125/0.25/0.5/0.75/1/1.5/2/3/4만 용량별 내부 fold에서 다시 고른다. 신경망 최종 적합 seed는 42/43/44다. 별도 5 µM 재튜닝 행은 커널 Ridge의 ECFP/MACCS 혼합 비중 0/0.3/1, alpha 0.1/1/10과 위 배율만 검토한다.
- 제안 v0는 B_pos-all과 위치 보정 fit 반응으로 적합한 화학 모델 잔차의 합이다. fit 정답의 위치 부분을 구할 때 그 행의 plate와 해당 parent를 제외한다. 사전에 고른 R13 커널 설정을 사용한다. 위치 배율과 잔차 배율을 내부 fold에서 함께 선택하며 0을 허용한다. 두 성분의 합 및 위치 단독·잔차 단독을 보고한다. 위치 배율 0/0.125/0.25/0.5/0.75/1/1.5/2, 잔차 배율은 R13 격자다. 내부 동률 시 작은 잔차 배율, 작은 위치 배율, 후보 선언 순으로 선택한다.
- 주 판정은 5 µM·최소 20세포에서 제안 v0 대비 RMSE − B_pos-all의 대응 99% 구간 상한 < 0이다. 같은 행의 B0 대비도 별도로 이 기준을 적용한다. 두 차이가 모두 기준을 충족한 범위에서만 두 기준선보다 개선되었다고 판정한다. 0.05/0.5 µM, 200세포, 그리고 세포주별 세부분해를 같은 방식으로 제공한다. 저용량 성능 차이에 대한 인과 판정은 하지 않는다.
- Plate 14 평가 반응과, 동일 parent·동일 위치 인덱스·동일 세포주로 맞춘 plate 6의 처리 반응을 비교한다. 공여 반응은 반복 자료에만 허용한다. B_pos-all에 반복의 추가 방향을 더했을 때의 배율은 고정 0.25를 주 기준으로 하고, 1.0의 단일 반복 이식도 보고한다. 전달 전 plate 6 반응에도 같은 위치 기준을 적용하고, 대응하는 plate 14 pool에서 다시 중심화한다. 도달률은 같은 행의 `(RMSE_B_pos-all − RMSE_model) / (RMSE_B_pos-all − RMSE_repeat)`이다. 분모가 양수인 점추정에 한해 비율을 보고하고 재표집 분모가 0을 가로지르면 그 불안정성을 표시한다. 6↔14 metadata의 나머지 40쌍은 학습·선택에서 격리해 추적용 입력으로 남긴다.

## T2 기존 VC 비교

- 같은 Tahoe 행·패널·분할과 20/200세포 기준에서 XPert R7, MoE 이전 chemCPA, TranSiGen B1, ChemBERTa R11, FiLM 및 concat R12, scGPT 및 UCE 맥락 R12를 비교한다. 학습/검증 provenance가 정확히 일치하는 동결 자료만 재사용한다. 그 외는 같은 분할에서 적합한다. 공개 약물 실측을 동일 평가 parent의 학습 라벨로 사용한 checkpoint는 별도 참고로 표시한다. 모델 구조 또는 fit-only 입력을 Tahoe로 적응한 결과는 해당 적응을 표에 식별하고 원 논문 수치로 부르지 않는다.
- State의 ST-Tahoe 공개 가중치는 점대점 기준에서 제외한다. 공식 categorical drug 조건 또는 CPA 기본형에서 평가 parent 입력을 모델링할 수 있는지 공식 코드와 split 정의를 조사한다. 평가 약물 표현이 없으면 조건이 없는 평균/0 반응은 대조 행에 한한다. PRnet은 공식 화학 fingerprint 조건부 생성 구조를 우선 사용하고, matched panel의 웰 평균을 생성 학습 입력으로 쓰는 경우 적응 표기를 붙인다. 사전 훈련 없이 fresh fit하며 각 공식 저장소, 버전, 라이선스, 실제 실행 여부·입력 요건을 남긴다.
- 절대 RMSE, pool 대비 RMSE, 방향 코사인, top-1 검색률을 보고한다. 절대 RMSE는 반대 DMSO 기준의 처리 발현 재구성 오차다. 코사인은 대비 방향을 비교한다. 검색 후보는 같은 평가 pool의 parent별 실측 대비 평균이며, 예측 대비와의 코사인 최대 동률에서 `1 / 동률 수`로 점수를 준다. 0 벡터는 점수 동률로 취급한다.
- 적격 비교군은 동일 행과 유전자를 예측하고 평가 parent의 처리 반응을 학습에 쓴 이력이 없으며 원 모델 또는 문서화된 구조 적응으로 구동된 경우다. 누출 참고, null fallback 및 입력 지원이 없는 축약 프록시는 판정 경쟁군과 별도 표시한다. 5와 0.5 µM 각 용량에서 두 간 유래 세포주 합산의 최저 점추정 대비 RMSE를 기록한다. 각 비교군과 동시 대응해 재표집마다 최저 적격 비교군 RMSE를 다시 구한다. 제안 v0 − 이 최저치의 99% 구간 상한 < 0을 판정에 사용한다. 적격 비교군이 없으면 미평가로 표시한다. 비교군 목록과 적격 근거를 외부 채점 전에 동결한다.

## T3 HepaRG 위치와 고농도 모델

- GSE296254와 GSE284321의 검증 원본 캐시에서 24 h logCP10k의 반응을 사용한다. 데이터셋별 plate×dose rank pool에서 세 parent 이상을 요구하고 학습에서 얻는 공통 Ensembl 2,000 유전자 패널을 사용한다. shared parent 3 outer × 2 inner fold에서 두 연구의 같은 parent를 함께 제외한다. 비교는 같은 행, 데이터셋별로 낸다. 사전 층은 순번 7, 순번 8, 실제 ≥10 µM다. 실제 용량 층 내부 진단은 <.01, .01–.1, .1–1, 1–10, 10–100, ≥100 µM로 나눈다.
- 메타데이터에서 실제 µM, 최고 명목 농도, dose rank, 구조 계열이 웰 위치와 연관되는지 확인한다. plate 쌍별 동일 위치에서 같은 화합물·dose rank가 재등장하는 비율을 plate group·배양별로 기록한다. 위치 효과는 실제 용량 층을 맞추기 전·후, 처리 조건을 반영한 잔차, 그리고 plate 내 3개 고정 위치 순열에서 비교한다. 위치 배율은 내부 0부터 1까지 0.125 간격으로 고른다. 위치 donor는 같은 물리 plate에서 가져오지 않는다.
- B0, 기존 단일 자료 용량 공유 Ridge(0.7 ECFP/0.3 MACCS, alpha 0.1/1/10), 같은 용량 bin/rank 커널, 표적·작용기전 Jaccard kNN(k = 3/8), 두 자료 공동 용량 공유 Ridge, 농도–반응 분리형을 고정한다. 분리형은 적합 자료에서 화합물 반응 방향을 추정하고 단조 Hill 크기를 곱한다. Hill 반응의 중간 농도 후보는 실제 µM 0.1/1/10 또는 명목 최대 농도에 대한 상대 스케일이다. 단일 및 공동 적합 둘 다 수행한다. 공동 donor는 평가 parent 전체를 제외하고 화합물군을 균등 가중한다. 하이퍼파라미터와 모델 배율은 같은 두 내부 fold에서 고른다.
- 반복은 같은 화합물·실제 용량·세포 상태에서 plate와 위치가 다른 쌍을 쓰고, GSE296254에서는 서로 다른 배양을 요구한다. GSE284321의 배양 독립성은 미확인으로 표시한다. 고정 0.25배 반복 반응을 기준으로 B0 대비 격차와 모델 도달률을 공통 반복 지원 평가 행에서 구한다. 10,000회 대응 parent 재표집 95% 구간에서 B0 대비 개선률 하한 > 0%가 판정 기준이다. 단일 연구 용량 공유 Ridge 대비 개선률에도 같은 기준을 별도로 적용한다.

실행 원본은 G1의 별도 goal-tracks 네임스페이스에 보존한다. 공개 원본, 개인 검토 메모, 중간 예측 및 모델 가중치는 연구 Git에 올리지 않는다.
