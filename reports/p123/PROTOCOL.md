# P1–P3 사전 명세

## 공통 분할과 지표

Tahoe는 T1/T2의 동일 24시간 물리 웰, 203개 canonical parent 3-fold, 0.05·0.5·5 µM, 최소 세포 수 20과 200, 동결된 fold 및 내부 fold별 2,000 유전자 패널을 사용한다. 평가 parent의 Tahoe 처리 반응은 모든 용량·plate·세포주에서 학습과 설정 선택에서 제외한다. DMSO A/B의 적합·채점 역할은 T1/T2와 같다. 판정 대상은 5 µM·최소 20세포다. 간 유래 두 세포주 합산, 전체와 두 세포주 개별을 제공하며 0.05·0.5 µM, 세포 수 200과 세포주 개별 결과는 기술 분석이다.

기존 공동 주 지표인 대비 RMSE는 웰·세포주 행의 유전자 RMSE를 R13의 parent 균등 가중으로 평균한다. 두 번째 공동 주 지표는 같은 대비의 `R²_pooled = 1 − ΣSSE / ΣSST`다. 이 지표는 행과 유전자의 제곱합을 더한다. 발현 크기가 큰 행의 설명된 에너지가 더 많이 반영된다. 예측과 실측을 동일 pool로 각각 중심화한다. Tahoe 대응 99% 구간은 동일한 10,000회 parent 단위 양의 지수 가중 재표집으로 두 DMSO 역할과 웰을 함께 묶고 회차마다 pool 중심을 다시 계산한다. 적격 pool 지원 기준은 T1과 같다. T1/T2 동결 예측에 R²를 추가한 수치는 사후 재채점으로 표시한다. 두 지표마다 이득 방향과 0을 벗어나는지 기록한다. RMSE 차이는 상한 < 0, R² 차이는 하한 > 0일 때 해당 기준 대비 개선으로 판정한다. 두 지표를 통과한 경우를 따로 표시한다.

모든 결합 및 새 모델은 학습 내부 fold에서만 선택한다. 반응이 없는 주 보조 변수와 공개 LINCS 서명의 사용 범위를 기록한다. 예측 → SHA-256 동결 → 별도 채점을 Slurm 성공 의존성으로 연결한다. 원 예측과 표 계약, 유전자 축, 선행 동결, 코드·명세 확인값과 출력 해시를 영수증에 포함한다. 이전 점수와 프록시 진단은 사전 노출로 기록한다. 별도 봉인·격리·예약 코호트는 이 실행에서 접근 대상에서 제외한다. GPU가 필요한 업무는 연구 전체에서 한 배열의 동시 작업을 최대 8개로 설정한다.

## P1 Tahoe 위치 trim과 약물 잔차

- B_pos-all은 T1의 동결 비교군이다. 위치 임계 후보는 trim 없음, 그리고 `1.25 / 1.5 / 2.0 ×` 세포주별 donor L2 norm 중앙값이다. 다른 plate의 같은 barcode 위치·같은 세포주에서 pool 대비 donor를 가져오고 parent당 균등 가중한다. 적합 행의 위치를 추정할 때 해당 행의 parent와 plate를 제외하고, pool 중심과 임계 계산에서도 해당 parent를 뺀다. 지원 없는 행은 위치 성분 0으로 둔다. 별개의 정렬 단계에서 두 내부 fold의 에너지 오차로 임계와 0/0.125/0.25/0.5/0.75/1/1.5/2 배율을 고른다. 동률은 작은 배율, 덜 강한 trim 순서다. 이를 모든 P1 화학 arm와 P2의 위치 배경으로 재사용한다.
- 위치 보정 학습 대비에 ECFP4 Tanimoto Ridge(alpha 0.1/1/10), 가장 가까운 구조 형제의 동일 세포주 반응 복사(최소 Tanimoto 0.3/0.5/0.7), 공개 표적·작용기전 Jaccard 형제(표적, 기전, 두 값 평균), 각 계열의 선택 방향의 균등 결합을 적합한다. 동률인 가장 가까운 donor parent의 평균을 사용한다. 형제 지원이 없으면 잔차 0이다. 개별 arm과 결합의 잔차 배율은 위 격자로 고른다. v1은 공통 trim 위치에, 두 내부 fold의 에너지 오차 기준으로 가장 좋은 적격 화학 arm를 더한다. T1의 B_abs를 절대 예측 수준의 기준으로 재사용한다. 위치 임계·위치 점수와 화학 계열·배율은 순서대로 선택한다.
- 간 유래 합산과 전체의 5 µM에서 v1 대 trim 위치, B0, 기존 VC 최저, 그리고 공정성 결합 기존 VC 최저를 각각 99%로 비교한다. 최선 비교군은 지표별로 판단해 각 대응 재표집에서도 해당 지표의 최선값을 다시 계산한다. 위치 기준선, v0, v1과 사전 지정 ablation을 같은 표에 포함한다.
- 공정성 arm는 기존 VC 10종의 동결 외부 예측을 유지하고, 같은 fold·역할의 외부 학습에서 T2 레시피를 재현하는 두 내부 교차 예측으로 위치와 VC의 배율을 선택한다. T2가 외부 fit 안에서 선택한 epoch·학습률을 고정해 같은 내부 fold에서 gain을 맞추며, 이 내부 점수는 성능 주장에 사용하지 않는다. 절대 수준 anchor의 중복을 피하기 위해 VC의 pool 중심 대비를 더하고 B_abs를 절대 수준으로 사용한다. 공통 trim 방향의 두 배율은 0/0.125/0.25/0.5/0.75/1/1.5/2 중 선택한다. 위치 정답 제거 후 새로 적합하는 arm은 ChemBERTa Ridge와 R12 concat·FiLM·scGPT·UCE 맥락 모델이며 T2의 구조와 fit 설정을 재사용한다. 뺀 위치는 fit 자료만으로 추정하고 참값 처리 발현과 입력을 직접 공유하지 않는다. 동결 모델 조합 10종, 재적합 5종, 둘을 합친 최선 대조를 제공한다.
- 부모별 에너지 개선을 `SSE_trim − SSE_v1`로 계산한다. 양의 개선 상위 5/10/20 각각의 양의 개선 합 대비 점유율과 순합 대비 점유율, 원 전체 및 해당 parent들을 제외한 결과를 제공한다. 제외 후 최소 parent 지지와 pool 중심을 다시 계산하고 두 지표를 보고한다. 상위 그룹을 외부 실측으로 정하므로 이 제외 분석은 결과 의존적인 기술 분석이다.

## P2 Tahoe의 외부 LINCS 반응 사전 지식

- 평가 시나리오는 Tahoe 반응을 학습에서 보지 못한 parent의 **외부 LINCS 서명이 관측된 경우**와 구조만 주어진 경우다. GSE92742와 GSE70138 Level 5 `trt_cp` MODZ의 공통 landmark 978개 gene ID를 사용한다. LINCS와 대상 화합물의 largest organic fragment, 탈염·전하 표준화 및 stereo-free parent와 InChIKey를 우선 대조한다. 고유한 CID·이름은 확인 가능한 구조에 충돌이 없는 경우에만 사용한다. 대응 방법과 충돌, 보유율을 보고한다. 비공개 탐색 서명은 입력에서 제외한다.
- 개별 LINCS 벡터는 landmark 축에서 중심화하고 L2 정규화한다. 부모별·연구별·cell line별로 균형 있게 집계한다. 후보 서명은 24시간 전체 세포주 10 µM 근처(5–20 µM에서 가장 가까운 용량), 24시간 전체 세포주 모든 용량(용량 균형), 24시간 HepG2·PHH 10 µM 근처다. 24시간 전체 세포주 모든 용량의 실측 지원이 고정 보유군을 정하며 모델 선택과 독립이다.
- 공통 trim의 Tahoe 잔차에서 구조 Tanimoto Ridge, 서명 cosine Ridge, 구조와 cosine 혼합(서명 비중 0.25/0.5/0.75), 서명에서 저랭크 Ridge 직접 사상(PCA 16/32), 그리고 미보유 서명을 구조→서명 Ridge latent 사상으로 채우는 변형을 적합한다. 완전한 미보유 쌍의 서명 성분은 0 또는 혼합의 화학 성분으로 되돌린다. 사상과 PCA는 fit parent로만 적합하고 미보유군에 평가 반응을 채우지 않는다. 고정 위치는 P1과 같으며 alpha 0.1/1/10과 공통 배율 격자를 쓴다. 설정은 내부 에너지 지표로 선택한다.
- 5 µM 간 유래 합산에서 혼합 arm 대 같은 위치의 구조 Ridge가 공동 주 지표 각각에서 대응 99% 기준을 통과하는지 전체 및 보유군을 독립 보고한다. 미보유군, 개별 세포주와 전체 세포주, 저용량 결과는 지원과 함께 제공한다. cohort 지원은 최소 3 parent pool 규칙을 재적용하고 비교군을 동일 행에서 중심화해 채점한다. 같은 표에 P1 v1과 기존 VC를 넣는다. 관측 LINCS prior와 구조 예측 prior의 이득을 식별한다.

## P3 HepaRG 고농도

- 위치와 처리·배치 진단은 동결된 T3의 결과와 설계를 계승한다. GSE296254/GSE284321의 공동 parent 3-fold와 내부 두 fold를 유지한다. T3의 24 h, 연구별 plate×dose rank 반응 pool과 fit-only TempO-Seq 2,000 유전자를 유지한다. 순번 7·8을 주 평가하고 실제 ≥10 µM를 부가로 제공한다. 반복 지원, 연구, profile 보유·미보유, HepG2·PHH 지원을 기록한다.
- 각 연구에서 T3의 동결 예측을 두 지표로 재채점하고, P1과 같은 상위 5/10/20 에너지 기여, 제거 RMSE 및 R²를 낸다. 10,000회 대응 parent 재표집의 95% 구간을 사용한다. T3와 일관되게 B0 대비 RMSE 감소율 하한 > 0인지 판단하고, R² 차이의 95% 하한 > 0도 각각 판단한다. 공유 Ridge 대비 개선을 함께 준다. T3의 bulk 절대 단위를 유지하고 동일 풀 대비에 두 지표를 적용한다.
- P2의 LINCS bank로 검증된 화합물만 외부 서명을 조회한다. LINCS Entrez 또는 HGNC와 TempO Ensembl은 고유 대응만 감사하고 fit 패널과의 교집합 크기를 기록한다. 서로 다른 assay의 gene-scale을 등치하지 않는다. LINCS landmark 서명을 중심화·정규화한 입력 표현으로 쓰고, TempO logCP10k 대비는 훈련 TempO에서 적합한다. 고농도 Hill의 반응 방향을 구조, LINCS cosine 또는 두 커널로 적합하고, 서명 PCA 16/32에서 직접 사상을 비교한다. alpha 0.1/1/10, 서명 혼합 0.25/0.5와 동일 gain 격자에서 내부 에너지로 고른다. Hill half-dose는 T3의 해당 outer fit에서 선택한 값을 계승한다. 미보유군은 같은 설계의 구조 예측으로 복귀하거나 지원 제한을 별도 표기한다.

## 확인 평가

203 parent 바깥의 목록과 예약 40쌍은 기존 문서·동결 영수증의 메타데이터 범위만 확인한다. 처리 행, 실측과 점수 파일을 새로 열지 않는다. 별도 계획 문서는 자료 접근 승인, 기존 노출 감사, parent·염·별칭의 분리, 예상 보유율, plate 6↔14의 같은 위치 반복과 다른 위치 반복의 역할, 모델 동결 후 독립 채점을 정의한다. 공개 자료의 과거 노출 이력을 기록하고 검증이 불가능한 행은 완전 신규 확인 범위에서 제외한다.
