## 1. 질문과 비교 대상

**질문:** 다른 세포주의 약물 반응으로 사전학습한 공개 구조의 모델을 소량의 HCC 실측 반응으로 미세조정하면, 범용 모델을 그대로 쓰거나 같은 HCC 자료만으로 학습하는 것보다 그 HCC 세포주에서 미관측인 약물의 반응을 더 잘 예측하는가?

| 이름 | 내용 |
|---|---|
| B0 | 공개 TranSiGen 구조(ECFP4, 무작위 초기값)를 대상 HCC 계열을 뺀 161개 세포주로 학습. HCC 자료는 쓰지 않음 |
| B1 | 같은 구조를 무작위 초기값에서 시작해 HCC 적응 약물 k개만으로 학습 |
| B2 | B0에서 시작해 같은 k개로 전체 파라미터 미세조정 |
| 기준선 | 무변화, target 적응 약물 평균, source 같은 약물 평균, source Ridge, target Ridge, B0 + mean-offset |

- 시험 약물은 "그 HCC 세포주에서 미관측으로 취급한 약물"이다. 세 target의 모든 시험 약물은 source의 다른 세포주에서는 측정돼 있다. 세상에 처음 나온 약물의 예측이 아니다.
- 공개 full checkpoint는 학습 세포주에 HUH7·JHH5·JHH7이 들어 있어 쓰지 않았다(`EXPOSURE_AUDIT.md`).

- k는 약물 **그룹** 수다. HUH7은 한 그룹에 pert_id가 여러 개인 경우가 있어 조건 수가 16보다 많다.

## 4. 판정 (계획서 §9의 표를 그대로 적용)

|---|---|---|

## 5. 가능한 해석 (검증하지 않은 가설)

- **B0의 오차 대부분이 세포주마다 일정한 offset일 수 있다.** source 검증에서 떼어 둔 세포주의 B0 오차는 세포주별 평균 잔차를 빼면 0.973에서 0.707로 내려가 무변화(0.703)와 같아졌다(`SOURCE_PRETRAINING.md` 3.3). target에서 적응 약물의 평균 잔차를 빼는 mean-offset이 B0를 0.31–0.53 낮춘 것은 이 설명과 맞는다. B2가 얻은 이득도 같은 종류의 보정일 수 있다. 라벨 교환 대조는 조건을 통과하지 못해 실행하지 않았으므로, B2가 약물–반응 대응을 실제로 활용했는지는 시험하지 못했다.
- **JHH7에서 B2가 전혀 학습되지 않은 것은 plate가 한 장이기 때문일 수 있다.** 이 세포주는 모든 행의 X0가 같다. 공개 구조는 X0 encoder에 BatchNorm이 있어, batch 안의 X0가 모두 같으면 분산이 0이 된다. 관측된 것은 학습률과 무관하게 update 50부터 검증 ΔRMSE가 계속 나빠졌다는 것이다(학습률 1e-5에서 0.94 → 1.44 → 1.86 → 2.85 → 7.09, 1e-3에서 수백). BatchNorm이 원인이라는 것은 따로 분리해 시험하지 않았다.
- **B1이 나쁜 것은 이 구조가 Δ가 아니라 발현 절댓값 전체를 다시 만들기 때문일 수 있다.** 16개 약물로는 약 8.4 척도의 발현 전체를 복원하기 어렵다. 예제 80행 실험(`PUBLIC_MODEL_SMOKE.md`)에서도 같은 양상이었다.
- **무변화가 강한 것은 자료의 신호 대 잡음 때문일 수 있다.** well 하나의 측정이고(무변화의 ΔRMSE 0.53–0.81), HUH7에서 plate 사이 Δ 상관이 0.22–0.33이다. 반복을 합친 signature 수준 자료에서는 순위가 다를 수 있다. 확인하지 않았다.

1. **amendment 1 (자료):** source의 퇴화 plate 42행 제외. target 행은 거르지 않았다. target 값을 보기 전에 했다(`DATA_CARD.md` 6절).
2. **source 실행 재시작:** `_v1`(발산), `_v2`·`_v3`(속도 문제로 직접 취소) 뒤 `_v4`를 썼다. 바뀐 것은 Adam의 fused 구현, CPU thread 수, 실행 노드뿐이다(`SOURCE_PRETRAINING.md` 3.5).
3. **추론 경로:** 공개 `forward()`는 평가 때도 잠재 변수를 표본추출한다. 이 연구는 같은 층을 표본추출 없이 호출하는 잠재 평균 경로를 쓴다. source 검증에서 두 경로의 차이는 0.003 이하였다.
4. **선택 기준:** 공개 코드는 표본추출이 들어간 전체 loss로 모델을 고른다. 이 연구는 source와 target 모두 잠재 평균 경로의 ΔRMSE로 고른다. 시험을 열기 전에 정했다.
5. **학습 단위:** 공개 자료는 조건 수준 발현 쌍, 이 연구는 plate 수준 쌍이다. 논문 수치의 재현이 아니다.
6. **후보 범위 끝에 걸린 선택:** source Ridge의 α(10,000), B2의 학습률(HUH7 세 분할과 JHH5 두 분할에서 1e-3), 일부 target Ridge의 α. 범위를 넓히지 않았다.
7. **dose 정의:** `nearest_dose == 10`(명목 농도)을 썼다. 이전 감사의 `pert_dose == 10` 기준과 약물 수가 다르다(`DATA_CARD.md` 3절).

모델 구조와 loss는 바꾸지 않았다. LoRA, MoE, FiLM, genotype, 새 손실은 넣지 않았다.

## 8. 이 결과로 말할 수 있는 것과 없는 것

- 말할 수 있는 것: 이 세 HCC 세포주, 이 자료 단위와 이 예산에서, 공개 TranSiGen 구조의 전체 미세조정은 B0를 그대로 쓰는 것보다 두 세포주에서 좋았지만, 적응 약물의 평균 잔차를 더하는 한 줄짜리 보정보다 좋지 않았다. HCC-only 학습은 불안정했고 평균적으로 가장 나빴다.
- 말할 수 없는 것: 미세조정 일반이 쓸모없다는 것, 다른 구조·다른 자료 단위·더 많은 k에서도 같다는 것, 처음 보는 약물이나 다른 HCC 세포주·환자에서의 성능. 세 세포주의 결과를 HCC 전체로 넓히지 않는다.
