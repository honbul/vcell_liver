# 연구 B · 단계 B2 — source 사전학습과 source 쪽 기준선

**작성일:** 2026-11-16 · **원자료:** `manifests/transigen_adaptation_b1/`의 `source_lr_selection.json`, `source_selection.json`, `source_baselines.json`, `source_diagnostic.json`, `run_ledger.tsv`
**이 단계에서 읽은 자료:** source 행뿐이다. target HCC의 X1은 읽지 않았다.

## 1. 확인하려던 것

대상 HCC 계열을 뺀 161개 세포주(source)로 공개 TranSiGen 구조(ECFP4, 무작위 초기값)를 학습해 B0를 만든다. 학습률과 epoch는 통째로 떼어 둔 source 검증 세포주 16개로만 고른다.

## 2. 실제 실행

- 구조와 loss: 공개 `TranSiGen` 클래스 그대로(잠재 100, encoder 1200, decoder 800, 약물 embedding 400, β 0.1, dropout 0.1, weight decay 1e-5, batch 64, Adam).
- 학습률 후보 3e-4, 1e-3, 3e-3을 seed 42로 실행하고, source 검증의 ΔRMSE(X0와 약물만 넣는 잠재 평균 경로)가 가장 낮은 것을 골랐다. 고른 학습률로 seed 43, 44를 추가했다.
- 최대 300 epoch, 검증 점수가 30 epoch 동안 좋아지지 않으면 중단. 공개 코드에는 early stopping이 없어서 자체 실행기에 넣었다.
- 학습 221,100행(145개 세포주), 검증 17,432행(16개 세포주). GPU는 A40 1개, 최대 메모리 약 2.5 GB.

## 3. 관측된 사실

### 3.1 학습률 탐색 (seed 42, 유효한 실행 묶음 `_v4`)

| 학습률 | 종료 이유 | 실행 epoch | best epoch | source 검증 ΔRMSE (best) |
|---|---|---:|---:|---:|
| **3e-4** | patience | 87 | 57 | **0.9728** |
| 1e-3 | loss가 유한하지 않음 (epoch 2) | 2 | 1 | 1.1346 |
| 3e-3 | loss가 유한하지 않음 (epoch 1, 28번째 update 부근) | 1 | 0 | 8.5078 (초기값 그대로) |

- 규칙대로 3e-4를 골랐다. 발산한 후보는 발산 전의 가장 좋은 상태로 비교했다.
- 같은 source 검증 행에서 **무변화(Δ=0)의 ΔRMSE는 0.7025**다. 선택된 모델(0.9728)은 처음 보는 세포주에서 무변화보다 나쁘다.

### 3.2 선택된 설정의 세 seed (B0 checkpoint)

| seed | run id | best epoch / 실행 epoch | source 검증 ΔRMSE | 학습 시간 |
|---|---|---|---:|---:|
| 42 | `source_lr0.0003_seed42_v4` | 57 / 87 | 0.9728 | 2,092 s |
| 43 | `source_lr0.0003_seed43_v4` | 50 / 80 | 0.9794 | 2,179 s |
| 44 | `source_lr0.0003_seed44_v4` | 53 / 83 | 0.9761 | 2,207 s |

세 checkpoint의 SHA-256은 `source_selection.json`에 있다. 이 세 개를 모든 target·분할·k에 재사용한다.

### 3.3 점수가 나쁜 이유가 오류인지 확인한 것 (source 행만 사용)

계획서 §4.2에 따라 점수가 나쁠 때 오류·정답·추론 경로부터 확인했다(`diagnose_source.py`).

| 자료 | 무변화 | B0 (잠재 평균 경로) | 공개 `forward()` (표본 1개) | 행별 ΔPearson 평균 |
|---|---:|---:|---:|---:|
| 학습에 쓴 세포주의 행 20,000개 표본 | 0.713 | 0.673–0.675 | 0.675–0.677 | 0.31 |
| 떼어 둔 세포주 16개 (17,432행) | 0.703 | 0.973–0.979 | 0.975–0.982 | 0.16 |

| 떼어 둔 세포주에서 | seed 42 | seed 43 | seed 44 |
|---|---:|---:|---:|
| 세포주마다 잔차의 평균 벡터를 뺀 뒤의 ΔRMSE | 0.707 | 0.708 | 0.707 |
| 세포주별 평균 잔차의 RMS | 0.623 | 0.630 | 0.634 |

- 학습에 쓴 세포주에서는 B0가 무변화보다 좋다(0.673 대 0.713). 학습과 추론 경로는 작동한다.
- 잠재 평균 경로와 공개 `forward()`의 점수 차이는 0.003 이하다. 추론 경로 선택이 나쁜 점수의 원인이 아니다.
- 떼어 둔 세포주에서 세포주마다 상수 벡터 하나(그 세포주 잔차의 평균)를 빼면 ΔRMSE가 0.973에서 0.707로 내려가 무변화(0.703)와 거의 같아진다. 이 계산은 정답을 써서 한 진단이며 예측 방법이 아니다.

### 3.4 source 쪽 기준선

| 기준선 | source 검증 ΔRMSE |
|---|---:|
| 무변화 (Δ=0) | 0.7025 |
| source 학습 행의 평균 Δ 하나를 모든 조건에 적용 | 0.6957 |
| source Ridge ([표준화한 X0, ECFP4] → Δ), α = 1 / 10 / 100 / 1,000 / 10,000 | 1.024 / 1.020 / 0.983 / 0.839 / **0.716** |

- Ridge의 α는 후보 가운데 가장 큰 10,000이 선택됐다. 선택이 후보 범위의 끝에 걸렸고, 그 값에서도 무변화보다 나쁘다. 후보 범위는 사전에 정한 것이라 넓히지 않았다.
- "source 같은 약물 평균"은 약물 그룹 8,271개에 대해 source 학습 세포주별 조건 Δ를 세포주 단위로 같은 비중으로 평균해 저장했다. source 검증에서의 점수는 따로 계산하지 않았다.

### 3.5 버린 실행 (모두 run ledger와 서버에 남아 있다)

| 묶음 | 내용 | 상태 |
|---|---|---|
| `_v1` (5개) | 퇴화 plate 42행을 포함한 채 실행. 학습률 탐색 3개가 모두 첫 epoch에서 발산했고, 자동으로 이어진 seed 43·44도 발산하거나 취소됐다 | amendment 1의 근거. 사용 안 함 |
| `_v2` (3개) | 42행 제외 후 실행. 3e-3은 발산, 나머지 둘은 3 epoch에서 직접 취소 | 속도 문제(epoch당 약 76초)로 취소 |
| `_v3` (3개) | fused Adam과 CPU thread 1개로 변경. 3e-3은 발산, 나머지 둘은 13–14 epoch에서 직접 취소 | 속도가 나아지지 않아 CPU가 빠른 노드로 옮기려고 취소 |
| `_v4` (5개) | 위 표의 실행 | **사용** |

- v2·v3를 취소할 때 본 것은 초반 epoch의 source 검증 점수뿐이다. 취소 시점의 값은 1e-3이 1.007(14 epoch), 3e-4가 1.013(13 epoch)이었다.
- v2 → v3 → v4에서 바뀐 것은 Adam의 구현 방식(fused), CPU thread 수, 실행 노드뿐이다. 학습률 후보·batch·예산·자료는 같다.
- 계획서의 "source 학습 최대 5회"는 유효한 묶음(v4)에서 지켰다. 발산·취소된 시도까지 세면 16회를 시작했다.

## 4. 가능한 해석 (검증하지 않은 가설)

- 3.3의 결과는 "처음 보는 세포주에서 B0의 오차 대부분이 약물과 무관한, 세포주마다 일정한 offset"이라는 설명과 맞는다. 이 구조는 Δ가 아니라 처리 후 발현 전체를 decoder로 다시 만들기 때문에, 학습에 없던 세포주의 기저 발현을 정확히 복원하지 못하면 그 오차가 모든 약물에 똑같이 실릴 수 있다. offset이 생기는 내부 경로(encoder인지 decoder인지)는 분리해 시험하지 않았다.
- 학습률 1e-3이 v4에서는 2 epoch 만에 발산했지만 취소한 v2·v3에서는 같은 학습률로 10 epoch 넘게 발산하지 않았다. 이 구성에서 1e-3은 발산 경계에 가까워 실행 환경(GPU 종류, 연산 순서)에 따라 결과가 갈리는 것으로 보인다. 1e-3이 끝까지 학습됐다면 3e-4보다 좋았을지는 알 수 없다.
- plate 수준의 한 well 측정은 잡음이 크다(무변화의 ΔRMSE가 0.70). 저자 논문처럼 반복을 합친 signature 수준 자료에서는 결과가 다를 수 있다. 확인하지 않았다.

## 5. 다음 단계로 넘어가는 판단

- B0 checkpoint 3개를 고정했다. source 검증 점수가 무변화보다 나쁘다는 이유로 구조·손실·학습률 후보를 바꾸지 않았다. 계획서의 비교(B0, B1, B2와 기준선)를 그대로 진행한다.
- 3.3의 진단은 "B0 + mean-offset 보정" 기준선이 중요한 비교가 될 것임을 시사한다. 그 기준선은 이미 계획에 들어 있으며 새로 추가한 것이 아니다.
