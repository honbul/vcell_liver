# R9 — 자연 희귀 상태로 확장하기 위한 자료 조건 (v2 기록, 새 자료 수집 없음)

근거: private plan 2026-11-19 §6.4, `DATA_CONTRACT.md`, `label_inventory.tsv`. 이 문서는 **조건 명세**이며 새 자료를 찾거나 내려받지 않았다.

## 현재 자료가 답할 수 없는 것 (관측)
- GSE149614 배포 주석은 대분류 6개뿐이고 학습 fold 최소 비율이 2.55%(Fibroblast)라 **자연 희귀 대분류가 없다**. R9 Tier 1의 "희귀"는 N64/D4 **인공 희소화**다.
- Tier 2 `res.3` 군집 번호는 군집 ID 재현 과제이며, 전문가가 정의한 세부 상태의 독립 정답이 아니다.
- GSE151530은 대응 가능한 대분류 5개와 Malignant/unclassified(대응 없음)만 있다. 종양 유래라는 이유로 세포를 malignant로 만들거나 broad label을 임의로 세분하지 않는다.

## 새 자료를 채택하기 전 확인할 조건
| 항목 | 요구 조건 |
|---|---|
| label 정의 | 세부 상태 이름·정의·marker/기능 근거가 문서화됨; 군집 번호만 있는 경우 제외 |
| 주석자·근거 | 주석자(저자/전문가)와 방법(수동 marker, 기능 assay, 다중 모달)이 명시됨; 모델 예측으로 만든 label은 정답으로 쓰지 않음 |
| 다환자성 | 대상 상태가 ≥3 donor에서 각 ≥10세포로 관찰됨(v1 Tier 2 규칙과 동일 기준); 단일 donor 상태는 별도 표시 |
| batch 혼입 | 상태가 sample/batch/부위 하나와 일치하지 않음(상태×batch 교차표 확인) |
| donor 겹침 | 학습·평가 donor 겹침 0; GSE149614/GSE151530과의 환자 중복 여부 확인 |
| 원시 자료 | raw count + cell ID + gene symbol/Ensembl ID 제공; 공통 gene 정규화 계약(v2 C1과 같은 분모 규칙)을 적용할 수 있음 |
| 접근 | 공개·무료, 등록/유료 서비스 불필요 |

## 자료가 확보되면 적용 순서
1. 같은 N에서 donor 수(D)를 바꾸는 기존 N×D 진단과 LR_class/LR_donor/MLP_donor/P1 기준선을 먼저 적용한다.
2. 그 위에서만 선정된 prototype 변경(E1/E2에서 원인이 확인된 경우에 한함)의 추가 가치를 묻는다.
3. 지위는 "독립 확인"으로, 선택 규칙·threshold는 source에서 고정한 뒤 한 번 평가한다.

## 현재 상태
- 미실행: 자연 희귀 세부 상태 평가. 이유 = 위 조건을 만족하는 다환자 전문가 세부 주석 자료가 없음(새 자료 탐색·다운로드는 이번 범위 밖).
- 해소 조건 = 위 표를 만족하는 공개 자료 1개 이상의 확보와 사용자 승인.
- R9-C1/C2와 source 원인 분석(E1/E2)은 이 자료와 무관하게 진행했다.
