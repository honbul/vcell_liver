# GSE306429 독립 자료 전이 평가

Tahoe에서 A549를 포함한 0.5 µM·24시간 자료를 학습하고, 독립 연구의 A549 1 µM·24시간 처리 자료로 평가한다. 외부 메타데이터에서 화합물 구조와 두 역할의 물리 반복, 라이브러리 내 DMSO를 확인했다. 정확히 0.5 µM에 해당하는 화합물은 구조가 미확정인 한 종류였다. HepG2는 Tahoe의 HepG2/C3A와 모세포주·파생 클론 관계이므로 현재 A549 평가에 포함하지 않는다. 이 경로는 연구·플랫폼·용량을 함께 바꾼 전이 실험이다. [GSE306429 원본](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE306429) · [HepG2/C3A 계보](https://www.cellosaurus.org/CVCL_1098)

## 동결과 중복 제거

- GSE306429 원본 H5AD 해시를 고정했다. 메타데이터는 `obs`·`var`에서 읽었다. 공통 유전자 11,211개 중 학습 자료의 분산 순위로 2,000개를 고정한다. 예측기는 외부 추론에서 선택한 처리 웰의 발현을 읽기 전에 물리 매칭 DMSO와 분자 구조를 사용한다.
- Tahoe 원본·추가 용량의 원시 SMILES에서 계산한 비입체 표준 모화합물, 후보 모화합물, 이름·별칭·가용한 PubChem CID를 확인했다. 처음 manifest v2에서 제외한 6개 외에 예측기 중복 검사에서 4개가 확인됐다. 같은 화합물군의 Tahoe 행을 모두 제외한 v3는 193개 화합물군과 10,064개 행을 남겼다. 먼저 제출된 검증 배열 28181–28184는 이 검사 단계에서 실패했다. v3의 새 배열 28208–28211은 제외 후 동일 규칙을 실행한다. 어느 배열도 외부 처리 발현값을 읽지 않는다. [메타데이터 입력·출력 해시](external_manifest_receipt.json)
- Tahoe 개발의 학습과 검증 양쪽에서 같은 10개 군을 제외한다. R12 화합물 세 fold와 A/B 역할을 재사용한다. 두 역할을 합쳐 각 fold의 A549 대비 RMSE를 계산한다. 구조 자료만으로 외부에서 동일하게 계산할 수 있는 커널, 신경망, 세포주 전이, 용량 전이 후보와 잔차 배율을 비교한다. B0보다 개선된 fold 수, 전체 가중 차이, 더 작은 배율, 이름 순으로 고른 대표 설정 하나를 1차 비교로 고정한다. 계열별 대표 설정도 미리 고정해 탐색 비교한다.
- 초기에 등록한 42개 처리 웰에서 세 화합물군 이상이 있는 라이브러리만 유지한다. 최종 A/B는 15/12개 처리 웰이다. 7개 라이브러리, 4개 물리 plate, 17개 화합물군이며 10개가 두 역할에서 모두 적격이다. 각 라이브러리별로 약물 처리값을 중심화한 후 결과를 집계한다. 같은 라이브러리의 공통 DMSO는 대비 중심화에서 상쇄된다. 절대 발현 오차는 참고로 보고한다.
- 후보·배율과 학습 증빙, 유전자, 모델 코드, DMSO, 평가 웰, 예측 배열의 해시를 동결하고, 별도 scorer가 이를 검증한 뒤 해당 처리 웰 발현만 읽는다. 10,000회 화합물군 재표집으로 1차 비교 99% 구간, 탐색 95% 구간, 역할 및 plate별 결과를 보고한다. 화합물군 17개를 사용하므로 이 구간은 해당 실험과 plate에 조건부이며 폭이 클 수 있다.

## 외부 처리 결과를 열기 전 고정한 설정

Alias-disjoint Tahoe A549 개발에서 MACCS 이웃 8개와 세포주 보정 비율 0.75, 잔차 배율 0.125를 공식 후보로 고정했다. 세 fold에서 모두 점추정이 개선됐으며 가중 평균 차이는 −0.000143이었다. 각 탐색 계열의 설정과 개발 표 SHA-256도 함께 고정했다. 독립 레시피 재실행 28238과 예측 작업 28236의 결과는 SHA-256 `8cb387bfd97f3e081dbd002eb9bc03744a0c127fb211fed0b91768c62f2ca3ed`로 일치했다.
