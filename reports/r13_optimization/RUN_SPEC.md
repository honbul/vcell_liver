# R13 약물별 잔차 최적화 실행 명세

## 평가 계약

R12의 0.5 µM·24 h Tahoe 비교와 같은 물리 웰, fit-only 2,000 유전자 패널, 반대 DMSO 채점, 화합물군 균등 가중 RMSE를 사용한다. 화합물군 분할과 scaffold 분할을 사전 명세로 고정한다. R12에서 공개된 데이터와 점수가 있으므로 두 경로 모두 프로젝트 노출이 있는 후속 교차검증이다. 별도 실험 자료가 확보되면 노출 이력, 동일 화합물·염·별칭 교집합, assay 및 dose 차이를 기록하여 별도 전이 검증으로 수행한다. 외부에서 같은 화합물의 반응을 제공하는 설정은 참고 반응이 주어진 전이로 보고한다. [R12 노출 이력](../r12_multiaxis/exposure_ledger.tsv)

각 외부 fold와 DMSO 역할마다 두 내부 fold로 후보·가중치·학습 설정을 고른다. 모델에는 query 발현을 채우지 않으며, 선택 스크립트가 사용하는 검증 응답은 외부 fit 영역에 포함된다. 평가 프로그램은 여섯 외부 예측, 물리 웰 계약, 파티션·코드·예측 해시를 확인하고 동결 영수증을 작성한 뒤 score 배열을 읽는다. 부가 용량은 fit 화합물군 교집합만 사용한다. 같은 compound identity group의 모든 dose·세포주·웰은 함께 제외한다.

## 후보군과 기준선

| 축 | 비교 |
|---|---|
| 커널·검색 | ECFP Tanimoto, MACCS, physchem, ChemBERTa와 혼합 화학 표현. 그룹 균형 이웃 검색, 가중 커널 Ridge, 저랭크 및 강건 잔차 |
| 신경망 | 약물 단독, concat, FiLM, 곱 상호작용과 맞춘 폭·dropout·regularization·학습률·epoch 탐색. 전체 유전자 또는 fit-only 저랭크 출력, 평균·대비 손실 |
| 다중 과제 | 화합물 공유 반응, own-control 또는 fit 응답에서 추정한 세포주 요인, plate 연관 보정, 교차-view 출력 기저 |
| 공개 주석 | Tahoe 공개 표적과 작용기전은 제약사·문헌에 근거한 사전 주석이다. 표적·작용기전과 ECFP 혼합, fit-only 이웃의 동일 line 보정, 순열 대조를 비교한다. [공개 메타데이터 사양](https://huggingface.co/datasets/tahoebio/Tahoe-100M) |
| 보조 용량 | fit 화합물의 0.05/5 µM 실측으로 출력 부분공간 또는 학습 잔차만 보정한다. 보조 용량의 query 화합물 발현은 사용할 수 없다. |

기준선은 영 약물 대비 B0, 고정 shrinkage 2의 평균 반응 anchor, 내부 절대 RMSE로 후보 shrinkage 0/2/8/32 및 B0 중 고른 B_abs다. 대비의 공식 대조는 B0다. 각 후보는 anchor를 기준으로 잔차 배율 0·0.125·0.25·0.5·0.75·1·1.5·2·3·4를 내부 검증한다. 각 가족의 비영 후보 하나를 외부 평가한다. 공식 통합 선택기는 내부 두 fold 모두에서 대비 RMSE가 개선된 후보 중 가중 오차가 가장 낮은 것을 사용하며 후보가 없으면 anchor를 쓴다. 탐색 ensemble은 이 조건을 통과한 상위 세 가족까지 균등 평균한다. 최종 신경망 후보는 seed 42/43/44로 재적합한다. 순열 대조는 공식 선택에서 제외한다.

기준선과의 차이는 같은 화합물군과 score-control 계약으로 계산한다. 공식 통합 절차의 대비 및 절대 RMSE 차이는 10,000회 화합물군 가중 재표집 99% 구간 및 점추정을 함께 보고한다. 나머지 후보별 구간은 탐색 95%로 표기한다. 구간 상한이 0 미만일 때 개선 근거로 판정한다.

Compound 개발 배열은 28082–28086과 28113이다. Scaffold 개발 배열은 28114–28119다. 예측 배열 28146·28148과 채점 작업 28147·28149를 성능 조회 전에 연결했다. 처음 제출한 28057–28060은 원격 코드의 전이적 import가 빠져 학습 전에 종료됐다. 원격 의존성을 포함해 다시 제출했고 실패 로그를 보존했다.
