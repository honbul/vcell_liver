# R13 약물별 잔차 최적화 결과

Tahoe 0.5 µM·24시간에서 내부 검증으로 고른 잔차 모델은 화합물 분할과 골격 분할 모두에서 기준선 대비 개선이 확립되지 않았다. 화합물 분할에서 통합 모델의 대비 RMSE는 0.093475로 B0의 0.092792보다 0.74% 높았다. 골격 분할에서 표적·작용기전 계열은 세 fold 모두 낮은 점추정을 보였고, 합산 95% 구간에 0이 포함됐다. [실행 명세](RUN_SPEC.md) · [R12 원인 진단](DIAGNOSIS.md)

## 평가와 튜닝

R12와 같은 네 plate, 203개 화합물군과 2,000개 유전자에서 화합물군 3-fold와 공유 골격 연결 성분 3-fold를 평가했다. 각 평가 fold의 학습 화합물군을 내부 두 fold로 나눴다. DMSO A/B 역할마다 설정과 배율을 고르고, 예측 파일을 해시로 고정한 뒤 반대 DMSO를 사용해 채점했다. 같은 물리 처리 웰을 두 역할에서 함께 비교했다. 이미 프로젝트에 노출된 R12 자료의 후속 교차검증이다. 10,000회 화합물군 단위 재표집은 각 회차 pool 중심화를 다시 계산한다. 구간은 관측 plate, DMSO와 적합 결과에 조건부다. |---|---:|---|---:|

297개 설정에는 공개 주석 순열 대조 2개가 포함된다. 이와 별도로 기준선 5개를 시험했다. 잔차 설정별 배율 10개를 내부 검증했다. 배율은 계열별로 다른 크기의 원시 잔차에 곱한다. 계열 간 배율 수치는 예측 크기의 직접 비교로 사용할 수 없다. 신경망은 내부에서 종료 시점을 선택하고 외부 예측을 만들 때 세 seed로 재학습했다. [내부 선택](round1/inner_selection.tsv) · [실제 선택과 합성](round1/outer_choices.tsv)

차이는 각 분할의 B0 대비이며, 음수일수록 오차가 작다. 통합 선택기의 두 구간은 사전 명세한 99%다. 개별 계열과 앙상블은 탐색 95% 구간이다.

## 내부에서 좋아진 설정이 외부 fold에서 바뀐 경우

- 화합물 fold 0에서 통합 선택기가 고른 세부 작용기전 이웃 모델은 내부 평균 오차를 약 0.001 줄였다. 같은 설정의 외부 fold 오차는 B0보다 0.001722 높았다. Fold 1에서 고른 커널은 외부 오차를 0.000571 높였고, fold 2에서 고른 커널은 0.000240 낮췄다. 모델별 개선 방향이 fold에서 유지되지 않았다. [역할·fold별 화합물 결과](round1/compound_by_fold_role_seed.tsv)
- 골격 분할에서 표적·작용기전 계열의 오차 차이는 fold별로 약 −0.000249, −0.000149, −0.000019였다. Fold 0에서는 내부 점수가 B0보다 약간 높아 통합 선택기가 해당 계열을 사용하지 않았다. 같은 계열의 화합물 분할 결과는 +0.000549였으므로, 두 분할에서 재현된 개선은 없다. [역할·fold별 골격 결과](round1/scaffold_by_fold_role_seed.tsv)
- 화합물 분할에서 커널과 표적·작용기전의 평균 방향 코사인은 0.025와 0.032였고, 신경망은 −0.019였다. 예측 반응 크기는 실측의 약 6~10%였다. 같은 pool에서 올바른 약물의 반응을 찾는 탐색 상위 1위 비율은 커널 6.70%, 표적·작용기전 6.55%, B0 5.51%였다. 작은 순위 신호가 관측됐지만 전체 유전자 대비 RMSE 개선으로 이어지지 않았다. 순위의 구간은 이 비교에서 산출하지 않았다. [화합물 요약 지표](round1/compound_arm_metrics.tsv) · [골격 요약 지표](round1/scaffold_arm_metrics.tsv)

## 별도 내부 실험의 LINCS 학습 자료

LINCS의 8,028개 화합물군에서 세포주 간 재현 방향과 반응 PCA를 만들고, Tahoe의 약물 구조 Ridge 잔차에 적용했다. LINCS의 다른 화합물 구조와 반응만으로 학습하는 직접 전이도 비교했다. 전체 Tahoe 카탈로그 379개와 구조·별칭·확인 가능한 PubChem CID를 대조해 LINCS 407개 화합물 ID를 제외했다. 보존한 10,454개 ID 중 2,581개는 직접 CID가 없어 구조와 별칭으로만 대조했다. 외부 fold 0의 A 역할, 내부 두 fold에서 36개 설정과 배율 10개를 실험했다. 각 내부 fold는 검증 화합물군 68개였다. [ID 감사](lincs/identity_receipt.json) · [공여 반응 영수증](lincs/signature_receipt.json)

| 계열별 내부 검증 최저 대비 RMSE | RMSE |
|---|---:|
| 영 대비 | 0.0931770 |
| Tahoe 단독 ECFP Ridge | 0.0930973 |
| LINCS 교차 세포주 반응 부분공간 | 0.0930987 |
| LINCS 반응 PCA | 0.0930996 |
| LINCS에서만 학습한 ECFP Ridge | 0.0931766 |

교차 세포주 방향을 섞은 설정은 같은 규제와 배율의 Tahoe 단독보다 두 내부 fold 모두 오차가 높았다. 24시간은 일치했고 처리 용량은 명목 10 µM과 0.5 µM으로 달랐다. 정확히 매핑된 LINCS 랜드마크 978개 중 Tahoe 평가 유전자 2,000개에 해당하는 것은 fold별 182·184개였다. 이 실험은 개발 fold 수준의 비교이며, 용량과 유전자 범위의 효과를 분리하지 않았다. Slurm 28206·28228에서 실행했다. [두 내부 fold 비교](lincs/two_inner_comparison.json)
