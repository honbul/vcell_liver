# P4 Tahoe 세포주 고유 약물 반응 사전 명세

## 대상과 실험 계약

세포주 고유 대비는 P1 공정성 결과를 본 뒤 제안됐고 동일 Tahoe 개발 코호트의 내부 탐색에 노출됐다. P4는 이 대상을 채점 전에 동결한 후 기존 parent 교차검증으로 평가한다. T1/P1의 203 canonical parent 3-fold, 각 outer에 속한 두 inner fold, 24시간 웰, 0.05·0.5·5 µM, 최소 세포 수 20과 200, 기존 fold별 fit-only 2,000개 유전자 축 및 DMSO 역할을 유지한다. 세 용량 모두에서 평가 parent의 처리 발현은 적합·설정 선택에서 제외한다. 별도 봉인·격리·예약 자료는 접근 범위 밖이다.

각 물리 처리 웰의 **동일 세포 수 기준을 충족하는 T1 적격 행**을 사용한다. 세포주가 최소 10개 있는 웰을 유지한다. 별도 외부 채점에서 실측값은 기존 T1 방식의 처리 logCP10k−반대 역할 DMSO logCP10k 반응이고, 예측은 각 모델의 적합 역할 DMSO 기준 반응이다. 적합과 두 내부 설정 선택에서는 해당 적합 역할의 DMSO를 쓴다. 동일한 웰에서 해당 행의 유전자별 세포주 산술 평균을 각각 뺀다. 예측은 예측만으로 평균을 만들고 실측은 실측만으로 평균을 만든다. 세포주별 균등 평균을 사용하고, 두 간 유래 세포주를 점수로 골라내기 전에 모든 적격 세포주를 평균에 포함한다. 그 뒤 plate×세포주×용량×시간 pool당 최소 3 parent 지지를 다시 적용하고 기존 parent 균등 pool 중심화를 한다. 이 재적격성 판정 전에 사용한 웰 평균은 그대로 쓴다. B0 및 세포주 구별 없이 동일 웰에 같은 반응을 예측하는 경우의 기준은 0이다. 보존 에너지, 웰·세포주·parent 지원을 함께 보고한다. 이 변환은 웰 전체에 공통인 위치 성분과 공통 약물 반응을 모두 뺀다. 세포주별로 다른 위치 성분의 잔여는 재채점한 B_pos-all과 P1 trim으로 계량한다.

## 동결 예측 재채점과 P4 적합

- T1의 v0, B_pos-all, P1의 v1, trim, 공정성 결합 10종과 위치 잔차 재적합 5종, T2 동결 VC 10종, P2 LINCS 계열 5개를 원본 해시와 대조해 재채점한다. 모든 역사적 예측은 사후 재채점으로 표시한다. 웰 단위 반응이 동일한 모델의 0 예측 등가성을 명기한다.
- P4 새 arm은 최근접 구조 형제의 동일 세포주 복사, 세포주별 Tanimoto Ridge, 세포주별 Tanimoto+LINCS Ridge 3종이다. 형제 임계와 구조 Ridge alpha는 P1의 같은 dose×최소세포×fold×역할에서 저장한 선택값을 그대로 상속한다. 혼합은 P2 같은 조합의 alpha·LINCS preset·혼합률과 원본 Level 5 서명 bank를 상속한다. 각 세포주의 fit parent 반응으로 혼합 Ridge를 다시 적합해 세포주별 반응을 내고, LINCS가 없는 parent의 cosine 성분은 0이며 구조 성분은 유지한다. 새 arm에는 위치 정보를 입력하지 않는다.
- P1에서 재적합 가능했던 ChemBERTa Ridge, R12 concat·FiLM, scGPT·UCE 맥락 모델을 P4 학습 정답으로 다시 적합한다. T2의 고정 구조와 같은 outer-fit의 alpha 또는 epoch·학습률을 재사용한다. 세 경로와 다섯 비교군에는 동일하게 0/0.125/0.25/0.5/0.75/1/1.5/2 배율을 두 inner fold의 변환 후 에너지 SSE/SST 평균으로 선택한다. 동률은 작은 배율이다. 다른 후보와 설정 격자는 추가하지 않는다. 최종 예측에는 학습과 동일한 유전자와 행 축을 사용한다. 예측→SHA-256 동결→별도 채점 순서로 실행한다.

## 지표·사전 기준·기여와 반복

- 화합물군 균등 대비 RMSE와 행×유전자 에너지 합의 `R²_pooled = 1 − ΣSSE / ΣSST`를 공동 주 지표로 제공한다. 전체, 간 유래 두 세포주 합산, HepG2/C3A 및 SNU-423 각각을 보고한다. 동일 parent 양의 지수 가중 10,000회에서 역할 A/B·물리 웰을 묶고 pool 중심을 매 회 재계산한다. 웰 평균에는 각 parent가 한 웰을 차지하므로 화합물군 재표집 가중이 영향을 주지 않는다.
- 주 판정은 5 µM·최소 20세포 전체 및 간 유래 합산 각각이다. P4 새 arm 각각을 B0 및 지표별 최선 기존 VC와 대응 비교한다. 기존 VC에는 T2 원래 10종의 P4 재채점, 동일 모델의 P1 공정성 결합 10종·재적합 5종의 재채점, P4에서 세포주 고유 대상으로 재적합한 5종을 포함한다. 지표별 최선값은 각 대응 재표집에서도 다시 계산한다. ΔRMSE의 99% 상한 < 0, ΔR²의 99% 하한 > 0을 각각 적용하고 두 지표 동시 통과를 기록한다. 0.05·0.5 µM, 200세포 및 개별 세포주 결과는 기술 분석이다.
- 새 arm별 B0 대비 parent SSE 감소를 합산한다. 양의 이득 상위 5/10/20의 양의 합·순합 점유율과 상위군 제거 후 RMSE·R²를 보고한다. 제거 분석에서 pool 최소 지지와 중심을 다시 계산한다. 각 제거 parent가 자기 물리 웰 전체에 해당하므로 유지 웰의 원래 세포주 평균을 사용한다. 기여와 제거는 결과 의존 기술 분석이다.
- 5 µM의 공개 개발 코호트 내 plate 14 평가 행과 plate 6의 반복을 동일 parent·barcode 인덱스·세포주·역할로 대조한다. 각 plate에서 자기 웰의 평균이 빠진 실측을 만들고, 반복 지원 pool에서 plate 6의 대비를 plate 14에 0.25·1배로 가져온다. B0 및 각 모델과 같은 지원 행에서 두 지표를 계산한다. 도달률은 B0에서 반복 참조까지의 이득 중 모델이 달성한 비율이다. 분모 이득의 99% 하한 > 0일 때만 대응 비율 구간을 보고하고, 참조는 같은 위치·해당 조건 반복임을 명시한다. 예약 40쌍은 사용하지 않는다.
