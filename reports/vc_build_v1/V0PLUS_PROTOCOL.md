# V0+ 공개 자료 전이 평가

기존 LIMORE 소스 학습과 내부 MLP 결과는 0단계 실행 점검으로 보존한다. V0+는 공개 자료로 개발하며 VCB-06을 종료한다.

## 데이터 역할과 채점 순서

- 지도 학습·설정 선택은 GDSC2, CTRPv2, PRISM20Q2의 2D 약물 반응으로 제한한다. 동일 세포·환자 파생 모델은 소스가 달라도 같은 교차검증 그룹이다. 약물 매칭은 정확한 이성질체 parent 기준이다. 동일 배양물의 여러 플랫폼 측정은 학습 안에서만 쓰고, 외부 측정은 동결 후 별도 채점한다.
- 외부 2D는 기존 50개 LIMORE 독립 계통으로 고정한다. 이 계통의 0단계 결과는 이미 공개된 프로젝트 근거로 기록한다. 2단계와 3단계의 외부 예측을 함께 동결하고 4단계에서 한 번 채점한다. 그때 2단계 모델의 결과를 같은 표에 포함한다.
- 외부 3D는 LICOB 44 HCC 오가노이드의 표본·환자·기저 RNA·약물 반응 ID 교집합이다. 정확한 약물 일치와 학습에 없는 약물의 결과를 구분한다. RNA 자료 무결성, RNA의 처리 전 채취 출처, 환자 그룹과 분석용 재사용 조건을 확인한 범위만 등록한다. 환자별 원시 행렬과 반응 자료는 G1에 보관한다.
- 소스 홀드아웃과 별개의 외부 결과는 다른 파일·프로세스에서 채점한다. 외부 RNA의 배치 통계를 이용하는 전이 모델은 별도의 transductive arm에만 허용한다. 외부 반응은 어떤 arm의 스케일, 피처 선택, 모델 선택에도 쓰지 않는다.

## 1단계 고정 진단

GDSC2를 기준 AUC 소스로 둔다. 각 소스에서 낮은 AUC를 높은 감수성으로 바꾼다. 정확한 같은 세포·약물 pair가 12개 이상인 약물 중 최소 3개 약물과 총 60쌍을 요구한다. 기준과 소스의 약물별 IQR 비율 중앙값으로 양의 기울기를 정하고, 약물별 중앙값의 보정 차이 중앙값으로 절편을 정한다. 각 약물은 같은 기여를 한다. 지원이 부족하면 해당 규약으로 학습하지 않는다. 조회 시 약물 패널의 다른 구성원이 개별 예측의 훈련 레이블을 바꾸지 않는다.

이미 등록된 65,685개 소스 행에서 동일 계통을 묶는 GroupKFold 3분할을 쓴다. 모든 모델 입력과 출력 규약은 고정하고, 0단계의 세포×소스 백분위와 새 척도만 바꿔 원 소스별 AUC와 비교한다. 외부 측정은 이 진단에 사용하지 않는다. 소스가 달라도 동일 약물·세포의 예측은 같은 값을 쓰며 실제 각 소스의 지원에서 별도 평가한다. 이 진단의 기존 모형은 척도 수정의 효과를 일대일로 비교하기 위한 대조다.

## 공동 지표

- 약물별로 환자·계통 내 모델 평균을 낸 뒤 계통 간 Spearman과 Pearson을 계산한다. 관측 변동이 있고 5계통 이상인 약물을 동등 가중한다. 상수 예측의 두 지표는 0으로 보고한다. 약물 단위 재표집 구간과 함께 표에 분모를 싣는다.
- 모델별로 약물 간 NDCG@5, Precision@5, Spearman을 계산한다. 동점은 기대 top-5 overlap으로 계산한다. 표적·세포독성 및 사전 지정 HCC 관련 계열은 학습 반응과 무관한 원 출처 약물 주석으로 분류한다.
- 2D AA, 3D AUC와 학습 AUC는 별개 assay 정답으로 해석한다. 이들 사이 단위 차이를 임의의 절대 오차로 보고하지 않는다.

## 후속 모델 비교

소스 내부의 설정 선택은 두 공동 지표를 보고하며, 순위가 충돌하면 순위를 함께 제시한다. 개별 약물 ElasticNet/Ridge, CatBoost/LightGBM, additive를 기존 약물 평균과 비교한다. 공개 모델의 원 목적함수와 필수 입력을 확인해 소스 데이터에 재학습한다. 외부 코호트 사용 이력이 확인되지 않은 사전학습 모델은 직접 비교에 넣기 전에 노출을 감사한다. 주력 모델과 같은 지표와 분할을 쓰고 소스 전용 예측도 보존한다. 모델별 설정, 특징과 도메인 적응 절제는 외부 채점 전에 별도 명세로 동결한다.
