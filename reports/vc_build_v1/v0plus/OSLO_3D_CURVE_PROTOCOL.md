# 공개 3D 농도 곡선 등록의 범위

LICOB의 S7·S8은 요약값이며 같은 오가노이드–약물에서 불일치하는 경우가 있다. 공개 접근이 확인된 Oslo 대장암 간전이 PDO를 별도 **3D 개발 학습원 후보**로 등록한다. 간세포암 성능 판정의 LIMORE와 LICOB 외부 코호트는 기존 역할을 각각 유지한다. [LICOB 종말점 감사](LICOB_CROSSING_RESULTS.md) · [Oslo 공개 자료 v3](https://data.mendeley.com/datasets/hr94h42xdc/3) · [Oslo 원논문](https://pubmed.ncbi.nlm.nih.gov/42208542/)

- 배포 SHA-256이 맞는 Data S1, S2, S4, S5와 저자 Table S2·S5를 사용한다. 환자 ID는 저자 Table S2 표본 ID의 `Pt` 번호에서 추출하며, 수술·병변 접미 번호가 있어도 같은 환자로 묶는다. Data S1에서 두 표에 모두 있는 PDO의 환자 ID를 재검증한다. RNA는 S2의 고유 유전자 심볼과 비음수 정수 카운트로 보관한다. 원 조직과 PDO를 섞지 않는다.
- 농도 지지는 양의 nM, 유한한 저자 표준화 생존율, 서로 다른 농도 5개 이상, 명시적 FIMM 제품 코드가 있는 단일 약물이다. 복합 약제 표기가 분리된 TAS-102와 Disulfiram+Cu도 단일 약물에서 제외한다. 효과 유무나 출판사가 반응 결과를 본 뒤 지정한 제외 표시는 지지 결정에 쓰지 않는다. 플레이트 내 동일 웰은 단일 약물 조건에서 유일해야 한다.
- 원 신호의 음성·양성 대조가 각각 4웰 이상이고 음성 중앙값이 더 큰 플레이트에서 대조 정규화를 다시 계산한다. 저자 생존율과의 차이를 기록한다. 후속 실험용 자료에는 저자의 정규화 생존율과 원 농도를 보존한다.
- 반복은 같은 PDO와 동일 **전체** FIMM 제품 코드가 공통인 서로 다른 스크린 run 또는 약물 라이브러리다. 같은 샘플–제품마다 반복 범주별 최초 등록 키의 쌍으로 제한한다. 물리 농도 5개 이상이 정확히 같은 경우에만 공동 농도에서 로그 AUC와 최고 농도 반응의 환자별 일치를 집계한다. 생존율은 종말점 계산에만 0–1로 제한한다. 공여자 안 여러 병변은 평균하고 약물별 환자 5명 이상을 요약한다. 반복 측정의 실제 배양 독립성은 공개 ID가 증명하는 범위로 해석한다.
- LICOB와 이름이 같은 제품은 연결 후보를 표시하고 분자 구조·lot 확인 단계에 넘긴다. 원본과 환자별 파일은 G1에 둔다. 이번 단계에서는 HCC의 정답을 읽거나 모델 성능을 채점하지 않는다.
