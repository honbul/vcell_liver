# LICOB·Wong 공통 21약물의 양방향 전이 결과

**21약물에서도 3D 학습의 양방향 개선 기준은 미통과였다.** 다른 연구의 3D RNA Ridge는 두 코호트 모두에서 약물 내 환자 감수성 Spearman이 음수였다. 2D 약물 평균을 제공하면 같은 3D RNA 신호를 쓰면서도 Wong의 NDCG@5가 .539→.739로 오를 수 있었다. 이때 약물 내 감수성 상관은 불변이었다. [사전 명세](HCC_3D_21DRUG_PROTOCOL.md) · [전체 원표](hcc_3d_21drug_score.json)

LICOB 29명·34 PDO에 714개 지역 관측과 609개 환자·약물 값, Wong 10명에 210개 값이 있었다. 모든 환자는 21약물을 측정했다. 각 방향은 다른 연구만 3D 적합에 사용했다. 2D 비교군은 정정 70약물 학습표에 동일한 17,209유전자 축을 적용해 다시 적합했다. 두 코호트는 과거 채점한 자료이고 이번 결과는 연구 간 전이의 기술 평가다. [입력 영수증](hcc_3d_21drug_inputs_receipt.json)

## 약물 평균과 감수성 신호

- 평가 연구의 평균 약물 순위와 2D 약물 평균의 Spearman은 LICOB .519, Wong .618이었다. 반대 연구의 3D 약물 평균은 양쪽에서 .390이었다.
- 3D Ridge의 환자별 편차를 보존하고 2D 평균을 주면 Wong NDCG@5가 +.199 [+.073, +.300]였다. LICOB에서는 +.036 [−.012, +.081]이었다. 양방향에서 약물 내 Spearman과 Pearson은 각각 동일했다. 이 변화는 약물의 상대 위치와 배율만 바꾼 결과다.
- 다른 연구의 3D 평균에 기존 2D 편차를 더하면 LICOB NDCG@5가 .634→.681, Wong은 .734→.650이었다. 두 변화의 짝지은 95% 구간은 각각 [−.009, +.099], [−.160, +.006]이었다. 연구별 약물 순위는 3D 평균을 옮기는 것만으로 안정화되지 않았다.
