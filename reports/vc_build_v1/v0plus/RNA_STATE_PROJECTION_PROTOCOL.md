# 세포 상태 및 짝지은 배양 이동 방향 제거

같은 환자의 종양–오가노이드 RNA 이동과 사전에 지정한 세포 상태를 제거하면 간암 약물 감수성의 2D→3D 전이가 개선되는지 시험한다. GDSC2·CTRPv2·PRISM 정정 65,678행을 적합하고, 기존의 계통 3-fold·스크린 보류 세 조건·pooled, LIMORE 독립 50계통·68약물과 LICOB 38공여자·53약물을 유지한다. 두 외부 코호트에 이전 채점 이력이 있다. 이전 Wong 종양→PDO 변환은 평가 RNA만 바꾼 기술 비교였다. 이 회차에서는 학습과 평가 양쪽에 같은 사영을 적용한다. [선행 Wong 비교](WONG_PAIRED_RNA_ADAPTER_RESULTS.md) · [기존 RNA 분포 보정](GENE_CALIBRATION_RESULTS.md)

- Wong S6의 10개 HCC 원발 종양과 같은 환자 PDO의 공개 기저 TPM을 사용한다. 이전에 등록한 10개 모델 ID, RNA 영수증, 워크북 해시를 확인한다. Wong의 약물반응은 읽지 않는다. 학습과 평가 RNA는 기존 등록 유전자 전체에서 샘플 내 평균 순위를 구한다. Wong의 쌍은 양쪽에서 제공하는 공통 유전자에서 순위를 만들고, Wong에 없는 유전자의 짝 차이에는 0을 대입한다. 평가 RNA의 모집단 통계나 반응은 사영 적합에 전달하지 않는다. [Wong 원논문](https://doi.org/10.1016/j.jhepr.2025.101426)
- 등록 Hallmark E2F targets, G2M checkpoint, mitotic spindle, epithelial–mesenchymal transition, hypoxia의 서명 벡터를 정규직교화한다. 표준 대조인 상태 제거에는 이 다섯 축을 쓴다. 주 후보에서는 Wong의 PDO−조직 순위 차이행렬에서 상태 방향을 먼저 제거한다. 평균 방향과 그 평균을 제거한 차이의 상위 우특이벡터 세 개를 추가한다. 음성 대조는 고정 seed 69403의 순열 후 PDO를 한 칸 회전해 같은 타입의 조직과 다른 공여자의 PDO로 같은 절차를 실행한다. 네 차원 대조의 차이 평균은 짝을 바꿔도 같다.
- 각 순위 벡터에서 학습 RNA의 평균을 뺀 뒤 정규직교 사영을 제거한다. 이 결과로 기존 구조 커널의 유전자, 경로·TF, RNA에서 학습하는 Chronos와 유전체 보조 블록을 각각 다시 적합한다. 약물 평균과 원 학습 표적·가중, 약물 커널, 벌점 4는 그대로 둔다. 기존 구조 커널, 약물별 Ridge 및 외부에 등록한 공개 비교군을 같은 행에 둔다.
- 사전 주 후보는 실제 짝과 상태 축을 제거한 모델이다. 주 후보가 기존 구조 커널, 상태 제거 및 다른 공여자 짝 대조 대비 약물 내 Spearman·Pearson의 공여자×약물 짝지은 95% 하한이 0 초과하고, 계통 내 Spearman·NDCG@5 하한이 −.005 초과이면 해당 조건을 통과한다. 세 보류 스크린 중 두 곳 이상과 두 외부 코호트 각각의 통과가 승격 조건이다. Precision@5, 간암 TKI와 주요 기전군을 함께 보고한다. RNA 평균 이동의 상대 크기와 Wong 짝 차이에서 제거된 비율도 기록한다. Wong 짝 차이 감소는 축 적합에 사용한 두 RNA에 대한 기술 진단이다.
- 보류 실측을 전달하기 전에 각 예측을 SHA-256으로 동결한다. 별도 작업에서 채점한다. 외부 원본, 모델과 개별 예측은 G1에 둔다.
