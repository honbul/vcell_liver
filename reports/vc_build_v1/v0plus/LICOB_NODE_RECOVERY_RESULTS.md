# LICOB의 미채점 성인 HCC 공여자 9명 확인

손상된 공개 NODE 파일에서 손상 지점 앞의 실제 압축 바이트를 복원해 완결된 RNA 14,799행·65표본을 확보했다. 이 가운데 정정 2D 학습 RNA와 공통인 유전자는 7,123개다. 기존 저자 RNA와 겹치는 50개 샘플에서 같은 7,123유전자의 샘플 내 Spearman 중앙값은 .99814, 5백분위수는 .99677이었다. 두 수치는 반응 없이 비교했다. 전체 XLSX의 배포 MD5와 RNA 워크시트의 CRC 불일치는 여전히 남아 있다. 기존 원자료 감사는 43개 HCC 모델의 S6 숫자 존재 여부만 집계했다. 앞선 LICOB 모델 채점에 들어간 공여자는 29명이며 새 9명과 겹치지 않는다. 이번 등록은 S6 표본 ID·약물 헤더만 사용했다. 새 9명의 주 확인은 연령·환자 주석과 정확한 단일 약물 구조 연결을 확인해 고정했다. 여전히 전체 RNA 워크시트를 인증할 수 없고, 복구 축은 기존 저자 패키지 교집합보다 좁다. 원래 HCC 44개 표본 중 나머지 한 모델은 공식 S6 지원이 없다. 등록한 53약물은 학습 코어와 exact parent가 일치하는 범위다. DROMA의 LICOB 등록은 확인했으며 Zenodo 배포 파일은 접근 제한이다. [최초 LICOB 성적](LICOB_AUTHOR_RESULTS.md) · [DROMA 배포 접근 상태](https://zenodo.org/records/18503188)
