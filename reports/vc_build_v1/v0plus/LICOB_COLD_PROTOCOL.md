# LICOB 76약물 구조 재등록과 미관측 약물 전이

기존 LICOB 55약물과 실제 76약물의 차이를 감사하다 제조사 표의 입체 정보 누락을 확인했다. S5의 제품 번호와 CAS를 기준으로 PubChem 구조를 재조회하고 기존 결합성이 유지되는지를 먼저 검사한다. Gemcitabine HCl, ceralasertib, larotrectinib은 입체 이성질체를 바로잡으면 2D 학습 표와 연결된다. 과거 동일 기록을 사용한 AT-406은 공식 CAS의 정확한 입체 구조와 소스의 입체 미정 기록이 다르다. 소스의 AT-406 관련 행은 새 실험에서 제외한다. 역사적 결과를 새 exact-parent 검증으로 인용하지 않는다. [Gemcitabine 제조사](https://www.selleckchem.com/coa/gemcitabine-hydrochloride-coa-S114908.html) · [Ceralasertib 제조사](https://www.selleckchem.com/products/ceralasertib-azd6738-atr-inhibitor.html) · [Larotrectinib sulfate 제조사](https://www.selleckchem.com/datasheet/loxo-101-S796004-DataSheet.html) · [AT-406 PubChem](https://pubchem.ncbi.nlm.nih.gov/compound/25022340)

- 43개 HCC 오가노이드에서 76약물 전부를 예측한다. 주 결과는 이 중 성인 38명에게서 공여자 단위로 낸다. 동일키 지원 현황과 수정 이전·이후를 함께 남기고, 제조사 및 PubChem 증거를 해시로 확인한 76개 화학 카탈로그를 기록한다. 같은 연결성을 갖는 다른 이성질체 기록은 신규 약물의 학습에서 제거한다. 입체가 일부 불명인 미지원 약물의 성적은 전수 지원용 기술값에 남기고 주 미관측 비교는 입체가 지정된 약물만 사용한다. 기존 기록이 서로 맞더라도 입체 위치가 미정이거나 라세미인 약물은 따로 표시한다. PubChem에서 가져오는 자료는 CAS의 화합물 메타데이터에 한정한다. [이전 외부 평가와 등록 범위](LICOB_WIDE_RNA_RESULTS.md)
- 2D 정정 코어와 기존 CTRPv2·PRISM/GDSC2 확장표에서 학습한다. 데이터마다 훈련 안의 공통 약물·세포에만 양의 척도 보정을 맞춘다. 학습 세포의 기저 RNA와 경로·TF, Chronos·변이/CNV 추정 특징을 쓰고 같은 ECFP·약물 표적 커널을 적용한다. 약물 평균은 학습에서 직접 구한다. 미측정 약물 앵커는 가장 유사한 5약물의 Tanimoto 네제곱 가중 평균이다. 첫 대조는 이 앵커 단독, 두 번째는 같은 가중으로 각 이웃의 독립 적합 RNA 반응을 평균한 모형이다. 전체 평균도 기술값으로 낸다. 공동 커널은 화학 또는 화학+표적 두 가지다. 주 후보는 화학+표적 방법에서 관측 행의 약물·세포 두 가산항을 가중 사영으로 제거한 잔차만 학습하고 같은 앵커를 합친다. 벌점 4와 두 가지 커널 가중은 코드에 고정한다.
- 소스 개발은 정정 코어 약물을 scaffold군별로 3분할하고, 세포 역시 계통별로 3분할한다. 각 fold에서 보류 scaffold와 같은 확장 약물, 보류 약물과 같은 connectivity, 보류 계통을 모두 학습에서 빼고 양쪽이 동시에 보류된 코어 관측을 assay별 채점한다. 3개 assay 중 최소 2개에서 주 후보의 두 약물 내 상관의 짝지은 95% 하한이 두 주 대조 각각 대비 0보다 크고, 환자/계통 내 Spearman·NDCG@5 하한이 각각 −.005보다 높아야 한다.
- 외부 주 판정은 한 번의 동결·별도 채점에서 LICOB의 완전 입체 지정 미지원 약물에 적용한다. 같은 대조와 수치 기준을 쓴다. 전체 76, 소스 지원 약물, 미지원 전수 및 새로 소스와 연결된 약물의 기술값을 분리한다. 약물군, 최근접 구조 유사도, 전체 순위와 Precision@5를 함께 낸다. 보류 정답은 원 출판 S6의 AUC다. 이미 평가한 공여자가 포함되므로 기존 독립 공여자 판정을 갱신하지 않는다. 이 회차만으로 새 오프라인 배포 모델을 승격하지 않는다.
