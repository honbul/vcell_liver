# LICOB·Wong의 소수 환자 보정 결과

**현지 4명 반응으로 약물 평균을 보정하면 새 환자의 상위 약물 선별은 개선됐다.** 축소 약물 평균의 NDCG@5는 LICOB .603→.705, Wong .694→.807이었다. 2D 예측에 RNA 잔차 모델을 더한 주 후보는 동일한 4명 자료를 받은 사전 비교군을 두 축에서 함께 넘지 못했다. **두 연구 모두 주 기준 미통과다.** 이 회차는 기존 공개 자료에서 환자 단위로 다시 보류한 개발 평가다. [사전 명세](HCC_3D_FEWSHOT_PROTOCOL.md) · [채점 원표](hcc_3d_fewshot_score.json)

LICOB 29명과 Wong 10명의 공통 21약물을 5회 2-fold로 보류했다. 한 환자의 모든 지역은 같은 fold에 속한다. 예산별 결과는 각 반복에서 그 예산의 환자만 사용한 예측의 점수를 평균한 것이다. 감수성 지표는 같은 fold의 보류 환자끼리 비교했다. 2D 비교군도 같은 fold에서 다시 집계했으므로 감수성 수치는 이전 전체 코호트의 상관과 다를 수 있다. [분할 요약 및 원본 해시](hcc_3d_fewshot_split_receipt.json)
