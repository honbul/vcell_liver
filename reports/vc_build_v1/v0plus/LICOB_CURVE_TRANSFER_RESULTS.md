# 농도별 2D 곡선 학습의 LICOB 전이 결과

**범위 제한 IC50의 공동 기준은 미통과였다.** 곡선 공동 학습은 약물 평균보다 같은 약물의 환자별 감수성을 더 잘 구별했으나, 환자별 상위 5개 선별 성능은 낮았다. 같은 농도별 측정으로 직접 적합한 IC50 모델 대비 감수성 개선 구간에는 0이 포함됐다. [채점 전 명세](LICOB_CURVE_TRANSFER_PROTOCOL.md) · [채점 원표](licob_curve_transfer_score.json)

LICOB 공개 S5의 전체 농도 구간을 덮은 2D 곡선은 CTRPv2의 **38약물·23,482개 세포–약물 관측**이며 GDSC2와 PRISM20Q2의 지원은 각각 0이었다. 적격 약물은 성인 38명의 HCC 오가노이드 43개 모두에 등록했다. 한 사람의 여러 오가노이드는 평균해 종말점당 공여자–약물 실측 1,444개를 채점했다. 전수 S6–S8을 이전에 사용한 이력이 있어 이번 비교는 사후 기술 평가다. [기존 종말점 결과](LICOB_DOSE_ENDPOINT_RESULTS.md) · [공개 연구와 실험 방법](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949980/)

Emax에서 공동 학습의 약물 평균 대비 Spearman 차이는 약물 내 +.110 [95% .013, .202], 공여자 내 +.060 [.040, .080]이었다. NDCG@5는 +.016 [.0004, .031], Precision@5는 +.053 [.016, .089]이었다. 동일 행의 Emax 직접 적합 대비 약물 내 Spearman 차이 +.022의 구간은 [−.019, .067]이었다. Emax는 보조 기술값이며 여기서 농도별 공동 학습의 독립 이득과 배포 승격을 판정할 수 없다.

세 HCC TKI의 약물 내 Spearman은 직접 적합→공동 학습에서 IC50 −.079→.037, AUC .186→.150, Emax .348→.327이었다. 기전군별 전체 결과는 원표에 있고 표본이 적은 층은 기술 통계다. LICOB 원논문 Fig. S4C는 sorafenib 생물학적 반복에서 AUC 순위 상관 `R = .92`를 표기했다. 이 수치는 여러 간 종양 조직형을 포함한 31개 오가노이드의 한 약물에 해당한다. 이번 38약물·성인 HCC의 반복 상한은 별도로 확인해야 한다.
