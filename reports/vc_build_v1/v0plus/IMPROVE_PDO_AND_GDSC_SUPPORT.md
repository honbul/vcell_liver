# IMPROVE 공개 오가노이드와 GDSC2 약물 식별 감사

Zhu 등의 공개 자료 v1.0.0에는 대장암·두경부암·육종 오가노이드 네 스크린과 세포주 데이터가 있다. 자료의 공개 라이선스는 CC BY 4.0, 동반 코드 라이선스는 MIT다. 이 오가노이드 자료의 역할은 HCC 외부 채점 전 2D→3D 모델 개발이다. 원 발표의 대장암·두경부암·육종만 포함한다. [저자 데이터 DOI](https://doi.org/10.5281/zenodo.22920452) · [저자 자료 기술](https://arxiv.org/abs/2611.15769v1) · [저자 코드](https://github.com/zhuyitan/PDO_DRP_Analysis)

G1의 공식 전체 ZIP URL 응답은 HTTP 403이었다. 워크스테이션에서 같은 공개 URL의 ZIP 중앙 디렉터리와 필요한 멤버 범위를 받을 수 있었다. 필요한 5개 멤버를 공식 ZIP과 같은 CRC-32인지 확인해 다시 압축한 뒤 G1에 올렸다. 선택 아카이브 SHA-256은 `2399d48497557bc6f19eed9696d608112e1269ad248c868ec9c7420afcf3da3f`이다. Zenodo에는 전체 861,243,889바이트와 MD5가 게시되어 있고 여기서는 선택 멤버만 검증했다. [선택 멤버 SHA-256](improve_selected_members.json)

## GDSC2 화합물 지원

IMPROVE의 `drug_info.tsv`에 원본 `GDSC.<DRUG_ID>`와 구조가 들어 있어 GDSC 8.5 공식 약물 ID와 대조했다. GDSC2 실측의 295개 native ID 중 201개에 저자 카탈로그 행이 있었다. 공식 약물명 또는 공식 동의어가 맞고 구조가 한 parent로 일치한 후보는 197개였다. 기존 42개 ID 중 두 자료가 함께 가진 것은 40개이며 그중 19개에서 exact parent가 달랐다. 18개는 같은 연결성에서 IMPROVE 카탈로그의 입체 정보가 빠진 사례이고 하나는 연결성도 달랐다.

기존 검증 구조는 보존했다. 신규 후보는 미지정 입체 요소가 있는 ID 60개를 제외했고, 같은 GDSC2 native ID 또는 parent가 기존 GDSC2 코어에 있는 것을 건너뛰었다. 원래 세포·계통 보호 조건과 GDSC2 단일 약물의 농도 프로토콜 선정 규칙을 적용해 아래 테이블을 만들었다. 구조 근거는 저자 카탈로그와 공식 ID·이름의 결합이며, 기존 CTRPv2·PRISM 부모 구조와도 정확히 일치하는 하위 지원을 따로 기록했다. [공식 GDSC2 설명](https://depmap.sanger.ac.uk/documentation/datasets/drug-sensitivity/) · [보수적 등록 영수증](improve_gdsc_registry_receipt.json)

## 독립 암종의 3D 개발 자료

| 연구 | PDO 모델 | 학습 지지 전 유효 AUC 행 | 정정 68약물과 일치 | 1,129약물과 일치 |

| IMPROVE 1 | 4 | 384 | 16약물·64행 | 39약물·156행 |
| IMPROVE 2 | 5 | 195 | 9약물·45행 | 16약물·80행 |

57개 PDO는 대장암 36개, 두경부암 20개, 육종 1개다. 동일 PDO 5개가 서로 다른 스크린에 포함되므로 연구별 모델 수에 중복이 있다. 공개 Baseline RNA의 Ensembl·Entrez·symbol 헤더와 학습 발현의 유전자명을 교차 확인해 공통 유전자 17,830개를 등록했다. 공개 AUC의 공식 표와 연결하고 함께 실험된 세포주 480행은 PDO 평가에서 분리했다. 식별 및 화학 확인에서 구조 미매칭 33행과 한 PDO·스크린에서 같은 canonical parent로 충돌한 28행을 제외했다. [PDO 수치 영수증](improve_pdo_development_receipt.json)

`33170`에서 선택 ZIP, RNA, AUC, 구조 등록을 마쳤다. 네 스크린의 공개 비간암 자료는 이후 3D 적응 방법을 개발하는 입력이다. LIMORE와 LICOB를 포함한 HCC 확인 성적은 이번 평가의 분모에 들어가지 않는다. [작업 원장](RUN_LEDGER.tsv)
