# 스크린별 공통 감수성과 약물 고유 반응의 분리 적합

같은 약물에서 환자를 구분하는 상관에는 전반적으로 약물에 민감한 환자 효과도 포함된다. 약물 고유 반응이 외부 전이의 병목인지 검증한다. DrugDis의 관측 지지 위 가산·상호작용 분해를 참고하되, 정정한 GDSC2·CTRPv2·PRISM 학습과 기존 구조 커널의 설정으로 같은 지지에서 비교한다. [DrugDis 방법](https://boom5426.github.io/DrugDis/) · [이전 2D·3D 결과](STEP4_EXTERNAL_RESULTS.md)

- 각 fit 스크린에서 관측한 세포주×약물에만 이전 소스 균형 가중을 준다. 고정 약물 앵커의 기존 residual 행렬을 모델 단위 공통 감수성, 약물 단위 가산 효과, 양쪽 가중합이 0인 상호작용으로 정확히 분해한다. 결측 쌍은 분해와 손실에서 가중이 0이다. 연결 성분별 세포 가산항의 가중 평균은 0으로 고정한다. 약물별 기준 위치와 소스 척도 보정은 기존 정정 커널과 같다.
- 같은 RNA 순위·경로/TF·Chronos 및 driver의 RNA 보조 예측 특징을 제공한다. 세포별 공통 감수성은 1차원 반응을, 상호작용은 기존 표적/ECFP 약물 커널을 사용해 각각 적합한다. 두 커널의 벌점은 기존 4로 고정한다. RNA와 약물 Gram은 학습 표본에서 중심화하며 보류 RNA·정답의 집단 통계를 사용하지 않는다. 공통 감수성만, 약물 고유 상호작용만, 둘을 더한 주 후보, 주 후보와 기존 Ridge의 50:50 결합을 고정한다.
- 소스 개발은 기존 3계통 fold와 3개의 스크린 동시 보류 및 공동 학습의 12경우를 그대로 사용한다. 정정 코어의 구조 커널·Ridge·약물 평균 동결 예측을 같은 지지에 붙인다. 최소 두 보류 스크린에서 주 후보의 구조 커널 대비 약물 내 Spearman·Pearson의 짝지은 95% 하한이 양수, 계통 내 Spearman·NDCG@5의 하한은 각각 `−.005`보다 크고 두 점 추정은 약물 평균 이상이면 승격으로 기록한다.
- 같은 설정을 훈련원과 겹치지 않는 LIMORE 50계통·68약물 및 LICOB 43 PDO·38성인 공여자·53약물에 적용한다. LICOB의 과거 확인 9명도 기술 하위집단으로 포함한다. 모두 기존 채점 이력이 있다. 새 독립 확인으로 분류하지 않는다. 기존 구조 커널·Ridge·약물 평균·CellHit·CODE-AE·Velodrome·V0+의 정정 동결본을 동일 행에 붙인다. 대조별 사전 기준은 주 후보의 약물별 상호작용 PCC, 약물 내 Spearman·Pearson의 개선 95% 하한 `>0`, 환자 내 Spearman·NDCG@5 하한 `>−.005`다. 구조 커널·Ridge·CellHit 대비 모두 넘어야 하나의 코호트에서 통과한다. 학습원과 기존 외부 점수는 별도 이력으로 보존한다.
- 일반화 점수는 원래 공동 지표를 유지한다. 별도 기술 표에서 약물 평균 성분, 시료 전반 민감도 및 약물×시료 상호작용 PCC, 상호작용 진폭과 원 척도 R²를 낸다. 상호작용 진폭이 실측의 `10⁻⁸` 이하면 PCC는 정의하지 않는다. 원 척도 R²는 기준점과 단위에 민감하므로 기술값으로 보고한다. 분해는 학습과 별개로 각 평가 fold/공여자에서 공통 관측 지지를 고정한 뒤 수행한다. 완전 외부 패널의 PCC 차이는 공여자·약물을 짝지어 2,400회 교차 재표집한다. HCC TKI, 키나아제·HDAC, 비특이 세포독성 하위군도 보고한다.
- GPU 예측 단계는 정답 경로 없이 실행하며 각 분할·외부 파일을 해시로 동결한다. 소스 채점은 12개 비교 파일을, 외부 채점은 두 주요 평가 파일을 검증한 뒤 별도 실행한다. 기존 배포 CLI의 후보 교체는 새 승격 근거가 생겼을 때만 검토한다.
