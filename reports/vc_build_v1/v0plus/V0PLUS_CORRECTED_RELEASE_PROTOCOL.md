# 정정 70약물 V0+ 오프라인 패키지 재현

기존 배포는 CTRPv2 두 약물의 혼합 처리 입력을 포함했다. 단일 약물로 정정하고 apatinib·ivosidenib을 추가한 Yang 실험의 고정 70약물 소스 표에서 V0+ inductive, 약물별 Ridge, 약물 평균을 재적합한다. 배포 기본값은 이전 CLI와 같이 V0+다. 학습은 같은 예측 설정과 공통 유전자 축을 사용한다. 패키지 재현 작업에서는 평가 AUC를 읽지 않는다. 기존 외부 미통과 판정과 70약물 전체의 외부 검증 범위 차이를 모델 카드에 표시한다. [기존 패키지 이력](V0PLUS_MODEL_CARD.md) · [정정 Yang 성적](YANG_HCC_EXTERNAL_RESULTS.md)

- 모델 체크포인트를 저장하기 전에 기존 Yang 동결 예측과 방법별 1,115개 RNA·약물의 일대일 최대 절대 차이를 검사한다. 허용치는 Ridge·약물 평균 `1e-9`, V0+ `5e-4`다. 세 체크포인트와 70개 exact parent 등록부를 해시로 봉인한다.
- 독립 CPU 작업에서 실제 RNA 세 샘플로 전체 패널을 실행한다. 각 방법의 210개 예측과, 같은 입력이 기존 Yang 동결본에 있던 15개 쌍의 수치를 확인한다. GPU 원본과 CPU의 V0+ 최대 차이는 `5e-4` 이하여야 한다. 별도 입력으로 미등록 화합물과 영(0) 발현 프로필의 상태 코드를 확인한다.
- 기존 `vc_build.v0plus_cli predict`를 사용한다. 등록부와 모델 파일은 G1의 한 경로에서 함께 복사할 수 있다. Git에는 원자료·가중치와 개별 예측을 제외하고 코드와 작은 영수증만 보존한다.
