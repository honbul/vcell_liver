# 비간암 공개 PDO의 연구 간 2D→3D 전이 성적

**3D 잔차 적응은 사전 승격 기준 미통과다.** 가장 큰 보류 연구인 Pilot 1에서 각 오가노이드의 약물 순위는 크게 개선됐다. 같은 약물에 대한 오가노이드 간 감수성 순위는 낮아졌다. 평균 보정만으로 순위 개선의 대부분을 얻었다. [사전 명세](PDO_TRANSFER_PROTOCOL.md) · [연구별 원표 및 해시](pdo_transfer_score.json)

## 네 연구의 보류 결과

| 보류 연구 | PDO·약물·행 | 약물 내 Spearman 2D → 3D 적응 | 약물 내 Pearson | PDO 내 Spearman | NDCG@5 | Precision@5 |
|---|---|---:|---:|---:|---:|---:|
| IMPROVE 1 | 4·39·156 | −.497 → −.590 | −.471 → −.600 | .569 → .807 | .887 → .944 | .600 → .700 |
| IMPROVE 2 | 5·16·80 | −.414 → −.542 | −.484 → −.641 | .495 → .725 | .851 → .942 | .560 → .840 |
| IMPROVE 3 | 10·39·390 | .090 → .052 | .130 → .115 | .577 → .692 | .921 → .941 | .760 → .760 |
| Pilot 1 | 47·17·618 | .192 → .135 | .172 → .114 | .312 → .699 | .703 → .883 | .506 → .774 |

각 열은 같은 등록 행에서 2D 구조 커널과 3D 잔차 적응의 비교다. IMPROVE 1의 약물 내 점수는 4모델의 기술값이다. IMPROVE 2의 작은 재표집에서는 일부 약물·모델 조합이 변동을 잃어 구간 산출에서 제외됐다. Pilot 1에서 NDCG@5 차이 +.180의 짝지은 95% 구간은 [+.157, +.203], PDO 내 Spearman +.386은 [+.352, +.422]였다. 약물 내 Spearman −.057과 Pearson −.058의 구간은 각각 [−.154, +.029], [−.144, +.020]이었다. IMPROVE 3의 NDCG@5 차이는 +.019였으나 구간 하한 −.034가 사전 비열등 한계 −.01에 미달했다.

Pilot 1에서 적합 PDO의 직접 반응이 있는 11약물·383행만 모으면, 약물 내 Spearman .236 → .148과 NDCG@5 .768 → .857이 나왔다. 전체 지지와 같은 방향이다. 3D 보정을 받을 수 없는 나머지 6약물은 2D 예측이 적용됐다. [전체·직접 지지 표](pdo_transfer_score.json)

## 같은 3D 약물 평균을 제공한 비교

|---|---:|---:|---:|---:|---:|
| 2D 약물 평균 | .000 | .000 | .425 | .763 | .630 |
| 3D 약물 평균 | .000 | .000 | .691 | .881 | .762 |

2D 구조 커널에 3D 앵커만 더했을 때 NDCG@5 차이는 +.181 [+.157, +.204]였다. 약물마다 상수만 바뀌므로 각 약물의 감수성 순위와 상관은 그대로였다. 공정성 보강에서 동일한 앵커의 Ridge 대비 구조 커널의 NDCG@5 차이 +.0010 [−.0038, +.0056]과 약물 내 Spearman 차이 +.051 [−.114, +.198]은 0을 포함했다. 구조 커널의 결과를 3D 약물 평균과 비교하면 약물 내 Spearman 차이 +.192 [+.009, +.358]과 Pearson 차이 +.172 [+.001, +.336]였으며 NDCG@5 차이 +.0026 [−.0047, +.0113]은 0을 포함했다. 이는 비간암 사후 개발 비교다. ## 같은 PDO의 연구 간 실측 일치

| 같은 약물·PDO의 연구 쌍 | 모델 | 약물 | 실측 쌍 | 약물 내 Spearman | PDO 내 Spearman |

| IMPROVE 1 ↔ 3 | 4 | 95 | 380 | .059 | .802 |
| IMPROVE 2 ↔ 3 | 5 | 39 | 195 | −.049 | .732 |

연구 간에 같은 PDO를 대조할 수 있는 범위에서도 모델별 약물 순위와 약물별 모델 순위의 일치 수준이 달랐다. 약물 내 수치는 3모델 이상만 넣은 기술 통계다. 이 비교는 생물 또는 기술 반복의 정밀도 상한을 추정하는 실험과 구분한다. Pilot 1은 나머지 세 연구와 겹치는 PDO가 없다. [실측 일치 원표](pdo_repeat_audit.json)

Slurm `33180`에서 PDO 실측 없이 2D 예측을 동결했고, `33181`의 네 GPU 작업은 각 보류 연구와 같은 PDO가 나온 다른 연구의 실측을 적합에서 제거했다. `33182`에서 별도 채점했다. 새 앵커 공정 비교 `33187`은 원래 해시를 검증해 새 예측을 동결한 뒤 분리 채점했고, 일치도는 `33186`에서 계산했다. [작업 원장](RUN_LEDGER.tsv)
