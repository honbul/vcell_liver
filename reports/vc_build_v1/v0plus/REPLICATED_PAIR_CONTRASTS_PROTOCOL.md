# 독립 스크린에서 방향이 일치한 계통 쌍의 감수성 학습

세포주 스크린의 이식 가능한 환자별 약물 감수성 신호를 늘리기 위해, 동일 약물에서 두 실험의 감수성 순서를 공유하는 계통 쌍을 연속 회귀의 추가 제약으로 학습한다. 정정 GDSC2·CTRPv2·PRISM20Q2 65,678행, 공개 보조 특징, 기존 구조 커널을 사용한다. 계통 3-fold와 스크린 보류 3조건, 세 소스 pooled를 유지한다. LIMORE 50계통·68약물과 LICOB 38공여자·53약물은 앞선 평가에 사용한 외부 코호트의 기술 재검증이다. [원천 일치도 가중](ASSAY_CONSENSUS_RESULTS.md) · [공개 2D·3D 외부 성적](STEP4_EXTERNAL_RESULTS.md)

- 각 적합 약물과 스크린 쌍의 공통 exact cell 모델이 30개 이상일 때, 계통 그룹이 서로 다른 모델의 모든 쌍 중 최대 4,000개를 seed 90721로 균등 비복원 추출한다. 정정된 방향·보정 단위에서 공통 모델 내 각 스크린별 표준편차로 쌍의 실측 차이를 나눈다. 두 차이를 각각 ±2에서 자른 뒤 평균하고, 두 표준편차의 평균을 곱해 원 학습 잔차 단위의 추가 목표를 만든다.
- 주 후보는 두 스크린에서 차이 부호가 같고 각각의 표준화 차이 절댓값이 .15 이상인 쌍만 추가 손실에 넣는다. 대조는 같은 추출 쌍을 필터 없이 쓴다. 지원 약물마다 기존 관측의 총가중 × .35를 추가 쌍 제곱 손실에 부여하고, 지원 스크린 쌍과 그 안의 계통 쌍에 각각 동등 분배한다. 지원 없는 약물은 원래 점별 손실만 사용한다.
- 두 모델 모두 원래 모든 점별 관측, 기존 RNA·경로·ECFP·표적·Chronos·유전체 보조 특징, 약물 평균, 벌점 4를 유지한다. 학습 Gram의 최대값 대비 1e-7 이하 고유축을 제외한 특징에서 점별 손실과 쌍 손실의 정규방정식을 공액기울기로 푼다. 기존 동결 구조 커널, 약물 평균과 Ridge, 외부의 CellHit·CODE-AE·Velodrome·V0+를 동일 행에 둔다. 별도 확인 브랜치에서 같은 LIMORE 행으로 동결한 Pairwise Rank·Top-5와 ECFP4·경로 ElasticNet도 비교표에 포함한다. 해당 비교는 사후 공통 행 대조로 기록한다.
- 사전 판정은 스크린 보류 세 조건 중 두 곳 이상, 두 외부 코호트 모두에서 주 후보가 기존 구조 커널과 필터 없는 쌍 대조 대비 약물 내 Spearman·Pearson의 공여자·약물 짝지은 95% 하한을 각각 0 초과하고, 공여자 내 Spearman·NDCG@5의 하한을 각각 −.005 초과하는 것이다. 풍부한 다중 스크린 지원 약물과 지원 없는 약물, 공통 HCC TKI, 표적·키나아제와 비특이 세포독성, Precision@5를 함께 보고한다. 기존 2D 확인 비교군과의 차이는 별도 집계한다.
- 보류 스크린과 계통, 외부 코호트의 실측은 동결 이전에 학습이나 선택에 전달하지 않는다. G1 GPU 적합을 묶고 예측 SHA-256을 고정한 뒤 별도 채점한다. 원시 자료·가중치·개별 예측은 G1에 보관한다.
