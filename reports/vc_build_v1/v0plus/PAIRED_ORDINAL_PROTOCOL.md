# Matched cross-platform gene orders for HCC transfer

LIMORE, LICOB, Wong and Yang show large differences in exact expression ties. The earlier change in the RNA rank context moved drug rankings by different amounts across cohorts. Test a sample-level ordinal representation based on the relative expression of two genes from the same pathway or TF signature. An informative order can survive monotone changes in the expression scale and does not use values for genes outside the pair. Assay changes or quantization can still introduce reversals and ties. Use paired assays to select portable orders. [Input audit](INDEPENDENT_PDO_CALIBRATION_RESULTS.md) · [GEO and DepMap pairing registration](PAIRED_EXPRESSION_PROTOCOL.md)

Use LIMORE 50 lineages and LICOB 43 RNA profiles scored at 38 adult donor groups. Use exact previously matched drug and outcome rows, with earlier evaluation exposure recorded for both external cohorts. Reuse the registered 2D RNA-seq and GSE36133 RMA Affymetrix pairs, same Hallmark/PROGENy/DoRothEA signatures, and public Chronos/driver/CNV fit-only auxiliaries. Use the same shared RNA gene axis for every new condition. Score frozen wider-axis structure, drug mean, Ridge, two prior rank context models and the public external CellHit, CODE-AE, Velodrome and V0+ comparators on the same rows.
- In each available signature with at least 10 shared genes, sample at most 96 unordered pairs at seed 40121, in name order. Deduplicate the resulting pool. Encode order as sign(expression of the first gene − expression of the second gene), with ties equal to zero. Take the first available registered RNA assay pair per fit lineage, sorted by cell ID. Retain tissues with five or more paired fit lineages. Both signs must be observed in at least 10% of paired fit observations on both platforms. Mean-center each order within tissue only for feature selection. Use fit RNA-seq within-tissue variance quintiles, then select 200 pairs per quintile by highest paired-array order Pearson. Break ties by canonical pair order within each sorted variance bin. The sequence-only control chooses by sequence variance in those same bins. For the shuffled control rotate the permuted barcode indices once within each tissue at seed 40139, then use the resulting correlation with the sequence data. Both controls use the same eligibility filter and pair quota. Require at least 250 fit paired lineages and 1,000 eligible pairs with correct quota.
- Fit the ordinary rank-expression/pathway/TF/auxiliary kernel on the same common gene axis as a scope-matched control. Add a .35-weight trace-normalized linear/RBF order kernel and retain .65 of the ordinary kernel. For each selected order, scaling uses the corrected response-fit lineage data with standard deviation floor .25. Keep existing drug anchor, ECFP4, target and shared chemical geometry, and response penalty 4. Inference uses one sample independently. No query-pool feature scaling, selection or outcomes are used. Compare sign agreement and within-tissue order correlation on source-held paired RNA as a separate molecular diagnostic. Record counts, exact tie fractions and order list hashes.

Primary must achieve both within-drug Spearman and Pearson paired 95% lower bounds above zero and all within-sample Spearman, NDCG@5 and Precision@5 lower bounds above −.005 versus the registered controls and reference candidates. Require at least two held source assays and both external studies to pass. Use 800 crossed resamples for source and 1,000 for external.
