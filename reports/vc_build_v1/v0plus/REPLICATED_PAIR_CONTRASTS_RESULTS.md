# 원천 스크린에서 반복한 계통 간 반응 차이의 외부 전이

**두 스크린에서 같은 방향을 보인 계통 간 감수성 차이를 학습에 넣어도 LIMORE·LICOB 공동 기준은 미통과였다.** 같은 정정 학습표의 관측을 모두 유지하고, 계통 쌍의 실측 차이만 추가했다. 기존 구조 커널과 필터 없는 동일 추출 쌍을 대조했다. [사전 명세](REPLICATED_PAIR_CONTRASTS_PROTOCOL.md)

## 학습 지원

세 스크린을 모두 사용한 외부 적합에서 68약물 중 36개가 지원됐다. 추출한 183,403쌍 중 96,256쌍, 52.5%가 모든 방향·차이 기준을 충족했다. CTRPv2–GDSC2 111,403쌍 중 62,276쌍, CTRPv2–PRISM 48,000쌍 중 22,446쌍, GDSC2–PRISM 24,000쌍 중 11,534쌍이었다. 같은 모델과 계통이 여러 비교에 등장하므로 쌍 수는 독립 환자나 계통 수가 아니다. 기존 행의 손실은 두 후보에서 같고, 약물별 추가 손실의 총가중도 같았다.
