# VCB-01 약물 표적과 경로 활성의 외부 기술 비교

GDSC2·CTRPv2·PRISM20Q2의 정정 단일 약물 자료로 적합하고, 세 학습원과 계통·환자가 겹치지 않는 성인 HCC LIMORE 50계통·68약물·3,400행에서 평가한다. LIMORE는 OEP003191 또는 HRA004348 접근과 독립인 핵심 공개 2D 평가다. 이 코호트의 이전 평가 이력을 유지하고 이번 비교를 사후 기술 평가로 기록한다. [계통 감사](../data_function/VCB01_PUBLIC_CROSS_SUPPORT.md) · [기존 분자 특징 비교](MEASURED_DRIVER_RESULTS.md)

- 모든 새 조건에서 정정 약물 평균 anchor, 2,048비트 ECFP, 기저 RNA, 기존 경로·TF 표현, 표적 공유, 소스 보조 표현, 표적 RNA, 실측 HCC 코딩 변이·절대 CNA, 커널 벌점 4를 유지한다. 기존 `measured_genome`의 예측을 재현하고 허용 오차 `1e-5`를 초과하면 동결을 중단한다. 약물 평균, 약물별 Ridge, CellHit, CODE-AE, Velodrome, V0+ 및 기존 측정 유전체 비교군을 그대로 포함한다.
- 약물의 등록 표적과 유전자를 하나 이상 공유한 Hallmark 경로를 연결한다. 경로 연결을 만든 뒤 등록 약물 표적 전체를 해당 경로 활성 계산에서 제거한다. 나머지 RNA 유전자가 10개 이상인 경로의 샘플 내 평균 순위를 계산한다. 소스 평균과 표준편차 하한 `.05`로 변환하고 경로를 동일 가중 평균해 약물별 경로 활성 항을 만든다. `mapped_pathway`는 기존 실측 결합에 이 항 하나를 추가한다. `target_pathway`는 약물 표적 RNA와 이 경로 활성의 곱을 추가한다. 추가 항은 각각 fit 평균·표준편차 하한 `.05`로 표준화하고 약물별 내적 커널에 각각 `.10`을 부여한다. 대응이 없는 약물의 두 추가 항은 0이다.
- `shuffled_pathway_link`에서 경로 활성 주효과와 표적 RNA는 고정하고 곱에 쓰는 경로 연결만 교체한다. seed `54189`로 연결 약물을 정렬 뒤 순열하고, 경로 수의 오름차순으로 안정 정렬한 목록에서 이웃 약물의 연결을 한 칸 회전한다. 전체와 연결 약물의 지원을 따로 표시한다. 연결 약물이 20개 미만인 경우 하위집단 점수는 기술 지원 수만 보고한다.
- 주 지표는 전체 68약물의 약물 내 Spearman·Pearson이다. 기존 실측 결합, 경로 주효과만 쓴 조건, 교체 대조 각각 대비 두 지표의 공여자×약물 짝지은 95% 구간 하한이 모두 0을 넘으면 표적×경로의 추가 신호를 지지한다. 약물 평균 대비 두 주 지표와 계통 내 Spearman·NDCG@5의 짝지은 하한이 모두 0을 넘으면 공동 기준을 통과한다. 같은 관측에서 Ridge·CellHit와의 차이, Precision@5, 연결 지원의 기술 점수를 함께 표기한다.
- 입력과 기존 예측의 SHA-256을 대조하고 동일 비교 행의 새 예측을 동결한 뒤 별도 프로세스에서만 반응 파일을 연결한다. Git에는 코드, 명세, 동결 영수증, 집계 점수만 보관한다.
