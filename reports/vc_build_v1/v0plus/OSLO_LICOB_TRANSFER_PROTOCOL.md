# Oslo 3D 반응의 LICOB HCC 전이

공개 Oslo 대장암 간전이 PDO를 **3D 적합 자료**로 사용하고, 기등록 LICOB 성인 HCC 공여자에서 기존 2D 예측의 환자별 부분을 보완하는지 확인한다. LICOB는 과거 이미 채점했으므로 이 비교는 기술 평가다. LIMORE 50계통은 핵심 2D 외부 검증으로 따로 유지한다. [Oslo 감사와 내부 전이](OSLO_3D_CURVE_RESULTS.md) · [기존 LICOB 2D 평가](LICOB_COLD_RESULTS.md)

- 암종 간 약물 연결은 출판사의 일반 제품명·공급사 기록과 고정 CAS/PubChem 구조를 사용한다. 염을 제거한 전체 parent InChIKey가 고정 LICOB 키와 일치하고, 잠재 입체 표기가 완결되어야 한다. Erastin은 한 입체가 미지정되어 평가에서 제외한다. 이 등록은 화학 parent 수준이며 원래 공급 lot나 조제 형태는 보증하지 않는다. [화학 출처 표](oslo_licob_chemistry.tsv)
- Oslo에서 native AUC는 각 곡선의 실측 로그 농도 구간에서 0–1 제한 생존율을 적분하고 폭으로 나눈 뒤 부호를 뒤집는다. S6와 동일 물리 범위를 갖는다고 가정하지 않는다. 다른 라이브러리와 제품의 반응 범위를 합치기 전에 각각 공여자 균등 평균과 표준편차로 표준화하며 표준편차 하한은 .05다. 같은 PDO의 반복 곡선은 중앙값을 쓴다.
- 기존 검증과 같은 RNA 순위 커널에 Oslo 표준화 반응을 적합한다. 경로·TF를 추가한 커널은 별도 절제 조건이다. 약물별 Ridge도 같은 RNA·반응에서 비교한다. 보류 표현은 단일 표본에서 계산한다. Oslo에서 예측한 편차는 기등록 2D 학습 반응의 약물별 소스 균등 표준편차로 환산한다. 2D 화학 평균을 모든 추가 방법의 공통 앵커로 고정한다. 주 후보는 기존 2D 상호작용의 편차에 Oslo RNA 커널 편차의 .5배를 더한다. 기존 2D 상호작용, 2D 이웃 전이, 화학 평균과 같은 관측에 비교한다.
- **주 판정**은 두 자료에 반응 및 구조 지지가 있는 10약물 이상과 성인 공여자 20명 이상을 요구한다. 주 후보가 세 대조 각각 대비 약물 내 Spearman·Pearson의 95% 하한이 0 초과이고, 환자 내 Spearman·NDCG@5·Precision@5의 95% 하한은 −.005 초과여야 한다. 76개 전체의 기술 비교도 포함한다. 약물 등록이 없는 3D 편차는 0이며 2D 동결 예측을 그대로 쓴다.
- Emax는 실제 투약 농도가 LICOB 최고 농도를 포함하는 Oslo 제품만 사용한다. 이 조건은 이번 회차에 ceralasertib·panobinostat·regorafenib 세 후보로 제한된다. 로그 농도에서 최고점을 내부 보간한 상대 생존율을 예측하며, 기존 2D의 Emax 직접 적합과 비교한다. 약물 내 지표는 기술값이며 표의 세 약물에서는 Top-5 선별을 판정에 쓰지 않는다. Emax와 무관한 S7 IC50은 이번 목표에서 사용하지 않는다.

기존 입력·예측 해시와 공급 구조의 증거를 먼저 검증하고, 새 모델 예측은 별도 해시로 동결한다. 새 적합에는 Oslo 반응과 등록 소스 및 발현·농도 메타데이터만 전달한다. S6·S8 공개 정답은 별도 채점 작업에서 사용한다.

## 채점 전 Emax 지지 확인

최초 적합에서 2D 농도 지원이 없어 ceralasertib의 동결 Emax 비교군을 만들 수 없었다. 해당 작업은 예측 동결 전에 중단됐다. 3약물의 Oslo Emax 적합은 유지한다. 2D 비교군과 합치는 범위는 panobinostat·regorafenib 2약물이고, ceralasertib은 Oslo 적합만 별도의 약물 내 기술값으로 기록한다. 주 AUC의 지원과 판정은 기존 명세를 적용한다.
