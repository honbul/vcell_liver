# 2D와 3D 간암 연구에서 집단 약물 순서의 일치

기존 RNA 모델은 2D LIMORE보다 3D LICOB에서 약물 내 개인차를 약하게 예측했다. 이 분석은 별개의 문제인 **같은 21약물의 코호트 평균 순서**를 측정한다. LIMORE에서 성인 HCC 50계통, LICOB에서 성인 HCC 38공여자, Wong에서 성인 HCC 10공여자를 사용한다. 모두 프로젝트의 기존 채점 이력이 있다. 공통 약물은 LICOB·Wong의 21약물 등록표에 있는 전체 parent InChIKey로 고정한다. LIMORE의 일부 약물에서 키가 일치하지 않으면 자동으로 부분집합을 사용하지 않고 실패한다. LICOB의 여러 PDO는 같은 공여자 안에서 먼저 평균한다. LIMORE의 연속 감수성, LICOB의 −생존 AUC, Wong의 +성장억제 AUC를 각각 높은 값이 높은 감수성을 뜻하도록 사용한다. 원 단위가 다른 값을 연구 사이에서 더하지 않는다.

- LIMORE↔LICOB와 LIMORE↔Wong의 평균 감수성 순위 Spearman, 약물쌍 방향 일치율, 상위 5개 교집합을 주 기술값으로 보고한다. LICOB↔Wong을 같은 21약물로 나란히 비교한다. 동률은 Spearman에서 평균 순위, 약물쌍 방향에서 일치 0.5로 처리한다. 상위 5개 동률은 InChIKey 정렬을 사용한다. 각 연구의 공여자를 연구별로 독립적으로 2,000회 복원 추출한다. 보류 약물 집합은 고정한다. Spearman, 모든 약물쌍 방향 일치와 3D↔3D 대비 각 2D↔3D Spearman 차이의 95% 구간을 계산한다. 약물쌍은 서로 의존하므로 210쌍을 독립 표본으로 재표집하지 않는다.
- 모든 210개 약물쌍의 관측 방향으로부터, 각 연구에서 방향 재현 확률이 97.5% 이상인 쌍을 센다. 두 연구 모두 이 기준을 넘긴 쌍에서 방향이 반대인 수와 쌍을 보고한다. 이는 다중 검정을 보정한 유의성 선언이 아니라 표본 재추출에 대한 기술 안정도다. 모집단 차이, 배양 방식, 노출·분석법의 영향을 따로 식별할 수 없다. 3D↔3D의 Spearman이 두 2D↔3D 비교보다 높다고 판정하려면 짝지은 차이 구간의 하한이 각각 0을 넘어야 한다.
- 전체 관측 요약은 사전 명세를 커밋한 후 별도 CPU 작업에서 계산한다. 새 모델, 배율 선택, 재채점은 없다. 공여자별 반응은 G1에 보관하고 약물별 집계와 원본 해시를 기록한다. 이 분석은 이전 동결 비교를 대체하지 않는다.
