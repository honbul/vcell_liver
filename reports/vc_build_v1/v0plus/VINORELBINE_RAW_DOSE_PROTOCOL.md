# Vinorelbine at matched physical concentrations in GDSC2 and PRISM

Prior external technical results showed opposite PDX rank directions for the GDSC2 and PRISM fits. The two fitted AUCs cover different physical concentration ranges. This paired experiment changes only the labels, using source cells observed in both assays and the same fixed model. The common-dose comparison tests whether the unmatched AUC ranges can account for the 2D disagreement and whether that change helps on the previously evaluated Singapore PDX. [Prior PDX prediction](VINORELBINE_TRANSFER_RESULTS.md)

## Inputs and labels

- Use GDSC2 8.5 raw single-agent vinorelbine 2048 with the previously registered Sanger/COSMIC model intersection. Use only the 0.0001–0.1 µM library, 5+ observed doses, verified compound position, Glo blank/vehicle counts and plate Z′ ≥ .3, same as the original raw GDSC2 processing. Keep separate barcodes. [Sanger raw documentation](https://depmap.sanger.ac.uk/documentation/datasets/drug-sensitivity/)
- Use the 20Q2 PRISM raw normalized log2 fold changes, detection plate metadata, and registered exact parent and STR roster. Verify provider hashes. Match drug-product and fitted screen IDs, and where multiple compound plates are eligible use the first source plate token as in the provider processing. Use exact cellset row matches, without merging distinct cellsets. Treat distinct detection plates as technical readouts. Collapse at each dose by the median of 2+ such measurements before converting to a viable fraction. [PRISM release](https://doi.org/10.6084/m9.figshare.20564034.v1) · [Provider processing](https://github.com/broadinstitute/repurposing/blob/master/depmap_reprocessing_script_for_secondary.R)
- Compare publisher fitted AUC, measured native-range AUC and measured common-range AUC (0.0025–0.05 µM). Clip viability to [0,1], integrate piecewise linear interpolant in log concentration, require both endpoints within measurements, and discard curves with fewer than 5 distinct measured concentrations. Whole-curve comparisons use only the same matched cell and drug IDs. Within each assay report agreement between the two earliest eligible independent plate identifiers for both AUC definitions. PRISM technical detection repeats do not establish biological replication. Across the matched assays, aggregate cell relatives by lineage and report paired 95% bootstrap intervals. The concentration-matching gate is point Spearman improvement at least .05 and both correlation differences' lower 95% bounds greater than zero.

## Frozen external evaluation

- Keep only paired source cells with all three endpoints in both assays. Require at least 100 pairs. Use the previously fixed full RNA/pathway/TF/auxiliary kernel and L2 penalty 4. Standardize each source endpoint on this fitting roster as before. Fit the raw matched window and the fitted and raw native-range endpoints under identical cell support. Technical comparison arms include pooled assays and each assay alone, plus constant mean. No re-selection of model or penalty on these endpoints. Process GDSC2 and PRISM separately, fit on G1 GPU, freeze predictions for all 17 PDX inputs, then open the same public external labels in a separate job.
- Primary CPM evaluation uses the same six common patient groups and each of the 2023 and 2024 endpoints separately. The pooled common-range arm must beat pooled fitted-range and both common-range single-assay arms in Spearman and Pearson with positive paired 95% lower bounds in both publications. As sensitivity, report each publication's full RNA support and the same fixed models with the approximate GENCODE length correction. Two publication endpoints share patients. The in vivo dose is not a measured µM target, so PDX evaluates the empirical value of the source definition.
