# 단일 약물 학습 코어 정정과 확장 약물의 전이 효과

기존 68약물의 계통 분할을 고정한다. 참가하는 모델은 같은 행에서 예측하며 소스와 계통을 함께 보류하는 세 조건 및 세 소스 공동 학습을 평가한다. 평가 쪽은 기존 및 정정 학습 코어에 공통으로 있는 행의 **정정 실측**을 사용한다. 신규 약물 1,061종의 반응을 학습에만 추가한다. 각 fold에서는 학습 계통·세포와 허용 소스에 속하는 신규 행만 쓴다. 기존·정정 원본과 신규 테이블의 영수증을 각각 확인한다. 시험용 독립 코호트의 발현·반응은 이번 실험에 포함하지 않는다. [자료 정정과 확장](SOURCE_PANEL_EXTENSION.md)

- 정정 효과를 재는 두 arm은 같은 구조 커널을 기존 코어와 정정 코어에 각각 적합한다. 새 조직 신호 없이 원래 RNA rank·경로·TF·Chronos 및 변이/CNV proxy, 약물 ECFP/Tanimoto, 표적 일치 커널을 유지한다. 해당 두 약물의 점수를 나머지 공통 지원 위에 별도로 기록한다.
- 주 후보는 정정 코어에 확장 자료 전부를 결합한다. 약물 앵커와 소스 간 affine 보정은 fold의 정정 코어에서만 적합한다. 확장 약물 반응은 고정 변환 뒤 소스·약물별 적합 평균을 빼고 동등 소스 가중치로 잔차 학습에 추가한다. 기존 화합물의 표적 지식은 그대로 유지하며 신규 화합물에는 소스 원주석에서 발현 축과 정확히 일치하는 유전자 기호만 연결한다.
- 또 하나의 arm은 기존과 확장 약물 블록 사이에서 지문·표적 유사도를 차단하고 공통 항 .10을 남긴다. 각 블록 내부 커널은 그대로다. 모든 구조 커널은 벌점 4와 잔차 배율 1이다. 같은 정정 자료로 Ridge(벌점 1,000, 유전자 선택 512, 배율 1)와 약물 평균을 적합하고 확장 커널과 Ridge의 50:50 결합을 보조로 고정한다. 전체 arm에서 설정 선택을 생략한다.
- 12개 예측을 먼저 동결하고 별도 채점한다. 약물 내 Spearman·Pearson은 fold·assay별로 약물당 계통 5개 이상인 조건을 쓰며 약물·계통 짝지은 교차 재표집 900회의 95% 구간을 사용한다. 계통 내 Spearman·NDCG@5·Precision@5와 계통 재표집 구간을 보고한다. HCC 21계통만의 결과와 fold 내 중심화 Spearman도 보조 보고한다.
- 각 보류 조건에서 확장 후보의 승격에는 정정 구조 커널 대비 약물 내 Spearman·Pearson 95% 하한 >0, 소스별 계통 내 Spearman·NDCG@5 차이 하한 >−.005, 두 순위 지표의 약물 평균 대비 비음수 점 추정, HCC fold 내 중심화 Spearman의 소스 평균 차이 ≥0을 모두 요구한다. 외부 확인 후보로 올리려면 네 조건을 모두 통과해야 한다.
