# 간암 오가노이드의 연구 단위 보류와 다중 연구 적합

서로 다른 간암 오가노이드 연구에 3D 적합을 하나씩 전이했을 때 같은 약물의 환자 감수성 개선은 확인되지 않았다. 이번 회차는 다른 두 연구의 데이터를 병합하고 연구별 반응 척도를 통제해 이미 동결한 2D 예측의 환자별 편차를 보정한다. 모두 기존 연구이며 새 확인용 데이터로 간주하지 않는다. [양방향 21약물](HCC_3D_21DRUG_RESULTS.md) · [Yang 학습의 세 TKI 전이](HCC_3D_STUDY_TRANSFER_RESULTS.md)

| 보류 연구 | 주 평가의 공여자·약물 | 두 3D 학습 연구의 공여자 |
|---|---|---|
| LICOB | 38명·21약물 | Wong 10명 + Yang 74명 |
| Wong | 10명·21약물 | 기존 LICOB 29명 + Yang 74명 |
| Yang | 74명·세 TKI | 기존 LICOB 29명 + Wong 10명 |

- LICOB와 Wong의 이전 정확 구조 공통 21약물과 Yang의 공통 세 TKI만 등록한다. 두 3D 학습 연구가 각각 제공한 동일 parent 지지 수를 분리한다. LICOB 9명의 최근 확인 공여자는 모든 적합에서 제외하고 LICOB 기술 평가를 별도 보고한다. Yang 초기 노출 공여자 P1·P2는 모든 역할에서 제외한다. 연구별 공여자 ID를 격리하고 같은 환자의 지역별 오가노이드를 보류·채점에서 묶는다. 공개 연구 간 공용 개인 식별자는 없다. [LICOB 지원](LICOB_NODE_RECOVERY_RESULTS.md) · [Yang 등록](YANG_HCC_EXTERNAL_PROTOCOL.md)
- 2D 비교군은 기존 공개 세포주 스크린으로만 적합한 동결 약물 평균, Ridge, CellHit, 구조 커널, Ridge+구조 커널 50:50 혼합이다. 같은 held study에서 모든 3D 후보가 동일한 약물 평균 및 2D prior를 받는다. 2D 레시피별 발현 교집합은 기존 등록값을 유지한다. 3D 모델은 세 연구 발현 교집합에서 샘플별 순위 및 학습 쪽만 표준화한 경로·RNA·표적 특징을 사용한다. 외부 연구 RNA의 평균·공분산을 맞추지 않는다.
- 3D 교육 응답은 연구·약물별로 환자 평균에서 중심·표준편차를 구해 표준화한다. 학습 환자 내 여러 지역의 총 가중은 1이다. 첫 비교는 단순 병합, 둘째는 약물별 연구 총가중을 동일하게 하고 적합 Gram에 같은 연구 블록 `0.5 × K`를 추가한다. 새 연구로 가는 예측에는 공유 Gram만 사용한다. 구조·표적 약물 커널과 벌점 2를 고정한다.
- 주 후보는 학습 연구·약물에서 중심화한 2D 환자별 편차를 3D 표준화 응답에서 뺀 뒤 잔차를 두 번째 규칙으로 학습한다. 단위 환산은 학습 연구의 약물별 2D 편차 표준편차를 같은 비중으로 평균하고 하한 .02를 준다. 공유 잔차 예측의 0.5배를 기존 2D 혼합에 더한다. 고정 절제는 같은 잔차에서 샘플의 전체 약물 평균을 더 제거한다. 단순 병합과 연구 균형 기준선은 2D 약물 평균에 잔차 예측을 더한다. [독립 연구 교차 적합](HCC_3D_21DRUG_PROTOCOL.md)
- 두 21약물 평가에서 2D 혼합 대비 약물 내 Spearman·Pearson과 환자 내 Spearman·NDCG@5의 짝지은 95% 하한이 모두 양수이면 공동 이득으로 판정한다. Precision@5와 공통 세 TKI의 약물 내 두 상관을 함께 보고한다. 세 TKI 표에서 Top-5는 판정에 사용하지 않는다. 시험 연구의 응답을 새 후보나 배율 선택에 사용하지 않는다. 예측과 등록 해시를 동결하고 모든 보류 응답은 별도 채점으로 연결한다.
