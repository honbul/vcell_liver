# 2D 농도별 곡선으로 LICOB의 3D 반응을 예측

기존 LICOB의 성인 38공여자·43개 오가노이드 중, S5의 전체 농도 구간을 덮는 동일 parent의 2D 측정 세포가 30개 이상인 약물을 평가한다. 자료는 이전에 채점했으므로 사후 기술 평가다. 앞선 IC50 직접 학습은 약물 평균보다 환자 감수성 구별에서 높았고 상위 5개 순위의 비열등 기준을 통과하지 못했다. 이번에는 스칼라로 미리 요약하기 전의 농도별 곡선에 모델을 적합해 두 지표가 함께 개선되는지 확인한다. [기존 종말점 평가](LICOB_DOSE_ENDPOINT_RESULTS.md) · [공개 LICOB 측정 방법과 보충자료](https://www.ebi.ac.uk/biostudies/studies/S-EPMC10949980)

- 기존 S5·정확한 parent 등록과 소스 선별 및 정규화 규칙을 쓰고, 관측 농도점 5개 이상이고 전체 공개 S5 범위를 덮는 곡선만 쓴다. 2D 생존율은 0–1에 제한하고 약물별 S5 최저·최고 농도 사이 로그 등간격 9점으로 선형 보간한다. 반응은 원래 실측 범위 안에서만 계산한다. 반복 노출은 이전과 같이 좌표별 중앙값으로 합친다. S5 자체의 처리 기간·기기 차이는 보정하지 않는다.
- **주 방법 `curve_joint`**은 RNA 순위·경로/TF·Chronos/유전체 대리값 및 구조·약물 표적의 기존 상호작용 커널을 농도 축과 곱한다. 농도 분수 `f = (log d − log min)/(log max − log min)`의 RBF는 폭 .25를 쓴다. 소스×약물별 평균을 빼고 각 농도에서 적합 행의 공통 세포·약물 효과를 분리한다. 벌점 4, 동일 소스 가중을 재사용한다. 예측에는 소스 균등 약물 평균 곡선을 더하고 0–1의 비증가 곡선으로 사영한다. 곡선에서 최초 0.5 교차의 `−log10(µM)`, 로그 농도 정규화 AUC의 음수, 원래 S5의 최고 두 농도 중 작은 생존율의 음수를 얻는다. 측정 범위 밖 교차는 각 경계에 둔다.
- 동일 소스 측정 행과 특성에서 **`curve_independent`**는 농도 Gram을 단위행렬로 바꾸고 동일 사영을 적용한다. **`direct_endpoint`**는 같은 2D 아홉 점을 비증가 곡선으로 사영해 각 종말점 값을 얻은 뒤 스칼라에 별도 적합한다. **`drug_mean`**은 이 직접 적합의 소스 균등 약물 평균이다. 네 방법 모두 같은 약물·공여자 지지로 동결한다.
- 주 판정은 **범위 제한 LICOB S7 IC50**에서만 한다. 최소 10개 약물에 5명 이상 실측과 변이가 있어야 한다. 세 대조 각각 대비 약물 내 Spearman·Pearson의 95% 하한이 모두 0 초과이고, 공여자 내 Spearman·NDCG@5·Precision@5의 하한이 모두 −.005 초과면 통과한다. 공여자·약물 교차 및 공여자 짝지은 재표집을 각각 적용한다. LICOB S6 AUC·S8 Emax 및 약물군과 경계에 걸린 예측 비율은 기술값이다. S6 공개 AUC와 직접 적합의 2D 아홉 점 정규화 AUC는 척도가 달라 순위를 비교한다.
- 소스 추출 및 예측에는 등록된 농도 메타데이터, 2D 반응, 기저 RNA와 기존 분자 특징만 쓴다. 전체 예측 행, 소스 추출 및 입력의 해시를 고정한 뒤 별도 채점에서 S6–S8을 연다. 3D 환자 내 여러 PDO는 같은 공여자로 집계한다. GDSC2·CTRPv2·PRISM에서 LIMORE 50계통으로 전이한 핵심 2D 검증과 별개로 기록한다.
