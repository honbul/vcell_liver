# 플랫폼 간 재현성으로 고른 유전자 상대 순서의 HCC 전이 평가

[사전 명세](PAIRED_ORDINAL_PROTOCOL.md) · [발현 척도와 동순위 감사](INDEPENDENT_PDO_CALIBRATION_RESULTS.md)

Hallmark·PROGENy·DoRothEA 서명에서 같은 서명에 있는 두 유전자의 발현 순서를 사용했다. RNA-seq와 Affymetrix에서 같은 세포를 측정한 공개 자료의 **적합 계통**에서 플랫폼 간 순서 일치가 높은 1,000쌍을 골랐다. 동일 RNA 축의 표준 순위·경로·Chronos·유전체 대리 커널에 이 순서 커널을 .35 비중으로 더했다. 두 대조도 같은 RNA-seq 분산 층에서 각각 1,000쌍을 골랐으며, 선택 점수는 RNA-seq 분산 또는 같은 조직 내의 짝 순열로 바꿨다. 적합의 ECFP4, 표적 매핑, 다중 소스 약물 앵커와 벌점은 공통이다.

## 반응값 없이 확인한 RNA 재현성

세 소스와 pooled의 바깥 분할 12개에서 적합에 쓰지 않은 동일 세포의 두 플랫폼 측정을 대조했다. 분할당 적합 RNA 쌍은 487–531계통, 보류 RNA 쌍은 169–256계통이었다. 표는 분할을 동등 가중한 값이다.

실제 RNA 짝으로 고른 1,000개 중 두 유전자의 값이 같았던 비율은 LIMORE 0.034%, LICOB 0%였다. 각 외부 적합은 800개의 학습 쌍을 사용했다. LIMORE의 RNA 공통 축은 15,737유전자와 12,312개 적격 후보 쌍, LICOB는 13,483유전자와 12,522개 적격 후보 쌍이었다. 두 외부 코호트는 이전 평가 이력이 있다. 이번 외부 반응은 적합 또는 쌍 선택에 사용하지 않았다.

선택 쌍을 동결본의 해시와 대조한 뒤, 연구 간 순서 분포를 사후 기술 비교했다. 각 유전자 쌍에서 공여자를 동등 가중해 −1·0·+1의 빈도를 얻고, LICOB와의 총변동거리(0–1)를 쌍에 걸쳐 평균했다. 아래 쌍 수는 2D 소스와 양쪽 외부 코호트, Wong과 Yang 모두에서 두 유전자가 측정된 교집합이다.

|---|---:|---:|---:|---:|

실제 짝으로 고른 유전자 순서의 2D 플랫폼 간 재현성은 좋아졌다. 2D 학습 집단과 LICOB 사이의 순서 분포 차이는 짝 순열 대조와 비슷한 크기였다. 독립 HCC 오가노이드 두 연구와 LICOB 사이에서는 실제 짝으로 고른 조건의 거리가 가장 작았다. 쌍별 분포 거리에는 측정법과 연구별 표본 구성이 함께 들어간다. [반응값을 쓰지 않은 순서 분포 진단](paired_ordinal_distribution.json)

같은 축 기존 커널에서 순서 커널을 더해 생긴 예측 변화도 두 축으로 분해했다. LICOB에서 변화 RMS는 .00968이었다. 전체 공통 이동 16.0%, 약물별 공통 이동 37.8%, 공여자별 공통 이동 26.9%, 약물×공여자 상호작용 19.4%였다. 짝 순열의 상호작용 비중은 20.9%였다. 이 분해는 예측값만 사용했으며 각 성분의 정답 재현성은 추정하지 않는다.
