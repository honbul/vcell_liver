# LIMORE와 LICOB의 실측 유전체 입력 비교

**실측 유전체를 추가한 약물 내 환자·계통별 감수성 개선의 사전 기준은 두 코호트 모두 미통과다.** 같은 2D 소스 학습과 공통 행에서 약물 표적 발현, 실제 코딩 변이, 절대 복제 수 범주의 효과를 비교했다. 기존 평가 이력이 있는 LIMORE 50계통·68약물과 LICOB 29명·53약물에서 기술 분석으로 판정했다. [사전 명세](MEASURED_DRIVER_PROTOCOL.md)

## 입력 지원

| 특징 | 2D 적합 모델 | LIMORE 보류 | LICOB 보류 | 2D 적합의 선택 특징 수 |
|---|---:|---:|---:|---:|
| 코딩 변이 | 1,005/1,014 | 50/50 | 34/34 | 8 |
| 절대 CNA 증폭·동형 결실 | 807/1,014 | 50/50 | 적용 범위 밖 | 11 |
| CRC가 유효한 NODE CNV 헤더 |  |  | 34/34 |  |

약물 표적 발현은 학습 68약물 중 61개에서 계산했다. LIMORE의 CN은 출판사가 분류한 `CN>4`와 `CN=0`이며 DepMap 절대 복제 수에서 동일 조건으로 만들었다. 기존 V0+ 간접 CN 특징의 25Q3 파일은 배수성 대비 상대 복제 수다. LICOB CNV 시트의 무결성과 보류 34모델 ID는 확인했으며 절대 복제 수 범주를 비교하는 이번 모델에는 코딩 변이만 적용했다. DNA 순열은 기존 보류 계통·공여자 묶음의 크기를 보존하면서 LIMORE 48/50모델, LICOB 24/34모델의 DNA 할당을 바꿨다.
