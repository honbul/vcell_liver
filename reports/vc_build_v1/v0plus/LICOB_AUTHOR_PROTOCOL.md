# LICOB 저자 패키지 기반 독립 HCC 오가노이드 확인

NODE 원발행 아카이브는 공개 MD5와 내부 CRC가 불일치한다. 대체 기저 RNA는 원저자 iLICOB의 공개 커밋 `c65cb2f9305defbf5b87b56a7216d673d6b94a39`의 `data/data_ilicob_org` 중 `[[4]][[1]]`이다. 저자 함수 `iLICOB_query`가 RNA 행렬로 읽는 위치다. 패키지에서 이 행렬만 추출한다. 패키지 내 순위 선정용 100개 유전자, 저자의 예측 모델·가중치, 패키지 내 반응 데이터는 모델 코드에 전달하지 않는다. 패키지 DESCRIPTION의 라이선스 필드는 템플릿 문구이며 별도 라이선스 파일을 확인하지 못했다. 원본과 추출본은 G1에 두고 다운로드·해시와 집계 결과만 남긴다. [저자 패키지 고정 버전](https://github.com/wu-yc/iLICOB/tree/c65cb2f9305defbf5b87b56a7216d673d6b94a39) · [원논문과 S1–S13](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949980/) · [NODE 무결성 감사](STEP1_SCALE_AND_LICOB.md)

- RNA, 공식 S1의 HCC 및 S6 표본 ID를 연결한다. 문서에서 18세 이상인 공여자를 주 평가에 사용한다. 사전 등록에서 문자열로 저장된 나이 6건을 제외하는 오류를 발견했으며 S6 수치 열람 전에 숫자 해석을 적용한다. S1 표 하단의 동일 환자 주석을 이용해 공여자 단위로 묶고, 같은 공여자의 약물별 실측·봉인 예측을 각각 산술 평균한 다음 공여자를 단위로 평가한다. 모든 HCC의 모델 단위 지표는 기술 표로 함께 낸다. 연구 간 공통 환자 식별자 부재를 기록한다. 실측 세포주·계통 ID는 적합 자료와 교집합이 없어야 한다. 비교용 공통 유전자에서 각 샘플을 독립적으로 순위화한다. 저자 처리의 정확한 발현 단위는 미확인이다. 손상 전 NODE 접두부는 표본·유전자 식별 확인에만 쓰며 유전자별 Pearson 중앙값 .90 이상을 요구한다.
- S5·S6 약물명은 표준화한 키로 일대일 연결한다. S5의 정확한 Selleck 품목 코드로 제조사 공개 L1700 표의 구조를 확인한다. 누락·입체화학 불완전 품목은 해당 코드의 제조사 CAS를 사용해 PubChem의 구조를 교차 확인한다. 구조의 비입체 연결만 일치한 행은 채점 대상에서 제외한다. RDKit 정규화 후 완전한 parent InChIKey가 기존 학습 패널과 일치한 약물만 평가하고 76개 전체의 매칭 결정은 남긴다. [제조사 L1700 카탈로그](https://www.selleck.co.uk/screening/chemical-library.html) · [PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)
- GDSC2·CTRPv2·PRISM으로만 원래 고정한 V0+ 설정 `9fb42665b3d5bce1757bab31f341c256bc2f9bcf5434e6239c48c47dd3be3474`을 그대로 적합한다. 비교군은 약물 평균, 약물+세포 가산, 약물별 Ridge·ElasticNet, LightGBM, CatBoost, CellHit, Velodrome inductive, CODE-AE inductive다. 주 후보 V0+ inductive, 보조 후보 Ridge+V0+ 동일 가중 평균이다. 예측은 반응 파일 경로 없이 실행하며, 각 예측의 행·해시를 검증해 병합 동결하고 S6을 별도 작업에서 한 번 채점한다.
- S6 생존율 AUC를 음수로 바꿔 더 높은 점수가 감수성을 뜻하도록 한다. 약물 내 Spearman·Pearson과 환자 내 Spearman·NDCG@5·Precision@5를 공동 보고한다. 주 후보의 3D 확인 조건은 약물 평균 대비 약물 내 Spearman·Pearson과 환자 내 Spearman·NDCG@5의 짝지은 95% 하한이 모두 양수다. 기존 VC 우위는 개발에서 고른 CellHit과 Ridge 양쪽 대비 같은 네 하한을 요구한다. 약물·환자 교차 재표집 및 환자 재표집은 기존 Wong 구현을 계승하며 Precision@5는 함께 보고한다. 유무효 판정, 지원 수, 약물군별 구별 성능을 공개한다. 이 평가는 iLICOB의 저자 배포 교집합에 한정한다.

초기 등록은 34개 전체에 대한 예측을 설정했다. 채점 작업 `33019`을 결과 접근 전에 보류했으며 S1 전용 감사 영수증을 확인한 뒤 새 채점 작업을 연결한다. `33016/33017 → 33018`의 모델 단위 예측과 예측 설정은 그대로 사용한다.

첫 S6 채점 `33050`의 수치 검산에서 공여자별 평균의 반올림 오차가 환자 간 동일해야 할 약물별 기준선에 가짜 순위를 부여했다. 모델별 원본 약물 평균이 약물 내 상수임을 확인하고 공여자별 집계에서 그 값을 정확하게 보존하도록 수정했다. 같은 모델 단위 동결본과 환자 등록부에 같은 사전 기준을 적용해 채점 오류를 수정한다.
