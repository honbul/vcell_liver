# LICOB 공개 RNA의 전체 배포 축과 추가 단일 약물 평가

DrugDis 가공 배포본 revision `fc66d2991e499a03b92778347a8a251d0bd9eb7c`의 `omics_mrna_raw/LICOB.parquet`는 65표본·23,121유전자다. 가공 파일은 CC BY 4.0이며 출처인 LICOB 원 데이터의 조건은 별도다. 발현과 SHA-256만 가져와 G1에 보관한다. 전 회차 NODE 복구 발현과 공통인 43모델·7,123유전자에서 최대 절대 차이 `≤3e-7`을 요구한다. 원저자 iLICOB 발현과 비교한 샘플별 교차 확인도 보존한다. 응답은 기존 출판사 S6을 항상 사용한다. DrugDis의 harmonized 반응, 비교 결과, 가중치는 본 학습에 사용하지 않는다. 메타데이터에서 HKUPDO는 위암 PDO로 확인해 HCC 평가와 분리한다. [DrugDis 가공 자료와 라이선스](https://huggingface.co/datasets/Boom5426/DrugDis/tree/fc66d2991e499a03b92778347a8a251d0bd9eb7c) · [LICOB 원 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949980/) · [이전 부분 복구 평가](LICOB_NODE_RECOVERY_RESULTS.md)

- **같은 53약물 RNA 측정 기술 비교.** 같은 43 PDO·38성인 공여자와 2D 정정 학습 65,678행을 사용하고 RNA를 공통 유전자 7,123개에서 14,421개로 바꾼다. 기존과 같은 주 후보 구조 커널, 같은 50:50 Ridge 결합, 같은 표적 발현·실측 DNA·순열 대조, 약물 평균·Ridge·CellHit·CODE-AE·Velodrome·V0+를 모두 다시 적합한다. 모델 설정과 정답은 이전과 같다. 샘플별 순위 계산도 공통 유전자에 대해 정확히 다시 한다. RNA 폭의 효과는 각 방법의 새 예측과 동일 행의 기존 동결 예측을 직접 비교한다. 구조 커널의 약물 내 Spearman·Pearson의 짝지은 95% 하한이 모두 양수이고 환자 내 Spearman·NDCG@5의 점 추정이 음수가 아닐 때 이 발현 축의 기술적 이득으로 판정한다. 이전의 9명 범위와 전체 38명을 각각 해석한다. 선행 채점을 재사용한 범위이므로 새 독립 확인 판정에는 쓰지 않는다.
- **55약물 지원 기술 평가.** 등록된 76개 구조에서 기존 53약물 밖에 있는 AT-406과 capmatinib에 정확한 단일제 parent 연결이 있다. 각각 433개 CTRPv2 행과 487개 PRISM20Q2 행만 정정 코어에 추가한다. 둘 모두 없는 나머지 21약물은 채점 지지 밖이다. GDSC2 추가 카탈로그는 새로운 일치를 더하지 못했다. 기존 공통 약물과 보정값을 단일 약물 행 추가 전후에 확인한다. 추가 비교는 정정 약물 평균·Ridge·구조 커널·고정 평균이다. 전체 55약물에서 두 축의 점수를 보고하고 새 두 약물은 38명의 약물 내 Spearman·Pearson을 개별 표로 제공한다. 두 약물의 Top-5 순위는 계산하더라도 해석하지 않는다. - 모든 중간 예측 파일의 SHA-256과 행 지원을 확인하고 합친다. 기존 RNA 축의 예측은 봉인본에서 읽으며, 모형 적합 과정과 합본에는 정답을 사용하지 않는다. 학습과 동결 뒤 별도 Slurm 작업에서만 S6을 채점한다.
