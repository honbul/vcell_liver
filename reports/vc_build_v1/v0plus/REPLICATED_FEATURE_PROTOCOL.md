# 독립 스크린에서 재현되는 RNA 특징의 전이 검증

이전 절제에서 스크린 간 관측 일치도로 손실을 가중해도 소스 보류 성적이 일관되게 개선되지 않았다. 이번에는 약물별 RNA·경로 특징과 감수성의 관계가 독립 스크린에서 같은 방향인지를 적합 단계에서 추정한다. 비교는 같은 반복 계통과 같은 약물을 쓰는 특징 선택 대조군을 포함한다. GDSC2·CTRPv2·PRISM20Q2 정정 68약물 코어의 기존 세 계통 fold와 세 소스 보류 및 공동 학습을 유지한다. LIMORE·LICOB 등 외부 코호트는 이번 입력에 포함하지 않는다. ## 후보와 대조군

- 소스·약물별 앵커와 잔차의 정정 척도는 기존 구조 커널과 같다. 적합 RNA의 샘플 내 순위, 고변이 유전자 768개, 등록 약물 표적 유전자, PROGENy·Hallmark·DoRothEA를 사용한다. RNA 특징과 반응 잔차는 계통 안에서 각각 평균한다.
- 동일 parent가 두 적합 스크린에 있고 같은 계통 실측이 30개 이상일 때, 두 반응의 교집합 내 평균 순위를 표준화한다. 각 투약 전 RNA 특징과 각 반응 순위의 Pearson을 계산한다. `replicated`의 후보 특징 점수는 두 계수의 부호가 같을 때 공통 부호를 붙인 절댓값의 최솟값이며, 부호가 다르면 0이다. `matched_pooled`는 두 반응 순위의 단순 평균과 같은 특징의 Pearson을 사용한다. 적합 스크린 쌍별 점수는 `n−3`에 비례해 평균한다. 안정 정렬로 절대 점수가 큰 특징 128개를 고른다. 재현 점수가 0인 특징은 제외하며 비교군도 같은 수를 고른다. 양의 재현 특징이 하나도 없으면 두 arm 모두 구조 커널로 돌아간다.
- 선택 특징의 선형 Ridge를 등록 약물의 모든 허용 소스·계통 잔차에 적합한다. 관측이 더 많은 소스가 더 큰 가중을 갖지 않도록 소스별 총가중을 같게 하고 행당 평균 가중을 1로 둔다. `alpha=100`, 절편은 가중 평균으로 풀고 약물 앵커는 구조 커널과 공유한다. 두 주 비교 arm은 이렇게 만든 예측과 동결 정정 구조 커널을 50:50으로 결합한다. 쌍이 없거나 선택 지원이 없는 약물은 구조 커널 예측을 유지한다. 학습원만으로 특징·반응을 계산하고 후보 수와 배율은 바꾸지 않는다.
- 기존 동결 구조 커널, 약물별 Ridge, 약물 평균을 함께 채점한다. 셀별 순위 지표는 기존 지원 전체에서, 약물 내 상관은 전체와 반복 특징이 지원된 약물·fold에서 각각 보고한다. Precision@5도 기록한다. 보조 성인 HCC 평가는 fold 중심화 Spearman으로 표시한다.

## 동결과 판정

12개 개발 분할마다 같은 등록 행을 동결하고 해시 확인 뒤 별도로 채점한다. 지원 범위가 세 fold 모두에서 평가 가능한 5개 이상의 약물로 유지될 때 해당 보류 소스를 승격 평가에 포함한다. 승격 평가에는 (1) 세 소스 가운데 둘 이상에서 `replicated`가 구조 커널과 `matched_pooled` 각각을 상대로 반복 특징 지원 범위의 약물 내 Spearman·Pearson 개선 95% 하한이 모두 0 초과, (2) 나머지 소스에서도 같은 개선 구간의 하한이 모두 −.01 초과, (3) 모든 소스의 전체 판에서 구조 커널 대비 계통 내 Spearman·NDCG@5의 하한이 −.005 초과이며 약물 평균 대비 두 점 추정값이 비음수인 조건을 요구한다. 소스 모두가 최소 지원을 갖춰야 한다. 약물 내 차이는 약물·계통 교차 재표집, 계통별 순위는 계통 짝지은 재표집을 사용한다.
