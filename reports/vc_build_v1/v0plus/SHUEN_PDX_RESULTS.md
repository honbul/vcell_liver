# 새 공개 HCC PDX에서 sorafenib 전이와 vinorelbine 재현

**Sorafenib의 RNA 기반 전이 기준은 미통과였다. Vinorelbine의 두 출판물 간 반응 순위 재현은 사전 기술 기준을 통과했다.** 이번에 공개된 치료 전 RNA 17계통을 네 출판물의 PDX ID로 연결했다. 연구별 동일 약물의 종말 종양 무게를 각각의 대조군으로 나눠 비교했다. [사전 명세](SHUEN_PDX_PROTOCOL.md) · [Shuen RNA 기탁](https://doi.org/10.17632/jwr6kptn5y.1)

## 동결 모델의 sorafenib 외부 기술 평가

2024년 S1의 단일군 22계통 중 치료 전 RNA와 정확히 일치한 10계통·10환자군을 채점했다. 17계통의 원시 카운트에 대해 두 입력 방식·세 모델의 102행을 모두 예측했다. 최소 전체 모델 유전자 커버리지는 CPM 99.02%, 길이 보정 99.00%였다. [2024년 원논문과 S1](https://doi.org/10.3390/ijms25031563) · [오프라인 모델과 소스 학습](STRUCTURED_RELEASE_MODEL_CARD.md)

## PRISM 구조 주석의 등록 누락 정정

PRISM20Q2의 한 SMILES 필드에 같은 화합물을 표현하는 문자열이 쉼표로 반복되는 사례를 확인했다. 기존에는 필드 전체를 단일 SMILES로 해석해 이 행을 제거했다. 모든 항목의 exact parent가 일치하는 필드만 복원한다. 구조가 불명확하거나 상충하는 필드, 조합 표시가 있는 약물명은 제외한다. 실제 vinorelbine과 everolimus의 exact parent는 PubChem과 일치했다. [Vinorelbine](https://pubchem.ncbi.nlm.nih.gov/compound/5311497) · [Everolimus](https://pubchem.ncbi.nlm.nih.gov/compound/6442177)

|---|---:|---:|
| PRISM20Q2 약물 | 664 | 1,393 |
| PRISM20Q2 관측 | 291,244 | 610,508 |
| PRISM20Q2 성인 HCC 관측 | 8,778 | 18,431 |
| CTRPv2+PRISM 전체 약물 합집합 | 1,061 | 1,709 |
| CTRPv2+PRISM 전체 관측 | 546,429 | 865,693 |

기존 확장표 546,429행이 모두 같은 값과 native ID로 유지됐다. 새 표에는 Vinorelbine 462계통(성인 HCC 14)과 everolimus 681계통(성인 HCC 18)의 단일군 AUC가 들어 있다. 정정 확장표를 새 경로에 보관했고, 위 Sorafenib 채점은 기존 동결 68약물 체크포인트를 사용했다. 추가 648약물은 모델 학습 지지의 변화다.
