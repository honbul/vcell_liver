# 비간암 3D 약물 앵커를 공유한 공정 비교

PDO 연구별 동결 성적을 본 뒤 고정한 개발 비교다. 3D 잔차 학습의 사전 판정은 최초 실험에서 그대로 적용한다. Pilot 1에서 평균 보정만으로 NDCG@5가 크게 달라졌으므로, 완전히 같은 3D 약물 앵커를 Ridge와 구조 커널에 준다.

- 기존 네 보류 연구 및 동결 예측 해시를 유지한다. 적합 3D의 각 약물에서 Ridge 예측 편차의 평균을 빼고 구조 커널이 쓴 동결 3D 약물 앵커를 더한다. 두 보정 모델을 50:50으로 평균한 후보도 고정한다. 기존 최종 예측의 약물별 상수만 이동하므로 각 모델의 약물 내 상관은 그대로여야 한다. 이 계산은 적합 약물·모델의 메타데이터와 기존 예측만 읽는다.
- 새 예측을 동결한 뒤 별도 채점한다. Pilot 1에서 3D 앵커를 공유하는 구조 커널·Ridge·고정 평균의 약물 내 Spearman·Pearson 및 PDO 내 Spearman·NDCG@5·Precision@5를 비교한다. 95% 구간은 기존 개발 점수 함수와 같다. 균일 지원에서 두 축의 차이 하한을 보고한다. 모델 선택을 위한 새 격자나 간암 확인 의존성은 없다.
