# V0+ 3단계 GPU 학습과 절제

GDSC2·CTRPv2·PRISM20Q2의 65,685행, 1,014개 세포 모델, 991개 계통에 대해 3-fold 보류 교차검증했다. 표는 세 소스를 동등 가중하며 각 소스의 native AUC와 비교한다. 합의된 외부 발현과 정답은 이 표에 들어가지 않았다. 표 안의 transductive는 각 소스 보류 fold의 **RNA만** 공동 정렬에 사용한 경우다.

Chronos 표적·HCC 관련 유전자 점수는 114개 출력, 754개 원천 모델에 있었고 driver 감독은 18개 출력, 1,005개 모델에 있었다. 임상 변이가 없는 외부 샘플에서도 RNA 입력만으로 실행할 수 있게 두 자료는 학습 중 보조 정답으로 사용했다. 원천의 해당 자료가 없는 측정은 손실에서 마스킹했다. 크기 선택에서 inductive는 320 hidden·100 epochs를 2회, 192 hidden·70 epochs를 1회 골랐다. Transductive는 세 fold 모두 320·100을 골랐다. 출력 배율은 주력 모델 6개 fold 모두 0.5였다.

관측된 범위에서 전체 특징을 넣은 주력 모델은 약물별 Ridge를 넘지 않았다. 고정 아키텍처에서 경로 서명을 빼면 약물 내 Spearman이 CTRPv2에서 +.020 [95% .011, .028], GDSC2에서 +.017 [.008, .025]이었다. Chronos 제거도 GDSC2에서 +.014 [.005, .024]였다. 이 구간은 소스별 약물 단위 재표집이며 다중 비교 미보정이다. 반면 GDSC2에서 source covariance 정렬을 빼면 −.007 [−.014, −.001]이었다. 표적·경로·의존성의 추가 이득을 이 결과로 주장할 수 없으며, 외부 전이에서 효과가 달라지는지 같은 예측 회차에서 비교한다.
