# VCAT 저자 SMILES 모델과 간암 외부 동일 행 비교

VCAT은 기저 RNA, CRISPR 의존성 및 LINCS 약물 전사 서명을 결합하며 HCC 오가노이드 이진 분류도 보고했다. 논문이 안내한 체크포인트 Zenodo API는 이번 확보 시 HTTP 404를 반환했다. 저자 MIT 코드 커밋 c122e8c3515bb1281e7210d40e585341f36ca956에 포함된 SMILES 모델을 정정 GDSC2·CTRPv2·PRISM으로 연속 반응에 재적합한다. 논문의 CTS 주 모델, 이진 분류 또는 연속 IC50 수치의 재현이 아니다. 외부의 기존 채점 이력도 유지한다. [저자 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC13671233/) · [저자 코드](https://github.com/ChrisChan99999/VCAT/tree/c122e8c3515bb1281e7210d40e585341f36ca956)

- 스크린·계통 공동 보류 3-fold, 공동 학습 3-fold, LIMORE 50계통·68약물과 LICOB 성인 38공여자·53약물을 고정한다. 다른 모든 비교와 같은 정정 소스 반응, 반응 단위와 약물 앵커를 사용한다. RNA는 샘플 내 순위로 변환하고 적합 RNA에서 계산한 유전자 표준화만 적용한다. DepMap Chronos 지원이 적합 독립 계통 40개 이상인 기존 등록 114유전자 중 공통 유전자만 입력한다. 관측 Chronos를 적합에서만 표준화하고 부호를 뒤집은 의존성 값을 표적으로 쓴다. 결측은 pretraining 손실에서 제외한다. 약물은 정확한 parent의 isomeric SMILES를 저자 토크나이저에 넣는다. 사전 토큰 사전과 최대 길이는 적합 약물로 고정하며 순위화에 평가 코호트 통계를 쓰지 않는다.
- 저자 VCAT의 전체 SMILES attention 구조 및 저자 concat_mlp 절제를 적합한다. 두 모델은 동일한 fit-only VPM pretraining 가중치를 공유하고 반응 학습 동안 VPM을 동결한다. 폭 64, 헤드 4, VPM과 cascade 각 1층, FFN 배율 2, dropout .1, SMILES 임베딩 64, GRU 두 층, seed 53을 고정한다. VPM은 40 epoch, AdamW 학습률 .001, 배치 64, 관측 의존성 MSE다. 연속 반응은 18 epoch, AdamW 학습률 .0004, 배치 약 256, weight decay .001, 5배 단위의 앵커 제거 정답에 MSE로 적합한다. 약물·스크린 조합의 행 수 역수로 손실을 가중한다. 출력을 원 단위로 되돌리고 공통 약물 앵커를 더한다. 학습 배치에서는 동일 약물 SMILES 한 번의 GRU 산출을 공유한다. 평가 모드에서는 같은 입력의 저자 원래 per-row GRU와 수치 일치를 확인한다.
- 주 후보는 기존 정정 구조 커널과 전체 VCAT-SMILES의 동일 가중 평균이다. 구조 커널·VCAT 전체·concat 절제·약물 평균·약물별 Ridge를 같은 행에 둔다. 외부는 CellHit·CODE-AE·Velodrome·V0+도 포함한다. 승격에는 보류 스크린 3곳 중 두 곳 이상과 외부 두 곳 각각에서 모든 구조 커널·VCAT 대조를 상대로 약물 내 Spearman·Pearson의 95% 하한 >0 및 시료 내 Spearman·NDCG@5·Precision@5 하한 >−.005가 필요하다. 두 외부에서는 기존 공개 모델 각각에도 같은 기준을 적용하고 구조 커널 대비 약물×시료 잔차 PCC 차이의 하한 >0을 요구한다. 약물군별 성적과 단독 VCAT·절제 역시 보고한다.
- 예측과 등록 해시를 동결하고 별도 CPU 프로세스에서 실측을 연결한다. 모델 설정과 자료 등록을 기록한다. 기존 논문과 이 비교는 모델 변형과 평가 단위가 다르므로 공개 논문 수치를 직접 대조하지 않는다.
