# 같은 성인 HCC 공여자의 2D·3D 약물 실측 일치도

Wong S7 헤더에서 같은 환자 번호의 2D PDTCL과 3D PDTO 8쌍을 확인했다. 이미 채점한 오가노이드 62약물과 동일 환자에서 얻은 2D 실측을 직접 대조한다. 등록 100개 모든 약물도 평가해 소스 학습 패널 편중을 확인한다. 2D 세포는 치료 전 조직 RNA와 다른 입력이다. 이 비교는 같은 환자에 대한 두 실험 형식의 합치도를 측정한다. 생물학과 측정 오차를 분해하거나 RNA 모델의 이론적 상한을 추정할 수 있는 독립 반복 설계는 아니다. [Wong 원논문 Figure 2와 S7](https://doi.org/10.1016/j.jhepr.2025.101426) · [기존 62약물 동결 평가](WONG_EXPANDED_RESULTS.md)

- 정확한 parent 구조와 기존 성인 HCC ID의 일치를 요구한다. 두 형식 모두 8명의 실측이 완결된 약물만 포함하며 주 패널이 80약물에 미달하면 채점하지 않는다. 다른 환자·정상 간·ATCC 라인은 제외한다. S7의 mean inhibition AUC를 그대로 사용한다. 두 형식의 상대 순위와 차이를 다루며 같은 환자 약물의 두 관측을 기술 반복으로 취급하지 않는다.
- 환자의 2D 실측 자체를 3D의 예측값으로 동결한다. 2D 약물 평균을 대조로 사용한다. 약물 내 Spearman과 Pearson, 환자 내 Spearman과 NDCG@5, Precision@5, 환자와 약물 가산 성분을 제거한 상호작용 Pearson을 낸다. 정확한 환자 짝과 8!개 환자 블록 재배열을 비교해 동일 약물 환자 순위와 상호작용의 단측 검정값을 계산한다. 같은 환자 재배열을 전체 약물에 공통 적용한다. 환자·약물 짝지은 2,400회 재표집 구간을 함께 보고한다. 전체 패널에서 약물 내 두 상관 개선 및 상호작용의 95% 하한이 모두 0보다 크고 두 순열 p값이 .05 미만이면 직접 전이를 지지한다. 과거 모델과 일치하는 62약물 및 그 중 신규 35약물에서도 동결된 조직·PDO RNA 모델 및 약물 평균과 비교한다. 기전군은 기술값으로 보고한다.
- 보조 과제로 같은 코호트의 공여자 3명에서 2D→3D를 보정하고 나머지 5명을 예측한다. 가능한 56개 분할 전체를 고정한다. 각 분할에는 적합 공여자의 3D만 전달하고 보류 공여자는 2D 실측과 등록 ID만 사용한다. 약물별 적합 3D 평균에 2D의 적합 평균 대비 편차를 더한다. 대조는 편차 미사용, 고정 기울기 1, 전체 약물 공통 OLS 기울기다. 주 후보는 약물별 기울기를 공통 기울기로 축소한 방식이다. 사용하는 벌점은 약물별 적합 2D 분산 평균에 8을 곱한 값 하나다. 각 비교군 대비 약물 내 두 상관과 환자 내 Spearman·NDCG@5의 짝지은 95% 하한이 모두 0보다 커야 통과한다. 짝지은 재표집 단위는 공여자와 약물이며 반복 분할을 새 공여자로 세지 않는다. 이 보정은 보류 공여자의 실측 2D를 요구한다.
- 동일한 해시의 등록부로 적합 파일과 채점 파일을 분리한다. 예측을 동결한 뒤 별도 채점한다. 새로운 RNA 모델의 외부 검증이나 V0+ 패키지 교체 근거에는 이 사후 실측 대조를 사용하지 않는다.
