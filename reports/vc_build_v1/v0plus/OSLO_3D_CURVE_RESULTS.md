# 공개 3D 농도 곡선 감사

## LICOB 원자료 확인

2026-11-22 접근 감사에서 NCBI PMC 저자원고의 공개 XML과 EMBL-EBI BioStudies의 파일 목록이 일치했다. 두 보충 파일은 Methods PDF와 S1–S13 XLSX다. XLSX의 반응 시트는 동일 표본의 AUC·IC50·Emax 요약값이다. 저자의 NODE 기탁 범위는 WES·RNA-seq·RRBS·단백체·인산화 단백체다. NODE 프로젝트 페이지와 LICOB 웹 포털은 이번 요청에서 각각 HTTP 403을 반환했다. 앞선 기탁 파일 손상과 별개로, 이번에 확인한 공개 경로에서 농도별 반응 웰 파일은 찾지 못했다. [저자원고](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949980/) · [보충 파일 목록](https://www.ebi.ac.uk/biostudies/studies/S-EPMC10949980) · [NODE 파일 감사](STEP1_SCALE_AND_LICOB.md)

iLICOB의 고정 커밋에는 저자 R 코드와 데이터 객체 두 개가 있다. 보관한 오가노이드 객체에서 반응 블록은 50×76 행렬이었다. 소스의 파일 단위 재배포 허가를 확인하지 못해 원본은 G1에 보관했다. 공개 S7과 S8의 불일치 원인은 원 농도–반응 곡선 확보 뒤 검증할 수 있다. [iLICOB 고정 커밋](https://github.com/wu-yc/iLICOB/tree/c65cb2f9305defbf5b87b56a7216d673d6b94a39) · [S7·S8 일치도](LICOB_CROSSING_RESULTS.md)

Table S2로 환자와 표본 소속을 확인했다. 같은 사람의 수술·병변 접미 번호를 한 공여자로 묶었고 Data S1과 공통으로 관측된 150개 PDO의 환자 ID가 일치했다. 자료는 **대장암 간전이**이며 별도 3D 개발 평가에 사용했다. RNA가 있는 자료에서 동일 PDO·전체 FIMM 제품을 서로 다른 run으로 비교할 수 있는 곡선은 80쌍이었다. 이들은 2명·40제품이어서 약물 내 공여자 5명 기준을 통과한 제품은 0개였다. 두 라이브러리는 각각 RNA가 연결된 공여자 26명을 포함하고 서로 겹치는 공여자가 없다. 전체 FIMM 코드가 같으면서 각 라이브러리에서 10명 이상 실측된 제품은 20개였다. [라이브러리 및 농도 지원](oslo_public_dose_bridge.json)

LICOB와 이름이 같은 약물 14개 중 S5의 전체 농도 범위를 포함한 후보는 **ceralasertib** 하나였고, 최고 농도를 포함한 후보는 ceralasertib·panobinostat·regorafenib 세 개였다. Regorafenib은 `FIMM100364-003`의 43곡선에서 최고 농도를 포함했고 `FIMM100364-001`에서는 없었다. 이 수치는 출판사 이름과 실제 투약 농도를 연결한 결과다. 제품 간 정확한 구조 확인과 다약물의 전체 농도 지원이 추가로 필요하다.

후속 CAS·입체 구조 대조를 거쳐 parent 수준에서 13약물을 등록하고 기존 2D와 Oslo 3D를 결합해 LICOB에서 평가했다. [Oslo–LICOB 전이 성적](OSLO_LICOB_TRANSFER_RESULTS.md)

등록 `5187b3f`의 G1 작업 `33684`가 RNA·약물 곡선을 만들었다. `ed9f703`의 `33685`가 생존율 열을 제외한 등록 정보로 두 라이브러리 및 LICOB 농도 지지를 확인했다. 두 작업 모두 종료 코드 0이다. 등록 SHA-256은 `4d6441a1126551ba5addd7cc4d5cecac7d6c25cfcda1be28100bbb5f292eeb58`, 농도 감사 SHA-256은 `935cd73545d42871fb8d757d28f6bb63ad0da88c0bc2a5ad378e3e4b76b48551`이다.
