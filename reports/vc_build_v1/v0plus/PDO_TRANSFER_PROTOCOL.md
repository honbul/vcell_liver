# 공개 PDO에서의 2D→3D 반응 전이 개발 검증

IMPROVE 1–3 및 Pilot 1의 비간암 오가노이드 57모델을 사용한다. 2D 정정 코어와 CTRPv2·PRISM 확장 패널에 정확한 parent가 있는 1,244행을 공통 평가 지지로 고정한다. 네 연구를 각각 보류하며, 보류 연구의 PDO ID가 다른 연구에 나오면 해당 적합 행도 모두 제거한다. 확인용 간암 발현과 실측은 이 개발 실험 범위 밖이다. [자료 등록과 해시](IMPROVE_PDO_AND_GDSC_SUPPORT.md)

| 보류 연구 | 채점 PDO | 약물 | 채점 행 | 적합 3D와 같은 약물의 채점 행 |
|---|---:|---:|---:|---:|
| IMPROVE 1 | 4 | 39 | 156 | 156 |
| IMPROVE 2 | 5 | 16 | 80 | 80 |
| IMPROVE 3 | 10 | 39 | 390 | 110 |
| Pilot 1 | 47 | 17 | 618 | 383 |

- GDSC2·CTRPv2·PRISM의 정정 반응과 등록 확장 자료를 사용해 2D 약물 평균, 약물별 Ridge, 구조 커널을 적합한다. 2D RNA 공통 유전자의 샘플별 순위, 경로·TF, Chronos와 변이/CNV 보조 정보 및 ECFP·표적 커널을 사용한다. 기존 공동 반응 보정과 벌점 4를 유지한다. Ridge는 벌점 1,000, 유전자 512개와 경로·표적 표현을 사용한다. 2D 예측을 먼저 고정하고 PDO 실측을 읽지 않는다. 질의 RNA는 각 표본 독립 변환에만 사용한다.
- 다른 연구의 등록된 3D 반응을 사용해 적합 연구마다 AUC 방향을 바꾸고 약물 평균과 2D 앵커 차이의 중앙값을 뺀다. 3D 약물별 보정은 적합 PDO 수 `n/(n+6)`으로 축소하고 지원 연구를 동등 평균한다. 적합 3D 약물의 평균만 쓰는 후보와 기존 2D 잔차에 이 앵커를 붙인 후보를 각각 기록한다.
- 주 후보는 다른 3D 연구에서 같은 연구·약물의 3D 실측 편차와 2D 예측 편차의 차이를 적합한다. 3D 적합 RNA에서 순위·경로·표적 표현을 학습해 선형 .6과 RBF .4의 세포 커널을 만든다. 구조·표적 약물 커널과 벌점 2를 고정한다. 2D 잔차에 평균을 뺀 새 3D 잔차 함수와 3D 보정 앵커를 결합한다. 3D 반응 편차를 직접 적합해 2D 예측 편차 없이 쓰는 절제도 포함한다. 같은 약물을 적합 3D에서 평가하지 못한 행은 각 arm에서 해당하는 2D 예측으로 대체한다. 구조·경로 표현의 표준화에는 적합 PDO만 쓴다.
- 연구별 예측을 따로 동결한 뒤 별도로 채점한다. 전체 지지와 같은 약물 3D 지지를 각각 보고한다. 약물 내 Spearman·Pearson은 PDO 5모델 이상을 원칙으로 하고 IMPROVE 1의 4모델 상관은 기술값으로 표시한다. PDO 내 Spearman·NDCG@5·Precision@5를 함께 기록한다.
- 사전 승격에는 가장 큰 독립 연구 Pilot 1 전체 지지에서 주 후보의 2D 구조 커널 대비 약물 내 Spearman과 Pearson 및 PDO 내 Spearman과 NDCG@5 차이의 짝지은 95% 하한이 모두 양수여야 한다. 추가로 IMPROVE 3 전체의 NDCG@5 차이 하한이 −.01을 넘어야 한다. 약물·모델 교차 재표집은 2,400회이며 PDO 내 비교는 기존 환자 재표집을 쓴다. 여기서의 판정은 비간암 개발에서만 해석한다.
