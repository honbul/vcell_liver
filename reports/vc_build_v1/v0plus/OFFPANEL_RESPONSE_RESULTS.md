## 보조 반응 지원

평가 약물과 연결 구조가 정확히 같은 물질을 보조 패널에서 제외하고 RNA만으로 새 시료를 추론했다. 구조적으로 유사한 별개 물질은 보조 패널에 남겼다. 원 68약물의 67개 연결 구조군을 보조 학습에서 제외했다. 외부 예측에 사용하는 1,014개 적합 세포에서 조직 내 감수성 학습에 지지가 있는 세포는 987개였다. 세 소스의 1,202개 지원 과제는 1,115개 정확 화합물 parent를 포함했다. 같은 parent가 여러 스크린에 있으면 별도 과제로 취급했다. 조직 안에서 측정 8개 이상인 자리에 관측 571,600건이 있었다.

조직 내 반응 특징을 기준으로, 기존 구조 커널, RNA 고유축, 관측 마스크, 조직 내 반응 짝 순열, 조직 평균을 남긴 반응 학습을 비교했다. CPU 사전 확인에서 실제 공개 학습표의 보조 반응이 보류 스크린이나 계통과 겹치지 않는지 확인했다. 별도 작은 행렬에서 결측을 제외한 직접 Ridge 해와 GPU 구현의 산식을 대조하고 부분 행 테스트에서 예측 불변성과 학습 커널의 양의 준정부호를 확인했다. 기존 테스트 29개가 통과했다.

## 소스 비교군 재현

이전에 동결한 직접 확장 실험과 이번 실행에서 같은 입력으로 만든 GroupKFold 배정은 991계통군 가운데 630개가 달랐다. 과거 환경은 scikit-learn 1.6.1·NumPy 2.2.6이고 이번 환경은 scikit-learn 1.0.2·NumPy 1.26.4다. 과거 환경으로 이전 세 fold의 배정을 재현했다. 소스 예측 `34146`은 대응 검사에서 멈췄다. `34148`은 실행되지 않았다. 이전 점수를 재사용할 수 없는 이유를 입력·예측 식별자로 확인하고, `bfaaba8`에서 현재 fold에 구조 커널·약물별 Ridge·약물 평균을 같은 설정으로 적합했다. 외부의 두 동결 파일과 설정은 원래 명세 `6eed7fa`를 적용했다.
