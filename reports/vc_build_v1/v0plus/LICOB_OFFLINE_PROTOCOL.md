# LICOB 76약물 V0+ 오프라인 재현

공개 LICOB에서 비교한 1,186약물·670,830행의 2D 학습 모델을 같은 14,421유전자와 76개 약물 등록으로 CPU에서 실행한다. 43개 오가노이드의 알려진 외부 동결 예측을 다시 생성하는 입력·배포 검증이다. 기존 2D V0+ 배포의 68약물·17,871유전자 조건은 별도 계약이다. [LICOB 기존 검증](LICOB_COLD_RESULTS.md) · [기존 CLI 모델 카드](STRUCTURED_RELEASE_MODEL_CARD.md)

- 학습에는 등록된 GDSC2·CTRPv2·PRISM20Q2 반응·기저 RNA와 공개 보조 특징 및 고정된 76약물의 구조·표적 주석만 사용한다. 6조건을 동일한 벌점·약물 커널·나머지 반응으로 재적합해 학습 반응에서 산출한 CPU 체크포인트를 만든다. 3D RNA 값은 재현 단계에서만 모델로 보낸다. 기존 비교의 동결 및 집계 점수는 해시로 연결한다.
- 이 패키지의 입력에만 순위 보존형 가공 RNA를 허용한다. 순위 적용 전 수치는 부호를 유지하며 행 내 발현 순서가 의미 있어야 한다. 전체 및 선택 유전자 커버리지 85%와 비상수 입력을 요구한다. 일반 TPM·log₂(TPM+1) 및 카운트 입력은 기존 계약을 따른다. 약물마다 동일 등록키의 2D 학습 관측 여부, 화학 이웃 유사도와 미지정 입체 위치 수를 출력한다. 기본 선택은 이전 비교의 주 후보 상호작용 모델이다. 미등록 화합물은 상태로 반환하고 예측하지 않는다.
- 동결 예측 19,608쌍의 정확한 ID와 6조건을 모두 CPU에서 재현한다. 조건별 최대 절대 오차는 5e-5 이하, 단독 처리와 일괄 처리 차이는 5e-6 이하여야 한다. 80% 유전자만 있는 가공 RNA, 상수 RNA와 미등록 약물의 거절을 확인한다. 기존 패키지에 이 가공 형식을 전달했을 때 형식 수준에서 거절되는지도 확인한다.
- 이미 공개한 TCGA-LIHC 원발 종양 16명의 같은 aliquot 카운트·TPM을 사용한다. 정정 유전자 길이로 TPM을 재현한 입력과 발행 TPM의 76약물 점수 최대 절대 차이 5e-5 이하, 종양별 Top-5 집합 16/16 일치를 재현 조건으로 정한다. 반응 자료 없는 RNA 형식 대조다.
- 이 회차에서는 기존 외부 반응을 재채점하지 않는다. 패키지는 앞선 외부 성적과 지원 구분을 그대로 표시한다. 동결 대비 재생 로그와 CPU 검증 영수증을 보관한다. 체크포인트와 RNA는 G1의 승인된 저장소에 둔다.

## RNA만 연결한 44번째 HCC 모델

공개 RNA 및 보충표 S1의 HCC 등록키로 앞서 채점한 43개의 여집합을 확인한다. 익명 모델 코드 HCCO42에 대해 S6·S7·S8의 ID 열에 대응 행이 없는지 검증한다. 동일 동결 패키지의 기본 모델로 76약물 값을 생성하고 커버리지와 해시를 기록한다. 이 한 모델은 발현 입력 재현에만 사용한다.
