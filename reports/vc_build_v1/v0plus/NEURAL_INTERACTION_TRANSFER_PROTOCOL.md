# 약물별 상호작용을 직접 학습한 분자 신경망과 구조 커널의 결합

기존 분자 신경망은 약물마다 같은 방향으로 움직이는 계통 감수성도 학습한다. RNA 가산 대조의 약물 내 Spearman은 LIMORE .334, LICOB −.091이었다. 공통 효과에 기대는 정도를 줄이고, 구조 커널이 놓친 약물별 계통 반응을 보완할 수 있는지 평가한다. [근거가 된 기술 비교](SPARSE_PATHWAY_TRANSFER_RESULTS.md)

- 정정 65,678행의 GDSC2·CTRPv2·PRISM을 학습한다. 3계통 fold, 세 스크린과 계통의 동시 보류, 세 스크린 공동 적합을 유지한다. 독립 LIMORE 50계통·68약물 및 LICOB 응답이 연결된 43 PDO·성인 38공여자·53약물을 쓴다. 이 두 외부 코호트에는 이전 채점 이력이 있다.
- 기존 V0+ inductive, 192 hidden·70 epochs, seed 11711과 배율 .5를 고정한다. RNA ranks 및 경로/TF, 약물 ECFP, 표적 attention과 gating, Chronos 및 변이·CNV 보조 정답, 소스 간 CORAL을 두 적합에 동일하게 쓴다. 각 분할은 평가 RNA를 정렬에 전달하지 않는다. 이전 적합에서 후보 크기와 배율을 어떻게 선택했는지 기록하되, 이번 분할이나 외부 실측에서 다시 선택하지 않는다.
- 주 적합은 각 학습 스크린·종말점에서 관측된 세포주×약물 행에만 균등 가중해 약물·세포주 공통 효과를 사영 제거한다. 상호작용 잔차를 Smooth L1의 정답과 두 축 순서 손실의 비교값으로 모두 쓴다. 대조는 원 규약처럼 약물 평균 기준 잔차에 Smooth L1을 적용하고 세포주 내 순서 손실에 소스 절대 반응을 사용한다. 나머지 구조·학습량은 같다.
- 학습된 두 신경망을 각 적합 RNA의 전체 학습 약물에 적용한다. 약물별 신경망 출력의 학습 시료 평균을 기록한다. 평가 시에는 한 번에 한 시료의 전체 학습 약물 예측에서 해당 평균을 빼고, 그 시료의 전 약물 평균을 뺀다. 각 요청 약물의 이 잔차 × .5를 고정 구조 커널 예측에 더한다. 신경망의 가산 성분과 평가 코호트의 모집단 통계는 결합에 전달하지 않는다. 원 소스 정답 신경망의 동일 결합, 구조 커널 단독, 기존 Ridge·약물 평균과 외부 CellHit·CODE-AE·Velodrome·V0+를 같은 지지에서 비교한다.
- 개발의 세 스크린 보류 중 두 곳 이상과 두 외부 코호트의 각각에서 주 결합은 구조 커널·원 정답 결합 대비 약물 내 Spearman·Pearson 차이 95% 하한 >0, 시료 내 Spearman·NDCG@5·Precision@5 차이 하한 >−.005를 만족해야 한다. 외부에서는 약물×시료 잔차 PCC 차이의 두 대조 대비 95% 하한도 >0이어야 한다. 외부 공개 세 비교군의 같은 순위 지표를 나란히 제시한다. 간암 TKI, 표적·키나아제·HDAC, 비특이 세포독성 층을 보고한다.
- G1 GPU에서 예측을 해시로 동결한 뒤 별도 CPU에서 채점한다. 개별 시료 RNA, 약물반응, 예측과 가중치는 G1에 둔다.
