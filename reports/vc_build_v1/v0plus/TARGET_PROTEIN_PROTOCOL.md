# 약물 표적 RNA를 보존하는 단백질 잔차의 간암 전이

선행 평가에서 2D 단백질 감독으로 만든 전역 표현은 LICOB에서 같은 유전자의 기저 RNA보다 실제 단백질 순위를 덜 보존했다. 이번에는 약물별 표적 RNA를 그대로 제공하고 동일 유전자 RNA로 설명한 양을 제외한 단백질 성분만 따로 예측한다. 정정 GDSC2·CTRPv2·PRISM, 등록 스크린·계통 공동 보류, LIMORE 성인 HCC 50계통·68약물, LICOB 성인 38공여자·53약물을 유지한다. 두 외부에는 이전 채점 이력이 있다. [전역 단백질 실험과 원자료 감사](PROTEIN_PROXY_RESULTS.md)

- ProCan과 LICOB 단백질체의 기존 등록 영수증과 파일 해시를 고정한다. 등록 약물 표적의 정확한 유전자명만 사용한다. 학습 RNA와 소스 실측 단백질을 계통별로 평균한다. 유전자별 100계통 이상이면서 단백질체가 연결된 적합 계통의 60% 이상이 측정된 표적을 쓴다. 분산이 0이면 제외하고 단백질 결측은 해당 회귀의 학습 행에서 제외한다. 관측 단백질을 유전자별 중간 순위의 정규 점수로 변환한다.
- 적합 분산 상위 256개 비표적 RNA와 기존 PROGENy·Hallmark·DoRothEA 경로·TF를 문맥으로 사용한다. 두 단계 최소제곱으로 각 단백질 정규 점수와 문맥에서 절편과 같은 표적 RNA를 사영 제거한다. 이 잔차들의 Ridge 벌점을 1000으로, 약물 반응 커널 벌점을 기존 4로 고정한다. 모든 질의에서 적합 RNA·단백질로만 추정한 기준과 계수를 사용한다. 단일 RNA와 배치의 표적 표현 차이를 2×10⁻⁵ 이하로 확인한다.
- 기존 ECFP·표적 공유 약물 커널, RNA·경로·Chronos·변이/CNV 대리 표현, 앵커와 관측 가중을 유지한다. 약물별 선형 항으로 각 등록 표적의 직접 RNA를 추가한다. 이 항은 합계 평균 제곱 기여 .10에 맞추고 다중 표적은 동일 가중한다. 단백질이 지원되는 표적에만 잔차를 추가한다. 주 후보는 잔차 주효과 .05와 표적 RNA×잔차의 곱 .05다. 곱과 각 항은 적합 평균과 표준편차 하한 .05로 표준화하고 절댓값을 8로 제한한다. 잔차 주효과만 .10을 준 절제와, 올바른 표적 RNA를 유지하면서 잔차를 비표적 유전자 잔차로 교체한 대조를 둔다. 교체 유전자는 다른 약물의 적격 표적 중 그 약물의 전체 등록 표적과 겹치지 않는 것으로, 적합 관측률 절대 차이가 최소인 후보를 우선하며 이름으로 동률을 푼다. 한 약물에 대조 유전자를 중복 사용하지 않는다. 교체 지원이 없으면 세 조건 모두 직접 RNA를 사용한다.
- LICOB 기술 비교는 성인 공여자의 75% 이상에서 측정된 적격 표적에서만 실측 단백질을 사용한다. 공여자 평균에 대한 단백질 정규 점수를 만들고 보류 단백질에서 같은 표적 RNA의 공여자 수준 선형 성분을 제거한다. 그 잔차와 RNA 기반 잔차에 동일한 공여자 정규점수 변환과 측정 마스크를 적용한다. 각 값을 동결한 주 후보의 잔차 입력에 대입해 같은 계수로 예측한다. 두 기술 arm의 약물 성적과 실제 단백질 잔차 대 RNA 기반 잔차의 표적별 공여자 간 Spearman을 함께 산출한다. 이 변환은 3D의 무라벨 코호트 통계를 사용하며 RNA 전용 주 후보와 별도다.
- 승격에는 보류 스크린 3곳 중 두 곳 이상과 각 외부에서 주 후보가 구조 커널·직접 표적 RNA·교체 대조 모두에 대해 약물 내 Spearman·Pearson 차이의 짝지은 95% 하한 >0, 시료 내 Spearman·NDCG@5·Precision@5 하한 >−.005를 충족해야 한다. 외부는 구조 커널 대비 약물×시료 잔차 PCC도 하한 >0을 요구한다. 약물 평균·약물별 Ridge 및 외부 CellHit·CODE-AE·Velodrome·V0+를 같은 행에 둔다. 전체 패널, 보류 스크린, 기전군, 단백질 지지 수를 함께 보고한다. 기술 arm과 절제로 주 후보를 바꾸지 않는다.
- 코드와 기준을 실행 전 커밋한다. 단백질 측정 및 RNA를 사용할 수 있는 예측 작업은 실측 반응의 입력 없이 예측을 동결한다. 별도 CPU 작업에서 해시를 검증하고 결과를 연결한다. 환자와 모델별 원본은 G1에 보관한다.
