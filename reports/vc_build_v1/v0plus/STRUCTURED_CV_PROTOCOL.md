# 계통·assay 동시 보류에서의 다중약물 커널

V0+ 비선형 모델과 약물별 Ridge가 서로 다른 순위 축에서 앞섰다. 이번 개발은 약물 유사성으로 반응 함수를 부분 공유하고 알려진 약물의 개별 잔차를 유지할 때 두 순위 축이 함께 개선되는지 평가한다. 이전 외부 평가의 점수와 데이터 사용 이력은 기록으로 보존한다. 이번 단계는 GDSC2·CTRPv2·PRISM20Q2의 65,685개 학습 측정만 사용한다. [기존 외부 성적](STEP4_EXTERNAL_RESULTS.md) · [독립 3D 성적](WONG_3D_EXTERNAL_RESULTS.md)

- 기존 991개 계통의 바깥쪽 3-fold를 그대로 쓰는 pooled 비교와, 동일 바깥쪽 계통을 보류하면서 한 소스의 실측을 전부 적합과 안쪽 선택에서 제외하는 assay 보류를 함께 실행한다. 시험 소스에서 측정한 약물 중 나머지 적합 소스에서도 측정된 약물만 사전 등록한다. CTRPv2 35약물·GDSC2 29약물·PRISM20Q2 13약물을 예상한다. 세 소스는 각각 native AUC 방향으로 채점한다.
- 전체 기저 RNA의 표본 내 순위, 적합 전용 유전자 표준화와 선형·RBF 커널을 사용한다. Hallmark·PROGENy·DoRothEA 서명, 적합 셀만으로 RNA에서 추정한 Chronos 및 HCC 변이/CNV를 별도 커널로 합친다. 약물 커널은 독립 약물 항, ECFP4 Tanimoto, 표적 유전자 코사인, 공통 반응 항으로 구성한다. 순서대로 가중치는 .65/.15/.10/.10이다. 약물별·소스별 평균을 제거한 원 소스 보정 잔차를 적합하고 같은 약물의 각 소스 총 가중치를 같게 한다. 최종 점수는 기존 방식의 약물 평균에 예측 잔차를 더한다. 질의 RNA가 다른 질의 행의 예측에 들어가지 않는다.
- 주 후보는 구조 커널이다. 약물 공유 제거, 서명·표적·Chronos·변이/CNV를 묶어 제외한 RNA+구조, 동일 지원의 고정 Ridge+구조 커널 평균을 보조로 비교한다. 각 커널 arm의 벌점 4/16/64 및 잔차 배율 .25/.5/1 중 안쪽 2-fold에서 기존 선택식으로 하나를 고른다. pooled Ridge·CellHit·V0+와 약물 평균은 같은 fold의 기존 동결 배열을 확인해 사용한다. assay 보류 Ridge와 약물 평균은 두 적합 소스에서 다시 고르고 적합한다.
- 12개 GPU 작업의 바깥쪽 예측을 해시로 봉인하고 별도 채점에서 합친다. 약물 내 lineage Spearman·Pearson, lineage 내 약물 Spearman·NDCG@5·Precision@5를 보고한다. 약물 내 차이는 계통·약물 짝지은 800회 재표집, 계통 내 차이는 기존 짝지은 계통 부트스트랩을 사용한다. 공통 지지의 소스 통계와 세 소스 동등 평균을 기록한다.
- 주 후보를 새 외부 확인으로 넘기는 기준은 pooled와 세 assay 보류 조건 모두에서 약물 내 Spearman의 Ridge 대비 짝지은 95% 구간 하한이 0을 넘고, lineage 내 Spearman과 NDCG@5의 약물 평균 대비 95% 구간 하한이 지원된 각 assay에서 모두 0을 넘는 것이다. 보조 후보의 성적은 이 판정을 소급해서 바꾸지 않는다.
