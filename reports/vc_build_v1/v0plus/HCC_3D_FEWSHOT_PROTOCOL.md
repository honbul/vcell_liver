# 간암 오가노이드의 소수 환자 보정 개발 평가

공개 LICOB와 Wong의 21개 exact parent에서 연구 간 3D 전이가 사전 기준을 통과하지 못했다. 이번 개발 평가의 질문은 대상 연구의 소수 환자 반응을 사용할 수 있을 때 새 환자의 감수성과 약물 순위가 나아지는지다. 이미 채점한 연구에서 환자를 다시 보류하므로 새 독립 확인에는 산입하지 않는다. [21약물 연구 간 성적](HCC_3D_21DRUG_RESULTS.md)

- LICOB 29명·34 PDO와 Wong 10명·10 PDO를 환자 단위로 나눈다. 정렬한 환자 ID를 `31041+i`, `i=0…4`의 시드로 섞은 5회 2-fold에서 매번 양쪽을 보류한다. 한 환자의 지역은 함께 이동한다. 적합 환자는 같은 시드에 `1000+fold`를 더해 정렬한 순서의 앞에서 뽑는다. LICOB는 2·4·8·12명, Wong은 2·4명을 서로 중첩된 예산으로 쓴다. 반복마다 각 환자의 보류 예측을 한 번 내고 모델은 매번 재적합한다. 예산별로 다른 반복의 예측을 평균한 앙상블은 만들지 않는다.
- 동결 비교군은 정정 70약물 소스에서 만든 2D 약물 평균, 2D Ridge, 2D 구조 결합, 2D CellHit, 반대 연구 3D를 섞은 2D 결합이다. 새 arm은 대상 연구의 단순 약물 평균, 소스 평균과 축소 결합한 약물 평균, 같은 평균 위에 2D 편차 또는 반대 연구의 3D 편차를 더한 모델, 대상 연구의 약물별 RNA Ridge, 주 후보 `local_residual_kernel`이다. 앞서 고정한 정확한 약물·RNA 지원을 그대로 적용한다.
- 적합 환자의 지역 AUC를 환자별 평균하고 약물별 평균을 계산한다. 2D 약물 평균을 적합 AUC의 약물 간 표준편차와 평균에 맞춰 양의 기울기로 변환한다. 기준선은 대상 연구 평균에 `n/(n+4)`, 단위 변환한 2D 평균에 `4/(n+4)`를 준다. 같은 변환 기울기로 2D 및 반대 연구 3D 편차를 옮기고 각 약물의 적합 환자 편차 평균을 빼 준다. 이 과정은 대상 연구의 보류 AUC·RNA 통계를 사용하지 않는다.
- RNA 특징은 사용하는 적합 환자와 반대 연구의 라벨 없는 RNA에만 고정한다. 표본 내 순위, 고변이 512유전자, 표적 발현과 Hallmark·PROGENy·DoRothEA 서명을 사용한다. 단독 RNA Ridge는 약물별 선형 항으로 적합한다. 주 후보는 보정된 2D 편차를 더한 뒤 남은 대상 연구 실측 차이를 비선형 RNA×ECFP·표적 구조 커널로 적합한다. 손실에서 한 환자의 지역 가중 합은 1이다. 약물별 편차 표준편차는 적합 표본 분산에 `n/(n+4)`, 약물 전체 평균 분산에 `4/(n+4)`를 준 뒤 제곱근을 취한다. 두 RNA 모델 모두 벌점 2를 고정한다. 새 후보나 배율을 고르는 안쪽 탐색은 없다.
- 주 보정 예산은 두 코호트에서 4명이다. 주 후보는 같은 환자 정보를 가진 축소 약물 평균과 보정 2D 모델 각각을 약물 내 두 감수성 지표와 환자 내 Spearman·NDCG@5에서 짝지은 95% 하한 >0으로 이겨야 한다. Precision@5, 모든 예산 및 fold 성적과 고정 약물군을 함께 낸다. 감수성 상관은 같은 보류 fold 안에서 계산하고 fold·약물을 동등 가중한다. 95% 구간은 환자와 약물에 공통 지수 가중을 준 2,400회 베이지안 부트스트랩으로 계산한다. 각 환자의 가중을 다섯 반복에 공유한다. Spearman의 각 fold 원래 순위에 가중 상관을 계산한다. 환자 내 순위의 구간은 환자별로 반복 차이를 평균한 뒤 환자를 짝지어 일반 재표집한다.
- 각 예측 작업은 해당 fold의 최대 적합 예산 AUC와 모든 발현, 보류 ID를 받는다. 예측 동결의 해시와 모든 보류 행을 확인한 후 별도 작업에서 보류 AUC를 연다. 사전 판정과 기존 외부 검증 결과를 따로 보존한다.
