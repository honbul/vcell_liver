# 구조 커널의 오프라인 RNA 예측 패키지

정정한 GDSC2·CTRPv2·PRISM20Q2 65,678행의 구조 커널(벌점 4, 출력 배율 1)과 동일 행에서 이미 고정한 약물 평균·약물별 Ridge를 V0+ CLI의 별도 68약물 패키지로 제공한다. 등록 70약물 V0+ 패키지를 유지한다. 이 68약물 패키지에는 정확한 구조의 RNA 순위·경로/TF·약물 표적 커널과 학습 RNA에서 예측한 Chronos·유전체 보조 표현이 들어간다. 질의에는 투약 전 bulk RNA와 화합물만 제공한다. 학습원 계통과 겹치지 않는 LIMORE 50계통의 기존 동결 결과를 재현하는 배포 검사다. [정정 학습표와 참조 성적](LIMORE_CORRECTED_RESULTS.md) · [기존 V0+ 70약물](V0PLUS_CORRECTED_MODEL_CARD.md)

- 구조 커널은 필수 학습 축, 표준화 계수, PROGENy/Hallmark/DoRothEA 가중, 보조 회귀, 적합 표현, 가중 선형계의 계수를 CPU 체크포인트에 보낸다. 예측에서 질의끼리 통계를 공유하지 않는다. 기존 CLI의 RNA 검증, 정확한 parent 매칭, 85% 전체·선택 유전자 커버리지, 출력의 약물 평균과 개인화 편차를 적용한다. 보조 회귀의 고변이 768개를 선택 유전자 축으로 사용한다. 훈련 원자료 및 체크포인트는 G1에 보관한다.
- 학습과 패키지 생성에서 외부 반응은 읽지 않는다. 원래 LIMORE 정정 채점과 예측 SHA-256을 검증해 패키지에 연결한다. 구조 커널·Ridge·약물 평균의 기존 동결 기술값을 유지한다. 동일한 50×68 예측의 새 CPU 재현과 단독 샘플 대 배치 실행에서 구조 커널의 최대 절대 차이는 `5e-4` 이하여야 한다. Ridge와 약물 평균의 동결 수치 허용치는 각각 `1e-6`, `1e-9`다. 신규 데이터로 반복 외부 채점하거나 모델 설정을 고르지 않는다.
- 실제 Wong 원발 환자 조직 RNA 10개에서 등록된 요청 지원 수와 발현 커버리지를 측정한다. 이미 등록한 LICOB RNA 43모델에서도 같은 85% 기준으로 지원 수를 기록한다. 두 자료의 반응은 여기서 읽지 않는다. 성공한 조직 입력의 출력은 연구용 감수성 점수다. 환자 치료 결과의 임상 성능은 별개다.
- 검증한 패키지 경로와 SHA-256, CPU 실행 시간·메모리, 샘플별 최소 유전자 커버리지, 동일 조건에서의 예측·보류 행 수를 보고한다. 세 모델의 수치 재현과 발현 부족·미등록 약물 보류를 모두 확인한 뒤 사용 경로를 공개한다.
