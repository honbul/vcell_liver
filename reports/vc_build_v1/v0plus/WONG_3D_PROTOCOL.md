# Wong 3D HCC 오가노이드 독립 공개 평가

Wong 등의 공개 보충 엑셀 S1·S3·S6와 S7의 표본·약물 헤더를 사용해 지원을 먼저 고정한다. S1에서 성인 HCC로 확인한 환자, S6의 기저 TPM 및 S7에서 같은 PDTO ID를 사용한다. 한 환자의 기저 RNA 한 개와 약물별 평균 AUC 한 개를 채점한다. Parental tissue, normal/adjacent-derived organoid, 같은 환자의 2D PDTCL, ATCC 행은 제외한다. 기존 GDSC2·CTRPv2·PRISM 학습 원천과 별개 연구에서 확립한 성인 HCC 오가노이드다. 논문·보충 문서와 데이터 파일의 해시는 기록하고, 원 워크북은 G1에 보관한다. [원논문](https://doi.org/10.1016/j.jhepr.2025.101426) · [저자 공개 워크북](https://www.surgery.cuhk.edu.hk/downloads/JHep_Reports/Wong%20AM%20et%20al_JHep_Reports_Supplementary%20Tables_v1.xlsx)

1. S3의 100약물을 Broad 2020-03-24 공개 구조 표의 전체 `BRD-…-lot` ID와 대조한다. Broad에서 구조가 해소되지 않는 행은 S3 CAS에 대한 PubChem 완전 일치 조회로 보완한다. RDKit 표준화 후 전체 isomeric parent InChIKey를 기존 학습 패널과 대조한다. S7 행과 S3 약물명을 비교할 때 출판사의 Afatinib dimaleate 및 Rucaparib phosphate 생략 표기 두 개만 명시적으로 연결한다. 반응값과 공백 여부는 등록·학습·동결 뒤 별도 채점에서 읽는다. [Broad 등록](https://repo-hub.broadinstitute.org/repurposing) · [Broad 구조 표](https://s3.amazonaws.com/data.clue.io/repurposing/downloads/repurposing_samples_20200324.txt)
2. S6 기저 TPM은 log2(TPM+1)로 바꾼다. 유일 기호로 식별되는 소스 공통 유전자만 사용한다. 내부 3-fold에서 잠근 feature recipe, 구성, 배율을 사용해 GDSC2·CTRPv2·PRISM만으로 재적합한다. 모든 비교군에 같은 유전자 교집합과 같은 오가노이드·약물 격자를 준다. 등록 방법은 약물 평균, 약물별 Ridge, CellHit, Velodrome inductive, CODE-AE inductive, V0+ inductive, Ridge+V0+ 고정 평균 7개다.
3. 각 독립 Slurm 예측 파일을 해시로 잠근다. 계산이 끝나면 같은 격자와 네임스페이스를 검증하고 비교군별 예측을 병합해 최종 동결한다. 별도 Slurm 채점에서만 S7의 AUC mean을 열고 미측정값을 공통 채점 격자에서 뺀다. 논문의 normalized inhibition AUC와 동일하게 높을수록 감수성 방향으로 처리한다.
4. 기존 공동 지표를 그대로 사용한다. 약물 내 계통 Spearman·Pearson은 약물별 5명 이상, 세포 내 Spearman·NDCG@5·Precision@5는 환자별 5약물 이상의 관측에서 보고한다. 약물·환자 교차 재표집과 짝지은 환자 재표집으로 구간을 추정한다. V0+의 같은 약물 환자 구별과 약물 평균 대비 환자 내 Spearman·NDCG@5 개선을 함께 확인한다. V0+, Ridge, CellHit의 차이와 약물군별 값을 보고한다. 이 새 공공 확인을 기존 LIMORE·Broutier·LICOB의 채점 이력과 구분한다.
