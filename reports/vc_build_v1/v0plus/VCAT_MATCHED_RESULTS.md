# VCAT SMILES의 연속 간암 약물반응 비교

**VCAT SMILES 전체 모형은 LICOB의 상위 5약물 회수율의 점 추정치가 가장 높았다. 구조 커널·VCAT 혼합은 두 외부의 공동 승격 기준에 미달했다.** 저자 MIT 코드의 VCAT SMILES 전체 구조와 concat 절제를 동일한 소스·계통 분할에서 연속 반응으로 적합했다. Zenodo API가 HTTP 404를 반환해 저자 가중치는 확보하지 못했다. 논문의 주 모형은 LINCS 전사 서명을 쓰고 Yang 코호트에서 이진 분류로 평가했다. 여기에는 기존 채점 이력이 있는 LIMORE·LICOB의 연속 반응을 사용했다. [사전 명세](VCAT_MATCHED_PROTOCOL.md) · [원 논문](https://pmc.ncbi.nlm.nih.gov/articles/PMC13671233/) · [저자 코드 커밋](https://github.com/ChrisChan99999/VCAT/tree/c122e8c3515bb1281e7210d40e585341f36ca956)

GDSC2 보류에서는 등록 척도 보정의 참조가 CTRPv2로 바뀐다. 적합 fold 0의 보정 반응 잔차 표준편차는 CTRPv2 2.18, PRISM 2.39였고, GDSC2가 적합에 포함된 공동 소스의 같은 값은 .100, .120이었다. 따라서 각 fold의 학습 MSE는 스크린 간에 직접 비교할 수 없다. 신경망의 동등 가중 혼합도 기존 등록 앵커 단위를 사용했다.

## 실행 검증

사전 커밋은 `d07eae8`이다. 최초 `34045`의 GRU 계산 검증에서 축소 정밀도의 배치 모양별 차이 .000271이 나타났다. 최초 체인을 정리하기 전에 예측 및 채점 아티팩트 0개를 확인했다. `1570ef9`에서 평가를 FP32의 저자 행별 SMILES 계산으로 복원하고 학습 규약은 유지했다. 최종 14개 동결에서 두 방식의 평가용 GRU 표현 차이는 최대 8.95×10⁻⁷이었다. 단위 입력으로 두 저자 구조의 전체 예측 일치도 검증했다.

G1 GPU `34056`과 `34057`의 개발 666,396개, 외부 56,790개 예측을 동결했고, CPU `34058`, `34059`에서 별도로 채점했다. 양 외부는 1,014개 적합 세포·68약물과 각각 113개, 109개 공통 Chronos/RNA 유전자를 사용했다. 저자 MIT 라이선스와 로드한 5개 코드 파일, 예측 14개의 SHA-256을 대조했다. 기존 테스트 29개가 통과했다. [해시와 작업 ID](vcat_matched_verification.json) · [작업 원장](RUN_LEDGER.tsv)
