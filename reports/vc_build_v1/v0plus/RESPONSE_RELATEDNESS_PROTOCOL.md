# 학습 스크린에서 추정한 약물별 반응 관계의 전이

구조가 다르거나 표적 주석이 비어 있는 약물에도 공유 감수성 기전이 있을 수 있다. 반대로 약물이 비슷해도 민감한 계통이 반대일 수 있다. 등록 구조 커널에 학습 반응에서 추정한 부호 있는 약물 관계를 결합한다. 세포·계통과 스크린을 함께 보류한 기존 3-fold 및 동일 계통 fold의 pooled를 유지한다. 외부는 보정 코어로만 적합한 LIMORE 50계통·68약물과 LICOB 38공여자·53약물이며 모두 앞선 채점 이력이 있다. ## 학습과 대조

- 적합 fold의 각 스크린에서 동일 계통·약물의 척도 정렬 반응을 먼저 평균한다. 관측 마스크는 보존한다. 주 후보는 스크린 내 계통·약물 가산 효과를 제거한 상호작용의 약물 쌍별 Pearson을 사용한다. 동일 계통 40개 이상에서 관측된 쌍에 한정한다. 결측 마스크를 유지하고 약물별 관측을 독립 순열하는 12회 대조에서도 같은 가산 분해를 실행한다. Fisher z에서 그 대조의 평균을 빼 공통 성분 제거 자체가 만드는 상관을 보정한다. 적합 스크린별 쌍의 z 값은 n/(n+100)으로 축소한 뒤 지원 스크린을 동등 평균한다.
- 대각선 1과 지원 없는 쌍 0으로 관계 행렬을 구성한다. tanh 역변환을 적용한 뒤 고유값 음수를 0으로 잘라 PSD로 사영하고 대각선 1로 정규화한다. 구조 약물 커널 .60과 학습 반응 커널 .40을 결합한다. RNA·경로·TF·Chronos·RNA 기반 유전체 보조 특징, 약물 평균 anchor, 원래 척도 정렬·적합 표적·가중, 벌점 4는 그대로 쓴다.
- 비교군은 기존 구조 커널, 가산 성분을 제거하지 않은 반응 상관 커널, 그리고 학습 상호작용 커널의 약물 연결을 바꾼 대조다. 마지막 대조는 같은 커널을 쓰되 지원되는 약물에만 고유 ID 정렬 후 고정 seed 순열을 적용한다. seed 61019로 가산 제거 순열, 82001로 약물 순열을 생성한다. 약물 평균과 약물별 Ridge를 모든 분할에, CellHit·CODE-AE·Velodrome·V0+의 정정 동결본을 외부에 함께 둔다. 외부에서 학습 관계나 배율을 다시 고르지 않는다.

## 판정

- 스크린 보류 3조건 중 최소 2조건에서 기존 구조 커널 대비 약물 내 Spearman·Pearson의 각 짝지은 95% 하한이 0 초과, 계통 내 Spearman·NDCG@5 하한이 −.005 초과여야 스크린 전이 기준을 통과한다. pooled와 Precision@5는 함께 보고한다.
- 두 외부 코호트 각각에서 기존 구조 커널·약물 연결 순열·약물별 Ridge·CellHit 대비 약물 내 두 상관과 상호작용 PCC의 짝지은 95% 하한이 0 초과하고, 계통 내 Spearman·NDCG@5 하한이 −.005 초과해야 외부 전이 기준을 통과한다. 두 기준을 모두 넘을 때 후속 독립 확인 후보로 기록한다. 간암 TKI, 키나아제·HDAC, 비특이 세포독성은 기술 하위군이다.
- 개발과 외부 범위를 명세로 고정해 동시에 예측을 생성한다. 예측에는 보류 계통·스크린 반응과 외부 반응을 전달하지 않는다. 모든 예측을 해시로 동결한 뒤 별도 프로세스에서만 보류 반응을 연결한다. 라이브러리, 학습원, 원시 파라미터와 행별 예측은 G1에 둔다.
