[사전 명세](PAIRED_EXPRESSION_PROTOCOL.md) · [공개 자산 영수증](paired_expression_public_asset.json) · [입력 등록 영수증](paired_expression_registration.json)

## 짝 등록과 동결

GEO GSE36133의 Affymetrix 발현 917건 중 911건을 DepMap 25Q3의 고유 세포주 ID와 연결했다. 반응 학습 코어에는 816개의 짝과 고유 단백질 코딩 유전자 15,737개가 있었다. 매칭은 정규화된 이름이 한 ID를 가리키고 그 ID에 어레이 표본이 하나일 때만 허용했다. 개별 조직에 최소 다섯 짝을 요구해 외부 예측 적합에는 814계통(간 계통 23개)을 사용했다. 학습 쌍으로 구한 동일 조직 내 유전자별 플랫폼 Pearson 중앙값은 LIMORE 유전자 축의 15,737개에서 .845, LICOB의 13,483개에서 .869였다. 소스 보류 적합에는 분할별 493–542개 짝을 사용했고 발현 일치도 중앙값은 .841–.850이었다. 이 상관은 세포주 기저 발현의 일치도다. [GEO GSE36133](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE36133) · [도입 자료의 RMA 설명](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM886917)

공통 유전자 축의 구조 커널에 64차원 RNA 기반 특징을 더하고, 같은 RNA 축의 구조 커널 단독, RNA-seq 잠재 특징, 조직 내 어레이 짝 순열을 비교했다. 별도 조건에서 두 플랫폼 간 일치도가 높은 유전자에 가중치를 줬다. 학습 특징 계산에는 각 분할의 적합 짝만 쓰고 예측에는 해당 시료 RNA를 입력했다. GEO의 원자료 처리 단계에는 기탁 어레이 전체의 RMA 정규화가 포함되어 있어 소스 교차검증에서 이 공개 전처리까지 분할별로 다시 적합한 설계는 아니다. LIMORE와 LICOB는 이전 채점 이력이 있는 기술 평가다.

등록 `34129` 뒤 GPU `34130`·`34131`로 소스 12개 파일(666,396개)과 외부 2개 파일(68,148개)을 동결했다. 사전 명세와 실행 코드는 `766ff57`로 잠갔다. 별도 채점은 `34132`·`34133`에서 수행했다. 작은 CPU 예제로 질의 단독·묶음 계산 일치와 적합 커널의 양의 준정부호 조건을 점검했고 기존 테스트 29개가 통과했다. [14개 동결 영수증](paired_expression_forecast_receipts.json) · [G1 작업 원장](RUN_LEDGER.tsv)
