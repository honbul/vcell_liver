# Oslo 3D의 공여자·라이브러리 동시 보류

Oslo 대장암 간전이 PDO의 원 농도 반응을 사용해, 공여자와 스크린 라이브러리가 동시에 바뀔 때 RNA가 같은 약물의 감수성을 예측하는지 검증한다. 등록 감사에서 두 라이브러리는 공여자 26명씩을 지원하고 공여자가 겹치지 않았다. 이 실험은 HCC 개발 학습원으로 사용하기 전의 별도 3D 개발 검증이다. [데이터 등록 명세](OSLO_3D_CURVE_PROTOCOL.md) · [원 연구](https://pubmed.ncbi.nlm.nih.gov/42208542/)

- 양쪽 10명 이상에서 측정한 동일 전체 FIMM 코드로 제한한다. 제품별 모든 등록 곡선의 공통 최저–최고 로그 농도 범위가 최소 한 자리 로그만큼 넓어야 한다. 그 범위의 33개 로그 등간격 점에서 실측 농도 사이만 선형 보간하고, 0–1 생존율의 음의 정규화 AUC를 주 정답으로 만든다. 공통 최고 농도 생존율의 음수도 기술값으로 보고한다. 한 PDO에서 같은 제품의 여러 run은 종말점별 중앙값을 사용한다.
- 두 방향에서 다른 라이브러리의 반응은 모델에 전달하지 않는다. 적합 RNA에서 순위 발현의 유전자별 표준화와 고변이 512개 선정을 한다. 같은 공여자의 여러 병변에서 나온 약물 관측은 공여자당 합계 가중 1이다. 약물별 가중 평균을 모든 모델의 앵커로 쓴다. 고변이 512개에 대한 독립 약물별 Ridge 벌점은 1,000이다.
- 같은 적합군에서 전 유전자 순위의 선형+RBF 세포 커널을 사용한다. 주 후보는 이 커널 70%와 PROGENy·Hallmark·DoRothEA 가중 경로/TF의 선형 커널 30%의 결합이다. 부가 대조는 경로를 뺀 RNA 커널이다. 약물 커널은 전체 FIMM 제품 코드 동일성 .8과 공유값 .2를 합치고, 양쪽에 동일한 벌점 4를 적용한다. 모든 설정은 고정값이다. 이 회차에는 화학 구조 이름만으로 연결한 LICOB 약물과 LICOB 반응을 쓰지 않는다.
- 약물 평균, 약물별 Ridge, RNA 커널 각각에 대해 주 후보의 약물 내 Spearman·Pearson 차이 짝지은 95% 하한이 모두 0 초과이고, 공여자 내 Spearman·NDCG@5·Precision@5 차이 하한이 모두 −.005를 초과해야 통과한다. 최소 10약물과 라이브러리마다 독립 공여자 20명을 요구한다. 주 판정은 두 방향의 AUC가 모두 기준을 충족하는 경우에만 통과다.
- 입력 등록의 SHA-256, 라이브러리 및 농도 교집합과 모든 예측의 SHA-256을 고정한다. 개별 적합은 자기 라이브러리의 반응만 읽고 상대 라이브러리의 투약 메타데이터와 RNA를 사용한다. 별도 채점에서 두 방향의 적격 공여자를 동일 관측으로 평가한다.
