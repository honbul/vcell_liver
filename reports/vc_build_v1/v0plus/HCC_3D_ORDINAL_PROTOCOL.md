# 공여자 간 순서로 학습하는 간암 오가노이드 전이

같은 약물의 환자별 반응 순서가 배양 연구별 반응 척도 차이에 덜 민감한지 평가한다. 기존 LICOB·Wong·Yang RNA 13,961유전자, 정확 구조 교집합, 연구 전체 보류 분할 및 동결 2D 예측을 유지한다. 보류 LICOB 38명·21약물, Wong 10명·21약물, Yang 74명·공통 TKI 3개를 사용한다. 기존 기술 평가와 동일하게 LICOB 9명의 이전 확인 자료는 모든 적합에서 제외한다. [이전 다중 연구 전이](HCC_3D_STUDY_POOL_RESULTS.md)

- 학습 연구에서 공여자·약물 안의 관측과 2D 예측을 각각 평균한다. 같은 연구·약물을 공유하는 모든 공여자 비동률 쌍을 구성한다. 약물별 총가중과 그 약물에 관측이 있는 연구별 총가중은 같다. 2D 선행점수는 고정 Ridge+구조 커널 예측에서 약물 평균을 뺀 값이다. 약물별 척도는 학습 연구의 2D 편차 표준편차를 동등 평균하고 하한 .02를 준다.
- 기존 3D RNA에서 샘플 내 순위·경로·표적 특징과 비선형 RNA 커널을 쓴다. 전처리는 학습 RNA에서만 적합한다. 공여자 특징은 그 공여자의 RNA 모델 커널 특징의 평균이다. 구조·표적 약물 커널을 결합하고 두 Gram의 양의 고유축을 곱한 선형 상호작용으로 3D 보정을 만든다. 두 Gram은 부동소수점 정밀도로 인해 최대 고유값의 1e-7 미만을 자른다. 시험 연구의 RNA에 적합하는 과정은 없다.
- 주 후보는 2D 선행점수의 공여자 간 차이에 3D 보정 차이를 더하고 logistic pairwise 손실로 순서를 맞춘다. 연속값 대조는 같은 비동률 쌍과 2D 선행점수에 표준화 실측 차이의 절반 제곱 오차를 적용한다. 두 모델은 가중 손실 평균과 커널 특징 계수의 L2 벌점 .02/2를 최소화한다. 결정론적 L-BFGS는 140회까지 사용한다. 2D 선행점수 없이 적합한 순서 모델도 대조한다. 보류 시 주 후보와 연속값 대조는 2D 결합에 학습 척도로 되돌린 3D 보정의 .5를 더한다. 2D 선행점수 없는 조건은 같은 보정을 2D 약물 평균에 더한다. 보류 반응에서 강도나 배율을 고르지 않는다.
- LICOB와 Wong의 두 21약물에서 각각 2D 결합 및 연속값 대조 대비 약물 내 Spearman·Pearson의 환자×약물 짝지은 95% 하한이 모두 0 초과이고, 같은 두 대조 대비 환자 내 Spearman·NDCG@5의 짝지은 하한이 모두 −.005 초과면 순서 학습을 승격한다. 기존 3D 제곱 잔차, 약물별 Ridge, 구조 커널, CellHit 및 약물 평균도 동일 행에서 제시한다. Precision@5와 두 축의 측정값을 함께 기록한다. 공통 TKI 세 약물과 LICOB의 9명은 기술 하위군이다. 3약물에서는 Top-5 지표를 생략한다.
- 보류 연구별 학습 파일, 고정 2D·3D 비교 확정본과 분할 해시를 검증한다. 보류 연구 반응은 예측에 전달하지 않는다. 독립 작업으로 동결한 뒤 별도 채점하고, 원시 발현·반응·예측은 G1에 둔다.
