# 공유·소스별 약물 반응을 분리한 모델 결과

**사전 조건은 GDSC2 보류에서 통과했다.** PRISM 보류에서는 같은 약물의 감수성 순위가 개선됐고, 상위 5개 약물 선별의 약물 평균 대비 하한은 0을 넘지 않았다.

| 보류 조건 | 약물 내 Spearman 기존 → 새 공유 모델 | 짝지은 차이 95% | 약물 내 Pearson 기존 → 새 공유 모델 | 계통 내 Spearman 기존 → 새 공유 모델 | NDCG@5 기존 → 새 공유 모델 | Precision@5 기존 → 새 공유 모델 |
|---|---:|---:|---:|---:|---:|---:|
| 세 소스 학습, 계통 보류 | .370 → .368 | [−.0061, .0016] | .404 → .403 | .731 → .731 | .888 → .887 | .617 → .615 |
| CTRPv2와 계통 보류 | .384 → .381 | [−.0145, .0065] | .428 → .427 | .565 → .555 | .794 → .793 | .489 → .488 |
| GDSC2와 계통 보류 | .368 → .378 | [.0024, .0165] | .446 → .453 | .426 → .415 | .696 → .698 | .411 → .413 |
| PRISM과 계통 보류 | .153 → .158 | [.0005, .0091] | .136 → .141 | .615 → .615 | .846 → .848 | .725 → .726 |

GDSC2 보류에서 새 모델의 약물 평균 대비 NDCG@5 차이는 +.0471 [95% +.0413, +.0531], 계통 내 Spearman 차이는 +.0896 [+.0833, +.0959]였다. PRISM 보류의 NDCG@5 .848은 약물 평균 .850보다 −.0017 [−.0054, +.0019]였다. PRISM 약물 내 Spearman의 기존 구조 커널 대비 차이는 +.0048, Pearson 차이는 +.0050 [+.0019, +.0085]였다.

Ridge와 새 모델을 50:50으로 평균했을 때 약물 내 Spearman은 pooled .378, CTRPv2 .386, GDSC2 .380, PRISM .147이었다. GDSC2에서 기존 Ridge+구조 커널 평균 대비 약물 내 Spearman 차이 +.0067의 95% 구간은 [.0021, .0108]이었다. 나머지 세 조건에서 이 차이의 구간은 0을 포함했다. 소스별 성분의 상대 크기 .25가 12개 fold 중 10개에서 선택됐고 두 fold는 1을 선택했다. 모든 소스에 걸친 공동 승격 조건은 미충족이다.
