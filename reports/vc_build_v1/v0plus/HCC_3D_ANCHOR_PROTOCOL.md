# 약물 기준값만 다른 간암 오가노이드 연구에서 전이하는 검증

이전 다중 연구 실험은 다른 3D 연구에서 환자별 잔차를 배웠고 약물 기준값은 2D에서 유지했다. 이번에는 같은 동결 예측의 약물 기준값만 보정해 환자 간 감수성을 보존하면서 환자별 약물 순위를 개선할 수 있는지 검증한다. 이미 채점 이력이 있는 공개 자료를 쓴 후속 기술 평가다. 각 코호트의 정답을 예측 생성에서 제외한다. [이전 잔차 전이](HCC_3D_STUDY_POOL_RESULTS.md) · [6일 TKI 전이](TKI_GR50_RESULTS.md)

- 기존 leave-study-out 등록을 고정한다. 주 범위는 LICOB 성인 38명·Wong 성인 10명의 각 21공통 약물이다. Yang 74명의 공통 세 TKI와 Sagmeister 성인 6계통의 네 TKI는 보조 기술값이다. LICOB를 각각 적합에 사용하는 경우 이전 29명만 사용하며, Yang에서 초기에 노출된 P1·P2는 원 등록과 동일하게 제외한다. Sagmeister 적합에서 Wong의 네 TKI 지원은 이미 등록한 62약물에서 취한다. 기타 자료는 기존 21약물 등록을 쓴다. Sagmeister의 Table 2 및 같은 환자의 LIMORE AA는 보정에 쓰이지 않는다.
- 다른 연구의 AUC를 감수성 방향으로 정렬하고 같은 공여자의 지역은 평균한다. 각 약물쌍을 같은 공여자에서 비교해 두 약물의 순서 승률을 계산한다. 동점은 0.5승이며, 소스 연구마다 공여자 지지가 5명 이상인 약물쌍만 연결한다. 같은 약물쌍은 연구별 승률을 동등 평균한다. 2D 약물 평균의 중앙값과 IQR로 시작점을 만들고 Bradley–Terry 온도 .7, 2D 기준값으로 향하는 평균 L2 벌점 .05를 고정한다. 연속 차이 대조는 각 연구에서 공여자 AUC의 전체 IQR로 나눈 약물쌍 중앙 차이를 같은 L2 벌점으로 적합한다. 두 결과는 2D 평균의 단위로 환산한다.
- 주 후보는 순서형 3D 기준값에 기존 2D 혼합(Ridge·구조 커널 평균)의 동결 예측에서 원 2D 약물 평균을 뺀 편차를 그대로 더한다. 기준값만 쓰는 상수 대조, 연속 차이 기준값 + 같은 편차, 같은 순서형 기준값을 공유한 Ridge·CellHit·보류 연구 3D 잔차를 함께 비교한다. Sagmeister에서는 기존 구조 커널을 주 편차로 쓴다. 설정, 부호, 잔차 배율은 모두 고정한다.
- 보류 결과를 전달하기 전에 계산한 모든 예측을 동결한다. 같은 약물의 환자 간 예측 편차가 수치 오차 `1e-10` 이내에서 보존되는지 확인한다. 약물 내 두 상관 및 환자 내 Spearman·NDCG@5·Precision@5를 보고한다. 세·네 TKI 패널은 환자 내 Spearman과 Top-1을 쓴다.
- 사전 순위 이득은 LICOB와 Wong 모두에서 주 후보가 기존 2D 혼합 대비 환자 내 Spearman과 NDCG@5의 짝지은 환자 재표집 95% 하한을 0보다 높게 기록할 때다. 공동 개인화 이득에는 같은 3D 기준값 단독 대비 약물 내 두 상관과 환자 내 두 순위 지표 95% 하한 >0도 두 연구에서 요구한다. 약물 내 구간은 공여자와 약물 교차 재표집이다. Ridge·CellHit 및 동일 기준값을 쓰는 모든 비교군을 같은 행에 채점한다.
- 채점 시 별도의 원인 진단을 기록한다. 평가 연구에서 한 공여자를 뺀 나머지 결과로 약물 평균을 계산하고 해당 공여자에 적용한다. 이 진단의 약물 평균과 기준값 교체 + 동결 2D 편차의 환자 내 수치만 보고한다. 수행 명세, 데이터 접근 및 임상 적용 여부에서 이 진단은 전이 예측과 구분한다.
