# Adult ICC to held adult HCC transfer on the LICOB assay

The public LICOB matrix has baseline RNA and S6 measurement identifiers for 12 adult intrahepatic cholangiocarcinoma (ICC) models as well as the existing adult HCC cohort. Leave all HCC records out of this ICC transfer estimator. This adds same-study assay supervision with a distinct histology. Use Wong to check transfer beyond the study and LIMORE to check the 2D axis. The original HCC external validation and full 76-drug benchmark remain in the project record. [LICOB published study](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949980/) · [Public expression provenance](LICOB_WIDE_RNA_PROTOCOL.md)

- Verify old LICOB and molecular archives. For ICC require S1 exact ICC histology and adult age, S6 row, and the public baseline RNA all match the same model. Use the 12 models and the 53 exact registered LICOB-core drugs. Exclude combined liver cancer and pediatric hepatoblastoma. Require no overlap with HCC model or donor keys and no same-patient S1 note for these ICC models. Verify the processed RNA values against the decodable NODE prefix for these same ICC samples. The register job exports ICC expression and S6 values only. Prediction processes consume the separated ICC files. The public donor key and footnote audit cannot establish independence beyond the study metadata. HCC outcomes are opened only in the separate scoring job.
- Fit a 2D GDSC2·CTRPv2·PRISM structured kernel on the corrected source. Use PROGENy/Hallmark/DoRothEA, inferred Chronos and driver/CNV, ECFP and drug target features and ridge penalty 4. Within each evaluation platform use the same intersected RNA gene names for the two training resources and held input. Run the 2D kernel on the 12 ICC profiles and target query. The matched 2D arm uses the same fit and RNA axis.
- In ICC map negative S6 AUC to the 2D output scale, using the ratio of IQRs of per-drug means of the two quantities, clamped to .25–4. Let the intercept be the median across the 53 differences after applying the slope. Decompose the difference between transformed ICC measurements and 2D predictions in the complete ICC matrix into drug mean, shared sample and interaction. Apply half the drug mean difference to supported compounds as an anchor control. Train the correction of the interaction with the ICC and crossed query cell-structure kernel blocks, centered on ICC fit genes and donors, and the submatrix of the original chemical kernel centered on all 53 ICC drugs. Use the same ridge penalty 4 with unit weights and half the output. Set the added terms to zero outside the 53-compound map. The primary model combines anchor and interaction corrections. Include interaction only and a within-ICC donor rotation of the response interaction (seed 20327) with the same anchor, predictions and kernel settings. The latter preserves the response matrix and breaks RNA/response correspondence.
- Use LIMORE 50 × 68, LICOB 43 × 53 with adult aggregation to 38 donors, and the core-supported 27 of the registered Wong drugs in 10 donor PDOs. All three HCC cohorts have prior evaluation exposure. LICOB is a same-study histology holdout and Wong is a different-study evaluation of the ICC bridge. Comparators on the same fixed support are drug mean, Ridge, the frozen structural kernel, CellHit, CODE-AE, Velodrome and V0+, before and after giving them the same 3D drug offset as the primary model. Wong frozen comparators use the previously registered extended 2D source training. The ICC-adjusted outputs use an individual input RNA and the fixed bridge, without target-population calibration.
- Freeze predictions and the input SHA-256 before scoring. Apply crossed donor/lineage and drug resampling (1,000) and paired within-donor intervals. Require both within-drug correlation difference lower bounds (>0) and within-sample Spearman/NDCG@5/Precision@5 difference lower bounds (>−.005) against the matched 2D, anchor-only, donor shuffle and the anchor-adjusted frozen comparators. Formal model promotion requires all three benchmarks to pass in this technical comparison. Report exact supports, both axes and HCC TKI, kinase/targeted and nonselective cytotoxic strata. Record assay offset and interaction predictions separately to distinguish drug prioritization from patient discrimination.
