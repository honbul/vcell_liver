# ProCan 단백질체 감독과 LICOB 실측 단백질 비교

**2D 단백질체로 보조 학습한 RNA 모델은 LIMORE·LICOB의 공동 승격 기준에 미달했다.** LICOB에서 실측 단백질을 넣으면 약물 내 상관의 점 추정치는 올라갔으나, 짝지은 95% 구간에 0이 포함됐다. 두 외부 코호트는 이전 채점 이력이 있다. [채점 전 명세](PROTEIN_PROXY_PROTOCOL.md)

## 단백질 입력 지원

| 입력 | 연결 및 품질 확인 |
| --- | --- |
| ProCan 합의 단백질체 | 승인 유전자 6,673개, 공식 SIDM으로 DepMap에 일대일 연결한 946개 세포주. 원 행렬과 모델 매핑의 발행 MD5 일치. [자료 DOI 및 CC BY 4.0](https://doi.org/10.6084/m9.figshare.19345397) |
| 정정 GDSC2·CTRPv2·PRISM 학습 코어 | 698개 독립 계통, 반응 52,328개가 단백질체와 연결. [DepMap 25Q3 자료 설명](https://depmap.org/portal/data_page/) · [HGNC CC0](https://hgnc.genenames.org/about/license/) |
| LICOB 단백질체 | NODE의 전체 워크북은 발행 MD5가 다르다. H 시트의 CRC-32 `ee7185d5`를 검증해 별도로 복원했다. 43 PDO·38공여자 전체와 단백질 6,872개를 연결했고 ProCan과 정확한 이름을 공유하는 단백질은 5,352개였다. NODE 행렬의 별도 재배포 허가는 확인하지 않아 원자료는 G1에 보관했다. [원 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949980/) · [공개 NODE 객체](https://www.biosino.org/node/api/download/node/data/public/OED00796358) |

전체 소스 적합의 보조 학습 표적은 LIMORE 유전자 축에서 2,369개, LICOB 축에서 2,363개였다. 적합 계통의 단백질 값 중 93.8%와 93.7%가 각각 관측됐다. LICOB의 무라벨 비교에 적용한 단백질 2,347개는 43개 PDO 모두에서 측정됐다. 양쪽의 상관을 계산할 수 있는 2,323개 단백질에서 공여자 간 실측 단백질 순위와의 Spearman 중앙값은 동일 유전자의 RNA .404, 2D 단백질 감독을 적용한 추정치 .246이었다. 직접 RNA와 추정치의 상관에서 상수 벡터 등으로 계산이 불가능한 단백질은 공통 집계에서 제외했다. [원본과 변환 해시](protein_proxy_input_receipt.json)

13개 등록 약물 표적에서 대응 단백질 순위를 비교했다. 예를 들어 HDAC1의 Spearman은 직접 RNA .574, 단백질 추정 −.111이었고, HSP90AB1은 −.037과 .496이었다. 이 값은 단백질 양의 예측 성적이다. 그 단백질을 표적으로 하는 약물의 감수성에 대한 인과 효과와는 별개다. [표적별 단백질 일치 원표](protein_proxy_verification.json)
