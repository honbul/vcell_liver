# 2D 반응 상호작용의 보류 환자 적용

같은 환자에서 측정한 2D·3D의 직접 약물 내 상관이 약했다. 환자와 약물 가산 성분을 뺀 두 실측의 상호작용 Pearson은 100약물에서 .260이었다. 이 관측을 모델 제안에 사용했다. 아래 검사는 이미 여러 회 채점한 Wong의 동일 자료를 사용한 사후 모형 개발이며, 새 독립 검증으로 분류하지 않는다. [짝지은 2D·3D 사전 명세](WONG_ASSAY_BRIDGE_PROTOCOL.md)

- Wong 동일 8명의 고정 56분할을 재사용한다. 각 분할에서 3명의 3D 실측만 보정에 쓰고 나머지 5명으로 평가한다. 보류 환자의 반응은 보정 작업에 보내지 않는다. 주 입력은 100약물의 실측 2D이다. 동일한 62약물에서 2D 실측 또는 조직 RNA의 기존 동결 상호작용 예측을 입력으로 주는 민감도를 추가한다. 마지막 조건에서 보류 환자에 필요한 것은 해당 고정 패널의 조직 RNA 예측이며, 다른 환자나 본인의 보류 3D는 쓰지 않는다. 보정 공여자 3명의 공개 3D 실측은 두 입력 조건에 공통 제공한다.
- 약물별 적합 3D 평균을 동일 앵커로 사용한다. 기준선은 이 앵커 단독과, 같은 약물의 적합 입력 평균을 뺀 편차를 하나의 부호 있는 최소제곱 기울기로 옮긴 모형이다. 주 후보는 적합 입력·정답을 환자와 약물에 대해 이중 중심화해서 얻은 단일 기울기다. 음수 기울기는 0으로 제한한다. 보류 입력은 적합 약물 평균을 뺀 뒤, 같은 환자의 고정 패널 평균을 뺀 편차를 쓴다. 보조군은 적합 환자의 전반 민감도에 대한 부호 있는 기울기로 예측한 공통 항도 더한다. 기울기·약물 계수의 탐색은 없다.
- 주 후보의 약물 내 Spearman과 Pearson 차이의 짝지은 95% 하한이 두 기준선 각각 대비 0보다 커야 한다. 환자 내 Spearman과 NDCG@5의 하한은 각각 −.005보다 커야 한다. 같은 고정 조건을 실측 100, 실측 62, RNA 62에 적용하고 Precision@5를 기술값으로 기록한다. 환자·약물에 공통 가중을 반복 분할 전체에 적용한다. 56분할은 동일 8인에서 재사용됐다. 동결 뒤 별도 채점한다. 이 회차를 근거로 기존 배포 모델이나 사전 외부 검증 판정을 바꾸지 않는다.
