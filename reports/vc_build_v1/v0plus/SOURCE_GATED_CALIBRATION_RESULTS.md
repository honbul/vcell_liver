# 소스 재현성으로 제한한 약물별 보정

**약물별 배율과 소스 아핀 보정은 외부 두 코호트에서 시료 내 순위를 보존했으며, 약물 내 상관의 공동 개선 기준에는 미달했다.** 이전에 동결한 구조 커널과 신경망 결합 예측을 사용했다. 외부 둘 다 기존에 채점한 코호트다. [사전 명세](SOURCE_GATED_CALIBRATION_PROTOCOL.md)

## 약물별 배율

등록 68약물 중 36개가 두 개 이상 스크린의 보류 검증 지지 기준을 충족했다. 12개는 적격 스크린 모두에서 획득한 Spearman·Pearson 차이의 fold 평균이 양수였다. 나머지 56개는 구조 커널 값을 사용했다. 여기서 선택한 배율은 이전 신경망 보정에 곱한다. 소스에 대해 별도 검증 성적을 주장하지 않는다.

주 후보는 두 코호트에서 구조 커널 대비 시료 내 세 순위 지표의 비열등 하한 −.005를 충족했다. 약물 내 두 상관의 개선 하한은 모두 0보다 낮았다. 약물×시료 PCC 차이의 95% 구간도 LIMORE [−.0106, +.0259], LICOB [−.0141, +.0232]였다. 고정 배율과 배율 순열 대비 주 후보의 두 상관 차이 구간에 모두 0이 포함됐다. [외부 원표](source_gated_external_score.json)

기존 전체 보정을 부여하면 LICOB 전체 순위 Spearman은 .2769였다. 약물별 배율과 소스 아핀을 적용한 값은 .3384였고 구조 커널은 .3387이었다. 배율만 골라 아핀 변환 전의 점수를 내면 LICOB NDCG@5는 .6379였고, 아핀 변환 이후에는 .6240이었다. 규모 보정 후 전체 순위는 유지됐고 상위 5개 선별 이득은 관측되지 않았다.

비영 배율을 선택한 약물만의 약물 내 Spearman 차이 기술값은 LIMORE 12개 −.0152, LICOB 11개 +.0250이었다. 두 코호트의 약물별 지지가 완전하고 0 배율의 예측이 구조 커널과 정확히 같으므로, 전체 약물 평균 차이에 전체 약물 수를 곱해 비영 약물 수로 나눴다. 이 하위집합의 별도 구간은 계산하지 않았다.

## 재현

`8b2be38`을 등록했다. G1 `33968`가 소스 배율·아핀 모수를 고정했고, `33969`가 85,185개 예측을 동결했다. 별도 작업 `33970`가 외부 반응을 읽고 채점했다. 소스 예측 12개, 모수, 외부 예측 2개, 채점 파일의 SHA-256 연결을 검증했다. 실데이터에서 두 코호트 각각 한 RNA에 해당하는 기존 예측만 넣어도 주 후보의 점수가 전체 배치 실행과 같았다. 무라벨 순위 보정은 각 약물의 정렬된 구조 커널 점수와 정확히 일치하는 분포를 냈다. 29개 기존 테스트와 재현성·동률·단일 입력 검사가 통과했다.
