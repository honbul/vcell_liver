# 신경망 보정의 약물·시료·상호작용별 기여

LICOB에서 기존 구조 커널에 상호작용 신경망을 더하면 NDCG@5가 .624→.661, 공여자 내 전체 순위 Spearman이 .339→.277이었다. 실측을 쓰지 않고 예측을 분해했을 때 보정 변동의 77.7%는 공여자가 공유하는 약물별 편차였다. 이번에는 같은 동결 예측에서 각 성분의 기여를 분리해 다시 채점한다. [선행 성적과 예측 분해](NEURAL_INTERACTION_TRANSFER_RESULTS.md)

- 원본의 SHA-256을 확인한다. 정정 GDSC2·CTRPv2·PRISM의 계통 3-fold 및 스크린 보류, LIMORE 50계통·68약물, LICOB 응답이 연결된 43개 PDO·성인 38공여자·53약물과 비교군의 지지를 그대로 쓴다. 예측 차이 `D=신경망 결합−구조 커널`를 스크린·fold 또는 외부 코호트별로 관측된 시료×약물 요청에서 분해한다. 외부의 예측 시료는 각 PDO이며 채점 때 기존 공여자 집계 규약을 적용한다.
- 동일 요청의 예측 차이를 전체 상수, 약물별 평균, 시료별 평균, 약물×시료 잔차로 분해한다. 보류 스크린의 결측 셀은 관측 요청에만 단위 가중을 주어 두 가산 성분을 사영한다. 세 성분의 전 조합 여덟 개를 구조 커널 위에 구성한다. 세 성분을 모두 넣은 경우의 예측은 기존 상수까지 포함해 원 예측과 동일하게 복원한다. 전체 상수는 모든 순위에서 불변이므로 나머지 조합의 상수는 0으로 둔다. 새 배율 선택과 재학습은 없다.
- 주 후보는 약물×시료 잔차만 추가한 예측이다. 개발의 세 스크린 보류 중 두 곳 이상과 LIMORE·LICOB 각각에서 구조 커널과 기존 전체 결합 대비 약물 내 Spearman·Pearson의 짝지은 95% 하한 >0, 시료 내 Spearman·NDCG@5·Precision@5의 하한 >−.005를 모두 만족해야 한다. 외부에서는 두 대조 대비 약물×시료 잔차의 PCC 개선 95% 하한도 >0이어야 한다. 기존 공개 비교군, HCC TKI, 표적·키나아제·HDAC, 비특이 세포독성 층을 함께 보고한다.
- 설명 분석은 여덟 조합의 차이를 모든 성분 추가 순서에 걸쳐 평균한 Shapley 기여량으로, 외부의 NDCG@5·Precision@5·시료 내 Spearman 차이를 분해한다. 시료가 중복된 공여자는 먼저 평균한다. seed 14822로 공여자 또는 계통을 4,000회 짝지어 재표집해 기여의 95% 구간을 낸다. 약물별 평균만의 NDCG@5와 전체 순위 차이도 구조 커널에 짝지어 제시한다. 이는 고정 예측 안에서의 성분별 기여이며 생물학적 인과 효과와 구분한다.
- 코호트별 성분은 그 코호트의 다른 **예측**을 사용한다. 이 계산은 무라벨 배치 보정이며 단일 RNA를 바로 투입하는 V0+를 대체하지 않는다. 이전 채점 이력이 있는 외부 코호트의 사후 가설 검증이다. 예측을 먼저 별도 SHA-256으로 고정하고 이후 각 원 정답으로 채점한다.
