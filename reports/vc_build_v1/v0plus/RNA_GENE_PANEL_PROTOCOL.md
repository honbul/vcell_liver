# RNA gene membership, rank context and cross-platform reproducibility

LICOB at the intersected pancreatic PDO gene axis showed higher per-sample drug ranking than the previously used wide axis. A 2D-only fit on that axis reproduced the ranking. Separate gene membership, percentile context, and the number of genes. Test a fixed-sized reproducibility-selected panel that can be used by the same pipeline in both HCC domains. [Pancreatic PDO experiment](PANCREAS_PDO_TRANSFER_RESULTS.md) · [Independent CCLE expression pairing](PAIRED_EXPRESSION_RESULTS.md)

- Use the corrected 2D response core, prior assay/lineage splits, matched full-axis structured forecasts, and fixed drug anchor, ECFP/target drug kernel and penalty 4. Keep the same RNA, pathway/TF, inferred Chronos and driver kernel weights. Each additional kernel recomputes the source-only scaling and auxiliary expression fits before scoring. Use the frozen Ridge, drug mean, CellHit, CODE-AE, Velodrome and V0+ on the same available rows.
- `pancreas_rerank` retains the intersection of the available native RNA axis with the GSE194249 PDO expression **gene names** and ranks expression only within that intersection. `pancreas_native_rank` keeps the same genes in the same order and uses their percentile ranks from the wider RNA axis. Gene expression is ranked in each sample alone. `pancreas_width_control` averages three random gene panels of that exact size, with seeds 40103, 40109, 40111, each reranked after selection. Match the exact number of selected genes in each of the 25 bins defined by the first-rank quintiles of the mean and variance of the full context per-sample ranks in fit RNA. Empty bins contribute zero genes. The pancreas models and controls do not read RNA values or responses from the PDAC source.
- For reproducibility selection, require gene names in the published Affymetrix RNA and both registered HCC RNA schemas, without target values. Keep only paired historical CCLE array and sequencing measurements of fit cell models in the same lineage split, with at least five pairs in their tissue. Rank expression per sample over the candidate genes in each platform. Subtract the platform-specific fit tissue mean for each gene, and compute the per-gene cross-platform Pearson. Choose the highest 9,000 genes, resolving equal correlations by gene symbol. Rank RNA inside that panel in all domains. The stable width control draws 9,000 genes from the same candidate universe, with the same mean/variance bin counts and seed 40639. In external estimation, both cohorts use one fitted gene list. Their RNA column names are part of support registration and their RNA values enter per-sample prediction only. The historical arrays were normalized by the depositor across the full deposited CCLE collection.
- The primary model is the equal average of the stable-panel prediction and the full-axis structured prediction. The primary control averages the matched random-panel and the same full-axis prediction equally. These fixed models use no query-batch statistics or target treatment outcomes. Use the 12 existing source assay/lineage splits, LIMORE 50×68 and LICOB 43×53 (38 adult donors in scoring). Both external cohorts have previous evaluation exposure. The pancreas comparison is a post hoc-motivated, preregistered technical diagnosis on those same cohorts.
- Freeze each prediction before separate scoring. Primary advancement requires both within-drug Spearman and Pearson paired 95% lower bounds above 0 versus full axis, matched width blend, drug mean, Ridge, and each public external comparator. Require all three within-sample Spearman, NDCG@5 and Precision@5 lower bounds above −.005 against the same methods. At least two held screens and both external cohorts must pass. Use 800 crossed repeats per source, 1,000 externally. Report the diagnostic pair contrasts of pancreas rerank versus native context, random width and full axis, plus the stable standalone versus matched single panel. These diagnostic contrasts do not select the candidate or change the rule. Include the main mechanism strata, gene counts, axis hashes, agreement and matched control distributions.
