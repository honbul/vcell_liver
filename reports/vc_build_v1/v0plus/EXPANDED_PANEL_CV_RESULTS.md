# 정정된 단일 약물 학습과 확장 자료의 효과

**1,129약물까지 확장한 구조 커널은 네 조건 모두에서 사전 승격 기준을 통과하지 못했다.** CTRPv2·GDSC2 보류에서 세포별 약물 순위가 소폭 개선됐으나, 같은 약물에 대한 계통별 감수성은 정정 코어보다 낮았다. 세 소스 공동 학습에서 약물 내 Spearman과 Pearson의 하락 구간은 0을 포함하지 않았다. [사전 명세](EXPANDED_PANEL_CV_PROTOCOL.md) · [채점 원표](expanded_panel_cv_score.json)

CTRPv2 보류의 Pearson 차이 95%는 [−.0648, −.0324]였다. 같은 조건에서 두 약물 블록 사이의 ECFP·표적 연결을 끄고 공통 항만 남기면 약물 내 Spearman .3552, Pearson .3952가 나왔다. 전체 연결의 차이는 Spearman −.0124 [−.0184, −.0064], Pearson −.0163 [−.0218, −.0099]였다. 이 절제에서 화학·표적을 통해 옮긴 신호가 성능 감소 일부를 설명한다. 공동 학습에서는 전체 연결과 공통 항만 공유한 경우의 Spearman 차이 구간이 0을 포함했다.

확장 커널+정정 Ridge의 고정 평균은 공동 학습에서 정정 Ridge보다 약물 내 Spearman .3648 → .3740, Pearson .4043 → .4110이었다. 각각 개선의 95% 구간은 [+.0021, +.0158], [+.0014, +.0126]였다. NDCG@5는 .8932 → .8929, Precision@5는 .6254 → .6238이었다. 새 라이브러리만의 효과는 정정 구조 커널과의 고정 비교에서 판단한다. [모든 arm 및 원표](expanded_panel_cv_score.json)

## 성인 HCC와 정정 효과

성인 HCC에서 fold 간 평균 이동을 없앤 약물별 Spearman은 CTRPv2 보류 .041 → .072, GDSC2 보류 .204 → .163, PRISM 보류 .278 → .317이었다. 공통 지원은 각각 33, 27, 13약물이다. 보류 소스에 따라 방향이 달랐다. 세 소스 공동 학습에서는 세 assay 모두 HCC 기술값이 낮아졌다. [HCC 세부 원표](expanded_panel_cv_score.json)

원래 학습 코어와 정정 코어를 동일한 정정 실측에 대조하면, 세 소스 공동 학습에서 전체 약물 내 Spearman은 두 경우 모두 .3690이다. 해당 CTRPv2 실측에서 ABT-263은 .356 → .372, Rapamycin은 .377 → .395였다. 두 개별 약물의 변화는 기술값이다. CTRPv2를 전부 보류하면 두 코어의 예측은 일치했다. GDSC2 보류에서 정정은 NDCG@5 .696 → .705였고 PRISM 보류에서는 .846 → .841이었다. 정정의 영향은 순위 요약과 약물별 수치에서도 달랐다. [원자료 정정](SOURCE_PANEL_EXTENSION.md) · [공통 실측의 약물별 점수](expanded_panel_cv_score.json)
