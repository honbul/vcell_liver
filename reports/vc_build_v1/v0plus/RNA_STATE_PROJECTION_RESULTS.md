# 종양–오가노이드 RNA 변화를 제거한 약물 감수성 예측

**실제 환자 짝에서 구한 RNA 사영은 LIMORE와 LICOB 모두에서 사전 공동 기준을 통과하지 못했다.** GDSC2·CTRPv2·PRISM 학습과 각 평가에서 같은 아홉 방향을 제거했다. Wong의 공개 기저 RNA 10쌍에서 구한 네 방향과 사전 Hallmark 다섯 방향이다. 두 외부 코호트의 실측에는 이전 채점 이력이 있으며 이번 결과는 기술 비교다. [사전 명세](RNA_STATE_PROJECTION_PROTOCOL.md)

## RNA에서 제거한 분량과 한계

| 코호트 | 모델 유전자 / Wong 공통 유전자 | Wong의 실제 짝 이동 제곱 크기 제거율, 실제 짝 / 순열 | 학습→평가 평균 RNA 차이 제곱 크기 제거율, 실제 짝 / 순열 |
|---|---:|---:|---:|
| LIMORE | 17,871 / 17,741 | 74.2% / 54.3% | 3.5% / 4.8% |
| LICOB | 14,421 / 14,356 | 74.3% / 52.7% | 9.7% / 9.2% |

Wong 10쌍을 축 적합과 첫 번째 진단에 함께 사용했다. 외부 코호트 RNA는 두 번째 진단에서만 모집단 평균을 계산했다. 관찰 결과는 이 방향이 적합에 쓴 종양–PDO 차이를 많이 담고 있음을 보여 준다. 실제 약물 반응의 전이로 이어지려면, 이 차이에서 약물과 무관한 배양 효과를 분리할 수 있어야 한다는 가설은 남는다. [동결 영수증](rna_state_forecast_receipts.json)
