# 비간계열 LINCS 약물 서명의 간암 전이

**비간계열 LINCS 처리 서명과 경로 상호작용은 두 외부의 사전 공동 기준에 미달했다.** 서명 보유 여부를 동일하게 맞춘 대조와 비교해 추가 이득이 확인되지 않았다.
[사전 명세](LINCS_PATHWAY_PROTOCOL.md) · [공개 GSE92742 원자료](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE92742) · [Broad Level5 처리 정의](https://clue.io/connectopedia/guide_to_geo_l1000_data)

## 입력 감사

| 등록 범위 | 수 |
| --- | ---: |
| 정정 학습 코어의 정확한 canonical parent | 68 |
| 구조가 완전히 일치한 LINCS canonical parent | 49 |
| 용량·시간·기술 반복과 최소 두 세포주 지지를 만족한 parent | 41 |
| 적격 Level5 서명 | 1,358 |
| 약물·세포주·시간·용량의 서로 다른 조건 | 622 |
| 직접 측정한 landmark 유전자 | 978 |

6시간 서명 626개, 24시간 서명 732개를 사용했다. 세포주별로 A375 136, A549 227, HT29 128, MCF7 399, PC3 230, VCAP 238개였다. GCTX에서 위 메타데이터 조건에 맞춘 행만 발현을 추출했다. 간암 예약 코호트는 이 등록과 채점에 쓰지 않았다. 메타데이터, 선택 발현의 바이너리와 최종 41약물 합의표의 SHA-256을 기록했다. 개별 서명과 합의표는 G1에 보관했다. [입력 영수증](lincs_pathway_input_receipt.json)

합의 서명 지원은 LIMORE 41/68약물과 LICOB 34/53약물이었다. 기존 RNA와 처리 서명의 공통 landmark 중 PROGENy·Hallmark 경로에 속한 유전자는 LIMORE 512개, LICOB 509개였다. 두 외부에서 44개 경로를 적합했다. 순열 대조에서는 두 외부의 적합 서명 41개가 모두 다른 약물에 연결됐다. [동결 진단](lincs_pathway_verification.json)

## 실행과 검증

`e382c8a`에 사전 명세를 고정했다. 최초 CPU `34072`에서 적격 서명 목록을 고정했으나 시스템 h5py가 계산 노드의 NumPy와 호환되지 않았다. 같은 목록을 사용해 공식 PyPI wheel의 SHA-256을 확인한 h5py 3.13.0 격리 환경에서 추출만 `34077`로 다시 실행했다. 최초 체인의 동결·채점은 모두 0개였다. [h5py 배포](https://pypi.org/project/h5py/3.13.0/) · [의존성 영수증](lincs_pathway_hdf_dependency.json)

G1 GPU `34078`, `34079`가 개발 777,462개와 외부 62,469개 예측을 동결했다. 별도 CPU `34080`, `34081`에서 실측을 연결했다. 자료 등록, 14개 예측, 두 채점 파일의 SHA-256을 확인했다. 해당 1,358개의 GCTX 서명 ID와 비간계열 세포 표기가 모두 일치했다. 기존 테스트 29개가 통과했고, 추가 공유 경로 커널과 가중 해를 작은 명시적 행렬로 독립 검산했다.
