# 약물 처리 전사체로 보강한 간암 반응 예측

정정 2D 스크린의 구조 커널에 약물 처리 전사체를 추가한다. 앞서 평가한 VCAT-SMILES와 같은 LIMORE 50계통·68약물 및 LICOB 성인 38공여자·53약물을 사용한다. 두 코호트는 기존 채점 이력이 있다. 공개 VCAT의 Level4 mixed-effects CTS와 이번 Level5 합의 서명은 정의가 다르다. [등록 약물반응 자료와 VCAT 비교](VCAT_MATCHED_RESULTS.md) · [GSE92742](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE92742) · [Broad Level5 명세](https://clue.io/connectopedia/guide_to_geo_l1000_data)

- 공개 GSE92742의 trt_cp 중 A375, A549, HT29, MCF7, PC3, VCAP만 허용한다. 용량 단위 µM 범위 .5–20, 6·24시간만 쓴다. 최소 기술 반복 2회 및 distil_cc_q75 ≥ .15로 고정한다. 정정 코어의 68개 화합물에 LINCS 공개 isomeric SMILES의 단일 canonical parent 전체 InChIKey가 일치할 때만 연결한다. 동일 연결성의 입체 이성질체, 이름 기반 매칭, 처리 혼합물, 간 유래 발현 행은 제외한다.
- Level5에 실제 측정으로 등록된 landmark 유전자만 가져온다. 화합물·세포주·시간·용량별 복수 서명은 중앙값, 용량은 시간별 중앙값, 시간은 세포주별 동등 평균, 세포주는 다시 동등 평균한다. 최소 두 세포주가 남아야 해당 물질의 합의 서명을 등록한다. 선택 서명 목록, 메타데이터와 선택 발현의 SHA-256, 결과 서명 표와 학습 코어를 G1에 고정한다. 질의 환자 RNA·반응은 서명 등록에 필요하지 않다.
- 기존의 ECFP·표적 공유 약물 커널, 샘플 내 RNA 순위, 경로·TF, DepMap Chronos·변이/CNV 대리 표현, 공동 앵커·손실 가중·벌점 4를 공유한다. 합의 약물 서명을 유전자 축 중심화·단위 노름화해서 양의 준정부호 cos Gram을 만들고 그 .20을 구조 약물 커널에 더한다. 서명 결측은 0 행·열이다. 서명 보유 여부 곱만 .20 더한 조건이 결측 마스크 대조다.
- 주 후보는 위 서명 커널과 함께 약물 처리 서명과 투여 전 RNA를 같은 landmark 유전자의 PROGENy·Hallmark 경로 가중에 각각 사영한다. 측정 유전자 10개 이상인 경로만 쓰고 절댓값 기준 경로 가중의 L2 노름을 1로 둔다. 각 점수는 적합 RNA 또는 적합의 서명 보유 약물을 기준으로 중심화하고 표준편차 하한 .05, 절댓값 상한 4를 적용한다. 경로별 RNA 상태 × 약물 처리 방향의 부호 있는 곱을 여러 약물에서 공유하는 저랭크 커널로 더한다. 추가 커널의 관측 이전 평균 대각 크기는 적합 RNA와 서명 보유 약물의 교차곱에서 .10이다. 결측 서명의 곱은 0이다. 같은 서명 지원을 고정하고 seed 15149로 등록 약물 ID를 순열한 대조에서 서명 Gram과 경로의 약물 열을 모두 교체한다. 단일 시료는 다른 평가 시료의 발현 없이 계산한다.
- 보류 스크린 3곳 중 2곳 이상 및 두 외부에서 주 후보가 기존 구조 커널, 보유 여부, 서명만, 서명 순열 대조 각각에 대해 약물 내 Spearman·Pearson의 짝지은 95% 하한 >0와 시료 내 Spearman·NDCG@5·Precision@5의 하한 >−.005를 충족해야 한다. 외부는 구조 커널 대비 약물×시료 잔차 PCC 하한도 >0이어야 한다. 약물 평균·Ridge·CellHit·CODE-AE·Velodrome·V0+는 해당 원판에 같은 행으로 포함한다. 서명 지원 약물의 점수와 기전 층은 기술값이다. 주 후보나 배율을 평가 결과로 바꾸지 않는다.
- 사전 커밋 뒤 G1에서 자료 등록과 GPU 예측을 실행한다. 예측을 먼저 해시 동결하고 별도 CPU에서 실측과 결합한다. 개별 발현, 서명, 예측은 G1에 둔다.
