# 학습 반응에서 얻은 약물 관계의 간암 전이

기존 구조 커널에 더해 학습원에서 같은 계통의 반응이 함께 달라지는 약물을 연결했다. 주 후보는 스크린별 공통 계통 민감도와 약물 평균을 제거했고, 가산 효과 추정에서 생기는 상관은 관측을 독립 순열한 대조로 보정했다. 이후 스크린·계통을 함께 보류한 3개 조건과 LIMORE·LICOB 기존 외부 코호트에 적용했다. [사전 명세](RESPONSE_RELATEDNESS_PROTOCOL.md)

## 학습 시 지원

정정 65,678행의 세 소스에서 68약물의 가능한 2,278쌍 중 1,731쌍이 한 스크린 이상에서 동일 계통 40개 이상으로 지원됐다. CTRPv2·GDSC2·PRISM의 지원은 각각 1,170·842·153쌍이었다. 424쌍은 스크린 두 개 이상에 분포했고, 나머지 1,307쌍은 스크린 한 곳의 실측으로 추정했다. 여러 스크린에 관측된 쌍의 수는 추정 방향이 일치한 쌍의 수와 구분한다. 상호작용 관계 행렬의 음의 고유값 하나를 제거했고, 약물 연결 대조에서 68개 약물의 할당을 바꿨다. [동결·학습 지원 영수증](response_relatedness_forecast_receipts.json)

**GDSC2 보류만 통과했다.** 그 조건의 계통 내 Spearman과 NDCG@5 개선 하한은 각각 +.0040, +.0021이었다. 3조건 가운데 2조건을 요구한 사전 기준은 미달했다. 세 스크린을 공동 적합하고 계통만 보류했을 때 약물 내 Spearman은 CTRPv2 .458→.464, GDSC2 .401→.424, PRISM .248→.251이었다. 공동 적합은 측정 소스 이동의 검증과 구분한다. [분할별 원표와 신뢰구간](response_relatedness_source_score.json)

LIMORE는 학습원과 겹치지 않는 50계통·68약물·3,400쌍이다. LICOB는 43개 오가노이드의 예측과 실측을 38명·53약물·2,014쌍으로 모았다. 두 코호트의 기술 평가에서 사전 외부 기준을 통과한 대조는 각각 0/4였다. [외부 원표](response_relatedness_external_score.json)

LICOB에서는 기존 커널과 연결 순열 대비 Pearson의 하한이 양수였다. 같은 대조의 Spearman 및 상호작용 PCC 구간은 모두 0을 포함했다. 환자 내 약물 전체 Spearman은 구조 커널 대비 .339→.325로 낮아졌고 NDCG@5는 .624→.630이었다. LIMORE에서는 순열 대조보다 상호작용 PCC가 높았지만 약물 내 상관 점 추정치는 낮았다.

| 기전군 | LIMORE 약물 수, 구조 → 결합 Spearman | LICOB 약물 수, 구조 → 결합 Spearman |
|---|---:|---:|
| HCC TKI | 4, .195 → .188 | 3, .044 → .122 |

| 비특이 세포독성 | 12, .412 → .414 | 9, .051 → .041 |

LICOB TKI와 표적치료군에서 상대적으로 큰 점 추정 변화가 보였다. 이 값은 기전군별 기술 통계다. 이 결과만으로 개별 간암 TKI나 환자별 치료 순위의 개선을 확정할 수 없다.

## 재현 기록

`2d3221f`에서 주 후보, 대조와 판정을 먼저 고정했다. G1 GPU `33837`에서 개발 12개 분할의 666,396개 예측, `33838`에서 외부 두 코호트의 56,790개 예측을 동결했다. CPU `33839`와 `33840`은 동결된 결과를 별도 채점했다. 14개 예측 SHA-256과 두 점수의 연결을 확인했다. 28개 기존 테스트와 직접 계산한 결측 포함 Pearson·PSD·순열 불변 고유값 검사가 통과했다. 외부 두 코호트의 공동 기준과 스크린 전이 기준은 모두 미달했다. [작업 원장](RUN_LEDGER.tsv)
