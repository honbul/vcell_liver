# 공개 보충표로 등록하는 Zhu 성인 HCC 오가노이드

기존 접근 감사는 HRA004348 원시 자료와 S4 반응표를 확인했다. 같은 논문의 공개 S3 RNA-seq 시트에 표본별 기저 발현 정량표가 있다. 따라서 접근 제한 GSA 파일을 쓰지 않고 공개 S1·S3·S4만으로 독립 연구의 HCC 평가 명부를 등록한다. [원논문 및 보충표 설명](https://pmc.ncbi.nlm.nih.gov/articles/PMC10897507/) · [NCBI 공개 객체와 MD5](https://pmc-oa-opendata.s3.amazonaws.com/PMC10897507.1/PMC10897507.1.json) · [HRA004348 등록](https://ngdc.cncb.ac.cn/gsa-human/browse/HRA004348)

- S1의 조직형이 정확히 HCC이고 성인 연령이 명시된 환자만 포함한다. S1 모델명, S3 RNA 열, S4의 각 반응축을 문자열로 대조하고 공여자 키의 중복을 확인한다. 모델명 접두어만으로 HCC를 정하지 않는다. 접근이 제한된 시퀀스는 분석에 사용하지 않는다. 원표와 파생 행 명부는 G1에 둔다. 공개 원 논문의 명시 라이선스는 CC BY-NC-ND이며 별도 파일의 재배포 허가는 확인되지 않았다.
- 다농도 (1-AA) 시트와 301개 초기 단일농도 시트의 등록 좌표, 지지, 제외 이유를 따로 기록한다. 다농도는 번호의 명시적 대응과 제조사·제품번호로 연결한다. 같은 파일의 Selleck SMILES를 우선하고, 별도 검증한 같은 제조사의 동일한 제품번호를 보조로 사용한다. 초기 화면은 단일 화합물 이름과 같은 파일의 화학 목록을 대조한다. 정확한 isomeric parent를 만들 수 없는 경우, 미지정 입체 또는 여러 처리 행에 같은 parent가 있을 경우를 표시한다. 학습 코어와 exact parent가 맞는 범위를 별도 집계한다.
- 기존에 검증한 1,186약물 학습 등록부와의 exact parent도 비교한다. 두 학습 범위의 합집합을 좌표 명부에 기록하고 각 범위의 지원 플래그를 따로 남긴다. 이 비교는 화합물 식별자와 학습 영수증만 사용한다.
- 이번 등록에는 반응값을 전달하지 않는다. 새 연구는 지금까지 이 프로젝트의 행 단위 HCC 예측 평가에 들어가지 않았다. 등록 행의 지지와 표준 범위가 확정된 뒤, 모델과 수치 판정 규칙을 미리 고정하고 별도 채점한다.

## 검증된 공개 명부

S1·S3·S4의 배포 MD5 세 개는 NCBI 공개 메타데이터와 일치했고 각 XLSX의 ZIP 무결성 검사를 통과했다. S3에 53개 간담도 오가노이드의 발현 16,410행이 있다. 정정 2D 코어의 유전자와 정확히 일치한 기저 RNA 14,535유전자를 등록했다. 자료를 만들 때 원 논문은 53시료에 대해 FPKM을 보고했다. 원 논문의 공개 방법은 초기 10 µM 억제율과 후속 5점 곡선 측정을 구분한다. 후속 약물은 초기 스크린 반응을 이용해 선택된 패널이므로 두 화면을 별도 평가 범위로 유지한다. 같은 모델 ID가 두 반응표에 있을 수 있으므로 공여자 수를 더하지 않는다. 위 좌표 수는 수치를 읽기 전의 등록 지원이다. 미정 입체 구조, 화학 레코드 누락, 같은 parent 충돌을 제외했다. 연구 간 공통 환자키는 공개 문서에서 확인되지 않아 동일 연구 내부 중복만 직접 대조했다. G1의 `34310`에서 정정 코어 명부를 만들고 `34313`에서 기존 1,186약물 사전 등록과 합집합을 만들었다. 발현 및 양쪽 화학 파일의 해시는 두 등록에서 일치하며 게시된 결과값 열은 읽지 않았다.
