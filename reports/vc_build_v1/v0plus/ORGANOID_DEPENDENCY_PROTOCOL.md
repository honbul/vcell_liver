# Measured 3D genetic dependency as a prerequisite for HCC response transfer

Directly test whether an RNA model trained on measured patient-derived organoid dependencies adds target-specific signal to the existing 2D Chronos proxy. This precursor keeps both HCC drug-response cohorts separate. Experimental success concerns the portability of the dependency proxy across 3D tissues. It provides a supervised test of a dependency feature before another HCC drug benchmark.

- Register the Sanger organoid study supplementary S2 donor and sample metadata and S3.6 RNAseq TPM, plus continuous cell-level fitness log fold changes from the July 2026 Cell Model Passports release. Match published sample and Sanger model IDs. Require released PASS status, RNA and dependency measurements. Drop every donor with a registered Broad DepMap overlap flag, even if some of the donor's other models lack a flag. Average multiple same-donor cultures within tissue. Use tissue of the primary tumour, so colorectal organoids established from liver metastases remain colorectal. The public fitness values use author-level assay and library normalization, and the supervised predictors do their own fold-local preprocessing. [Sanger dataset paper and supplement](https://pmc.ncbi.nlm.nih.gov/articles/PMC13581617/) · [Released fitness table](https://cellmodelpassports.sanger.ac.uk/downloads)
- The 2D reference uses the drug-response core's registered RNA axis and DepMap 25Q3 Chronos. Keep human cell lines with a labelled tissue and without an HCMI identifier. Aggregate documented same-patient lines within tissue, with the model ID as fallback when no DepMap patient ID is given. Neither 2D drug outcomes nor LIMORE/LICOB values are used. The fixed candidate target set is the exact symbol intersection of Sanger and DepMap dependencies, the joint RNA axis and the existing targets of the 68 core drugs.
- Hold out all colorectal donors, then all oesophageal donors. Exclude a held tissue's CRISPR files from fitting. Each arm uses the same eligible genes per fold. Within each fit tissue, transform negative fitness LFC or negative Chronos to standardized gene-wise fractional ranks where at least five donors have nonconstant measurements. Require support from at least 20 3D and 100 2D fit donors. Fit RNA ranks, 512 variable genes, target RNA and PROGENy/Hallmark/DoRothEA features separately on each training domain. Use the existing mixed linear/RBF kernel and fixed ridge penalty 4. Average the 2D and 3D predictions equally for the primary arm. The controls are 2D only, expressed rank of the same target and 3D training dependencies cyclically reassigned within each tissue using seed 62093. Also report 3D only. Evaluate both tissues on original continuous negative LFC and measure agreement across donors within each target.
- For each held tissue, at least 40 targets must have 30 or more measured donors eligible for all arms. A pass requires paired donor × gene resampling over 1,000 draws with each lower 95% bound above zero for both within-target Spearman and Pearson versus all three controls. Apply this criterion to each tissue separately. This gates HCC model expansion using the proposed equal blend.
- If passed, lock a separate downstream HCC specification before predicting. Place the 3D-informed RNA dependency on only the registered targets of each drug, compare against the same model using 2D dependencies and target RNA alone, and evaluate both originally designated HCC cohorts on the shared rows and fixed rank metrics. If the prerequisite fails, preserve the HCC benchmark and record the measured failure of the dependency feature rather than selecting a new candidate from those outcomes.
- Keep public matrices on G1. Freeze predictions per held tissue with SHA-256 before the independent scoring job reads held response labels. Provide source version, support, split and receipt hashes.
