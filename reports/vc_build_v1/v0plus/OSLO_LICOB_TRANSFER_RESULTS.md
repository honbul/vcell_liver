# Oslo 3D 반응의 LICOB HCC 전이 성적

**Oslo 반응을 기존 2D 예측에 추가한 주 후보는 공동 기준을 통과하지 못했다.** 대장암 간전이 PDO에서 약물별 26–52명·901개 AUC 행을 적합에 사용했다. 이미 평가 이력이 있는 LICOB 성인 HCC 38명의 동일 13약물, 494개 공여자–약물 값을 별도로 채점했다. [사전 명세](OSLO_LICOB_TRANSFER_PROTOCOL.md) · [Oslo 출처와 등록](OSLO_3D_CURVE_RESULTS.md)

## 화학 및 종말점 지원

공개 Oslo의 공급사·일반 제품명과 CAS의 PubChem SMILES를 대조해 염 제거 후 전체 InChIKey가 같은 후보 14개를 검증했다. 잠재 입체 하나가 미지정된 erastin을 제외해 13개를 주 평가에 넣었다. Ceralasertib은 공급사의 일반 제품 CAS 1352226-88-0으로 연결했다. 동일 공급사의 S-이성질체 제품은 별도 CAS 1352226-87-9를 갖는다. 공개 기록은 제품 parent를 뒷받침하며 실제 테스트 lot와 제형의 동일성은 확인되지 않았다. [약물별 CAS·공급 증거](oslo_licob_chemistry.tsv) · [공급사의 ceralasertib 변형 목록](https://www.medchemexpress.com/search.html?fa=&fp=&ft=&q=Ceralasertib)

Oslo AUC는 개별 곡선의 원 물리 농도 구간을 사용한 뒤 라이브러리·제품별로 표준화했다. LICOB의 공개 S6 AUC는 해당 연구의 조건에서 얻은 값이다. 이 비교에는 서로 다른 농도 구간과 실험 형식의 이동이 함께 반영된다. 최고 농도를 직접 덮는 Emax 범위는 따로 평가했다.
