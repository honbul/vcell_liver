# LICOB transfer from exact-parent public viability screens

The existing 76-drug LICOB panel includes eleven fully assigned parents with no fitted response after the PRISM20Q2 dose-curve restoration. Another compound, dBET6, has one unspecified stereocenter. To audit same-compound coverage use published PRISM24Q2 treatment and lot records and NCI DTP compound identifiers. This is a retrospective technical evaluation on previously scored LICOB S6, restricted to the existing 43 organoid query profiles and their 38 age-confirmed adult donor groups. LIMORE remains the separate primary public 2D evaluation.

- The metadata search nominates five PRISM24Q2 matrix rows by full Broad sample ID, including three new REP1M rows and two legacy REP.PRIMARY rows carried into the extended release. The Hub 2024-06-10 lot SMILES must map to a unique matching isomeric parent with the existing standardizer. The three new rows need the released 2.5 µM, five-day wells in both cultures. Record matrix coverage before and after restriction to the RNA training roster. [PRISM24Q2](https://doi.org/10.6084/m9.figshare.25917643) · [Broad physical sample catalogue](https://repo-hub.broadinstitute.org/repurposing)
- In NCI DTP October 2026, nominate NSCs by exact known compound names, salt names and CAS. Require a complete matching isomeric parent from the DTP SMILES file and count rejected lots. Extract finite molar GI50 observations. Match screened cells using an unambiguous normalized DepMap name or CCLE identifier within the existing 2D RNA training roster. Keep raw measurement counts, experimental runs and fitted coverage. Use reported values at the concentration limits as supplied, so floor or ceiling ties remain in training. [NCI compound catalogue](https://wiki.nci.nih.gov/spaces/NCIDTPdata/pages/155844992/Chemical%2BData) · [NCI GI50 measurements](https://wiki.nci.nih.gov/spaces/NCIDTPdata/pages/147193864/NCI-60%2BGrowth%2BInhibition%2BData)
- Train an independent model per source lot. In PRISM use negative log-fold viability. For NCI take the median negative log molar GI50 per NSC and RNA model over experiments. Within each lot standardize fractional ranks, retaining ties. Require at least 20 distinct DepMap patients or fallback model IDs and at least five distinct finite target values. Fit the existing nonlinear rank-RNA/pathway kernel with penalty 4 and inverse patient multiplicity weights. Select RNA features only on the linked 2D source roster. Fit weights never use LICOB profiles or outcomes.
- Standardize predicted query contrasts within lot and average equally within a source. Equal-source transfer averages PRISM and NCI ordering scores for the five shared parents and uses NCI for GSK126. Transfer changes the order within each supported drug by mapping the predicted rank onto that drug's existing frozen score distribution. This step uses the full unlabeled query batch and is transductive. Unsupported parents retain their earlier predictions. Compare the joint candidate, the two source-only controls, the frozen earlier transfer and frozen drug mean. This preserves earlier between-drug score distributions at the organoid level and avoids joining single-dose LFC, GI50 and AUC in one regression.
- Freeze all five conditions across the entire 43 × 76 query table before a separate S6 score. Average measurements and estimates within the same adult donor as in the earlier comparison. Report the intersection, the two source supports, and full-panel results. The registered decision requires a paired patient-and-drug bootstrap 95% lower limit above zero for both within-drug Spearman and Pearson on the six exact parents, versus both frozen drug mean and the earlier frozen transfer. On the full panel the donor-paired 95% lower limit must exceed −.005 for within-donor Spearman, NDCG@5 and top-five overlap against each reference. Report individual drug estimates as descriptive values. This decision addresses the six-parent data expansion and cannot establish overall superiority to published models.
