# HCC 오가노이드 반응의 반복 성분과 같은 검체 내 차이

약물 평균과 환자 전반 감수성의 일치가 높더라도 특정 환자의 약물별 편차까지 반복된다고 볼 수 없다. 기존 공개 자료에서 이 세 성분을 각각 비교하고, LICOB의 동일 검체에서 확립한 서로 다른 PDO 간 반응 차이를 기존 RNA 예측이 추적하는지 확인한다. [기존 3D 일치도](HCC_3D_PUBLIC_RESPONSE_RESULTS.md)

- Kim S7의 18개 HCC PDO×8약물×3회 완전 반복에서 반복 번호 세 쌍을 각각 비교한다. 표에 기록한 passage 차이를 포함한 반복 일치도다. Zhang의 성인 HCC 33명×4약물은 같은 환자의 단일배양과 CAF 공배양을 비교한다. 두 자료를 합치지 않는다. [Kim 논문과 S7](https://doi.org/10.1002/ctm2.70853) · [Zhang 논문과 S3·S13](https://pmc.ncbi.nlm.nih.gov/articles/PMC13700430/)
- 각 완전 반응 행렬에 전체 평균·약물 평균·환자 평균을 제거하는 두 방향 분해를 적용한다. 관측 반응의 약물별 환자 Spearman·Pearson, 환자 내 약물 Spearman, 약물 평균과 환자 평균의 PCC, 잔차 PCC 및 반응 제곱합 중 잔차 비율을 낸다. Kim은 같은 쌍의 양방향 NDCG@5·Precision@5를 평균한다. Zhang은 네 약물이므로 Top-5 대신 Top-1을 보고한다. 잔차 PCC 및 두 약물 내 상관은 환자·약물을 함께 2,400회 짝지어 재표집한다. 잔차 PCC 구간 하한 >0을 해당 측정 비교에서의 양의 일치 근거로 본다. 독립 재배양의 이론적 모델 상한은 이 통계로 추정하지 않는다.
- LICOB S1의 동일 검체 각주와 성인 HCC 및 S6의 ID 헤더를 반응 수치 없이 연결한다. 등록 RNA와 반응이 있는 4공여자·9 PDO에서 각 공여자의 모든 순서 없는 쌍을 분석한다. PDO ID 사전순으로 차이의 방향을 고정한다. 원 데이터의 76약물과 기존 RNA 예측과 일치한 53약물에서 같은 공여자 및 다른 공여자 간 관측 AUC 차이의 RMS를 각각 보고한다. 각 공여자 또는 공여자 쌍을 동등 가중한다. 기존 논문의 sorafenib 반복 그림과 S6의 PDO별 요약값을 구분한다. [LICOB 논문과 S1·S6](https://pmc.ncbi.nlm.nih.gov/articles/PMC10949980/)
- 기존 해시 등록의 53약물 구조 커널, Ridge, CellHit, CODE-AE, Velodrome, V0+, 상호작용 신경망, 소스 선택 보정에서 각 PDO 쌍의 예측 차이를 다시 동결한다. 별도 작업에서 관측 차이와의 약물 내 패턴을 쌍별 Spearman·Pearson 및 비영 실측 차이의 부호 일치율로 측정한 뒤 공여자별 동등 평균을 낸다. 공여자 한 명씩을 뺀 값의 범위를 기록한다. 4공여자의 기술 결과이며 모형 승격이나 치료 판단에 사용하지 않는다.
- 원본과 이전 예측의 SHA-256을 검증한다. Kim·Zhang 반복 일치도는 독립 작업에서 계산한다. LICOB 예측 차이는 먼저 해시로 동결한 뒤 별도로 채점한다. 원본과 환자별 수치는 G1에 보관하고 집계와 영수증을 버전에 남긴다.
