# VCB-01 공개 외부 평가와 VCB-05 보정

GDSC2·CTRPv2·PRISM 20Q2에서만 반응을 학습하고, 이 세 학습 자료에서 확인되지 않은 성인 LIMORE HCC 50개 독립 계통의 68약물 순위를 평가했다. LIMORE의 입력은 별도 기저 발현과 화합물 구조다. LIMORE의 Activity Area는 예측과 해시를 고정한 후 별도 채점 프로세스에 제공했다. 이전 프로젝트에 LIMORE 노출 이력이 있어 이번 결과의 독립성은 동결한 세 학습원과 50개 계통에 한정된다.

| 역할 | 반응 행 | 세포 모델 | 약물 |
|---|---:|---:|---:|
| GDSC2 학습 | 24,839 | 714 | 42 |
| CTRPv2 학습 | 31,097 | 731 | 49 |
| PRISM 20Q2 학습 | 9,749 | 717 | 18 |
| 학습 전체 | 65,685 | 1,014 | 68 |
| LIMORE 외부 평가 | 3,400 | 50 | 68 |

학습 소스 간 세포 중복을 합쳤다. 77개 성인 LIMORE에서 네 소스 명부(GDSC1/2 모두 감사)와 Cellosaurus의 별칭·부모/관련 세포·환자 키를 비교했다. 원자료 독립성 기준을 만족한 55개 모델·54개 계통 가운데 미리 정한 순서로 50개를 골랐다. 남은 5개 모델은 다른 후보를 탐색하거나 급간을 맞추는 데 쓰지 않았다. 공통 기저 RNA 축은 17,871개 유전자다. 각 소스 원 AUC를 감수성 방향으로 정렬하고 세포 내부 순위로 변환했으며, 예측 우선순위는 LIMORE AA의 수치 단위를 갖지 않는다. ## 공개 소스 보정

계통을 무작위 해시 순서로 사전 분할했다. 15개 계통으로 LIMORE 척도를 맞추고, 별도 10개 계통에서 구간을 보정했다. 남은 25개 계통에서 5개 sentinel 약물을 제외한 63개씩 1,575개 실측으로 채점했다.

| 보정 모델 | LIMORE AA MAE | NDCG@5 | 90% 목표 구간 |
|---|---:|---:|---|
| 약물 평균 + 소스 척도 | 0.15202 | 0.70011 | 관측 coverage 100%, 평균 폭 1.73173 |
| 구조·RNA 직접 + 소스 척도 | 0.15589 | 0.73016 | 관측 coverage 100%, 평균 폭 1.78793 |
| 약물 평균 + 소스 척도 + sentinel | 0.15375 | 0.70011 | 구간 유보 |
| 구조·RNA 직접 + 소스 척도 + sentinel | 0.15969 | 0.73016 | 구간 유보 |

직접 모델에서 sentinel 추가의 MAE 상대 개선은 −2.44% [−8.20%, +2.90%]였다. 평균에서도 −1.14% [−6.92%, +4.22%]였다. 추가 측정이 이 규약에서 이득을 준다는 근거가 부족하다. 계통별 상한 잔차로 만든 구간은 이 공개 검증에서 모든 관측을 포함했으나 폭이 넓었다. 동일 계통의 일정한 보정은 개별 계통의 순위를 보존한다. 현지 sentinel 측정과 지역별 보정은 자료 대기다.
