# Basal molecular context features on the same public LIMORE lineage folds

This comparison tests feature blocks with the same endpoint, train-only transformation, Ridge penalties and scope as the functional lineage holdout. For every arm, the baseline is ECFP and a fixed descriptor block with train-fold RNA PCA and the known-drug fit mean. Each arm independently chooses from ridge penalties 10, 100 and 1,000 by three inner lineage folds. The scorer runs separately after prediction freeze. The comparison is public development and every added field is measured or available at prediction time on the evaluated rows.

- **Target expression.** LIMORE Table S4 supplies the assay authors' drug target annotations. A conservative symbol/family translation maps these labels to expression genes. Mean and maximum fit-standardized basal expression among the mapped symbols, plus measured-gene fraction, are tested as a small block. Generic mechanism terms with ambiguous protein membership remain unmapped. A term such as VEGFR can represent a family without implying that every drug binds each member equally.
- **Pathway interactions.** Eight prelisted MSigDB Hallmark v2026.1.Hs sets for cell cycle, apoptosis, DNA repair, KRAS, PI3K/AKT/mTOR, mTORC1 and WNT are represented by the mean standardized basal expression of measured members. The unweighted signatures are tested with interactions against eight fit-only chemical PCs. These are basal RNA summaries.
- **Driver mutations and CNAs.** LIMORE Table S3 provides per-line categorical codes. Separate sequence-alteration and homozygous-deletion/amplification indicators are computed for the prelisted driver panel in `context_features.py`. The sequence block includes the publisher's promoter and integration events where relevant, so its flags convey reported sequence events. A blank entry for an assayed cell means that Table S3 reports no qualifying event for that gene, and binary copy indicators convey published threshold events. Unmapped cell aliases remove that cell from all five arms, including the comparison baseline. Driver-to-drug interaction uses the same fit-only chemical PCs.
- **Combined.** All three measured blocks share the preceding direct baseline and penalty grid.

Target, pathway and driver blocks are single predeclared comparisons and the combined block includes all three. Report pairwise effects with lineage-bootstrap intervals alongside exact same-support denominators. This secondary analysis does not change the original C gate or the public external cohort contract. Archived R18/R19 predictions and treated expression are outside these feature inputs.

Sources are the authors' Tables S3 and S4 and the server copy of the MSigDB Hallmark release. The worktree stores source hashes and study summaries. Publisher sheets, MSigDB gene sets and per-cell genomic matrices stay on G1 under their source terms.
