# 요청 R16: 기존 VC에 같은 출력 배율을 준 공정 비교, 결합 모델, 새 자료 확인

2026-11-21 · Claude Code 검토 세션 작성. R15(`1213ffc` 명세, `e3526d6` 결과)의 명세·동결·채점은 건드리지 않는다.

## 왜 필요한가

R15는 사전 기준을 문자 그대로 통과했다. 그러나 R15의 추정값에는 내부 fold에서 고른 출력 배율(0.75)이 있었고 기존 VC 7종에는 없었다. R15 점수표에서 FiLM·concat은 방향 코사인이 R15보다 높은데(A: 0.154 대 0.119) RMSE는 B0보다 나쁘다. 크기를 과하게 예측한 것이다. 심사자는 "기존 VC에도 같은 배율을 주면 어떻게 되는가"를 물을 것이다. P1에서 위치를 맞춰 주자 우위가 사라졌던 것과 같은 종류의 질문이다.

## Claude의 탐색 확인 (공식 아님, `review_claude_20261121/diag16.py`, Slurm 29715)

R15 동결 예측을 그대로 읽어 각 모델 추정값(예측 − 공유 anchor)에 배율 {0, .125, .25, .5, .75, 1}을 곱했다. 배율은 다른 두 외부 fold에서 고르고 나머지 fold에 적용했다(외부 fold의 결과를 쓰므로 비교군에 유리한 근사다. 세 fold가 모두 같은 값을 골랐고 사후 최적값과 같았다). HEPG2 6 h 주 범위, 화합물군 10,000회 재표집 99%.

추정값의 크기(실측 잔차 대비 norm): R15 0.18–0.25, FiLM·concat 0.41–0.42, ChemBERTa 0.51, chemCPA 0.84–0.95, TranSiGen 0.94–1.06, PRnet 4.3–4.6. 방향 일치(에너지 가중 코사인)는 0.02–0.20 범위다.

해석(Claude, 미검증): 시나리오 A에서 R15가 기존 VC를 이긴 것은 대부분 출력 크기 차이다. 시나리오 B의 우위와 kernel+신경망 결합의 우위는 배율을 맞춰도 남는다. 다만 결합은 외부 fold 결과를 본 뒤에 떠올린 후보이므로 같은 fold에서의 수치는 낙관적이다. 새 자료에서 확인해야 한다.

## 요청

### 1. 공정 비교 (R15 사후 보강, 새 후보 없음)

- 기존 VC 7종 각각의 추정값에 출력 배율을 준다. 배율 격자는 R15와 같다. **내부 검증 fold에서** R15와 같은 선택 손실로 고른다. 내부 검증 예측이 저장돼 있지 않으면 CPU 모델(ChemBERTa, FiLM, concat)은 다시 적합하고, GPU 모델은 다시 적합하거나 "다른 두 외부 fold에서 선택" 방식을 쓰되 어느 쪽인지 명세에 적는다.
- B_cell에도 같은 배율을 준 `B_cell×g`를 기준선으로 추가한다.
- 판정: `R15 − 배율을 준 최선 기존 VC`, 시나리오 B는 `R15 − B_cell×g`도. 두 지표, 99%. 논문에서 출판된 모델(chemCPA, TranSiGen, XPert, PRnet)과 이 프로젝트 내부 기준 모델(ChemBERTa Ridge, R12 FiLM·concat)을 구분해 각각의 최선에 대해 따로 낸다.
- 이 결과는 R15 결과 문서에 "사전 기준 통과, 그러나 배율을 맞춘 사후 비교에서는 …"으로 함께 적는다. 사전 판정을 바꾸지 않는다.

### 2. R16 후보: 결합 모델 (사전 명세 후 한 번 채점)

- `예측 = anchor + a·(R15 선택 후보의 추정) + b·(FiLM 추정)`. a, b는 같은 격자에서 내부 fold로 고른다. 후보는 이것 하나와, FiLM 대신 concat을 쓴 것 하나까지만. anchor는 R15와 같다(A: 위치 성분, B: 위치 + B_cell×g).
- 판정(HEPG2 6 h 주 범위, A와 B 각각): 결합 − B0, − B_pos, − 배율을 준 최선 기존 VC, − R15, (B) − B_cell×g. 두 지표, 99%.
- 같은 외부 fold를 두 번째로 보는 것임을 문서에 명시한다. 이 fold에서의 통과만으로는 주장하지 않는다. 주장은 아래 3의 확인에 건다.

### 3. 새 자료 확인 (이 연구의 주 판정)

R16 절차(후보 종류, 격자, 선택 손실, 배율 규칙)를 **그대로 고정**한 뒤 R15·R16 선택에 쓰이지 않은 간 유래 자료에 적용한다.

- 후보 자료: CMap 2020 Level 3(`vcell_liver_transigen_adaptation_b1/assets/processed/cmap2020_v1`)의 HCC 세포주 HUH7·JHH5·JHH7과 HEPG2 24 h 중 **GSE92742·GSE70138에 없는 well**. HUH7·JHH는 간세포암이므로 목표에 더 직접 닿고, 24 h여서 Tahoe와 시간이 같다.
- 먼저 감사한다: (가) 두 GEO release와 겹치는 well·서명 제거 후 남는 화합물군 수, (나) R15·R16의 학습·선택에 들어간 측정과의 겹침, (다) 같은 위치 감사, (라) 품질 기준 적용 후 지원. 지원이 화합물군 100개 미만인 층은 기술 분석으로 표기한다.
- 설계: 각 대상 세포주에서 화합물 분리 3-fold. 학습에는 그 세포주의 학습 화합물과(있으면) HEPG2 자료를 쓴다. 시나리오 A와 B(같은 시간의 비간계열 실측 입력)를 둘 다 낸다. 비교군은 배율을 준 기존 VC 7종, B0, B_pos, B_cell×g다.
- 판정: 결합 모델 − B0, − 배율을 준 최선 기존 VC(출판 모델 최선과 내부 기준 최선 각각), (B) − B_cell×g. 두 지표, 99%. R8·B1에서 이 세포주들이 과거에 노출된 범위는 R15 감사 표대로 층을 나눠 낸다(과거 모델의 가중치는 쓰지 않으므로 새 모델의 평가로는 유효하나, 독자가 판단할 수 있게 표시한다).

### 4. 반복 측정 상한

HEPG2 6 h 주 범위에서 같은 화합물의 서로 다른 plate 측정끼리 예측했을 때의 RMSE·R²(한쪽 복제의 평균으로 다른 쪽을 예측)를 낸다. R15·결합 모델의 이득이 이 상한의 몇 %인지 한 줄로 적는다. 3의 확인 자료에서도 같은 값을 낸다.

## 지키는 것

감사 → 사전 명세 커밋 → 예측 동결 → 별도 채점. 봉인·격리·예약 코호트는 열지 않는다. Tahoe 외부 비교는 R15에서 실패로 확정했고 다시 하지 않는다. GPU는 다른 사용자 대기 시 동시 8개 이하. 보고는 관찰과 가설을 구분하고, "무엇을 측정했고 기준이 무엇이었고 통과했는가" 한 표를 낸다. 1이 끝나면 그 결과만 먼저 짧게 보고한다.
