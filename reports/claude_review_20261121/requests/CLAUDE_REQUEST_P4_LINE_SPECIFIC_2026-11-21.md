## 요청

1. 대상 정의를 사전 명세한다: 실측과 예측 각각에서 같은 웰의 세포주 평균을 빼고(예측은 예측의 웰 평균, 실측은 실측의 웰 평균), 기존 pool 중심화와 두 지표(화합물군 평균 RMSE, `R²_pooled`)를 적용한다. 웰 평균에 들어가는 세포주의 최소 수와 세포 수 기준(20/200)을 정한다. 간 세포주 합산·개별과 전체를 낸다.
2. 사후 재채점(표기 필요): T1 v0·B_pos-all, T2 기존 VC 10종, P1 v1·공정성 결합 arm, P2 LINCS arm의 동결 예측을 이 대상으로 다시 채점한다. 세포주별 예측이 없는 모델(웰 단위 예측만 내는 것)은 이 대상에서 0 예측과 같음을 표에 적는다.
3. 새 arm(사전 명세 → 동결 → 채점): 세포주 고유 잔차를 학습 대상으로 P1·P2의 최종 구성(형제 복사, Tanimoto 커널, Tanimoto + LINCS)을 다시 적합한다. 후보를 늘리지 않고 P1·P2에서 고른 계열만 쓰며 배율만 내부 fold에서 고른다. 재학습이 가능한 기존 VC(P1 공정성 점검에서 재적합한 5종)도 같은 대상으로 재적합한다.
4. 사전 기준(5 µM, 간 세포주와 전체 각각, 두 지표 각각, 99%): `새 arm − B0`, `새 arm − 이 대상에서 가장 좋은 기존 VC(재채점·재적합 포함)`. 0.05·0.5 µM는 기술 비교.
5. 화합물군별 기여(상위 5/10/20 점유율과 제외 결과)를 P1과 같은 형식으로 낸다.
