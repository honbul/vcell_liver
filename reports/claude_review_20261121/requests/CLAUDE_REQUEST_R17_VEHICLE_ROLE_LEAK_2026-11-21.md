# 요청 R17: 모델 선택에 섞인 vehicle 역할 누수를 고치고 다시 판정한다

2026-11-21 · Claude Code 검토 세션 작성. R15(`1213ffc`/`e3526d6`)와 R16(`de21f07`)의 동결·채점은 건드리지 않는다. 이 요청은 그 위에 얹는 교정 분석이다.

## 발견 (Claude 탐색, `review_claude_20261121/diag17.py`, Slurm 30517)

R16 보고서가 가설로 적은 것("안쪽 검증이 적합과 같은 역할의 DMSO를 쓰므로 그 역할의 대조군 변동을 재현하는 모델이 이득을 본다")을 동결된 배열로 직접 측정했다.

외부 fold 행에 대해 각 모델의 추정값을 두 가지 정답으로 채점했다. `같은 역할` = 처리 − 적합에 쓴 역할의 DMSO(안쪽 선택이 쓰는 규약), `반대 역할` = 처리 − 반대 역할 DMSO(공식 채점 규약). 각각이 선호하는 출력 배율과, 추정값이 두 DMSO 추출의 차이(순수 vehicle 잡음)와 이루는 에너지 가중 코사인이다.

| 모델 | 같은 역할이 고르는 배율 | 반대 역할이 고르는 배율 | cos(추정값, vehicle 차이) A / B |
|---|---|---|---|
| R15 (커널) | 1.0 | 0.75 | **+0.067 / +0.131** |
| ChemBERTa Ridge | 0.75 | 0.25 | +0.430 / +0.444 |
| FiLM_R12 | 1.0 | 0.25–0.5 | **+0.520 / +0.542** |
| Concat_R12 | 1.0 | 0.25–0.5 | **+0.525 / +0.542** |
| XPert_morgan | 1.0 | 0.25 | +0.471 / +0.450 |
| chemCPA_P0 | 0.25 | 0.125 | +0.262 / +0.239 |
| TranSiGen | 0.125–0.25 | 0.125 | +0.238 / +0.214 |
| PRnet | 0.0 | 0.0 | +0.052 / +0.049 |

관찰: 신경망 비교군의 추정값은 **방향의 약 절반이 적합에 쓴 역할의 vehicle 잡음**이다(코사인 0.43–0.54). 커널은 0.07–0.13이다. 그래서 같은 역할 정답은 신경망에 배율 1.0을 고르고, 반대 역할 정답은 0.25–0.5를 고른다.

해석(Claude, 미검증): R16의 "같은 배율 선택 기회"는 **절차는 같게 했지만 절차의 효과는 같지 않다.** 안쪽 검증이 적합과 vehicle 추출을 공유하므로, 대조군 잡음을 흡수하는 모델일수록 과도한 배율을 고르고 외부 채점에서 그만큼 손해를 본다. R15의 커널은 parent 평균에서 오므로 이 경로가 거의 없다.

이것이 R16의 두 결과를 설명할 수 있다. (가) 공정 비교에서 최선 기존 VC가 PRnet×0, 즉 약물 추정이 빠진 공유 anchor였던 것. 일곱 모델 전부가 자기가 고른 배율에서 "아무것도 예측하지 않기"보다 나빴다. (나) 결합 모델이 공식 R16에서는 졌는데(FiLM 배율 b=1) 다른 외부 fold로 배율을 고른 diag16에서는 이겼던 것(b=0.25).

## 요청

### 1. vehicle 역할 누수를 없앤 모델 선택 (이 연구의 핵심 교정)

RNA plate 안의 DMSO 웰을 **서로소 세 몫**으로 나눈다. 적합(fit), 안쪽 선택(select), 외부 채점(score). 현재는 fit과 select가 같은 몫을 쓰고 score만 다르다. 세 몫이 모두 독립이 되도록 R15의 A/B 분할 규칙(stable CRC32·ID 순서)을 3분할로 확장하고, DMSO가 3웰 미만인 행은 제외한다. 제외로 줄어드는 지원을 표로 낸다.

- 이 규약으로 **모든 모델의 배율과 안쪽 설정(epoch·학습률·커널 규칙)을 다시 고른다.** 후보·격자·자료·기준은 R15/R16과 동일하게 유지한다.
- 3분할이 지원을 크게 깎으면(평가 화합물군 1,000 미만) 대안으로 "select 몫 = score와 같은 반대 역할, fit만 분리"를 쓰고 어느 쪽을 썼는지 명세에 적는다. 이 경우 select와 score가 vehicle을 공유하므로 **선택이 평가를 들여다본다**는 점을 보고에 명시하고, 그때는 외부 fold 교차 선택(diag16 방식)을 같이 낸다.

### 2. 교정 규약에서의 판정 (사전 명세 후 한 번 채점)

HEPG2 6 h 주 범위, A와 B 각각, 두 지표, 99%:

- `R15 커널 − 배율을 맞춘 최선 기존 VC` (출판군 최선, 프로젝트 기준 최선 각각)
- `R16 결합(커널+FiLM, 커널+concat) − R15 커널`
- `결합 − 배율을 맞춘 최선 기존 VC`
- `R15 커널 − B0`, `− B_pos`, (B) `− B_cell×g`
- 모든 arm을 같은 교정 규약에서 다시 적합·선택한다. 비교군만 고치고 R15는 그대로 두는 비대칭을 만들지 않는다.

이 결과가 R15/R16의 사전 판정을 대체하지 않는다. "사전 규약에서는 통과했고, vehicle 역할을 분리한 교정 규약에서는 …"로 나란히 보고한다. 어느 쪽이 더 옳은 비교인지에 대한 판단을 한 단락으로 적는다.

### 3. vehicle 성분을 제거한 뒤의 화학 신호 (기술 분석)

각 모델의 추정값에서 vehicle 차이 방향 성분을 사영 제거한 뒤, 반대 역할 정답과의 에너지 가중 코사인과 화합물 균등 RMSE를 낸다. 질문은 "신경망이 커널보다 화학 신호를 더 많이 잡고 있는데 잡음 때문에 가려진 것인가, 아니면 애초에 더 적은가"다. 사영은 평가 행에서 추정하므로 사후 분석으로만 쓰고 판정에는 넣지 않는다.

### 4. 간암 세포주 자료 재고 조사 (보고만)

R16에서 HCC 확인 근거를 얻지 못했다(HUH7 비중복 웰 0, JHH5·JHH7 단일 웰). 목표가 간암 VC이므로, 서버에 있고 아직 쓰지 않은 간암 유래 섭동 자료가 무엇인지 한 표로 정리한다. 최소한 다음을 포함한다.

- LINCS/CMap 전체에서 `primary_site`가 간이거나 세포주명이 HCC 유래인 것의 세포주별 화합물군·서명·복제·plate 수, 품질 기준 통과 수, 이 프로젝트 과거 사용 이력.
- Tahoe의 SNU-423·HepG2/C3A에서, 위치를 통제한 뒤 남는 화합물군별 재현 에너지(T1·P1 수치 재사용 가능).
- GEO·기타 공개 자료 중 서버에 이미 받아 둔 간암 세포주 섭동 자료.

새 자료를 내려받거나 새 연구를 시작하지 말고 재고만 낸다. 이 표를 보고 다음 방향을 정한다.

## 지키는 것

사전 명세 커밋 → 예측 동결 → 별도 채점. 봉인·격리·예약 코호트는 열지 않는다. R15/R16의 기존 산출물은 보존한다. GPU는 다른 사용자 대기 시 동시 8개 이하. 보고는 관찰과 가설을 구분하고 사전 기준을 문자 그대로 적용한다. 1의 분할 방식이 정해지면 그 결정과 지원 수만 먼저 짧게 보고한다.
