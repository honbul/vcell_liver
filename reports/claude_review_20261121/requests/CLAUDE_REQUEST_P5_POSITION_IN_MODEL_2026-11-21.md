# 요청 P5: 위치 정보를 모델 안에 넣는 방식 비교

2026-11-21 · 사용자 질문("위치 정보를 모델에 태운다면 어떻게 태우는 것이 좋은지 실험")으로 Claude Code 검토 세션이 작성. 비공개 메모이며 Git에 커밋하지 않는다. P4가 끝난 뒤 시작한다. T1–T3, P1–P4의 명세·동결·채점은 건드리지 않는다.

## 배경

지금까지 위치는 모델 밖에서만 썼다. (1) 위치 추정값(trim donor 평균)을 예측에 배율을 곱해 더하는 방식(v0, v1, P1 공정성 결합 10종), (2) 학습 정답에서 위치 추정값을 뺀 뒤 모델을 다시 적합하는 방식(P1 재적합 5종). 5 µM 간 유래 합산에서 trim 단독은 RMSE 0.104251, R² 4.87%였고, 위 두 방식으로 기존 VC를 얹은 15종의 최선은 RMSE 0.104297(chemCPA 결합), R² 5.40%(FiLM 재적합)였다. 신경망 내부에 위치를 입력으로 주는 방식은 아직 평가하지 않았다.

## 질문

1. 위치를 신경망의 입력·조건으로 주면 바깥에서 더하는 것보다 나은가.
2. 위치와 약물의 상호작용(같은 약물이 위치에 따라 다르게 보이는 부분)을 모델이 잡아내는가.
3. 학습 때만 위치를 주고 추론 때 위치를 중립값으로 두면, 위치가 빠진 약물 반응 예측이 좋아지는가(위치가 없는 새 실험에 쓰는 경우).

## arm (호스트 구조는 R12 FiLM과 concat 두 개로 고정, 가능하면 chemCPA 하나 추가)

- A. 바깥 덧셈(기존 P1 결합, 대조).
- B. 위치 보정 정답으로 재적합(기존 P1 재적합, 대조).
- C. 위치 벡터 입력: 해당 (위치, 세포주)의 trim donor 평균을 fit-only PCA 16차원으로 줄여 약물·대조군 입력과 이어 붙인다.
- D. 위치 인덱스 임베딩: barcode 위치 인덱스(및 세포주와의 결합)의 학습 임베딩. 평가 화합물의 위치는 학습 화합물이 다른 plate에서 차지했던 위치이므로 학습 가능하다.
- E. FiLM 조건: C의 위치 벡터 또는 D의 임베딩으로 은닉층을 조절한다(위치×약물 상호작용 허용).
- F. 출력 덧셈 공동 학습: 출력 = 신경망(약물, 맥락) + s·위치 추정값, s를 함께 학습한다.
- G. 학습 때 C/E/F로 위치를 주고, 추론 때 위치 입력을 0(중립)으로 둔다.

후보는 이 일곱 가지로 제한한다. epoch·학습률은 T2에서 쓴 격자를 그대로 쓰고 내부 fold에서 고른다. 위치 추정에는 P1의 trim 설정과 own-parent 제외 규칙을 그대로 쓴다. D는 학습 화합물의 강한 반응이 임베딩에 섞일 수 있으므로 그 점을 보고에 적는다.

## 대조

- 위치 라벨 순열(같은 plate 안에서 위치 인덱스를 섞음) 3회: C–F의 이득이 사라져야 한다.
- 약물 입력을 0으로 둔 위치 전용 신경망: 위치만의 기여를 분리한다.

## 사전 기준 (5 µM, 최소 20세포, 간 유래 합산과 전체 각각, 두 지표 각각, 99%)

- C–F 각각 − trim 단독: 신경망이 위치 위에 무엇을 더하는가.
- C–F의 최선 − A·B의 최선: 안에 넣는 것이 바깥 덧셈보다 나은가.
- C–F의 최선 − P1 v1.
- G는 P4의 세포주 고유 대상과, 위치 추정값을 뺀 대상에서 B0 및 같은 구조의 위치 미사용 모델과 비교한다(원 대상에서는 기술 비교).

0.05·0.5 µM는 기술 비교. 화합물군별 기여(상위 5/10/20 점유율과 제외 결과)를 P1과 같은 형식으로 낸다. 사전 명세 → 동결 → 별도 채점, 봉인·격리·예약 코호트 미개방, GPU는 다른 사용자 대기 시 동시 8개 이하.
