# 요청 R18: R17 절차를 고정하고 다른 측정에서 확인한다

2026-11-21 · Claude Code 검토 세션 작성. R15·R16·R17의 동결·채점은 건드리지 않는다.

## 배경

R17(`8ca2b3f`)에서 DMSO를 fit/select/score로 분리하자 커널+FiLM 결합이 두 시나리오 모두에서 R15 커널과 배율을 맞춘 최선 기존 VC를 99% 기준으로 이겼다(A: R² 3.22% 대 2.04%, B: 5.91% 대 4.50%). 그러나 R17은 같은 GSE92742 HEPG2 6 h 행을 세 번째로 본 것이고, 결합이라는 후보도 그 행의 결과를 본 뒤에 나왔다. 이 행에서의 통과만으로는 주장할 수 없다. R17 문서도 "새 자료에서의 확인 평가가 아니다"라고 적었다.

R17 재고 조사로 쓸 수 있는 측정이 정리됐다. 이제 **절차를 한 글자도 바꾸지 않고** 다른 측정에 적용한다.

## 고정하는 것 (R17 그대로)

- DMSO 물리 웰의 fit/select/score 3분할과 역할 교대, 안쪽 선택 손실, 배율 격자, 화학 후보와 격자, 비교군 7종과 격자, 공유 anchor 정의, 결합의 정의(커널 추정 + 신경망 잔차, 두 계수는 격자 곱집합에서 안쪽 선택).
- **주 후보는 커널+FiLM 결합 하나.** 커널+concat은 보조로 같은 표에 낸다. R15 커널 단독도 낸다. 새 후보, 새 격자, 새 특징은 추가하지 않는다.
- 품질 기준(원본 `distil_cc_q75 ≥ 0.20`, 복제 2 이상), 구조 parent 정의, 화합물군 3-fold(같은 CRC32 규칙), 지표, 10,000회 parent 재표집 99%, 공동 기준(ΔRMSE 상한 < 0 그리고 ΔR² 하한 > 0).

## 확인 코호트

각 코호트에서 가중치는 새로 적합한다(R15–R17의 가중치·예측·선택 결과는 쓰지 않는다). 평가 화합물군의 측정은 어느 시간·용량·세포주 것이든 적합과 선택에서 제외한다(B의 비간계열 입력 제외).

| | 코호트 | 지위 |
|---|---|---|
| C1 | CMap 2020 HEPG2 24 h, 5–20 µM, GEO 두 release와 겹치지 않는 웰 (R16 확인 코호트와 같은 행, 약 500군) | **주 확인.** R16에서 이전 규약(fit/select 같은 DMSO)으로 한 번 채점된 행이다. 절차 변경은 다른 자료(GSE92742 6 h)에서 정했으므로 사전 고정 확인으로 쓰되, "이 행은 이전 규약으로 한 번 채점됐다"를 판정 표에 명시한다 |
| C2 | HEPG2 24 h 저용량 계열(GSE70138·CMap 2020의 0.04–3.33 µM) 중 R15–R17에서 적합·채점되지 않은 측정 | 보조 확인. 용량별로 따로 내고, 적격군이 100 미만인 층은 기술 분석. Tahoe의 0.05/0.5/5 µM와 같은 용량대다 |
| C3 | GSE92742 HUH7 3 µM (6 h 68군, 24 h 67군, 과거 원장과 일치하지 않는 QC 측정) | **간세포암 세포주 기술 확인.** 지원이 100군 미만이므로 판정이 아니라 99% 구간과 함께 기술 분석으로 낸다 |

C3의 설계는 두 가지를 사전에 정해 둘 다 낸다. (가) HUH7 측정을 전혀 쓰지 않고 같은 시간의 HEPG2로만 적합한 모델을 HUH7에 적용(간 계열 내 전이). (나) HUH7의 학습 fold를 추가한 적합. 주 기술값은 (가)다. 시나리오 B의 비간계열 입력은 같은 시간·같은 용량대의 측정으로 한정한다.

C1–C3 각각에 대해 먼저 감사한다: GEO release 간·과거 연구 간 웰 중복, DMSO 3분할 후 지원(plate당 3웰 미만 제외), 품질 적용 후 지원, 위치 감사(같은 위치 기준선의 B0 대비 이득). 감사 결과가 코호트 정의를 바꾸면 채점 전에 명세에 커밋한다.

## 판정 (C1이 주, A와 B 각각)

- `커널+FiLM 결합 − B0`
- `결합 − 배율을 맞춘 최선 기존 VC` (전체 최선, 출판 모델 최선, 프로젝트 내부 기준 최선을 각각)
- `결합 − R15 커널 단독`
- `결합 − B_pos`, (B) `결합 − B_cell×g`
- 같은 표에 커널 단독의 같은 비교도 낸다(결합이 실패하고 커널이 통과하는 경우를 독자가 볼 수 있게).

C1에서 A·B 모두 위 전부 통과면 "확인됨", B만 통과면 "전이 조건에서만 확인됨", 그 밖은 "확인되지 않음"으로 적는다. 이 세 문구 중 하나를 결과 문서 첫 줄에 쓴다.

## 함께 낼 것

- 각 코호트의 교차 plate 반복 측정 기준(R16과 같은 정의)과 도달률.
- 화합물군별 기여(상위 5/10/20 점유율, 제외 결과).
- 배율 선택 표(모델별로 고른 배율)와 추정값의 vehicle 방향 코사인(사후 기술).
- R15→R16→R17→R18에서 같은 비교가 어떻게 달라졌는지 한 표.

## 지키는 것

감사 → 사전 명세 커밋 → 예측 동결 → 별도 채점. 봉인·격리·예약 코호트는 열지 않는다. 새 자료 다운로드 없음. GPU는 다른 사용자 대기 시 동시 8개 이하. 관찰과 가설을 구분하고 사전 기준을 문자 그대로 적용한다. 감사가 끝나 코호트별 지원이 정해지면 그것만 먼저 짧게 보고한다.
