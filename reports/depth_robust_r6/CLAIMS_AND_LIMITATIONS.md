# R6 주장 범위와 한계

근거 수치는 [RESULTS.md](RESULTS.md)와 `tables/final_*.tsv`에 있다. 시험 약물 그룹 70개, 약물 그룹 bootstrap 95% 구간.

## 1. 주장하는 것 (관측)

1. Tahoe-100M 0.5 µM, 2,000 유전자, 대조군 세포 64개 조건에서, 대조군 UMI를 계산으로 25%까지 줄여도 박화 증강으로 학습한 모델(B00)의 미관측 약물 평균 반응 오차는 변하지 않는다(0.0838 대 0.0837).
2. 증강 없이 학습한 같은 모델은 p=0.25에서 11.6% 나쁘다(B00 − TEACH0 = −0.0110, 구간 [−0.0157, −0.0065]). 증강의 전체 관측 비용은 0.35%다.
3. 관측 신뢰도 입력, teacher 반응·latent 일치, 발현 재구성은 B00 대비 사전 기준(구간이 0 제외, 상대 차이 1% 이상)을 충족하지 못했다(−0.54% ~ +0.70%).
4. B00은 같은 입력·같은 증강의 Ridge보다 3.7%, 세포주 평균보다 9.0% 낮다. 세포주 48개 모두에서 Ridge보다 낮다.
5. 대조군 상태 입력을 빼면 13.1% 나빠진다.
6. SNU-423에서도 같은 양상이다.

## 2. 주장하지 않는 것

- **실제 저깊이 측정에 대한 강건성.** 범위는 "합성 관측 감소(이항 박화)에 대한 강건성"이다. 독립된 저깊이 wet-lab 자료로 확인하지 않았다.
- **blind 결과.** 이미 채점된 공개 benchmark에서의 사전 고정 후속 평가다.
- **teacher·관측 신뢰도 입력이 쓸모없다는 일반 명제.** 이 깊이 범위, 이 과제(평균 반응), 이 구성에서 추가 가치가 확인되지 않았다는 것까지다. B01의 −0.5%는 구간이 0을 제외하지만 기준 미달이며 p=1.0에서도 같은 크기다.
- **새 세포주·새 plate·새 용량으로의 일반화.** 시험하지 않았다.
- **약물 특이 기전.** 예측 이득의 대부분은 세포주·pool 수준의 공통 반응이다. retrieval top-1은 6%다.
- **chemCPA에 대한 저깊이 우위.** p=0.5, 0.25의 chemCPA 값은 adapter의 기준 평균 불일치가 지배하므로 공정한 승패로 세지 않는다. p=1.0 비교(−20.9%)도 chemCPA를 재학습하지 않은 고정 checkpoint 대비다.
- **State 대비 우위.** State는 실행하지 않았다.
- **환자 HCC에 대한 함의.** SNU-423은 세포주 하나다.

## 3. 가설이며 검증하지 않은 것

- 상태 입력의 이득 일부는 입력 세포와 정답의 기준 대조군이 같은 well을 공유하는 데서 올 수 있다(pool 고유 성분). plate를 숨기는 평가로만 가를 수 있다.
- 수정 1(약물 특이 항 축소)이 왜 14% 이득을 주는지: 약물 수 130–209개로는 약물 특이 항이 과적합한다는 설명이 관측과 맞지만 분해 실험은 하지 않았다.
- teacher arm의 0.3–0.5% 이득은 깊이 보존이 아니라 일반적인 정규화 효과일 수 있다(p=1.0에서도 같은 크기라는 관측에 근거).

## 4. 알려진 한계

- 수정 1은 개발 fold 결과를 보고 넣은 기본 모델 변경이다(사전 기록 D7, 모든 arm 공통). 시험 약물은 그 뒤에 처음 읽었다.
- 선택된 학습률 일부(3e-3)와 λ=10, Ridge 약물 벌점이 탐색 격자의 끝이다.
- 개발 fold 선택은 학습 seed 하나로 했다.
- Tahoe는 전체 관측도 얕다(중앙값 1,882 UMI). "전체 관측"이 깊은 측정을 뜻하지 않는다.
- 유효 조건 257개(pool의 대조군 세포 부족)를 제외했다. 정답의 기준 대조군을 다시 정의했으므로 이전 연구의 수치와 소수 셋째 자리에서 다르다.
- 신경망의 N=16, p<0.25는 실행하지 않았다.
- GPU 시간은 로그 기준 추정치다(scheduler 회계 조회 불가).
