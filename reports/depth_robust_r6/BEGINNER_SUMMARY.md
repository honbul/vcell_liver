# R6 쉬운 요약: 대조군을 덜 읽어도 약물 반응을 맞힐 수 있는가

아래 수치는 모두 실제 실행 결과다. "가상 예시"라고 표시한 부분만 설명용이다. 자세한 표는 [RESULTS.md](RESULTS.md).

## 1. 표의 한 줄은 무엇인가

한 줄은 "세포주 하나에 약물 하나를 처리한 실험"이다. 예: 간암 세포주 SNU-423에 약물 A를 0.5 µM로 넣었다.
이런 줄이 시험용으로 3,283개 있다(약물 그룹 70개 × 세포주 최대 48개).

## 2. 모델에 무엇을 넣는가

- 약물을 넣지 않은 **대조군 세포 64개**의 RNA 개수(유전자 2,000개). 같은 plate, 같은 세포주에서 고른다.
- 약물의 화학 구조(지문).

이번 연구의 핵심은 대조군 세포를 **덜 읽은 것처럼** 만드는 것이다. RNA 분자 하나하나를 동전 던지기로 남기거나 버려서 100%, 50%, 25%만 남긴다.

가상 예시: 어떤 세포에서 유전자 X의 분자가 8개 읽혔다면, 25% 보기에서는 분자마다 25% 확률로 남겨 2개쯤 남는다. 0개가 될 수도 있다.

실제로는 세포 하나에서 읽힌 분자 수의 중앙값이 1,882 → 941 → 471개로 줄고, 검출되는 유전자는 490 → 293 → 165개로 줄었다.

## 3. 진짜 정답은 무엇인가

실제로 약물을 처리하고 측정한 세포들의 평균 발현에서, 대조군 평균을 뺀 값이다. 유전자 2,000개 각각이 얼마나 오르내렸는지다.
**정답은 항상 전부 읽은 자료로 계산한다.** 입력만 줄이고 정답은 줄이지 않는다. 모델 출력으로 정답을 대신하지 않는다.

## 4. 모델은 무엇을 배우는가

학습 약물 209개 그룹에서 "이 대조군 상태 + 이 약물 → 이런 변화"를 배운다. 다섯 가지 방식을 같은 조건에서 비교했다.

| 이름 | 한 줄 설명 |
|---|---|
| B00 | 학습 때 대조군을 무작위로 덜 읽은 것처럼 바꿔 가며 보여 준다(증강). 그 밖에는 아무것도 추가하지 않는다 |
| B10 | B00 + "이 세포는 얼마나 읽혔는가"를 입력에 알려 준다 |
| B01 | B00 + 전부 읽은 자료로 먼저 학습한 선생 모델의 답과 같아지도록 추가로 훈련한다 |
| B11 | B10과 B01을 둘 다 한다 |
| DEN | B10 + 덜 읽은 입력에서 원래 발현을 복원하는 연습을 시킨다 |

## 5. 무엇을 숨겼는가

**약물**을 숨겼다. 시험 약물 70개 그룹은 학습, 설정 선택, 선생 모델 어디에도 쓰지 않았다.
세포주와 plate는 숨기지 않았다. 따라서 이 결과는 "처음 보는 약물"에 대한 것이고 "처음 보는 세포"에 대한 것이 아니다.
또한 덜 읽은 자료는 계산으로 만든 것이다. 실제로 얕게 측정한 실험이 아니다.

## 6. 숫자는 무엇을 뜻하는가

오차(ΔRMSE)는 예측한 변화와 실제 변화의 차이다. **낮을수록 좋다.**

| 모델 | 25%만 읽음 | 전부 읽음 |
|---|---|---|
| 아무 변화 없다고 예측 | 0.1041 | 0.1041 |
| 세포주별 평균 반응 | 0.0920 | 0.0920 |
| 단순 선형 모델(Ridge) | 0.0870 | 0.0870 |
| **B00** | **0.0838** | 0.0837 |
| B10 | 0.0844 | 0.0843 |
| B01 | 0.0833 | 0.0833 |
| B11 | 0.0835 | 0.0835 |
| DEN | 0.0842 | 0.0841 |
| 증강 없이 학습한 모델 | 0.0948 | 0.0834 |

읽는 법:

1. **증강이 없으면 덜 읽었을 때 나빠진다.** 0.0834 → 0.0948(13% 악화). 문제는 실제로 있었다.
2. **증강만 하면 해결된다.** B00은 25%만 읽어도 0.0838로 전부 읽었을 때와 같다.
3. **더 복잡한 방법은 차이를 만들지 못했다.** B10, B01, B11, DEN은 B00과 0.3–0.7% 차이로, 미리 정한 기준(1% 이상)에 못 미친다.
4. B00은 단순 선형 모델보다 3.7%, 세포주 평균보다 9.0% 좋다.

간암 세포주 SNU-423만 봐도 같은 순서다(B00 0.0921, Ridge 0.0947, 세포주 평균 0.0989).

주의할 점:

- 이 자료는 이전 연구들이 이미 채점한 공개 자료다. 완전히 새로운 시험이 아니다.
- 모델이 맞히는 것은 주로 "이 세포주, 이 plate에서 약물이 일으키는 평균적인 변화"다. 약물마다 다른 고유한 반응을 맞힌다는 증거는 약하다.
- 공개 모델 chemCPA는 전부 읽은 조건에서 0.1059였다. 덜 읽은 조건의 chemCPA 값(0.2064)은 계산 방식 때문에 불리해서 공정한 비교로 세지 않는다.

## 7. 다음 결정

관측 신뢰도 입력, 선생 모델, 발현 복원 같은 추가 장치는 여기서 개발을 멈추고, 앞으로는 "덜 읽은 것처럼 바꿔 가며 학습하기"만 기본으로 쓰는 것을 권고한다.
실제로 얕게 측정한 자료에서도 같은지는 그런 자료가 생겼을 때 확인해야 한다.
