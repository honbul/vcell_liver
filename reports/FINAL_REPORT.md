# 유전자 개입 후 RNA 반응 예측: 재현 및 튜닝 연구

공개 자산으로 GEARS와 scGPT를 다시 학습했으나 두 논문의 원 수치와는 차이가 있었다. 별도의 공통 Norman 평가에서는 전체 미세조정 scGPT의 오차가 가장 낮았고, 대조군 재샘플링은 세 학습 시드의 홀드아웃 평가에서 개선을 보이지 않았다. 실제 유전자 개입 후 단일세포 RNA를 갖춘 적격 HCC 자료는 조사한 후보에서 확보하지 못했다.

공개 모델이 실제 유전자 개입 뒤의 RNA 반응을 예측하는지, 같은 조건에서 모델의 학습 범위나 데이터 샘플링을 바꾸면 오차가 줄어드는지 살폈다. Norman 데이터는 K562 세포에 대한 단일·이중 CRISPRa 개입, 개입 후 단일세포 RNA, 대조군을 함께 제공한다. GEARS와 scGPT는 모두 개입 후 발현 벡터를 출력하는 원래 과제를 수행했다. 이전 작업은 [아카이브](../archive/README.md)에 보존했으며, 이번 실행에는 출처와 해시를 확인한 공개 데이터와 저자 배포 가중치만 가져왔다.

GEARS는 두 유전자를 함께 개입했을 때 미관측 표적이 늘수록 예측이 어려워지는지를 확인하는 데 썼다. 공개 가공본에 논문의 simulation 분할을 적용하고, 검증 오차로 체크포인트를 고른 뒤 미관측 표적 수별로 원 지표를 계산했다. 저자 결과처럼 미관측 표적이 늘수록 오차가 커졌지만, 재실행의 오차는 세 그룹 모두 더 높았다. 두 표적이 모두 미관측인 그룹에서는 대조군 오차로 나눈 분모보다 GEARS 자체의 오차 차이가 컸다.

scGPT는 사전학습한 표현 모델을 같은 Norman 개입 예측에 적용하는 비교점이다. 저자의 Fig. 3a 코드에서 학습·검증 방식을 가져왔고, 공개 체크포인트에서 backbone 텐서 153개가 실제로 로드됐음을 확인했다. 학습에는 원 코드의 무작위 유전자 패널을 사용하고 평가는 전체 출력 패널에서 했다. 재실행에서는 패널에 포함된 개입 표적 플래그가 30.37%여서, 이후 공통 실험에서는 표적을 항상 포함하도록 별도 규칙을 적용했다.

[논문 재현 상세 보고서](PAPER_REFERENCE_RESOLUTION.md)에는 원 수치의 출처, 환경 차이, 재계산 검증을 기록했다. 두 모델 모두 저장한 예측에서 해당 지표를 다시 계산해 일치시켰다. 원 실행의 비공개 데이터 캐시와 대조군 배정은 확인할 수 없었으며, scGPT 그림의 근삿값(전체 0.58, DE 0.77)과 저자 로그 값은 별도로 기록했다. 이후 개선 여부는 이 연구의 공통 기준선과 비교한다.

## 공통 기준선과 모델 변경

논문 재현과 별개로 개입 단위의 공통 분할을 고정했다. 학습 155개, 검증 34개, 테스트 34개 개입에 대해 출력 유전자 4,547개와 동일한 평가 대조군 32개를 사용한다. 주지표는 각 개입의 평균 발현 변화량에 대한 RMSE를 계산한 뒤 개입에 같은 가중치를 주어 평균한 값이다. 세포 수는 독립 생물학적 반복 수로 해석하지 않는다.

평가 대조군 32개는 학습용 대조군 풀 7,353개에 포함된다. 평가에서 신경망은 같은 32개 각각에 대해 발현을 예측해 평균하고, 단순 기준선은 같은 32개의 평균 발현에 학습 데이터에서 구한 반응을 더한다. 배치 메타데이터가 없어 실제 실험 배치별 대조군 매칭이나 독립 대조군 반복은 확인할 수 없다. 홀드아웃 단위는 처리 개입이며, 이미 공개된 데이터의 새 분할이다. 예측과 실측 양쪽에서 같은 대조군 평균을 빼므로 ΔRMSE에서 그 평균은 상쇄된다. 따라서 변화량 상관, 반응 방향, 상위 반응 유전자 회복도 함께 본다.

[기준선 검증](common/C0/README.md)에서 전체 미세조정 scGPT의 ΔRMSE는 0.03429였다. 선형 GO ridge는 0.05071, GEARS는 0.06363, 학습 평균 반응은 0.06779, 무변화 예측은 0.07707이었다. 가산 기준선은 두 단일 개입이 모두 학습에 있는 8개 조합에서 비교했다.

학습 범위를 줄인 세 조건 모두 M0보다 검증 오차가 높았다. LoRA는 학습 파라미터를 M0의 약 2.4%로 줄였지만, 같은 GPU에서 전체 학습·검증 시간은 약 12%만 줄었다. 무작위 초기화는 같은 구조와 학습 조건에서 M0보다 오차가 높았다. 이 비교는 단일 분할·학습 시드의 검증 결과다. [모델 선정 기록](common/M/model_selection.json)에 따라 데이터 비교에는 M0를 고정한다.

## 모델을 고정한 데이터 변경

전체 미세조정 scGPT(M0)와 분할을 고정하고, 학습용 대조군의 배정 방식 또는 개입별 표본 노출을 바꿨다. 세 조건 모두 15회 학습 동안 회차마다 표본 56,049개와 업데이트 1,752회를 사용했다. 검증에는 같은 34개 개입과 고정 평가 대조군을 사용했다.

| 데이터 조건 | 실제로 바뀐 것 | 최적 회차 / 검증 ΔRMSE ↓ | D0 대비 검증 오차 차이 |
|---|---|---:|---:|
| [D0: 고정 대조군 배정](common/C0/scgpt/result.json) | 개입별 노출 52–1,171회 | 15 / 0.03429 | 기준 |
| [D1: 학습용 대조군 재샘플링](common/D/D1/result.json) | 같은 처리 세포를 사용하고 회차마다 고정 배정의 99.97–99.99%를 교체 | 15 / 0.03494 | +0.00065 |
| [D2: 개입별 균등 샘플링](common/D/D2/result.json) | 개입당 361–362회, 고유 처리 세포 43,022–43,037개 | 15 / 0.03576 | +0.00147 |

D1의 배정은 서로 다른 대조군 세포와 처리 세포의 학습용 조합이다. D2는 표본이 적은 개입을 반복해서 뽑았고, 단일·이중 개입의 비율도 달라 회차당 표적 플래그가 86,783–86,790개가 됐다(D0와 D1은 79,348개). [첫 회차 기록](common/D/first_epoch_sampling.json)과 15회 전체 결과에서 학습 예산과 샘플링 차이를 대조했다. 두 변경 모두 검증 주지표를 개선하지 않았다.

[확인 실험 계획](common/D/confirmation_plan.json)은 검증 점수로만 정했다. 모델 변경과 데이터 변경이 모두 검증 기준선을 넘지 못했으므로, 사전에 정한 규칙에 따라 차이가 가장 작았던 D1과 D0를 M0로 고정해 비교했다. 각 조건의 시드 0 체크포인트는 앞선 실행에서 가져왔고 시드 1·2는 새로 학습했다. [확정 목록](common/F/study/frozen_test.json)에 체크포인트와 검증 결과의 해시를 저장한 뒤, 같은 34개 홀드아웃 개입을 평가했다.

[분할 메타데이터 검증](preflight/common_split_audit_s26.json)에서 테스트 개입은 단일 표적 15개와 조합 19개였다. 단일 표적 중 8개는 어느 학습 개입에도 등장하지 않았다. 조합 19개의 구성 표적은 모두 학습 중 한 번 이상 등장했지만 해당 조합 자체는 홀드아웃이다. 두 구성 표적의 단일 개입이 모두 학습에 있는 8개 조합에서만 가산 기준선을 비교할 수 있다.

[사전 분석 규칙](../protocols/common/selection-v1.json)은 같은 시드와 같은 개입에서 `D0 오차 − D1 오차`를 계산하고, 개입별로 세 시드의 차이를 평균하도록 정했다. 양수는 D1에 유리하다. 이 개입별 차이를 10,000회 재표집해 95% 구간을 계산한다. 표적과 대조군을 공유한 개입은 서로 의존할 수 있으므로, 구간은 관찰한 개입 집합에 대한 기술적 요약이다. 학습 시드는 생물학적 반복이 아니다. 세 시드 모두에서 오차가 줄고 구간의 하한도 0보다 클 때만 추가 분할 27·28에서 같은 두 조건을 확인한다.

D1의 시드별 개선량은 −0.00185, −0.00012, +0.00015였다. 평균 오차는 소폭 높았고 구간이 0을 포함했다. 두 방식의 효과가 정확히 같다고 결론 내릴 수는 없다. 세 시드가 모두 개선되지 않았으므로 추가 분할 27·28은 실행하지 않았다. 평균 ΔPearson은 D0 0.8465 / D1 0.8427, 반응 방향 일치율은 97.21% / 97.25%, 상위 20개 변화 유전자 회복률은 56.37% / 54.22%였다. 여기서 상위 20개는 평가 단계에서 관측한 절대 변화량으로 고르며 통계적으로 유의한 DE 목록을 뜻하지 않는다. A100 80 GB PCIe에서 시드당 학습·검증은 평균 74.37 / 74.55분, 홀드아웃 평가 작업은 평균 18.47 / 16.75초였다.

같은 홀드아웃에서 무변화, 학습 평균 반응, 선형 GO ridge, GEARS, scGPT(M0, 시드 0)의 ΔRMSE는 각각 0.07621, 0.06960, 0.05661, 0.06423, 0.04012였다. 가산 기준선은 적용 가능한 조합 8개에서 0.04827이었고 같은 8개에서 scGPT는 0.04668이었다.
