# 연구 R4 — 쉬운 요약

## 무엇을 물었나

어떤 약물을 세포에 넣으면 유전자 978개의 발현이 바뀐다. **한 번도 실험하지 않은 새 약물**이라도, 그 약물의 화학 구조와 처리 전 세포 상태만 보고 이 변화를 미리 맞힐 수 있을까?

이번 아이디어: 학습할 때 "실제로 비슷한 변화를 일으킨 약물끼리는 모델 안에서도 가깝게" 배우게 하자. 반복 실험에서 흔들리는 관계는 약하게 믿는다. 이렇게 하면 새 약물도 더 잘 맞힐 것이라고 기대했다.

## 어떻게 시험했나

- 약물 8,288개를 셋으로 나눴다: 학습 70%, 개발용 검증 15%, 마지막 시험 15%. 시험 약물은 **어떤 세포주에서도** 학습에 쓰지 않았다.
- 비교한 모델
  - W0: 공개 모델 WAVE 그대로
  - W1: 같은 부품으로 "변화량"을 직접 예측하게 바꾼 모델
  - W2: W1 + 비슷한 반응끼리 가깝게 배우는 보조 목적(이번 제안)
  - 단순 기준선: 아무 변화 없음, 세포주별 평균 변화, 선형 회귀(Ridge)
- 설정은 검증 약물로만 고르고, 모든 것을 고정한 뒤 시험 약물로 **한 번만** 채점했다.

## 무엇이 나왔나 (오차, 낮을수록 좋음)

| 모델 | 시험 오차 |
|---|---:|
| 선형 회귀 (Ridge) | **0.538** |
| 세포주별 평균 변화 | 0.543 |
| W2 (제안) | 0.550 |
| W1 | 0.551 |
| 아무 변화 없음 | 0.557 |
| W0 (WAVE 원형) | 0.709 |

- **제안한 보조 목적(W2)은 W1과 차이가 없었다.** 그래서 채택하지 않았다.
- 변화량을 직접 예측하게 바꾼 것(W0 → W1)은 크게 도움이 됐다.
- 그러나 신경망 모델 모두가 **단순한 선형 회귀보다 나빴다.** 신경망은 변화의 크기를 너무 작게 예측하는 경향이 있었다.
- 간암 세포주 3개(HUH7, JHH5, JHH7)에서도 같은 순서였고, 시험 약물이 적어 확실한 차이는 말하기 어렵다.

## 주의할 점

- 결론은 이번 설정(이 모델 구조, 이 자료, 이 학습 예산)에 한정된다. "반응 관계를 이용한 학습은 언제나 쓸모없다"는 뜻이 아니다.
- 공개 자료라 완전히 처음 보는 자료는 아니다.
- 환자 치료 반응이나 약물의 작용 기전을 예측한 것이 아니다.
