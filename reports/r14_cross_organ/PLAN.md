# R14 여러 암종의 약물 반응을 이용한 간암 예측 검증 계획

**주 질문은 다른 장기·암종의 처리 발현을 학습에 추가하면 SNU-423에서 처음 보는 약물의 발현 변화 방향을 더 잘 맞히는가다.** 이전 R13의 화합물 분할과 독립 A549 전이에서 영 대비 기준선 B0 대비 개선이 재현되지 않았다. 이번에는 모델 구조와 평가 표본을 맞추고 학습 데이터만 바꿔, 어느 자료가 간 예측에 기여하는지 측정한다. [R13 결과](../r13_optimization/RESULTS.md)

## 실험 순서

| 단계 | 비교 | 판단에 쓰는 결과 |
|---|---|---|
| 1. 학습 전 자료 계약 | 약물명·염·별칭·SMILES·CAS·DTXSID·PubChem CID를 원본 수준에서 연결한다. 확인되지 않은 구조는 엄격한 새 약물 학습에서 보류한다. 샘플 ID·세포주 ID·농도 단위·시간·물리 웰·배치·대조군·유전자 매핑을 동결한다. | 자료별 실제 남는 화합물군, 겹치는 평가 화합물, 판정 가능한 처리 웰, 유전자 교집합과 최고 학습 이웃 유사도. 새로 더해지는 화학 영역이 어느 평가 화합물군에 도움이 될지 수치화한다. |
| 2. 반복으로 반응 재현성 측정 | Sci-Plex3에서 같은 약물·농도의 rep1↔rep2, 같은 plate·용량의 다른 약물 대응, DMSO↔DMSO를 비교한다. Tahoe는 실제 분리된 0.5 µM 반복 웰을 확인한 범위에서 같은 진단을 반복한다. | 같은 약물 반복끼리의 중심화 방향 코사인, RMSE와 무작위로 짝지은 대조. 예측 오차가 큰 구간에서 발현 자체가 재현되는지 확인한다. 정답 반복을 사용한 수치는 진단용이다. |
| 3. 동일 모델로 데이터 축 비교 | 아래 비교군을 R12·R13의 세 화합물 fold에 적용한다. 세포주·용량·plate 기준으로 평균 반응을 구하고 약물별 잔차를 학습한다. 동일 모델과 출력, 같은 최종 적합 비용으로 데이터 소스를 바꾼다. | 주 지표는 SNU-423의 약물별 대비 RMSE. 방향 코사인, 절대 RMSE, 학습 약물 유사도별 오차, HepG2/C3A와 비간 세포주의 결과를 함께 기록한다. |
| 4. 다른 장기와 다른 실험으로 검증 | 학습에서 특정 장기를 전부 빼는 별도 평가를 한다. 새 약물 문제에서는 해당 약물군도 모든 자료의 학습과 튜닝에서 뺀다. donor·모델·배율을 고정한 뒤 적격한 외부 간 자료를 한 번 채점한다. | 간암 세포주 결과와 타 장기, 세포주·시간·용량·측정법이 달라진 외부 결과를 각각 보고한다. 외부에서 효과가 유지되면 그 조건과 표본 수를 명시한다. |

### 데이터가 실제로 도움이 되는지 확인할 비교군

| 비교군 | 이용하는 반응 자료 | 확인하는 질문 |
|---|---|---|
| B0 / B_abs | 영 약물 대비 / 적합 자료의 평균 반응 | 약물 대비와 절대 발현의 기본 성능은 얼마인가 |
| D0 | SNU-423의 학습 fold만 | 같은 모델의 간 단독 성능은 얼마인가 |
| D1 | D0 + 비간 Tahoe 학습 화합물 | 같은 실험 플랫폼에서 장기 범위를 넓히면 좋아지는가 |
| D2 | D1 + Sci-Plex3·MIX-seq의 적격한 비간 단일세포 처리 자료 | 독립 실험의 다른 암종 반응을 더하면 좋아지는가 |
| D3 | D1 + HepaRG bulk | 간 유사 세포의 더 넓은 화학 범위가 추가로 도움이 되는가 |
| D4 | D1 + D2의 외부 단일세포 + D3의 HepaRG bulk | 두 자료의 이득이 함께 유지되는가 |

기존 R13의 커널 Ridge와 이웃 모델을 같은 조건으로 시작한다. 입력은 동일한 ECFP·MACCS, 대조군 발현, 세포주와 용량으로 맞춘다. 훈련 화합물 수와 역전파 횟수 차이를 확인할 수 있도록 donor 가중치를 맞춘 비교와 같은 처리량에서 자료를 일부 뽑는 비교를 둔다. 새 신경망은 donor가 어느 분할에서 도움이 되는지 확인한 뒤 해당 후보에만 적용한다. 내부 학습 화합물로 출력 유전자 패널·규제·이웃 수·잔차 배율을 고른다. 외부 자료 간 유전자 이름의 다의 매핑은 제거하고, 목표 평가 유전자는 모든 모델에 공통으로 유지한다.

### 평가와 누출 방지

- 주 평가는 SNU-423 0.5 µM·24시간의 화합물군 분할이며, 공유 골격으로 다시 묶은 분할을 보조 평가한다. 같은 부모 화합물군은 모든 장기·용량·외부 자료의 학습·특징 학습·모델 선택에서 함께 제외한다. 같은 물리 처리 웰에 속한 다른 세포주의 발현도 평가 입력에서 제외한다. 외부에서 관측한 동일 약물의 반응을 예측 입력으로 쓸 경우에는 별도 연구 질문으로 기록한다.
- 외부 평가 표본과 그 처리 발현은 모델 선택에 사용하지 않는다. 대상 약물군·유전자·표본·모델·예측 배열을 동결한 뒤 별도 Slurm 작업에서 채점한다. 과거 R12·R13에 노출된 Tahoe는 프로토콜을 다시 동결해도 프로젝트 내부 교차검증이다. HepG2와 C3A, SNU-423 24시간과 5일은 각각 조건이 바뀐 전이로 해석한다.
- 외부 평가값을 읽기 전 내부 검증으로 고른 통합 후보를 B0와 모델을 맞춘 D0에 각각 비교한다. 같은 평가 화합물군의 오차 차이를 10,000회 군 단위 재표집하고 99% 구간을 보고한다. 두 구간의 상한이 모두 0 미만이면 주 평가에서 자료 추가의 개선 근거로 판정한다. 골격 분할에서는 연결 골격 성분으로 재표집한다. 개별 자료·세포주별 탐색 구간은 95%로 보고한다. 독립 간 자료가 화합물이나 대조군 부족으로 불확실하면 해당 조건의 점수와 범위를 표시한다.

## 자료 준비와 재현

원본은 G1 `vcell_liver_r14_cross_organ/raw`에 뒀다. 수집 작업은 원본 GEO와 Figshare 파일의 바이트 수와 SHA-256을 기록했다. Sci-Plex3는 과거 GEO 다운로드 SHA-256, MIX-seq와 GSE284321은 출판자 MD5를 다시 확인했다. 메타데이터 감사는 용량, 화합물, 배치, 대조군, 표본 및 유전자 식별자를 다뤘다. 학습과 채점은 다음 단계에서 별도 실행한다. [준비 데이터와 검증 결과](DATA.md)
