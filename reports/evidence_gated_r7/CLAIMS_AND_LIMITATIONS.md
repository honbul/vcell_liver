# R7 주장과 한계 (CLAIMS_AND_LIMITATIONS)

## 주장할 수 있는 것 (관측, 이 설정에 한정)

| 주장 | 근거 |
|---|---|
| 제안한 증거·세포 조건부 기전 모듈(B11)은 사전 기준으로 chemistry-only보다 나아지지 않았다 | test B11 − chem_only −0.00076 [−0.00147, +0.00008] |
| 같은 지식을 단순 연결(concat)하거나 gate를 고정한 모델보다 나은 점은 없다 | B11 − B01 +0.00021, B11 − fixed +0.00006(둘 다 CI가 0 포함) |
| 지식 결측 augmentation의 추가 효과는 확인되지 않았다 | B11 − B10 −0.00010 [−0.00037, +0.00019] |
| 실제 OmniPath 관계 구조와 ChEMBL 근거 종류·작용 부호는 성능에 기여하지 않았다 | 재배선 재학습 −B11 −0.00014, 근거 제거 −B11 −0.00006(validation·test 모두 차이 없음) |
| 주석 있는 약물에만 붙는 보정 항(어느 변형이든)은 test source ΔRMSE를 약 0.0008–0.0010 낮췄다 | B00/B01/fixed/재배선/근거 제거 − chem_only, CI < 0. **사전 주 대비가 아닌 보조 관측** |
| backbone을 함께 학습하면 주석 없는 약물의 fallback이 흔들릴 수 있다 | 원 2×2 validation missing stratum B11 − chem +0.0030(점추정, CI가 0 포함) → 수정 1에서 backbone 고정 |
| 같은 split·실측으로 재학습한 XPert와 평균 오차는 같은 범위이고, 패턴 지표는 XPert가 높다 | ΔRMSE 0.53604 vs 0.53598, centred Pearson 0.183 vs 0.129 |

## 주장하지 않는 것

- 기전 발견, 인과 관계, gate·attention의 생물학적 의미. 관계를 무작위로 섞어도 같은 결과였다.
- "외부 표적 지식이 새 약물 예측에 도움이 된다"는 일반 주장. 이번 구성에서 사전 기준을 넘지 못했다.
- 다른 KG, 다른 표현, 더 큰 모델의 불가능성. 이번 구성의 음성 결과일 뿐이다.
- XPert보다 낫다는 주장. 차이 −0.00005로 CI가 넓다.
- HCC 개선. HCC 평균 B11 − chem −0.00020 [−0.00098, +0.00059], 3계열이다.
- 독립 blind 검증. R4가 test를 한 번 열었다.

## 확인되지 않은 가설

- 보조 관측의 이득은 "주석 있음" 표시와 그 약물에만 쓰이는 보정 용량에서 왔을 수 있다(표적 50% 마스킹 무영향과 부합). 표적 정체성 섞기 대조는 실행하지 않았다.
- XPert의 높은 패턴 지표가 UniMol/HG embedding 때문인지, 학습량(100 epoch) 때문인지, 손실 구성(PCC 항) 때문인지는 분리하지 않았다.

## 한계

1. **자료:** CMap LINCS 2020 Level 3, 10 µM·24 h, 978 landmark, 단일 저분자, R4 unit 정의.
2. **지식:** ChEMBL 37(pchembl ≥ 6, confidence ≥ 7)과 OmniPath(2026-11-18) 두 자원뿐이며, 효능 수치는 쓰지 않았다. 주석 있는 약물은 그룹의 약 40%이고, 주석이 많은 약물은 잘 알려진 약물일 수 있다.
3. **절차:**
   - validation 신호는 수정 1 뒤 경계선(여유 0.000004)으로 섰다.
   - 첫 pilot 취소 전 출력된 이른 점수 일부를 보았다(D-2).
   - 동결 전 mock 검사에서 HCC validation 수치를 계산하고 일부를 보았다(D-5, 절차 위반). 동결 목록은 그보다 먼저 commit되었고, 동결 manifest가 그 목록과 동일하며, 예측 코드가 바뀌지 않았음을 확인했다(`hcc_deviation_check.json`).
4. **XPert:**
   - epoch 상한 100(원 2500), flash_attn을 SDPA shim으로 대체, 원 코드의 UniMol 생성 함수 이름 버그를 메모리에서만 수정.
   - 1,199개 그룹은 XPert 약물 색인에 연결되지 않아 HG embedding이 0이다.
   - HG embedding의 DDS 관계는 구조 유사도임을 확인했다(Pearson 0.995 vs ECFP Tanimoto). 기본 관계만으로 학습됐는지는 미확인이다.
5. **stress test:** 50% 조건은 ChEMBL 표적 항목 단위로 가린다. 표적 항목이 하나인 약물은 그대로 남는다.
6. **통계:** 3 seed이고, 약물 그룹 bootstrap 2000회다. 대비 여러 개를 다중 비교 보정하지 않았다(주 대비는 사전 지정).
