# R7 결과 — 불완전한 약물 표적 지식의 증거·세포 조건부 활용

**판정: 제안 모듈(B11)은 채택하지 않는다.**
- validation에서는 수정 1 뒤 사전 신호 기준을 경계선으로 충족했다.
- test에서 제안 모델은 chemistry-only 모델보다 0.00076 낮았지만, CI가 0을 포함했다(사전 기준 미충족).
- 귀속 실험(재배선 그래프, 근거 제거, gate 제거, 결측 학습 제거)에서는 그래프 구조·근거 종류·조건부 gate의 기여가 확인되지 않았다.

모든 수치는 동결 commit `a7ab705` 뒤 job 25976에서 한 번 계산한 test 결과다(표: `manifests/evidence_gated_r7/test_*.tsv`). validation 수치는 개발 기록이다.

## 1. 한 학습 예시는 무엇인가

| 항목 | 내용 |
|---|---|
| 단위 | (세포주, 약물 그룹) |
| 입력 | 그 세포주 plate DMSO 대조군 RNA(X0, 978 landmark), 약물 ECFP4, 같은 세포주의 training 약물 평균 반응(m_c), 있으면 ChEMBL 37 표적 근거와 OmniPath 관계 |
| 정답 | 같은 plate의 처리군−대조군 RNA 차이(Δ)를 조건·plate에 걸쳐 같은 무게로 평균한 값(R4 정의) |
| 손실 | 978개 유전자 Δ의 MSE(보조 손실 없음) |
| 독립 표본 단위 | 약물 그룹(bootstrap 재표본). 세포 수나 seed를 독립 표본으로 세지 않음 |

## 2. 무엇을 보류했는가

- **새 약물:** validation(1,243 그룹)·test(1,243 그룹) 약물의 RNA는 어느 세포주에서도 학습·통계·선택에 쓰지 않았다(R4 전역 약물 분할).
- 새 세포주가 아니다. 모든 세포주에는 training 약물 반응이 있다.
- 표적 주석은 test 약물에도 예측 입력으로 준다(외부 정보, `inference_information_contract.json`).
- test는 R4가 이미 한 번 연 공개 benchmark다. 따라서 이번 평가는 **사전 등록 후속 평가**이지 blind test가 아니다.

## 4. 개선이 있었다면 어디서 왔는가

제안 모듈의 개선은 사전 기준으로 확인되지 않았다. 아래는 관측과 가설을 나눠 적은 것이다.

**관측(확인)**
1. 기전 보정 항이 있는 다섯 변형(B00, B01, fixed, 재배선, 근거 제거)은 test source에서 chem_only보다 0.0008–0.0010 낮았고 CI가 0 미만이었다. B10과 B11은 CI가 0을 포함했다. 이것은 사전 지정 주 대비(B11)가 아니라 보조 관측이다.
2. 그 이득은 주석이 있는 약물(complete/partial)에서만 생긴다. missing 약물은 구성상 chem_only와 같다.
3. 그래프 edge의 85%를 무작위로 바꿔 재학습해도, 근거 종류·부호·매핑 flag를 지워도, gate를 고정해도 이득이 그대로였다. validation(`val_attribution*`)과 test에서 같았다.
4. **annotation stress**(test, 주석 있는 source unit 6,304개):
   - 표적 블록의 50%를 가려도 B11 ΔRMSE는 +0.00001로 거의 변하지 않았다.
   - 100% 가리면 +0.00097 [+0.00004, +0.00181] 나빠져 chem_only와 같아졌다.
   - 주의: 표적 블록이 하나뿐인 약물은 50% 조건에서 그대로 남는다.
5. 수정 전 v0_B11(backbone 공동 학습)은 test에서 chem_only와 차이가 없었고(−0.00012), HCC 평균은 오히려 나빴다(+0.00416 [+0.0018, +0.0064]).

**가설(미검증)**
- 이득은 "주석이 있다"는 표시와 그런 약물에만 붙는 보정 용량(세포 상태 + 약물 ECFP embedding을 입력으로 받는 작은 head)에서 왔을 수 있다. 어떤 표적인지, 관계가 무엇인지는 거의 쓰이지 않은 것으로 보인다(관측 3·4와 부합).
- 표적 정체성을 약물 사이에서 섞는 대조는 실행하지 않았다(사전 등록 없음, 수정 횟수 정책). 그래서 정체성 정보의 기여는 분리하지 못했다.

## 5. 상관·보정일 뿐 기전 증명이 아닌 것

- 평균 오차 0.1–0.2% 감소는 기전 발견이 아니다. gate 값은 모델 내부 사용량이다. 실제 관계를 바꿔도 결과가 같았으므로 gate·그래프를 생물학적으로 해석하지 않는다.
- D1 진단(training 약물): 표적이 겹치는 약물 쌍의 반응 유사도는 겹치지 않는 쌍보다 약간 높았다(0.025 vs 0.001). 그러나 구조가 다르고 plate도 다른 쌍에서는 차이가 작았다(0.006 vs −0.006). 같은 plate 효과(0.085 vs −0.003)가 더 컸다.
- 입력 KG를 GRN 정답으로 다시 채점하지 않았다.

## 6. 남은 한계와 다음에 할 결정 하나

**한계**
- 이미 노출된 공개 benchmark다. R4 test가 한 번 열렸다.
- 동결 전 mock 검사에서 HCC validation 수치가 계산되었다(D-5, 절차 위반). 동결 목록은 그 전에 commit되었고, 동결 manifest와 같음을 확인했다(`hcc_deviation_check.json`). HCC를 보고 바꾼 설정은 없다.
- validation 신호는 기준선에서 0.000004 차이로 섰다.
- XPert: epoch 상한 100, flash_attn 대신 SDPA. HG embedding의 DDS 관계는 구조 유사도임을 확인했고, 기본 관계만으로 학습됐는지는 미확인이다.
- HCC는 3계열(test 약물 HUH7 10, JHH5 98, JHH7 10)뿐이다.
- 주석 있는 test 약물은 465/1,243 그룹(37%)이다.

**다음 결정 하나:** 표적 정체성 섞기 대조로 "용량 vs 표적 공유 정보"를 가를지 정해야 한다. 이번 결과만으로는 그래프·근거 기반 기전 모듈을 키우는 방향을 권하지 않는다.
